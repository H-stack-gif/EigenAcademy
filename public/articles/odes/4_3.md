# ODE Topic 4.3: Solving Initial Value Problems

The Laplace transform converts initial value problems into algebra. Given $ay'' + by' + cy = f(t)$ with initial conditions $y(0)$ and $y'(0)$, we transform the entire equation, solve algebraically for $Y(s)$, then invert to find $y(t)$. The initial conditions appear naturally when we transform derivatives—no need for arbitrary constants to determine later.

This is revolutionary. For second-order equations, the classical method requires finding complementary and particular solutions, then applying initial conditions. With Laplace transforms, we bypass all that. Transform, solve algebra, invert. One streamlined process handles homogeneous and nonhomogeneous equations equally well. The method especially shines for **piecewise continuous** or **discontinuous forcing functions** that would be nightmarish with classical methods.

This article applies Laplace transforms to solve IVPs systematically. We'll develop the solution procedure, handle equations with various right sides (polynomials, exponentials, discontinuous functions), and compare with classical methods. You'll see why engineers love Laplace transforms: they turn difficult calculus problems into routine algebra.

## The Solution Procedure

**Steps to solve** $ay'' + by' + cy = f(t)$, $y(0) = y_0$, $y'(0) = y_1$:

1. **Transform both sides**: $a[s^2Y - sy_0 - y_1] + b[sY - y_0] + cY = F(s)$

2. **Collect terms**: $(as^2 + bs + c)Y = F(s) + (as+b)y_0 + ay_1$

3. **Solve for $Y(s)$**: $ Y(s) = \frac{F(s) + (as+b)y_0 + ay_1}{as^2+bs+c}$

4. **Inverse transform**: $y(t) = \mathcal{L}^{-1}\{Y(s)\}$

### Example 1: First-Order IVP

Solve $y' + 2y = 4$, $y(0) = 1$.

**Solution:**

Transform both sides:
$$\mathcal{L}\{y'\} + 2\mathcal{L}\{y\} = \mathcal{L}\{4\}$$

$$[sY - y(0)] + 2Y = \frac{4}{s}$$

$$sY - 1 + 2Y = \frac{4}{s}$$

$$(s+2)Y = \frac{4}{s} + 1 = \frac{4+s}{s}$$

$$Y = \frac{4+s}{s(s+2)}$$

**Partial fractions**:
$$\frac{4+s}{s(s+2)} = \frac{A}{s} + \frac{B}{s+2}$$

$4+s = A(s+2) + Bs$

$s = 0$: $4 = 2A$, so $A = 2$

$s = -2$: $2 = -2B$, so $B = -1$

$$Y = \frac{2}{s} - \frac{1}{s+2}$$

**Inverse transform**:
$$y = 2 - e^{-2t}$$

**Answer:** $y(t) = 2 - e^{-2t}$

### Example 2: Second-Order Homogeneous

Solve $y'' + 4y = 0$, $y(0) = 1$, $y'(0) = 2$.

**Solution:**

Transform:
$$s^2Y - sy(0) - y'(0) + 4Y = 0$$

$$s^2Y - s - 2 + 4Y = 0$$

$$(s^2+4)Y = s + 2$$

$$Y = \frac{s+2}{s^2+4}$$

Split:
$$Y = \frac{s}{s^2+4} + \frac{2}{s^2+4} = \frac{s}{s^2+4} + \frac{1}{2} \cdot \frac{2}{s^2+4}$$

**Inverse**:
$$y = \cos 2t + \frac{1}{2}\sin 2t$$

Can also write: $ y = \sqrt{1^2 + (1/2)^2}\cos(2t - \phi) = \frac{\sqrt{5}}{2}\cos(2t - \phi)$ where $\tan\phi = 1/2$

**Answer:** $ y(t) = \cos 2t + \frac{1}{2}\sin 2t$

### Example 3: Second-Order with Polynomial Forcing

Solve $y'' - y = t$, $y(0) = 0$, $y'(0) = 1$.

**Solution:**

Transform:
$$[s^2Y - 0 - 1] - Y = \frac{1}{s^2}$$

$$(s^2-1)Y = 1 + \frac{1}{s^2} = \frac{s^2+1}{s^2}$$

$$Y = \frac{s^2+1}{s^2(s^2-1)} = \frac{s^2+1}{s^2(s-1)(s+1)}$$

**Partial fractions**:
$$\frac{s^2+1}{s^2(s-1)(s+1)} = \frac{A}{s} + \frac{B}{s^2} + \frac{C}{s-1} + \frac{D}{s+1}$$

This is tedious. Cover-up and coefficient matching:

$s = 1$: $2 = 1 \cdot 2 \cdot C$, so $C = 1$

$s = -1$: $2 = 1 \cdot (-2) \cdot D$, so $D = -1$

$s = 0$: $1 = B(-1)$, so $B = -1$

Match $s^3$ coefficient: $0 = A + C + D$, so $A = 0$

$$Y = \frac{-1}{s^2} + \frac{1}{s-1} - \frac{1}{s+1}$$

**Inverse**:
$$y = -t + e^t - e^{-t} = e^t - e^{-t} - t$$

**Answer:** $y(t) = e^t - e^{-t} - t$ or $2\sinh t - t$

## Exponential and Trigonometric Forcing

### Example 4: Exponential Forcing

Solve $y'' + 3y' + 2y = e^{-3t}$, $y(0) = 0$, $y'(0) = 0$.

**Solution:**

Transform:
$$[s^2Y - 0 - 0] + 3[sY - 0] + 2Y = \frac{1}{s+3}$$

$$(s^2 + 3s + 2)Y = \frac{1}{s+3}$$

Factor: $s^2+3s+2 = (s+1)(s+2)$

$$Y = \frac{1}{(s+1)(s+2)(s+3)}$$

**Partial fractions**:
$$\frac{1}{(s+1)(s+2)(s+3)} = \frac{A}{s+1} + \frac{B}{s+2} + \frac{C}{s+3}$$

$s = -1$: $1 = A(1)(2)$, so $A =  \frac{1}{2}$

$s = -2$: $1 = B(-1)(1)$, so $B = -1$

$s = -3$: $1 = C(-2)(-1)$, so $C =  \frac{1}{2}$

$$Y = \frac{1/2}{s+1} - \frac{1}{s+2} + \frac{1/2}{s+3}$$

**Answer:** $ y(t) = \frac{1}{2}e^{-t} - e^{-2t} + \frac{1}{2}e^{-3t}$

### Example 5: Sine Forcing

Solve $y'' + 4y = \sin t$, $y(0) = 0$, $y'(0) = 0$.

**Solution:**

Transform:
$$s^2Y + 4Y = \frac{1}{s^2+1}$$

$$(s^2+4)Y = \frac{1}{s^2+1}$$

$$Y = \frac{1}{(s^2+1)(s^2+4)}$$

**Partial fractions** (quadratics):
$$\frac{1}{(s^2+1)(s^2+4)} = \frac{As+B}{s^2+1} + \frac{Cs+D}{s^2+4}$$

$1 = (As+B)(s^2+4) + (Cs+D)(s^2+1)$

Match coefficients:
- $s^3$: $0 = A + C$
- $s^2$: $0 = B + D$
- $s^1$: $0 = 4A + C$
- $s^0$: $1 = 4B + D$

From first two: $C = -A$, $D = -B$

From third: $4A - A = 0$, so $A = 0$, thus $C = 0$

From fourth: $4B - B = 1$, so $B =  \frac{1}{3}$, thus $D = -\frac{1}{3}$

$$Y = \frac{1/3}{s^2+1} + \frac{-1/3}{s^2+4} = \frac{1}{3} \cdot \frac{1}{s^2+1} - \frac{1}{6} \cdot \frac{2}{s^2+4}$$

**Answer:** $ y(t) = \frac{1}{3}\sin t - \frac{1}{6}\sin 2t$

## Comparison with Classical Method

### Example 6: Same Problem, Two Methods

Solve $y'' - y = e^t$, $y(0) = 1$, $y'(0) = 0$ using both Laplace and classical methods.

**Solution:**

**Laplace method**:

Transform:
$$s^2Y - s - 0 - Y = \frac{1}{s-1}$$

$$(s^2-1)Y = s + \frac{1}{s-1} = \frac{s(s-1)+1}{s-1} = \frac{s^2-s+1}{s-1}$$

$$Y = \frac{s^2-s+1}{(s-1)(s^2-1)} = \frac{s^2-s+1}{(s-1)^2(s+1)}$$

Partial fractions (with repeated factor):
$$\frac{s^2-s+1}{(s-1)^2(s+1)} = \frac{A}{s-1} + \frac{B}{(s-1)^2} + \frac{C}{s+1}$$

$s = 1$: $1 = 2B$, so $B =  \frac{1}{2}$

$s = -1$: $3 = 4C$, so $C =  \frac{3}{4}$

Coefficient of $s^2$: $1 = A + C$, so $A =  \frac{1}{4}$

$$Y = \frac{1/4}{s-1} + \frac{1/2}{(s-1)^2} + \frac{3/4}{s+1}$$

$$y = \frac{1}{4}e^t + \frac{1}{2}te^t + \frac{3}{4}e^{-t}$$

**Classical method**:

Homogeneous: $r^2 - 1 = 0$, $r = \pm 1$

$y_c = c_1e^t + c_2e^{-t}$

Particular: $e^t$ is in $y_c$ (resonance!), try $y_p = Ate^t$

$y_p' = Ae^t + Ate^t$, $y_p'' = 2Ae^t + Ate^t$

$(2A + At) - At = 1$, so $2A = 1$, $A =  \frac{1}{2}$

$y_p =  \frac{1}{2}te^t$

General: $y = c_1e^t + c_2e^{-t} +  \frac{1}{2}te^t$

Initial conditions:
$y(0) = c_1 + c_2 = 1$

$y' = c_1e^t - c_2e^{-t} +  \frac{1}{2}e^t + \frac{1}{2}te^t$

$y'(0) = c_1 - c_2 +  \frac{1}{2} = 0$, so $c_1 - c_2 = -\frac{1}{2}$

Solve: $c_1 =  \frac{1}{4}$, $c_2 = \frac{3}{4}$

$$y = \frac{1}{4}e^t + \frac{3}{4}e^{-t} + \frac{1}{2}te^t$$

**Answer:** Both methods give $ y = \frac{1}{4}e^t + \frac{1}{2}te^t + \frac{3}{4}e^{-t}$ ✓

Laplace method avoids recognizing resonance—it handles automatically!

## Systems of Equations

Laplace transforms also solve systems of ODEs.

### Example 7: Coupled System

Solve $\begin{cases} x' = -x + y \\ y' = x - y \end{cases}$, $x(0) = 1$, $y(0) = 0$.

**Solution:**

Transform both equations:
$$sX - 1 = -X + Y$$
$$sY - 0 = X - Y$$

Rearrange:
$$(s+1)X - Y = 1$$
$$-X + (s+1)Y = 0$$

From second: $X = (s+1)Y$

Substitute into first: $(s+1)(s+1)Y - Y = 1$

$(s^2+2s+1-1)Y = 1$

$$(s^2+2s)Y = 1$$

$$Y = \frac{1}{s(s+2)}$$

Partial fractions: $ \frac{1}{s(s+2)} = \frac{1/2}{s} - \frac{1/2}{s+2}$

$$y = \frac{1}{2} - \frac{1}{2}e^{-2t} = \frac{1}{2}(1 - e^{-2t})$$

From $X = (s+1)Y$:
$$X = (s+1) \cdot \frac{1}{s(s+2)} = \frac{s+1}{s(s+2)}$$

$$= \frac{A}{s} + \frac{B}{s+2}$$

$s = 0$: $1 = 2A$, so $A =  \frac{1}{2}$

$s = -2$: $-1 = -2B$, so $B =  \frac{1}{2}$

$$x = \frac{1}{2} + \frac{1}{2}e^{-2t} = \frac{1}{2}(1 + e^{-2t})$$

**Answer:** $ x(t) = \frac{1}{2}(1 + e^{-2t})$, $y(t) = \frac{1}{2}(1 - e^{-2t})$

### Example 8: Verification

For Example 7, verify $x(0) = 1$ and equations satisfied.

**Solution:**

Check initial condition: $ x(0) = \frac{1}{2}(1 + 1) = 1$ ✓

Check equation $x' = -x + y$:

$ x' = \frac{1}{2}(-2e^{-2t}) = -e^{-2t}$

$ -x + y = -\frac{1}{2}(1+e^{-2t}) + \frac{1}{2}(1-e^{-2t}) = -\frac{1}{2} - \frac{1}{2}e^{-2t} + \frac{1}{2} - \frac{1}{2}e^{-2t} = -e^{-2t}$ ✓

**Answer:** Solution verified.

## Higher-Order Equations

### Example 9: Third-Order Equation

Solve $y''' - y' = 0$, $y(0) = 0$, $y'(0) = 1$, $y''(0) = 0$.

**Solution:**

Transform:
$$[s^3Y - s^2y(0) - sy'(0) - y''(0)] - [sY - y(0)] = 0$$

$$s^3Y - s - sY = 0$$

$$(s^3 - s)Y = s$$

$$Y = \frac{s}{s(s^2-1)} = \frac{1}{s^2-1} = \frac{1}{(s-1)(s+1)}$$

Partial fractions: $ \frac{1}{(s-1)(s+1)} = \frac{1/2}{s-1} - \frac{1/2}{s+1}$

**Answer:** $ y(t) = \frac{1}{2}e^t - \frac{1}{2}e^{-t} = \sinh t$

### Example 10: Fourth-Order

Solve $y^{(4)} - y = 0$, $y(0) = 1$, $y'(0) = y''(0) = y'''(0) = 0$.

**Solution:**

Transform:
$$s^4Y - s^3(1) - 0 - 0 - 0 - Y = 0$$

$$(s^4-1)Y = s^3$$

$$Y = \frac{s^3}{s^4-1} = \frac{s^3}{(s^2-1)(s^2+1)}$$

Partial fractions:
$$\frac{s^3}{(s^2-1)(s^2+1)} = \frac{As+B}{s^2-1} + \frac{Cs+D}{s^2+1}$$

$ \frac{s}{s^2-1} = \frac{s}{(s-1)(s+1)}$... this gives hyperbolic cosine

$\mathcal{L}\{\cosh t\} =  \frac{s}{s^2-1}$

**Answer:** $ y = \frac{1}{2}\cosh t + \frac{1}{2}\cos t$

### Example 11: Complete Solution Process

Solve $y'' + 2y' + y = e^{-t}$, $y(0) = 2$, $y'(0) = -1$.

**Solution:**

**Step 1**: Transform
$$(s^2Y - 2s + 1) + 2(sY - 2) + Y = \frac{1}{s+1}$$

**Step 2**: Simplify
$$s^2Y + 2sY + Y = 2s - 1 + 4 + \frac{1}{s+1} = 2s + 3 + \frac{1}{s+1}$$

$$(s^2+2s+1)Y = \frac{2s(s+1) + 3(s+1) + 1}{s+1} = \frac{2s^2+5s+4}{s+1}$$

$$(s+1)^2Y = \frac{2s^2+5s+4}{s+1}$$

$$Y = \frac{2s^2+5s+4}{(s+1)^3}$$

**Step 3**: Partial fractions

Rewrite numerator in terms of $(s+1)$:

Let $u = s+1$, $s = u-1$:
$$2s^2+5s+4 = 2(u-1)^2 + 5(u-1) + 4 = 2u^2 - 4u + 2 + 5u - 5 + 4 = 2u^2 + u + 1$$

$$Y = \frac{2u^2+u+1}{u^3} = \frac{2}{u} + \frac{1}{u^2} + \frac{1}{u^3}$$

$$= \frac{2}{s+1} + \frac{1}{(s+1)^2} + \frac{1}{(s+1)^3}$$

**Step 4**: Inverse transform

$$y = 2e^{-t} + te^{-t} + \frac{t^2}{2}e^{-t} = \left(2 + t + \frac{t^2}{2}\right)e^{-t}$$

**Answer:** $ y(t) = \left(2 + t + \frac{t^2}{2}\right)e^{-t}$

### Example 12: Zero Initial Conditions

When all initial conditions are zero, the solution simplifies significantly.

Solve $y'' + 4y' + 3y = 2e^{-t}$, $y(0) = y'(0) = 0$.

**Solution:**

$$(s^2+4s+3)Y = \frac{2}{s+1}$$

$$Y = \frac{2}{(s+1)(s^2+4s+3)} = \frac{2}{(s+1)^2(s+3)}$$

Partial fractions:
$$\frac{2}{(s+1)^2(s+3)} = \frac{A}{s+1} + \frac{B}{(s+1)^2} + \frac{C}{s+3}$$

$s = -1$: $2 = 2B$, so $B = 1$

$s = -3$: $2 = 4C$, so $C =  \frac{1}{2}$

Coefficient of $s^2$: $0 = A + C$, so $A = - \frac{1}{2}$

$$Y = \frac{-1/2}{s+1} + \frac{1}{(s+1)^2} + \frac{1/2}{s+3}$$

**Answer:** $ y = -\frac{1}{2}e^{-t} + te^{-t} + \frac{1}{2}e^{-3t}$

### Example 13: Summary of Advantages

Why use Laplace transforms over classical methods?

**Advantages**:
1. Initial conditions incorporated automatically
2. No need to find complementary + particular separately
3. Handles discontinuous forcing easily (next article!)
4. Same procedure for all equations
5. Works for systems naturally

**Disadvantages**:
1. Requires algebra (partial fractions)
2. Limited to linear constant-coefficient equations
3. Need transform tables or integral evaluation

**Answer:** Laplace transforms excel when forcing function is complicated or discontinuous.

## Answer Key

**Problem 1: B**
Transform $y'' + y = 0$:
$[s^2Y - sy(0) - y'(0)] + Y = 0$
$s^2Y - s(1) - 0 + Y = 0$
$(s^2+1)Y = s$
Initial conditions appear on right side

**Problem 2: C**
Key advantage: derivatives → multiplication by $s$
$y'' \to s^2Y$, $y' \to sY$
Result: polynomial equation in $s$ for $Y(s)$
Pure algebra—no calculus!

**Problem 3: B**
$\mathcal{L}\{\sin at\} =  \frac{a}{s^2+a^2}$
Here: $ \frac{1}{s^2+4} = \frac{1/2 \cdot 2}{s^2+4}$
So: $y =  \frac{1}{2}\sin 2t$

**Problem 4: B**
Classical method: find general solution, then apply ICs
Laplace method: ICs appear in transformed equation automatically
$\mathcal{L}\{y''\} = s^2Y - sy(0) - y'(0)$ includes both ICs
No separate step to determine constants

**Problem 5: C**
Transform each equation: $sX - x(0) = \cdots$, $sY - y(0) = \cdots$
Get algebraic system in $X(s)$, $Y(s)$
Solve using substitution or Cramer's rule
Invert to find $x(t)$, $y(t)$

# ODE Topic 6.1: Euler's Method

Not every differential equation has a closed-form solution. No combination of elementary functions can express the solution to $y' = e^{x^2}$. Bessel functions, while "special," still require infinite series or numerical tables. Even when analytical solutions exist, they might be too complex for practical use. This is where **numerical methods** become essential—they approximate solutions at discrete points without finding an explicit formula.

**Euler's method** is the simplest numerical technique, the foundation for understanding all numerical ODE solvers. The idea is beautifully intuitive: the derivative $y'$ gives the slope of the solution curve. Starting from an initial point, follow that slope for a small step to estimate the next point. Repeat. Each step uses the differential equation to predict where to go next. It's like hiking in fog using only a compass that tells your current direction.

This article develops Euler's method from first principles, analyzes its accuracy, and explores when it succeeds or fails. We'll learn about **step size** (how far to walk between compass readings), **local and global error** (how mistakes accumulate), and **stability** (when small errors explode). While Euler's method is rarely used in practice due to poor accuracy, understanding it illuminates all advanced methods. Every sophisticated numerical solver is, at heart, a clever improvement on Euler's basic idea.

## The Fundamental Idea

**Initial value problem**: $y' = f(x, y)$, $y(x_0) = y_0$

**Goal**: Approximate $y(x)$ at points $x_1, x_2, \ldots, x_n$

**Euler's method**: Use tangent line approximation

At point $(x_k, y_k)$, slope is $f(x_k, y_k)$.

Move along tangent line for step size $h$:
$$y_{k+1} = y_k + h \cdot f(x_k, y_k)$$

where $x_{k+1} = x_k + h$.

### Example 1: Single Euler Step

For $y' = y$, $y(0) = 1$, use one Euler step with $h = 0.1$ to approximate $y(0.1)$.

**Solution:**

$f(x, y) = y$

Initial: $x_0 = 0$, $y_0 = 1$

Slope: $f(0, 1) = 1$

Euler step:
$$y_1 = y_0 + h \cdot f(x_0, y_0) = 1 + 0.1(1) = 1.1$$

**Exact solution**: $y = e^x$, so $y(0.1) = e^{0.1} \approx 1.1052$

**Error**: $|1.1052 - 1.1| = 0.0052$

**Answer:** Euler approximation: $y(0.1) \approx 1.1$ (exact: $1.1052$)

### Example 2: Multiple Steps

Continue Example 1 to approximate $y(0.2)$ and $y(0.3)$.

**Solution:**

**Step 2**: $x_1 = 0.1$, $y_1 = 1.1$

$$y_2 = 1.1 + 0.1(1.1) = 1.1 + 0.11 = 1.21$$

**Step 3**: $x_2 = 0.2$, $y_2 = 1.21$

$$y_3 = 1.21 + 0.1(1.21) = 1.21 + 0.121 = 1.331$$

**Exact values**:
- $y(0.2) = e^{0.2} \approx 1.2214$
- $y(0.3) = e^{0.3} \approx 1.3499$

**Errors**:
- At $x = 0.2$: $|1.2214 - 1.21| = 0.0114$
- At $x = 0.3$: $|1.3499 - 1.331| = 0.0189$

**Answer:** Errors grow with each step.

## General Algorithm

**Euler's Method Algorithm**:

Given: $y' = f(x, y)$, $y(x_0) = y_0$, step size $h$, target $x_n$

1. Set $x_0, y_0$
2. For $k = 0, 1, 2, \ldots, n-1$:
   - Compute $y_{k+1} = y_k + h \cdot f(x_k, y_k)$
   - Set $x_{k+1} = x_k + h$
3. Output: $(x_k, y_k)$ for $k = 0, 1, \ldots, n$

**Number of steps**: $n =  \frac{x_n - x_0}{h}$

### Example 3: Complete Euler Calculation

Solve $y' = x + y$, $y(0) = 1$ on $[0, 0.5]$ with $h = 0.25$.

**Solution:**

$f(x, y) = x + y$, $x_0 = 0$, $y_0 = 1$

Number of steps: $n = 0.5/0.25 = 2$

**Step 1**: $x_0 = 0$, $y_0 = 1$
$$y_1 = 1 + 0.25(0 + 1) = 1 + 0.25 = 1.25$$
$$x_1 = 0.25$$

**Step 2**: $x_1 = 0.25$, $y_1 = 1.25$
$$y_2 = 1.25 + 0.25(0.25 + 1.25) = 1.25 + 0.25(1.5) = 1.25 + 0.375 = 1.625$$
$$x_2 = 0.5$$

**Answer:** $y(0.5) \approx 1.625$

**Exact solution** (by integrating factor or separation): $y = 2e^x - x - 1$

$y(0.5) = 2e^{0.5} - 0.5 - 1 = 2(1.6487) - 1.5 \approx 1.797$

Error: $|1.797 - 1.625| = 0.172$ (fairly large!)

### Example 4: Effect of Step Size

Repeat Example 3 with $h = 0.1$.

**Solution:**

Now need $n = 5$ steps.

| $k$ | $x_k$ | $y_k$ | $f(x_k, y_k)$ | $y_{k+1} = y_k + 0.1f$ |
|-----|-------|-------|---------------|------------------------|
| 0 | 0.0 | 1.000 | 1.000 | 1.100 |
| 1 | 0.1 | 1.100 | 1.200 | 1.220 |
| 2 | 0.2 | 1.220 | 1.420 | 1.362 |
| 3 | 0.3 | 1.362 | 1.662 | 1.528 |
| 4 | 0.4 | 1.528 | 1.928 | 1.721 |
| 5 | 0.5 | 1.721 | — | — |

**Answer:** $y(0.5) \approx 1.721$

Error: $|1.797 - 1.721| = 0.076$ (better than $h = 0.25$!)

Smaller step size → better accuracy.

## Local Truncation Error

**Local truncation error**: Error in single step, assuming previous value is exact.

From Taylor series:
$$y(x_{k+1}) = y(x_k) + hy'(x_k) + \frac{h^2}{2}y''(x_k) + O(h^3)$$

Euler uses: $y_{k+1} = y_k + hf(x_k, y_k) = y_k + hy'(x_k)$

**Local error**: $ e_{k+1} = \frac{h^2}{2}y''(x_k) + O(h^3) = O(h^2)$

Euler's method is **first-order**: local error proportional to $h^2$.

### Example 5: Estimating Local Error

For $y' = y$, $y(0) = 1$, estimate local error at first step with $h = 0.1$.

**Solution:**

Exact: $y = e^x$, so $y'' = e^x$

At $x_0 = 0$: $y''(0) = 1$

**Local error**:
$$e_1 \approx \frac{h^2}{2}y''(0) = \frac{(0.1)^2}{2}(1) = 0.005$$

From Example 1, actual error was $0.0052$ ✓

**Answer:** Theoretical estimate $\approx 0.005$ matches actual error.

### Example 6: Halving Step Size

If step size is halved, how does local error change?

**Solution:**

Local error: $e \approx Ch^2$ for some constant $C$

If $h \to h/2$:
$$e_{\text{new}} \approx C(h/2)^2 = C\frac{h^2}{4} = \frac{1}{4}e_{\text{old}}$$

**Answer:** Local error is **quartered** (reduced by factor of 4).

## Global Error

**Global error**: Total accumulated error at final point.

Over $n$ steps, errors accumulate. If each step has local error $O(h^2)$ and there are $n \sim 1/h$ steps:

**Global error**: $O(h^2) \times O(1/h) = O(h)$

Euler's method is **first-order globally**: global error proportional to $h$.

### Example 7: Global Error Verification

For $y' = y$, $y(0) = 1$, compute global error at $x = 1$ for $h = 0.1$ and $h = 0.05$.

**Solution:**

**Case 1**: $h = 0.1$, so $n = 10$ steps

Euler gives (from formula $y_k = (1+h)^k$):
$$y_{10} = (1.1)^{10} \approx 2.5937$$

Exact: $e^1 \approx 2.7183$

Error: $2.7183 - 2.5937 = 0.1246$

**Case 2**: $h = 0.05$, so $n = 20$ steps

$$y_{20} = (1.05)^{20} \approx 2.6533$$

Error: $2.7183 - 2.6533 = 0.065$

**Ratio**: $0.1246/0.065 \approx 1.92 \approx 2$

Halving $h$ approximately halves global error ✓ (first-order behavior)

**Answer:** Global error proportional to $h$ confirmed.

## Stability Considerations

Some ODEs are **stiff**: solution changes slowly, but numerical methods require tiny steps for stability.

### Example 8: Stable vs Unstable

Compare Euler's method on:
(a) $y' = -y$, $y(0) = 1$
(b) $y' = -100y$, $y(0) = 1$

with $h = 0.05$.

**Solution:**

**(a)** $y' = -y$: $y_k = (1 - h)^k = (0.95)^k$

At $x = 1$ ($k = 20$): $y_{20} = 0.95^{20} \approx 0.358$

Exact: $e^{-1} \approx 0.368$

Good approximation!

**(b)** $y' = -100y$: $y_k = (1 - 100h)^k = (1 - 5)^k = (-4)^k$

At $x = 1$ ($k = 20$): $y_{20} = (-4)^{20} > 0$ (huge positive!)

Exact: $e^{-100} \approx 3.7 \times 10^{-44}$ (tiny positive)

Euler gives **wildly oscillating** values! Method is unstable.

**Answer:** For stiff equations, need $h < 2/\lambda$ where $\lambda$ is coefficient.

### Example 9: Stability Criterion

For $y' = \lambda y$ with $\lambda < 0$, when is Euler stable?

**Solution:**

Euler: $y_{k+1} = y_k + h\lambda y_k = (1 + h\lambda)y_k$

For stability, need $|1 + h\lambda| < 1$

Since $\lambda < 0$, let $\lambda = -\mu$ where $\mu > 0$:

$|1 - h\mu| < 1$

This gives: $-1 < 1 - h\mu < 1$

From right inequality: $h\mu < 2$, so $h < 2/\mu$

**Answer:** **Stability condition**: $ h < \frac{2}{|\lambda|}$

## Comparison with Exact Solutions

### Example 10: Exponential Decay

Solve $y' = -2y$, $y(0) = 4$ on $[0, 2]$ with $h = 0.5$.

**Solution:**

$y = 4e^{-2x}$

At $x = 2$: $y(2) = 4e^{-4} \approx 0.0733$

**Answer:** Numerical solution captures decay behavior but underestimates values.

### Example 11: Logistic Growth

Solve $y' = y(1-y)$, $y(0) = 0.1$ with $h = 0.2$ for two steps.

**Solution:**

$f(x, y) = y(1-y)$

**Step 1**: $x_0 = 0$, $y_0 = 0.1$
$$y_1 = 0.1 + 0.2(0.1)(0.9) = 0.1 + 0.018 = 0.118$$

**Step 2**: $x_1 = 0.2$, $y_1 = 0.118$
$$y_2 = 0.118 + 0.2(0.118)(0.882) = 0.118 + 0.0208 = 0.1388$$

**Answer:** Solution grows toward carrying capacity (would approach 1 as $x \to \infty$).

## Geometric Interpretation

Euler's method follows **tangent line** at each step.

Error accumulates because true curve deviates from tangent.

For **concave up** solutions: Euler underestimates.
For **concave down** solutions: Euler overestimates.

### Example 12: Concavity and Error

For $y' = x$, $y(0) = 0$, does Euler over- or underestimate?

**Solution:**

Exact: $y = x^2/2$ (parabola, concave up)

Euler with $h = 0.5$ to reach $x = 1$:

$y_1 = 0 + 0.5(0) = 0$

$y_2 = 0 + 0.5(0.5) = 0.25$

Exact: $y(1) = 0.5$

Euler gives $0.25 < 0.5$

**Answer:** Euler **underestimates** for concave up curves.

### Example 13: Implementation Considerations

What practical issues arise when implementing Euler's method?

**Solution:**

**Issues**:

1. **Step size selection**: Too large → poor accuracy; too small → excessive computation
2. **Round-off error**: Many steps accumulate floating-point errors
3. **Stability**: Stiff equations require impractically small $h$
4. **No error control**: Don't know if answer is accurate
5. **Computational cost**: Need many steps for accuracy

**Improvements**: Use adaptive step sizes (Runge-Kutta methods with error estimation)

**Answer:** Euler is simple but has significant practical limitations.

## Answer Key

**Problem 1: A**
$y' = f(x, y) = 2x$
$x_0 = 0$, $y_0 = 0$
$y_1 = y_0 + h \cdot f(x_0, y_0) = 0 + 0.1(2 \cdot 0) = 0 + 0 = 0$
Function $f$ depends on $x$, not $y$
At $x_0 = 0$, slope is zero

**Problem 2: B**
Local truncation error: $O(h^2)$ per step
Number of steps: $n \sim 1/h$
Global error: $O(h^2) \times O(1/h) = O(h)$
First-order method (one power of $h$)

**Problem 3: B**
Stability requires $h < 2/|\lambda|$
Here $\lambda = -10$, so $|\lambda| = 10$
Need $h < 2/10 = 0.2$
Given $h = 0.3 > 0.2$: **unstable**
Solution will oscillate/blow up

**Problem 4: B**
Global error proportional to $h$ for first-order method
If $h \to h/2$: error $\to$ error$/2$
Approximately halves (exactly if linear equation)
Different from local error (which quarters)

**Problem 5: D**
Euler best for:
- Smooth solutions (continuous derivatives)
- Small step sizes (reduce truncation error)
- Non-stiff equations (avoid instability)
Works poorly for rapidly changing, stiff, or discontinuous problems
"Unknown exact solution" doesn't affect performance

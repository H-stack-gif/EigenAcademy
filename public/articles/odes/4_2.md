# ODE Topic 4.2: Inverse Laplace Transforms

The Laplace transform converts time-domain functions into s-domain algebraic expressions. To solve differential equations, we transform the ODE into an algebraic equation, solve for $Y(s)$, then need to **transform back** to get $y(t)$. This reverse process is the **inverse Laplace transform**, denoted $\mathcal{L}^{-1}\{F(s)\} = f(t)$.

Finding inverse transforms is pattern matching. Given $F(s)$, we search our table of transforms to find which $f(t)$ produces it. Simple expressions like $ \frac{1}{s-3}$ are immediate: that's $e^{3t}$. But most problems give messy rational functions requiring algebraic manipulation first. **Partial fraction decomposition** is the workhorse technique—it breaks complex fractions into simpler pieces we can recognize.

This article develops techniques for finding inverse Laplace transforms. We'll master partial fractions for distinct linear factors, repeated factors, and irreducible quadratic factors. We'll learn completing the square to recognize shifted transforms. By article's end, you'll be able to invert any rational function $F(s)$, the crucial step between solving the transformed equation and obtaining the actual solution $y(t)$.

## Definition and Linearity

**Inverse Laplace transform**: If $\mathcal{L}\{f(t)\} = F(s)$, then:
$$\mathcal{L}^{-1}\{F(s)\} = f(t)$$

**Linearity**: $\mathcal{L}^{-1}\{aF(s) + bG(s)\} = a\mathcal{L}^{-1}\{F(s)\} + b\mathcal{L}^{-1}\{G(s)\}$

### Example 1: Direct Inverse Transforms

Find $\mathcal{L}^{-1}\left\{ \frac{1}{s}\right\}$.

**Solution:**

From transform table: $\mathcal{L}\{1\} =  \frac{1}{s}$

Therefore: $\mathcal{L}^{-1}\left\{ \frac{1}{s}\right\} = 1$

**Answer:** $f(t) = 1$

### Example 2: Using Linearity

Find $\mathcal{L}^{-1}\left\{ \frac{3}{s^2} + \frac{2}{s-5}\right\}$.

**Solution:**

$$\mathcal{L}^{-1}\left\{\frac{3}{s^2} + \frac{2}{s-5}\right\} = 3\mathcal{L}^{-1}\left\{\frac{1}{s^2}\right\} + 2\mathcal{L}^{-1}\left\{\frac{1}{s-5}\right\}$$

$\mathcal{L}\{t\} =  \frac{1}{s^2}$, so $\mathcal{L}^{-1}\left\{ \frac{1}{s^2}\right\} = t$

$\mathcal{L}\{e^{5t}\} =  \frac{1}{s-5}$, so $\mathcal{L}^{-1}\left\{ \frac{1}{s-5}\right\} = e^{5t}$

**Answer:** $f(t) = 3t + 2e^{5t}$

### Example 3: Trigonometric Inverse

Find $\mathcal{L}^{-1}\left\{ \frac{4}{s^2+16}\right\}$.

**Solution:**

Recognize pattern: $ \frac{a}{s^2+a^2}$ is transform of $\sin at$

Here $a^2 = 16$, so $a = 4$

$\mathcal{L}\{\sin 4t\} =  \frac{4}{s^2+16}$

**Answer:** $f(t) = \sin 4t$

## Partial Fraction Decomposition

For rational function $ F(s) = \frac{P(s)}{Q(s)}$:

**Step 1**: If degree of $P \geq$ degree of $Q$, divide first (get polynomial + proper fraction)

**Step 2**: Factor denominator $Q(s)$

**Step 3**: Decompose based on factor types:
- **Linear factor** $(s-a)$: contributes $ \frac{A}{s-a}$
- **Repeated factor** $(s-a)^n$: contributes $ \frac{A_1}{s-a} + \frac{A_2}{(s-a)^2} + \cdots + \frac{A_n}{(s-a)^n}$
- **Quadratic factor** $(s^2+bs+c)$: contributes $ \frac{As+B}{s^2+bs+c}$

### Example 4: Distinct Linear Factors

Find $\mathcal{L}^{-1}\left\{ \frac{2s+5}{s^2+3s+2}\right\}$.

**Solution:**

**Factor denominator**: $s^2+3s+2 = (s+1)(s+2)$

**Partial fractions**:
$$\frac{2s+5}{(s+1)(s+2)} = \frac{A}{s+1} + \frac{B}{s+2}$$

Multiply both sides by $(s+1)(s+2)$:
$$2s+5 = A(s+2) + B(s+1)$$

**Method 1: Cover-up**
- Set $s = -1$: $2(-1)+5 = A(1)$, so $A = 3$
- Set $s = -2$: $2(-2)+5 = B(-1)$, so $B = -1$

Check: $3(s+2) - 1(s+1) = 3s+6-s-1 = 2s+5$ ✓

$$\frac{2s+5}{s^2+3s+2} = \frac{3}{s+1} + \frac{-1}{s+2}$$

**Inverse transform**:
$$\mathcal{L}^{-1}\left\{\frac{3}{s+1} - \frac{1}{s+2}\right\} = 3e^{-t} - e^{-2t}$$

**Answer:** $f(t) = 3e^{-t} - e^{-2t}$

### Example 5: Another Partial Fraction Example

Find $\mathcal{L}^{-1}\left\{ \frac{s-3}{s^2-s-6}\right\}$.

**Solution:**

Factor: $s^2-s-6 = (s-3)(s+2)$

$$\frac{s-3}{(s-3)(s+2)} = \frac{1}{s+2}$$

(The factor $s-3$ cancels!)

**Answer:** $f(t) = e^{-2t}$

### Example 6: Three Factors

Find $\mathcal{L}^{-1}\left\{ \frac{1}{s(s-1)(s-2)}\right\}$.

**Solution:**

$$\frac{1}{s(s-1)(s-2)} = \frac{A}{s} + \frac{B}{s-1} + \frac{C}{s-2}$$

Multiply by $s(s-1)(s-2)$:
$$1 = A(s-1)(s-2) + Bs(s-2) + Cs(s-1)$$

Cover-up method:
- $s = 0$: $1 = A(-1)(-2) = 2A$, so $A =  \frac{1}{2}$
- $s = 1$: $1 = B(1)(-1) = -B$, so $B = -1$
- $s = 2$: $1 = C(2)(1) = 2C$, so $C =  \frac{1}{2}$

$$= \frac{1/2}{s} + \frac{-1}{s-1} + \frac{1/2}{s-2}$$

**Answer:** $ f(t) = \frac{1}{2} - e^t + \frac{1}{2}e^{2t}$

## Repeated Linear Factors

For $(s-a)^n$, decomposition includes all powers:
$$\frac{A_1}{s-a} + \frac{A_2}{(s-a)^2} + \cdots + \frac{A_n}{(s-a)^n}$$

Inverse transform uses: $ \mathcal{L}^{-1}\left\{\frac{1}{(s-a)^n}\right\} = \frac{t^{n-1}}{(n-1)!}e^{at}$

### Example 7: Repeated Factor

Find $\mathcal{L}^{-1}\left\{ \frac{2s+1}{(s-1)^2}\right\}$.

**Solution:**

**Method 1**: Rewrite numerator in terms of $(s-1)$

Let $u = s-1$, so $s = u+1$:
$$\frac{2s+1}{(s-1)^2} = \frac{2(u+1)+1}{u^2} = \frac{2u+3}{u^2} = \frac{2}{u} + \frac{3}{u^2}$$

$$= \frac{2}{s-1} + \frac{3}{(s-1)^2}$$

**Inverse transform**:
$$\mathcal{L}^{-1}\left\{\frac{2}{s-1}\right\} = 2e^t$$

$$\mathcal{L}^{-1}\left\{\frac{3}{(s-1)^2}\right\} = 3te^t$$

**Answer:** $f(t) = 2e^t + 3te^t = (2+3t)e^t$

### Example 8: Higher Power Repeated Factor

Find $\mathcal{L}^{-1}\left\{ \frac{1}{s^3}\right\}$.

**Solution:**

Using formula: $ \mathcal{L}^{-1}\left\{\frac{1}{s^n}\right\} = \frac{t^{n-1}}{(n-1)!}$

For $n = 3$:
$$\mathcal{L}^{-1}\left\{\frac{1}{s^3}\right\} = \frac{t^2}{2!} = \frac{t^2}{2}$$

**Answer:** $ f(t) = \frac{t^2}{2}$

## Irreducible Quadratic Factors

For $s^2+b^2$ (or $s^2+bs+c$ that doesn't factor):

Complete the square to get form $(s-a)^2 + b^2$, then use:
$$\mathcal{L}^{-1}\left\{\frac{b}{(s-a)^2+b^2}\right\} = e^{at}\sin bt$$

$$\mathcal{L}^{-1}\left\{\frac{s-a}{(s-a)^2+b^2}\right\} = e^{at}\cos bt$$

### Example 9: Completing the Square

Find $\mathcal{L}^{-1}\left\{ \frac{s}{s^2+4s+13}\right\}$.

**Solution:**

Complete the square in denominator:
$$s^2+4s+13 = (s+2)^2 + 9$$

Rewrite numerator: $s = (s+2) - 2$

$$\frac{s}{s^2+4s+13} = \frac{s+2-2}{(s+2)^2+9} = \frac{s+2}{(s+2)^2+9} - \frac{2}{(s+2)^2+9}$$

Pattern: $ \frac{s-a}{(s-a)^2+b^2}$ with $a = -2$, $b = 3$

$$= \frac{s+2}{(s+2)^2+9} - \frac{2}{3} \cdot \frac{3}{(s+2)^2+9}$$

**Inverse transform**:
$$\mathcal{L}^{-1}\left\{\frac{s+2}{(s+2)^2+9}\right\} = e^{-2t}\cos 3t$$

$$\mathcal{L}^{-1}\left\{\frac{3}{(s+2)^2+9}\right\} = e^{-2t}\sin 3t$$

**Answer:** $ f(t) = e^{-2t}\cos 3t - \frac{2}{3}e^{-2t}\sin 3t = e^{-2t}\left(\cos 3t - \frac{2}{3}\sin 3t\right)$

### Example 10: Quadratic with Linear Numerator

Find $\mathcal{L}^{-1}\left\{ \frac{2s+3}{s^2+1}\right\}$.

**Solution:**

Already in standard form $(s^2+1)$ with $a = 0$, $b = 1$

Split numerator:
$$\frac{2s+3}{s^2+1} = \frac{2s}{s^2+1} + \frac{3}{s^2+1}$$

$$= 2 \cdot \frac{s}{s^2+1} + 3 \cdot \frac{1}{s^2+1}$$

**Answer:** $f(t) = 2\cos t + 3\sin t$

## Mixed Factors

When denominator has both linear and quadratic factors, use combination of techniques.

### Example 11: Linear and Quadratic

Find $\mathcal{L}^{-1}\left\{ \frac{3s}{(s-1)(s^2+4)}\right\}$.

**Solution:**

Partial fractions:
$$\frac{3s}{(s-1)(s^2+4)} = \frac{A}{s-1} + \frac{Bs+C}{s^2+4}$$

Multiply by $(s-1)(s^2+4)$:
$$3s = A(s^2+4) + (Bs+C)(s-1)$$

$s = 1$: $3 = A(5)$, so $A =  \frac{3}{5}$

Expand right side: $As^2 + 4A + Bs^2 - Bs + Cs - C$

Match coefficients:
- $s^2$: $0 = A + B$, so $B = - \frac{3}{5}$
- $s^1$: $3 = -B + C$, so $C = 3 -  \frac{3}{5} = \frac{12}{5}$

$$= \frac{3/5}{s-1} + \frac{-(3/5)s + 12/5}{s^2+4}$$

$$= \frac{3/5}{s-1} - \frac{3/5 \cdot s}{s^2+4} + \frac{12/5}{s^2+4}$$

$$= \frac{3/5}{s-1} - \frac{3}{5} \cdot \frac{s}{s^2+4} + \frac{6}{5} \cdot \frac{2}{s^2+4}$$

**Answer:** $ f(t) = \frac{3}{5}e^t - \frac{3}{5}\cos 2t + \frac{6}{5}\sin 2t$

### Example 12: Improper Fraction

Find $\mathcal{L}^{-1}\left\{ \frac{s^3+2}{s^2+1}\right\}$.

**Solution:**

Degree of numerator $\geq$ degree of denominator → **divide first**

$$\frac{s^3+2}{s^2+1} = s + \frac{-s+2}{s^2+1}$$

(Long division: $s^3 \div s^2 = s$, multiply: $s(s^2+1) = s^3+s$, subtract: $s^3+2-(s^3+s) = -s+2$)

$$= s - \frac{s}{s^2+1} + \frac{2}{s^2+1}$$

But $\mathcal{L}^{-1}\{s\} = $ ?

This doesn't have inverse (not proper Laplace transform).

This example is to show we need to handle the polynomial part differently. The $s$ term would correspond to derivative of delta function, which is beyond basic Laplace transforms.

**Insight**: If $F(s) = s$, this isn't a valid Laplace transform from our table.

### Example 13: Summary Example

Find $\mathcal{L}^{-1}\left\{ \frac{5s^2+3s+1}{s(s^2+1)}\right\}$.

**Solution:**

Partial fractions:
$$\frac{5s^2+3s+1}{s(s^2+1)} = \frac{A}{s} + \frac{Bs+C}{s^2+1}$$

$5s^2+3s+1 = A(s^2+1) + (Bs+C)s$

$s = 0$: $1 = A(1)$, so $A = 1$

Match coefficients:
- $s^2$: $5 = A + B = 1 + B$, so $B = 4$
- $s^1$: $3 = C$

$$= \frac{1}{s} + \frac{4s+3}{s^2+1} = \frac{1}{s} + 4\frac{s}{s^2+1} + 3\frac{1}{s^2+1}$$

**Answer:** $f(t) = 1 + 4\cos t + 3\sin t$

## Answer Key

**Problem 1: B**
$\mathcal{L}^{-1}\left\{ \frac{1}{s^n}\right\} = \frac{t^{n-1}}{(n-1)!}$
For $n = 4$: $\mathcal{L}^{-1}\left\{ \frac{1}{s^4}\right\} = \frac{t^3}{3!} = \frac{t^3}{6}$
With factor 6: $\mathcal{L}^{-1}\left\{ \frac{6}{s^4}\right\} = 6 \cdot \frac{t^3}{6} = t^3$

**Problem 2: B**
$\mathcal{L}^{-1}\left\{ \frac{1}{s-a}\right\} = e^{at}$
For $a = 7$: $\mathcal{L}^{-1}\left\{ \frac{1}{s-7}\right\} = e^{7t}$
Sign in exponent matches sign in denominator

**Problem 3: B**
$\mathcal{L}^{-1}\left\{ \frac{s}{s^2+a^2}\right\} = \cos at$
Here $a^2 = 9$, so $a = 3$
$\mathcal{L}^{-1}\left\{ \frac{s}{s^2+9}\right\} = \cos 3t$
Note: $s$ in numerator indicates cosine (not sine)

**Problem 4: B**
$\mathcal{L}^{-1}\left\{ \frac{1}{(s-a)^n}\right\} = \frac{t^{n-1}}{(n-1)!}e^{at}$
For $a = -2$, $n = 3$:
$\mathcal{L}^{-1}\left\{ \frac{1}{(s+2)^3}\right\} = \frac{t^2}{2!}e^{-2t} = \frac{t^2}{2}e^{-2t}$

**Problem 5: B**
Rational function → partial fractions
First: factor denominator $s^2-5s+6 = (s-2)(s-3)$
Then: $ \frac{s+1}{(s-2)(s-3)} = \frac{A}{s-2} + \frac{B}{s-3}$
Solve for $A, B$, then invert term by term

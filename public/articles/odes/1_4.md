# ODE Topic 1.4: Exact Equations and Substitutions

Some differential equations have hidden structure. Consider $2xy \, dx + x^2 \, dy = 0$. This isn't separable (can't factor as $g(x)h(y)$), and it's not linear in standard form. But notice something special: the left side is the differential of $x^2y$. Indeed, $d(x^2y) = 2xy \, dx + x^2 \, dy$. So our equation says $d(x^2y) = 0$, which means $x^2y = C$. We've found the solution without any integration!

Equations where the left side is an exact differential are called **exact equations**. We can recognize them by a simple test involving partial derivatives, and we can solve them by reconstructing the function being differentiated. When equations aren't exact, sometimes they can be made exact by multiplying by an **integrating factor**.

Other special forms yield to clever substitutions. **Homogeneous equations** (where $y' = f(y/x)$) become separable after substituting $v = y/x$. **Bernoulli equations** (linear except for a $y^n$ term) become linear after a power substitution. These techniques expand our toolbox for solving first-order equations.

## Exact Differential Equations

Equation $M(x,y) \, dx + N(x,y) \, dy = 0$ is **exact** if there exists function $F(x,y)$ with:
$$ \frac{\partial F}{\partial x} = M, \quad \frac{\partial F}{\partial y} = N$$

Then the equation is $dF = 0$, so $F(x,y) = C$ is the solution.

**Test for exactness**: Equation is exact if and only if:
$$ \frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$$

(This follows from $F_{xy} = F_{yx}$ for smooth $F$.)

### Example 1: Testing Exactness

Is $2xy \, dx + x^2 \, dy = 0$ exact?

**Solution:**

$M = 2xy$, $N = x^2$

$ \frac{\partial M}{\partial y} = 2x$

$ \frac{\partial N}{\partial x} = 2x$

Since $ \frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$, the equation is exact ✓

**Answer:** Yes, exact.

### Example 2: Finding Potential Function

For exact equation $2xy \, dx + x^2 \, dy = 0$, find $F(x,y)$ and solve.

**Solution:**

Need $F$ with $F_x = 2xy$ and $F_y = x^2$.

From $F_x = 2xy$, integrate with respect to $x$:
$$F = \int 2xy \, dx = x^2y + g(y)$$

where $g(y)$ is "constant" of integration (function of $y$ only).

Find $g(y)$ using $F_y = x^2$:
$$F_y = x^2 + g'(y) = x^2$$

So $g'(y) = 0$, thus $g(y) = C_1$ (constant).

$$F(x,y) = x^2y + C_1$$

Solution is $F = C$: $x^2y = C$ (absorbing $C_1$ into $C$).

**Answer:** $x^2y = C$

### Example 3: More Complex Exact Equation

Solve $(2x + y) \, dx + (x + 2y) \, dy = 0$.

**Solution:**

$M = 2x + y$, $N = x + 2y$

Check exactness:
$ \frac{\partial M}{\partial y} = 1$, $ \frac{\partial N}{\partial x} = 1$ ✓ Exact!

From $F_x = 2x + y$:
$$F = \int (2x + y) \, dx = x^2 + xy + g(y)$$

From $F_y = x + 2y$:
$$F_y = x + g'(y) = x + 2y$$

So $g'(y) = 2y$, thus $g(y) = y^2$

$$F(x,y) = x^2 + xy + y^2$$

**Answer:** $x^2 + xy + y^2 = C$

### Example 4: Not Exact

Is $y \, dx + x \, dy = 0$ exact?

**Solution:**

$M = y$, $N = x$

$ \frac{\partial M}{\partial y} = 1$, $ \frac{\partial N}{\partial x} = 1$ ✓ Exact!

Double-check: $M(x,y) = y$, so $M_y = 1$. $N(x,y) = x$, so $N_x = 1$. Correct.

From $F_x = y$: $F = xy + g(y)$

From $F_y = x$: $F_y = x + g'(y) = x$, so $g'(y) = 0$, $g = C_1$

$F = xy$, solution: $xy = C$

**Answer:** This is exact. Solution $xy = C$.

### Example 5: Non-Exact Example

Show $(y^2 + 1) \, dx + x \, dy = 0$ is not exact.

**Solution:**

$(y^2 + 1) \, dx + x \, dy = 0$

$M = y^2 + 1$, $N = x$

$M_y = 2y$, $N_x = 1$

Since $2y \neq 1$ (in general), not exact ✓

**Answer:** $(y^2 + 1) \, dx + x \, dy = 0$ is not exact.

## Integrating Factors for Exact Equations

If equation is not exact, sometimes multiplying by function $\mu(x,y)$ makes it exact.

**Common cases**:
- If $ \frac{M_y - N_x}{N}$ depends only on $x$, then $\mu(x) = e^{\int (M_y - N_x)/N \, dx}$
- If $ \frac{N_x - M_y}{M}$ depends only on $y$, then $\mu(y) = e^{\int (N_x - M_y)/M \, dy}$

### Example 6: Finding Integrating Factor

For $(y^2 + 1) \, dx + x \, dy = 0$, find integrating factor depending on $x$ only.

**Solution:**

$M = y^2 + 1$, $N = x$

$M_y - N_x = 2y - 1$

$ \frac{M_y - N_x}{N} = \frac{2y - 1}{x}$

This depends on both $x$ and $y$, so no integrating factor of form $\mu(x)$.

Try $ \frac{N_x - M_y}{M} = \frac{1 - 2y}{y^2 + 1}$

This depends on $y$, so try $\mu(y)$... but this doesn't simplify nicely either.

**Answer:** This particular equation doesn't have simple integrating factor. (Some equations resist this technique.)

### Example 7: Successful Integrating Factor

For $y \, dx - x \, dy = 0$, find integrating factor.

**Solution:**

$M = y$, $N = -x$

$M_y = 1$, $N_x = -1$

$M_y - N_x = 2$

Try $ \frac{M_y - N_x}{N} = \frac{2}{-x} = -\frac{2}{x}$ (depends only on $x$!)

$\mu(x) = e^{\int (-2/x) \, dx} = e^{-2\ln x} = e^{\ln x^{-2}} = x^{-2} =  \frac{1}{x^2}$

Multiply equation by $ \frac{1}{x^2}$:
$$ \frac{y}{x^2} \, dx - \frac{1}{x} \, dy = 0$$

Check exactness: $M = y/x^2$, $N = -1/x$

$M_y = 1/x^2$, $N_x = 1/x^2$ ✓ Exact!

**Answer:** Integrating factor $\mu = 1/x^2$ makes equation exact.

## Homogeneous Equations

Equation $ \frac{dy}{dx} = f(y/x)$ is called **homogeneous** (different meaning than "homogeneous linear").

**Solution method**: Substitution $v = y/x$, so $y = vx$ and $ \frac{dy}{dx} = v + x\frac{dv}{dx}$.

This converts equation to separable in $v$ and $x$.

### Example 8: Identifying Homogeneous

Is $ \frac{dy}{dx} = \frac{x + y}{x}$ homogeneous?

**Solution:**

$ \frac{dy}{dx} = \frac{x + y}{x} = 1 + \frac{y}{x}$

This is $f(y/x)$ where $f(t) = 1 + t$.

**Answer:** Yes, homogeneous.

### Example 9: Solving Homogeneous Equation

Solve $ \frac{dy}{dx} = \frac{y}{x} + 1$.

**Solution:**

Let $v = y/x$, so $y = vx$ and $ \frac{dy}{dx} = v + x\frac{dv}{dx}$

Substitute:
$$v + x\frac{dv}{dx} = v + 1$$

$$x\frac{dv}{dx} = 1$$

$$dv = \frac{dx}{x}$$

Integrate: $v = \ln|x| + C$

Back-substitute: $ \frac{y}{x} = \ln|x| + C$

**Answer:** $y = x\ln|x| + Cx$

### Example 10: Homogeneous with Initial Condition

Solve $ \frac{dy}{dx} = \frac{x^2 + y^2}{xy}$, $y(1) = 2$.

**Solution:**

Rewrite: $ \frac{dy}{dx} = \frac{x}{y} + \frac{y}{x}$

Let $v = y/x$, so $y = vx$ and $y' = v + xv'$

$$v + xv' = \frac{1}{v} + v$$

$$xv' = \frac{1}{v}$$

$$v \, dv = \frac{dx}{x}$$

Integrate: $ \frac{v^2}{2} = \ln|x| + C$

$v^2 = 2\ln|x| + K$

Back-substitute: $ \frac{y^2}{x^2} = 2\ln x + K$ (for $x > 0$)

Use $y(1) = 2$: $ \frac{4}{1} = 2\ln 1 + K = 0 + K$, so $K = 4$

**Answer:** $y^2 = x^2(2\ln x + 4)$

## Bernoulli Equations

**Bernoulli equation**: $y' + P(x)y = Q(x)y^n$ where $n \neq 0, 1$.

**Solution method**: Substitution $v = y^{1-n}$ converts to linear equation in $v$.

### Example 11: Identifying Bernoulli

Is $y' + xy = xy^3$ a Bernoulli equation?

**Solution:**

Rewrite: $y' + xy = xy^3$

This is $y' + P(x)y = Q(x)y^n$ with $P = x$, $Q = x$, $n = 3$.

Since $n = 3 \neq 0, 1$, this is Bernoulli.

**Answer:** Yes, Bernoulli with $n = 3$.

### Example 12: Solving Bernoulli Equation

Solve $y' - y = y^2$.

**Solution:**

This is Bernoulli with $P = -1$, $Q = 1$, $n = 2$.

Substitution: $v = y^{1-n} = y^{-1} =  \frac{1}{y}$

Then $v' = -y^{-2}y'$, so $y' = -y^2v'$

Substitute into original equation:
$$-y^2v' - y = y^2$$

Divide by $-y^2$:
$$v' + y^{-1} = -1$$

But $v = 1/y$, so $y^{-1} = v$:
$$v' + v = -1$$

This is linear! Integrating factor: $\mu = e^x$

$e^xv' + e^xv = -e^x$

$ \frac{d}{dx}[e^xv] = -e^x$

$e^xv = -e^x + C$

$v = -1 + Ce^{-x}$

Back-substitute: $ \frac{1}{y} = -1 + Ce^{-x}$

**Answer:** $ y = \frac{1}{-1 + Ce^{-x}}$ or $ y = \frac{1}{Ce^{-x} - 1}$

### Example 13: Bernoulli Application

In learning theory, rate of learning is proportional to product of amount learned and amount remaining to learn. If $L$ is amount learned (max is 100), this gives:
$$ \frac{dL}{dt} = kL(100 - L)$$

Is this Bernoulli?

**Solution:**

Expand: $ \frac{dL}{dt} = 100kL - kL^2$

Rearrange: $ \frac{dL}{dt} - 100kL = -kL^2$

This is $L' + P(t)L = Q(t)L^n$ with $P = -100k$, $Q = -k$, $n = 2$.

**Answer:** Yes, Bernoulli with $n = 2$. (Also note: this is separable—it's the logistic equation!)

## Practice Problems

A) $dx$
B) $dy$
C) $x$

E) $dt$

**Problem 3:** Homogeneous equation $y' = f(y/x)$ is solved using substitution:

A) $v = xy$
B) $v = x/y$
C) $v = y/x$
D) $v = x + y$
E) $v = y - x$

**Problem 4:** Bernoulli equation $y' + Py = Qy^n$ with $n = 2$ uses substitution:

A) $v = y^2$
B) $v = 1/y$
C) $v = y^{-2}$
D) $v = \sqrt{y}$
E) $v = \ln y$

**Problem 5:** Solution to exact equation $2xy \, dx + x^2 \, dy = 0$ is:

A) $xy = C$
B) $x^2y = C$
C) $xy^2 = C$
D) $x + y = C$
E) $x^2 + y^2 = C$

## Answer Key

**Problem 1: B**
Test: $M = 3x^2 + 2y$, $N = 2x + 4y$
$M_y = 2$, $N_x = 2$
Since $M_y = N_x$, equation is exact.
(Not separable: can't factor as $g(x)h(y)$)

**Problem 2: A**
Standard form: $M(x,y) \, dx + N(x,y) \, dy = 0$
$M$ is coefficient of $dx$
$N$ is coefficient of $dy$
Exactness test: $ \frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$

**Problem 3: C**
Substitution $v = y/x$ means $y = vx$
Then $y' = v + xv'$ (product rule)
Equation becomes separable in $v$ and $x$.

**Problem 4: B**
For $n = 2$: use $v = y^{1-n} = y^{1-2} = y^{-1} = 1/y$
Then $v' = -y^{-2}y'$
This linearizes the equation.

**Problem 5: B**
From Examples 1-2: $F(x,y) = x^2y$
Solution is $F = C$: $x^2y = C$
Can verify: differentiate implicitly and recover original equation.

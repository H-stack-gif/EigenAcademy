# ODE Topic 4.4: Step Functions and Impulses

Real systems don't start smoothly. A circuit switches on at $t = t_0$. A rocket engine fires at specific moments. An earthquake delivers sudden impulses to structures. These **discontinuous** or **impulsive** forces can't be modeled by nice smooth functions like $e^{at}$ or $\sin t$. We need the **unit step function** for switching and the **Dirac delta function** for impulses.

The Laplace transform handles discontinuities beautifully. The **second translation theorem** (t-shift) connects time-domain shifts to s-domain exponential factors: shifting $f(t)$ to start at $t = a$ multiplies $F(s)$ by $e^{-as}$. The delta function $\delta(t-a)$, despite not being a true function, has a simple transform: $e^{-as}$. These tools let us model realistic forcing: switches, impulses, rectangular pulses, periodic drives with sudden changes.

This article introduces the unit step and delta functions, develops the t-shift theorem, and applies these to solve ODEs with discontinuous forcing. We'll also explore **convolution**, which describes system response to arbitrary inputs, and periodic forcing. By the end, you'll be equipped to model and solve ODEs for any realistic engineering scenario—the full power of Laplace transforms realized.

## The Unit Step Function

**Definition**:
$$u_c(t) = u(t-c) = \begin{cases} 0 & t < c \\ 1 & t \geq c \end{cases}$$

Also called **Heaviside function**.

**Laplace transform**: $\mathcal{L}\{u_c(t)\} =  \frac{e^{-cs}}{s}$

### Example 1: Step Function Basics

Express $f(t) = \begin{cases} 0 & t < 2 \\ 3 & t \geq 2 \end{cases}$ using step function.

**Solution:**

The function "turns on" at $t = 2$ with value 3.

$$f(t) = 3u_2(t) = 3u(t-2)$$

Check: For $t < 2$: $u(t-2) = 0$, so $f = 0$ ✓

For $t \geq 2$: $u(t-2) = 1$, so $f = 3$ ✓

**Answer:** $f(t) = 3u_2(t)$

### Example 2: Piecewise Functions

Express $f(t) = \begin{cases} 0 & t < 1 \\ 5 & 1 \leq t < 3 \\ 0 & t \geq 3 \end{cases}$ using step functions.

**Solution:**

Function is 5 on interval $[1, 3)$.

"Turn on" at $t = 1$: add $5u_1(t)$

"Turn off" at $t = 3$: subtract $5u_3(t)$

$$f(t) = 5u_1(t) - 5u_3(t) = 5[u_1(t) - u_3(t)]$$

Check:
- $t < 1$: both steps are 0, so $f = 0$ ✓
- $1 \leq t < 3$: first step is 1, second is 0, so $f = 5$ ✓
- $t \geq 3$: both steps are 1, so $f = 5 - 5 = 0$ ✓

**Answer:** $f(t) = 5[u_1(t) - u_3(t)]$

### Example 3: Ramp with Delay

Express $f(t) = \begin{cases} 0 & t < 2 \\ t-2 & t \geq 2 \end{cases}$ using step function.

**Solution:**

Ramp $(t-2)$ starts at $t = 2$:

$$f(t) = (t-2)u_2(t)$$

**Answer:** $f(t) = (t-2)u_2(t)$

## Second Translation Theorem (t-shift)

**Theorem**: $\mathcal{L}\{f(t-c)u_c(t)\} = e^{-cs}F(s)$

where $F(s) = \mathcal{L}\{f(t)\}$.

**Meaning**: Shifting $f(t)$ to start at $t = c$ multiplies transform by $e^{-cs}$.

### Example 4: Using t-shift

Find $\mathcal{L}\{(t-2)u_2(t)\}$.

**Solution:**

Form is $f(t-c)u_c(t)$ with $f(t) = t$, $c = 2$.

$F(s) = \mathcal{L}\{t\} =  \frac{1}{s^2}$

By t-shift theorem:
$$\mathcal{L}\{(t-2)u_2(t)\} = e^{-2s} \cdot \frac{1}{s^2} = \frac{e^{-2s}}{s^2}$$

**Answer:** $ \frac{e^{-2s}}{s^2}$

### Example 5: Rewriting for t-shift

Find $\mathcal{L}\{tu_1(t)\}$.

**Solution:**

Need form $f(t-c)u_c(t)$ with $c = 1$.

$tu_1(t)$ is not quite right—need $(t-1)$ inside.

Rewrite: $t = (t-1) + 1$

$$tu_1(t) = [(t-1) + 1]u_1(t) = (t-1)u_1(t) + u_1(t)$$

First term: $\mathcal{L}\{(t-1)u_1(t)\} = e^{-s} \cdot  \frac{1}{s^2}$

Second term: $\mathcal{L}\{u_1(t)\} =  \frac{e^{-s}}{s}$

$$\mathcal{L}\{tu_1(t)\} = \frac{e^{-s}}{s^2} + \frac{e^{-s}}{s} = e^{-s}\left(\frac{1}{s^2} + \frac{1}{s}\right) = \frac{e^{-s}(1+s)}{s^2}$$

**Answer:** $ \frac{e^{-s}(1+s)}{s^2}$

### Example 6: Inverse with t-shift

Find $\mathcal{L}^{-1}\left\{ \frac{e^{-3s}}{s-2}\right\}$.

**Solution:**

Form: $e^{-cs}F(s)$ with $c = 3$, $F(s) =  \frac{1}{s-2}$

$f(t) = \mathcal{L}^{-1}\left\{ \frac{1}{s-2}\right\} = e^{2t}$

By t-shift (inverse):
$$\mathcal{L}^{-1}\{e^{-3s}F(s)\} = f(t-3)u_3(t)$$

$$= e^{2(t-3)}u_3(t)$$

**Answer:** $f(t) = e^{2(t-3)}u_3(t) = \begin{cases} 0 & t < 3 \\ e^{2(t-3)} & t \geq 3 \end{cases}$

## Solving ODEs with Discontinuous Forcing

### Example 7: Step Function Forcing

Solve $y'' + y = u_{\pi}(t)$, $y(0) = 0$, $y'(0) = 0$.

**Solution:**

Transform:
$$s^2Y + Y = \frac{e^{-\pi s}}{s}$$

$$(s^2+1)Y = \frac{e^{-\pi s}}{s}$$

$$Y = \frac{e^{-\pi s}}{s(s^2+1)}$$

Partial fractions for $ \frac{1}{s(s^2+1)}$:
$$\frac{1}{s(s^2+1)} = \frac{A}{s} + \frac{Bs+C}{s^2+1}$$

$s = 0$: $1 = A$

Match $s^2$: $0 = A + B$, so $B = -1$

Match $s^1$: $0 = C$

$$\frac{1}{s(s^2+1)} = \frac{1}{s} - \frac{s}{s^2+1}$$

$$Y = e^{-\pi s}\left(\frac{1}{s} - \frac{s}{s^2+1}\right)$$

Inverse transform:
$$y = [1 - \cos(t-\pi)]u_{\pi}(t)$$

Since $\cos(t-\pi) = -\cos t$:
$$y = [1 + \cos t]u_{\pi}(t)$$

**Answer:** $y = \begin{cases} 0 & t < \pi \\ 1 + \cos t & t \geq \pi \end{cases}$

### Example 8: Rectangular Pulse

Solve $y' + y = f(t)$ where $f(t) = \begin{cases} 0 & t < 1 \\ 1 & 1 \leq t < 2 \\ 0 & t \geq 2 \end{cases}$, $y(0) = 0$.

**Solution:**

$f(t) = u_1(t) - u_2(t)$

Transform:
$$sY + Y = \frac{e^{-s}}{s} - \frac{e^{-2s}}{s}$$

$$(s+1)Y = \frac{e^{-s} - e^{-2s}}{s}$$

$$Y = \frac{e^{-s} - e^{-2s}}{s(s+1)}$$

For $ \frac{1}{s(s+1)} = \frac{1}{s} - \frac{1}{s+1}$:

$$Y = e^{-s}\left(\frac{1}{s} - \frac{1}{s+1}\right) - e^{-2s}\left(\frac{1}{s} - \frac{1}{s+1}\right)$$

$$= e^{-s}\cdot\frac{1}{s} - e^{-s}\cdot\frac{1}{s+1} - e^{-2s}\cdot\frac{1}{s} + e^{-2s}\cdot\frac{1}{s+1}$$

Inverse:
$$y = [1 - e^{-(t-1)}]u_1(t) - [1 - e^{-(t-2)}]u_2(t)$$

Simplified:
$$y = \begin{cases} 0 & t < 1 \\ 1 - e^{-(t-1)} & 1 \leq t < 2 \\ e^{-(t-2)} - e^{-(t-1)} & t \geq 2 \end{cases}$$

**Answer:** Solution as piecewise function above.

## The Dirac Delta Function

**Delta function** $\delta(t-a)$: "Impulse" at $t = a$

**Properties**:
- $\delta(t-a) = 0$ for $t \neq a$
- $ \int_{-\infty}^{\infty} \delta(t-a) \, dt = 1$
- $ \int_{-\infty}^{\infty} f(t)\delta(t-a) \, dt = f(a)$ (sifting property)

**Laplace transform**: $\mathcal{L}\{\delta(t-a)\} = e^{-as}$

For $a = 0$: $\mathcal{L}\{\delta(t)\} = 1$

### Example 9: Impulse at $t = 0$

Solve $y'' + 4y = \delta(t)$, $y(0) = 0$, $y'(0) = 0$.

**Solution:**

Transform:
$$s^2Y + 4Y = 1$$

$$(s^2+4)Y = 1$$

$$Y = \frac{1}{s^2+4} = \frac{1}{2} \cdot \frac{2}{s^2+4}$$

**Answer:** $ y = \frac{1}{2}\sin 2t$

Interpretation: Impulse gives initial "kick" to system.

### Example 10: Delayed Impulse

Solve $y'' + 2y' + y = \delta(t-1)$, $y(0) = 0$, $y'(0) = 0$.

**Solution:**

Transform:
$$(s^2+2s+1)Y = e^{-s}$$

$$(s+1)^2Y = e^{-s}$$

$$Y = \frac{e^{-s}}{(s+1)^2}$$

Inverse (using t-shift):

$ \mathcal{L}^{-1}\left\{\frac{1}{(s+1)^2}\right\} = te^{-t}$

$$y = (t-1)e^{-(t-1)}u_1(t)$$

**Answer:** $y = \begin{cases} 0 & t < 1 \\ (t-1)e^{-(t-1)} & t \geq 1 \end{cases}$

## Convolution

**Convolution**: $(f * g)(t) =  \int_0^t f(\tau)g(t-\tau) \, d\tau$

**Convolution theorem**: $\mathcal{L}\{f * g\} = F(s)G(s)$

**Application**: $\mathcal{L}^{-1}\{F(s)G(s)\} = f * g$

### Example 11: Using Convolution

Find $\mathcal{L}^{-1}\left\{ \frac{1}{s(s^2+1)}\right\}$ using convolution.

**Solution:**

Write as product: $ \frac{1}{s} \cdot \frac{1}{s^2+1}$

$f(t) = \mathcal{L}^{-1}\left\{ \frac{1}{s}\right\} = 1$

$g(t) = \mathcal{L}^{-1}\left\{ \frac{1}{s^2+1}\right\} = \sin t$

Convolution:
$$(f * g)(t) = \int_0^t 1 \cdot \sin(t-\tau) \, d\tau$$

Let $u = t - \tau$, $du = -d\tau$:

When $\tau = 0$: $u = t$; when $\tau = t$: $u = 0$

$$= -\int_t^0 \sin u \, du = \int_0^t \sin u \, du$$

$$= [-\cos u]_0^t = -\cos t + 1 = 1 - \cos t$$

**Answer:** $y(t) = 1 - \cos t$

(Matches partial fractions result!)

### Example 12: Convolution in Solving ODEs

Use convolution to solve $y'' + 4y = f(t)$, $y(0) = y'(0) = 0$ for arbitrary $f(t)$.

**Solution:**

Transform:
$$(s^2+4)Y = F(s)$$

$$Y = \frac{F(s)}{s^2+4} = F(s) \cdot \frac{1}{s^2+4}$$

$g(t) = \mathcal{L}^{-1}\left\{ \frac{1}{s^2+4}\right\} = \frac{1}{2}\sin 2t$

By convolution:
$$y = f * g = \int_0^t f(\tau) \cdot \frac{1}{2}\sin 2(t-\tau) \, d\tau$$

$$= \frac{1}{2}\int_0^t f(\tau)\sin 2(t-\tau) \, d\tau$$

**Answer:** $ y(t) = \frac{1}{2}\int_0^t f(\tau)\sin 2(t-\tau) \, d\tau$

This is **Duhamel's principle**—general solution for arbitrary forcing.

### Example 13: Periodic Forcing

For periodic $f(t)$ with period $T$: $f(t+T) = f(t)$.

Transform: $ \mathcal{L}\{f(t)\} = \frac{1}{1-e^{-Ts}}\int_0^T e^{-st}f(t) \, dt$

**Example**: Square wave with period $2\pi$:
$$f(t) = \begin{cases} 1 & 0 \leq t < \pi \\ -1 & \pi \leq t < 2\pi \end{cases}$$

$$\mathcal{L}\{f(t)\} = \frac{1}{1-e^{-2\pi s}}\left[\int_0^{\pi} e^{-st} \, dt - \int_{\pi}^{2\pi} e^{-st} \, dt\right]$$

$$= \frac{1}{1-e^{-2\pi s}} \cdot \frac{1-e^{-\pi s} - e^{-\pi s} + e^{-2\pi s}}{s}$$

$$= \frac{1}{s(1+e^{-\pi s})}$$

**Answer:** Transform of square wave involves exponential factors.

## Answer Key

**Problem 1: B**
$\mathcal{L}\{u_c(t)\} =  \frac{e^{-cs}}{s}$
For $c = 5$: $\mathcal{L}\{u_5(t)\} =  \frac{e^{-5s}}{s}$
Step at $t = 5$ gives exponential factor $e^{-5s}$

**Problem 2: A**
$f(t) = t^2$ has $\mathcal{L}\{t^2\} =  \frac{2}{s^3}$
t-shift theorem: $\mathcal{L}\{f(t-c)u_c(t)\} = e^{-cs}F(s)$
$\mathcal{L}\{(t-2)^2u_2(t)\} = e^{-2s} \cdot  \frac{2}{s^3} = \frac{2e^{-2s}}{s^3}$

**Problem 3: B**
$\mathcal{L}\{\delta(t-a)\} = e^{-as}$
For $a = 3$: $\mathcal{L}\{\delta(t-3)\} = e^{-3s}$
Impulse at time $a$ gives simple exponential

**Problem 4: B**
Convolution: $(f*g)(t) =  \int_0^t f(\tau)g(t-\tau) d\tau$
Theorem: $\mathcal{L}\{f*g\} = \mathcal{L}\{f\} \cdot \mathcal{L}\{g\} = F(s)G(s)$
Transform of convolution is product of transforms

**Problem 5: B**
Step at $t = c$: multiply by $e^{-cs}$
Impulse at $t = c$: transform is $e^{-cs}$
Piecewise functions: sum of shifted transforms
Classical methods struggle with discontinuities
Laplace handles them algebraically

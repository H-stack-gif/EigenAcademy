# ODE Topic 2.4: Applications: Mechanical and Electrical Systems

A mass hanging from a spring. An RLC circuit with oscillating voltage. A swinging pendulum. A car's suspension system. These physical systems, seemingly different, all obey **the same mathematical equation**: a second-order linear differential equation. The universality is remarkable—mechanical vibrations and electrical oscillations follow identical mathematics.

Understanding these applications means understanding the world around us. Why does a guitar string vibrate at specific frequencies? How do engineers design shock absorbers to prevent oscillations? Why does resonance cause bridges to collapse or wine glasses to shatter? The mathematics of second-order equations answers these questions precisely.

This article explores mechanical systems (springs, dampers) and electrical circuits (inductors, capacitors, resistors). We'll see how differential equations model oscillations, analyze different damping regimes, and investigate the dangerous phenomenon of **resonance**. These aren't abstract examples—they're the foundation of engineering design in mechanics, electronics, and structural analysis.

## Spring-Mass Systems

A mass $m$ attached to spring (constant $k$) with damping (coefficient $\gamma$):

**Newton's second law**: $ m\frac{d^2x}{dt^2} = -kx - \gamma\frac{dx}{dt} + F(t)$

**Standard form**: $ mx'' + \gamma x' + kx = F(t)$

where:
- $x(t)$ = displacement from equilibrium
- $F(t)$ = external forcing
- $m$ = mass
- $k$ = spring constant (Hooke's law)
- $\gamma$ = damping coefficient

### Example 1: Setting Up Spring Equation

A 2 kg mass on spring ($k = 8$ N/m) with damping $\gamma = 4$ N·s/m. Write differential equation.

**Solution:**

$$2x'' + 4x' + 8x = 0$$

Divide by 2:
$$x'' + 2x' + 4x = 0$$

**Answer:** $x'' + 2x' + 4x = 0$ (second-order, constant coefficients)

## Undamped Motion

With $\gamma = 0$ and $F = 0$: $mx'' + kx = 0$

$$x'' + \omega_0^2 x = 0$$

where $\omega_0 = \sqrt{k/m}$ is **natural frequency**.

**Solution**: $x = c_1\cos\omega_0 t + c_2\sin\omega_0 t$

Or: $x = A\cos(\omega_0 t - \phi)$ where $A$ = amplitude, $\phi$ = phase

### Example 2: Simple Harmonic Motion

Mass 1 kg, spring constant 16 N/m, released from $x(0) = 0.5$ m with $v(0) = 0$. Find motion.

**Solution:**

$m = 1$, $k = 16$: equation is $x'' + 16x = 0$

$\omega_0 = \sqrt{16} = 4$ rad/s

General: $x = c_1\cos 4t + c_2\sin 4t$

$x(0) = c_1 = 0.5$

$x' = -4c_1\sin 4t + 4c_2\cos 4t$

$x'(0) = 4c_2 = 0$, so $c_2 = 0$

**Answer:** $x = 0.5\cos 4t$ meters

**Period**: $T =  \frac{2\pi}{\omega_0} = \frac{2\pi}{4} = \frac{\pi}{2}$ seconds

### Example 3: Frequency and Period

For $x'' + 25x = 0$, find natural frequency and period.

**Solution:**

$\omega_0^2 = 25$, so $\omega_0 = 5$ rad/s

Period: $T =  \frac{2\pi}{\omega_0} = \frac{2\pi}{5}$ seconds

Frequency (Hz): $f =  \frac{1}{T} = \frac{5}{2\pi} \approx 0.796$ Hz

**Answer:** $\omega_0 = 5$ rad/s, $T = 2\pi/5 \approx 1.26$ s

## Damped Motion

With damping ($\gamma > 0$), equation: $mx'' + \gamma x' + kx = 0$

Characteristic: $mr^2 + \gamma r + k = 0$

$$r = \frac{-\gamma \pm \sqrt{\gamma^2 - 4mk}}{2m}$$

**Discriminant**: $\Delta = \gamma^2 - 4mk$

Three cases:
1. **Underdamped** ($\Delta < 0$): oscillations with decay
2. **Critically damped** ($\Delta = 0$): fastest return without oscillation
3. **Overdamped** ($\Delta > 0$): slow return without oscillation

### Example 4: Underdamped System

For $x'' + 2x' + 10x = 0$, classify and solve.

**Solution:**

Characteristic: $r^2 + 2r + 10 = 0$

$$r = \frac{-2 \pm \sqrt{4 - 40}}{2} = \frac{-2 \pm 6i}{2} = -1 \pm 3i$$

$\alpha = -1 < 0$, $\beta = 3$

**Underdamped** (complex roots)

$$x = e^{-t}(c_1\cos 3t + c_2\sin 3t)$$

**Answer:** Oscillations with frequency 3 rad/s, exponentially decaying with rate $e^{-t}$.

### Example 5: Critical Damping

For what damping $\gamma$ is $mx'' + \gamma x' + kx = 0$ critically damped if $m = 1$, $k = 4$?

**Solution:**

Critical damping: $\gamma^2 = 4mk$

$\gamma^2 = 4(1)(4) = 16$

$\gamma = 4$ N·s/m

Characteristic becomes $(r + 2)^2 = 0$ (repeated root)

**Answer:** $\gamma = 4$ produces critical damping.

### Example 6: Overdamped Motion

Solve $x'' + 5x' + 4x = 0$, $x(0) = 1$, $x'(0) = 0$.

**Solution:**

Characteristic: $r^2 + 5r + 4 = (r+1)(r+4) = 0$

Roots: $r = -1, -4$ (distinct, real, negative)

**Overdamped**

$x = c_1e^{-t} + c_2e^{-4t}$

$x(0) = c_1 + c_2 = 1$

$x' = -c_1e^{-t} - 4c_2e^{-4t}$

$x'(0) = -c_1 - 4c_2 = 0$

From second: $c_1 = -4c_2$

Substitute: $-4c_2 + c_2 = 1$, so $c_2 = - \frac{1}{3}$, $c_1 = \frac{4}{3}$

**Answer:** $x =  \frac{4}{3}e^{-t} - \frac{1}{3}e^{-4t}$ (no oscillation, exponential decay)

### Example 7: Comparing Damping Cases

For $m = 1$, $k = 9$, compare motion for $\gamma = 0, 4, 6, 8$.

**Solution:**

Equation: $x'' + \gamma x' + 9x = 0$

Discriminant: $\Delta = \gamma^2 - 36$

- $\gamma = 0$: $\Delta = -36 < 0$ → **undamped** (pure oscillation)
- $\gamma = 4$: $\Delta = -20 < 0$ → **underdamped** (oscillation + decay)
- $\gamma = 6$: $\Delta = 0$ → **critically damped** (fastest non-oscillatory return)
- $\gamma = 8$: $\Delta = 28 > 0$ → **overdamped** (slow return, no oscillation)

**Answer:** Increasing damping transitions through underdamped → critical → overdamped.

## Forced Oscillations and Resonance

With external force: $mx'' + \gamma x' + kx = F_0\cos\omega t$

Particular solution has form: $x_p = A\cos\omega t + B\sin\omega t$

Or: $x_p = C\cos(\omega t - \delta)$ where amplitude $C$ depends on $\omega$.

**Resonance**: When forcing frequency $\omega$ matches natural frequency $\omega_0$ in undamped system, amplitude grows without bound.

### Example 8: Resonance in Undamped System

Solve $x'' + 4x = \cos 2t$ (note: $\omega = \omega_0 = 2$).

**Solution:**

Homogeneous: $r^2 + 4 = 0$, $r = \pm 2i$

$x_c = c_1\cos 2t + c_2\sin 2t$

Particular: forcing matches homogeneous frequency!

Try: $x_p = t(A\cos 2t + B\sin 2t)$ (resonance modification)

$x_p' = A\cos 2t + B\sin 2t + t(-2A\sin 2t + 2B\cos 2t)$

$x_p'' = -2A\sin 2t + 2B\cos 2t + (-2A\sin 2t + 2B\cos 2t) + t(-4A\cos 2t - 4B\sin 2t)$
$= -4A\sin 2t + 4B\cos 2t - 4At\cos 2t - 4Bt\sin 2t$

Substitute:
$[-4A\sin 2t + 4B\cos 2t - 4At\cos 2t - 4Bt\sin 2t] + 4t(A\cos 2t + B\sin 2t) = \cos 2t$

Simplifies: $-4A\sin 2t + 4B\cos 2t = \cos 2t$

$4B = 1$, $-4A = 0$

$B =  \frac{1}{4}$, $A = 0$

**Answer:** $x = c_1\cos 2t + c_2\sin 2t +  \frac{1}{4}t\sin 2t$

The $t\sin 2t$ term grows without bound—**pure resonance**.

### Example 9: Near Resonance

For $x'' + 4x = \cos 3t$, find steady-state amplitude.

**Solution:**

Try $x_p = A\cos 3t + B\sin 3t$

$x_p'' = -9A\cos 3t - 9B\sin 3t$

$(-9A + 4A)\cos 3t + (-9B + 4B)\sin 3t = \cos 3t$

$-5A = 1$, $-5B = 0$

$A = - \frac{1}{5}$, $B = 0$

$x_p = - \frac{1}{5}\cos 3t$

**Amplitude**: $ \frac{1}{5}$

**Answer:** No resonance (forcing $\omega = 3 \neq 2 = \omega_0$), bounded amplitude $1/5$.

## RLC Circuits

**Series RLC circuit** with inductance $L$, resistance $R$, capacitance $C$, voltage $E(t)$:

Kirchhoff's voltage law: $L \frac{d^2q}{dt^2} + R\frac{dq}{dt} + \frac{q}{C} = E(t)$

where $q$ = charge, $I = dq/dt$ = current.

**Mechanical analogy**:
- $L$ ↔ mass $m$
- $R$ ↔ damping $\gamma$
- $1/C$ ↔ spring $k$
- $E(t)$ ↔ force $F(t)$

### Example 10: LC Circuit (No Resistance)

For $L = 1$ H, $C = 0.25$ F, $E = 0$, find charge if $q(0) = 1$ C, $I(0) = 0$.

**Solution:**

Equation: $q'' +  \frac{q}{0.25} = 0$

$q'' + 4q = 0$

$\omega_0 = 2$ rad/s

$q = c_1\cos 2t + c_2\sin 2t$

$q(0) = c_1 = 1$

$q' = -2\sin 2t + 2c_2\cos 2t$

$q'(0) = 2c_2 = 0$, so $c_2 = 0$

**Answer:** $q = \cos 2t$ coulombs (oscillates indefinitely, no damping)

### Example 11: RLC Circuit Damping

For $L = 1$, $R = 6$, $C = 1/8$, classify the circuit.

**Solution:**

Equation: $q'' + 6q' + 8q = 0$

Characteristic: $r^2 + 6r + 8 = (r+2)(r+4) = 0$

Roots: $r = -2, -4$ (real, distinct, negative)

**Overdamped** circuit (analogous to overdamped mechanical system)

**Answer:** Charge decays exponentially without oscillation.

### Example 12: Forced RLC Circuit

Solve $q'' + 2q' + q = \sin t$ with $q(0) = 0$, $q'(0) = 0$.

**Solution:**

**Homogeneous**: $(r+1)^2 = 0$, $r = -1$ (repeated)

$q_c = (c_1 + c_2t)e^{-t}$

**Particular**: Try $q_p = A\cos t + B\sin t$

$q_p' = -A\sin t + B\cos t$

$q_p'' = -A\cos t - B\sin t$

$(-A\cos t - B\sin t) + 2(-A\sin t + B\cos t) + (A\cos t + B\sin t) = \sin t$

$2B\cos t - 2A\sin t = \sin t$

$2B = 0$, $-2A = 1$

$A = - \frac{1}{2}$, $B = 0$

$q_p = - \frac{1}{2}\cos t$

General: $q = (c_1 + c_2t)e^{-t} -  \frac{1}{2}\cos t$

$q(0) = c_1 -  \frac{1}{2} = 0$, so $c_1 = \frac{1}{2}$

$q' = c_2e^{-t} - (c_1 + c_2t)e^{-t} +  \frac{1}{2}\sin t$

$q'(0) = c_2 - c_1 = 0$, so $c_2 =  \frac{1}{2}$

**Answer:** $q = \left( \frac{1}{2} + \frac{1}{2}t\right)e^{-t} - \frac{1}{2}\cos t$ coulombs

### Example 13: Physical Interpretation

In $x = e^{-t}(\cos 3t + \sin 3t)$, what is decay rate and oscillation frequency?

**Solution:**

Form: $x = e^{\alpha t}(c_1\cos\beta t + c_2\sin\beta t)$

Here $\alpha = -1$, $\beta = 3$

**Decay rate**: $|\alpha| = 1$ (amplitude decreases as $e^{-t}$)

**Oscillation frequency**: $\beta = 3$ rad/s

**Period**: $T =  \frac{2\pi}{3}$ seconds

**Answer:** Decays exponentially with time constant 1 second, oscillates 3 rad/s.

## Answer Key

**Problem 1: C**
From $mx'' + kx = 0$: $x'' + (k/m)x = 0$
Compare to $x'' + \omega_0^2 x = 0$
Natural frequency: $\omega_0 = \sqrt{k/m}$ rad/s
Period: $T = 2\pi/\omega_0 = 2\pi\sqrt{m/k}$

**Problem 2: B**
Characteristic: $mr^2 + \gamma r + k = 0$
Discriminant: $\Delta = \gamma^2 - 4mk$
Critical damping: $\Delta = 0$ (repeated root)
Thus $\gamma^2 = 4mk$ or $\gamma = 2\sqrt{mk}$ (critical damping coefficient)

**Problem 3: B**
Resonance: forcing frequency matches natural frequency
For $x'' + \omega_0^2 x = F_0\cos\omega t$:
Resonance when $\omega = \omega_0$
Results in solution with $t\sin\omega_0 t$ (amplitude grows)

**Problem 4: C**
Circuit: $Lq'' + Rq' + q/C = E(t)$
Mechanical: $mx'' + \gamma x' + kx = F(t)$
Correspondence: $L \leftrightarrow m$, $R \leftrightarrow \gamma$, $1/C \leftrightarrow k$
Resistance $R$ provides damping (dissipates energy)

**Problem 5: C**
$x'' + 9x = 0$ has $\omega_0^2 = 9$, so $\omega_0 = 3$ rad/s
Period: $T =  \frac{2\pi}{\omega_0} = \frac{2\pi}{3}$ seconds
This is time for one complete oscillation

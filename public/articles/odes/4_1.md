# ODE Topic 4.1: Definition and Properties of Laplace Transforms

Imagine solving a differential equation by transforming it into an algebraic equation, solving the algebra, then transforming back to get your answer. This is the power of the **Laplace transform**—it converts calculus problems into algebra problems. Instead of dealing with derivatives and integrals, you manipulate polynomials and rational functions.

The Laplace transform is an **integral transform** that takes a function $f(t)$ of time and produces a function $F(s)$ of a complex variable. The magic happens when you apply it to differential equations: derivatives become multiplications by $s$, initial conditions appear naturally, and convolution becomes multiplication. Engineers use Laplace transforms to analyze circuits, control systems, and signal processing. The transform turns transient problems (rockets launching, circuits switching on) into steady-state algebraic equations.

This article introduces the Laplace transform definition, develops its fundamental properties, and builds a library of standard transforms. We'll learn how derivatives transform (the key property for solving ODEs), how to handle translations and scaling, and how the transform interacts with periodic functions. By the end, you'll have a powerful toolkit for converting differential equations into algebraic form—the first step in the Laplace transform solution method.

## Definition of the Laplace Transform

For function $f(t)$ defined on $t \geq 0$:

**Laplace transform**:
$$\mathcal{L}\{f(t)\} = F(s) = \int_0^{\infty} e^{-st} f(t) \, dt$$

where $s$ is a complex variable (usually real and positive for convergence).

**Notation**: $\mathcal{L}\{f(t)\} = F(s)$ or $f(t) \xleftrightarrow{\mathcal{L}} F(s)$

The transform exists if the integral converges for some values of $s$.

### Example 1: Transform of Constant Function

Find $\mathcal{L}\{1\}$.

**Solution:**

$$\mathcal{L}\{1\} = \int_0^{\infty} e^{-st} \cdot 1 \, dt = \int_0^{\infty} e^{-st} \, dt$$

$$= \left[-\frac{1}{s}e^{-st}\right]_0^{\infty} = 0 - \left(-\frac{1}{s}\right) = \frac{1}{s}$$

(assuming $s > 0$ for convergence as $t \to \infty$)

**Answer:** $ \mathcal{L}\{1\} = \frac{1}{s}$ for $s > 0$

### Example 2: Transform of Exponential

Find $\mathcal{L}\{e^{at}\}$.

**Solution:**

$$\mathcal{L}\{e^{at}\} = \int_0^{\infty} e^{-st} e^{at} \, dt = \int_0^{\infty} e^{-(s-a)t} \, dt$$

$$= \left[-\frac{1}{s-a}e^{-(s-a)t}\right]_0^{\infty} = 0 - \left(-\frac{1}{s-a}\right) = \frac{1}{s-a}$$

(for $s > a$)

**Answer:** $ \mathcal{L}\{e^{at}\} = \frac{1}{s-a}$ for $s > a$

### Example 3: Transform of Power Function

Find $\mathcal{L}\{t\}$.

**Solution:**

$$\mathcal{L}\{t\} = \int_0^{\infty} e^{-st} t \, dt$$

Use integration by parts: $u = t$, $dv = e^{-st} dt$

$du = dt$, $v = - \frac{1}{s}e^{-st}$

$$= \left[-\frac{t}{s}e^{-st}\right]_0^{\infty} + \frac{1}{s}\int_0^{\infty} e^{-st} \, dt$$

First term: $ \lim_{t\to\infty} -\frac{t}{s}e^{-st} = 0$ (exponential dominates)

$$= 0 + \frac{1}{s} \cdot \frac{1}{s} = \frac{1}{s^2}$$

**Answer:** $ \mathcal{L}\{t\} = \frac{1}{s^2}$

### Example 4: Transform of $t^n$

Find $\mathcal{L}\{t^2\}$.

**Solution:**

Using repeated integration by parts (or formula):

$$\mathcal{L}\{t^n\} = \frac{n!}{s^{n+1}}$$

For $n = 2$:

$$\mathcal{L}\{t^2\} = \frac{2!}{s^3} = \frac{2}{s^3}$$

**Answer:** $ \mathcal{L}\{t^2\} = \frac{2}{s^3}$

**General formula**: $ \mathcal{L}\{t^n\} = \frac{n!}{s^{n+1}}$ for $n = 0, 1, 2, \ldots$

## Linearity Property

**Linearity**: $\mathcal{L}\{af(t) + bg(t)\} = a\mathcal{L}\{f(t)\} + b\mathcal{L}\{g(t)\}$

The Laplace transform is a **linear operator**.

### Example 5: Using Linearity

Find $\mathcal{L}\{3e^{2t} + 5t\}$.

**Solution:**

$$\mathcal{L}\{3e^{2t} + 5t\} = 3\mathcal{L}\{e^{2t}\} + 5\mathcal{L}\{t\}$$

$$= 3 \cdot \frac{1}{s-2} + 5 \cdot \frac{1}{s^2}$$

$$= \frac{3}{s-2} + \frac{5}{s^2}$$

**Answer:** $ \frac{3}{s-2} + \frac{5}{s^2}$

### Example 6: Transform of Polynomial

Find $\mathcal{L}\{t^2 + 4t + 3\}$.

**Solution:**

$$\mathcal{L}\{t^2 + 4t + 3\} = \mathcal{L}\{t^2\} + 4\mathcal{L}\{t\} + 3\mathcal{L}\{1\}$$

$$= \frac{2}{s^3} + 4 \cdot \frac{1}{s^2} + 3 \cdot \frac{1}{s}$$

$$= \frac{2}{s^3} + \frac{4}{s^2} + \frac{3}{s}$$

**Answer:** $ \frac{2}{s^3} + \frac{4}{s^2} + \frac{3}{s}$

## Transform of Trigonometric Functions

**Sine**: $ \mathcal{L}\{\sin at\} = \frac{a}{s^2 + a^2}$

**Cosine**: $ \mathcal{L}\{\cos at\} = \frac{s}{s^2 + a^2}$

### Example 7: Deriving Sine Transform

Find $\mathcal{L}\{\sin t\}$ from definition.

**Solution:**

$$\mathcal{L}\{\sin t\} = \int_0^{\infty} e^{-st} \sin t \, dt$$

Use integration by parts twice (or Euler's formula):

Using $\sin t =  \frac{e^{it} - e^{-it}}{2i}$:

$$\mathcal{L}\{\sin t\} = \frac{1}{2i}\left[\mathcal{L}\{e^{it}\} - \mathcal{L}\{e^{-it}\}\right]$$

$$= \frac{1}{2i}\left[\frac{1}{s-i} - \frac{1}{s+i}\right] = \frac{1}{2i} \cdot \frac{(s+i) - (s-i)}{s^2+1}$$

$$= \frac{1}{2i} \cdot \frac{2i}{s^2+1} = \frac{1}{s^2+1}$$

**Answer:** $ \mathcal{L}\{\sin t\} = \frac{1}{s^2+1}$

### Example 8: Cosine Transform

Find $\mathcal{L}\{\cos 3t\}$.

**Solution:**

Using formula with $a = 3$:

$$\mathcal{L}\{\cos 3t\} = \frac{s}{s^2 + 9}$$

**Answer:** $ \frac{s}{s^2 + 9}$

## Transform of Derivatives

**Key property for solving ODEs**:

$$\mathcal{L}\{f'(t)\} = s\mathcal{L}\{f(t)\} - f(0) = sF(s) - f(0)$$

$$\mathcal{L}\{f''(t)\} = s^2F(s) - sf(0) - f'(0)$$

**General**: $ \mathcal{L}\{f^{(n)}(t)\} = s^nF(s) - s^{n-1}f(0) - s^{n-2}f'(0) - \cdots - f^{(n-1)}(0)$

### Example 9: Transform of First Derivative

If $\mathcal{L}\{f(t)\} =  \frac{1}{s^2+1}$ and $f(0) = 0$, find $\mathcal{L}\{f'(t)\}$.

**Solution:**

$$\mathcal{L}\{f'(t)\} = sF(s) - f(0) = s \cdot \frac{1}{s^2+1} - 0 = \frac{s}{s^2+1}$$

**Answer:** $ \frac{s}{s^2+1}$

(Note: $f(t) = \sin t$, so $f'(t) = \cos t$, which matches!)

### Example 10: Second Derivative

If $\mathcal{L}\{y(t)\} = Y(s)$, $y(0) = 1$, $y'(0) = -2$, find $\mathcal{L}\{y''(t)\}$.

**Solution:**

$$\mathcal{L}\{y''(t)\} = s^2Y(s) - sy(0) - y'(0)$$

$$= s^2Y(s) - s(1) - (-2) = s^2Y(s) - s + 2$$

**Answer:** $s^2Y(s) - s + 2$

## First Translation Theorem (s-shift)

**Theorem**: $\mathcal{L}\{e^{at}f(t)\} = F(s-a)$

Multiplying by $e^{at}$ shifts $s$ to $s - a$ in transform.

### Example 11: Using s-shift

Find $\mathcal{L}\{e^{3t}\sin 2t\}$.

**Solution:**

We know $ \mathcal{L}\{\sin 2t\} = \frac{2}{s^2+4}$

Using s-shift with $a = 3$:

$$\mathcal{L}\{e^{3t}\sin 2t\} = \frac{2}{(s-3)^2+4}$$

**Answer:** $ \frac{2}{(s-3)^2+4}$

### Example 12: Another s-shift Example

Find $\mathcal{L}\{e^{-2t}\cos 4t\}$.

**Solution:**

$ \mathcal{L}\{\cos 4t\} = \frac{s}{s^2+16}$

With $a = -2$:

$$\mathcal{L}\{e^{-2t}\cos 4t\} = \frac{s-(-2)}{(s-(-2))^2+16} = \frac{s+2}{(s+2)^2+16}$$

**Answer:** $ \frac{s+2}{(s+2)^2+16}$

## Table of Common Transforms

| $f(t)$ | $F(s) = \mathcal{L}\{f(t)\}$ | Conditions |
|--------|------------------------------|------------|
| $1$ | $ \frac{1}{s}$ | $s > 0$ |
| $t^n$ | $ \frac{n!}{s^{n+1}}$ | $s > 0$ |
| $e^{at}$ | $ \frac{1}{s-a}$ | $s > a$ |
| $\sin at$ | $ \frac{a}{s^2+a^2}$ | $s > 0$ |
| $\cos at$ | $ \frac{s}{s^2+a^2}$ | $s > 0$ |
| $\sinh at$ | $ \frac{a}{s^2-a^2}$ | $s > |a|$ |
| $\cosh at$ | $ \frac{s}{s^2-a^2}$ | $s > |a|$ |
| $e^{at}\sin bt$ | $ \frac{b}{(s-a)^2+b^2}$ | $s > a$ |
| $e^{at}\cos bt$ | $ \frac{s-a}{(s-a)^2+b^2}$ | $s > a$ |
| $t^ne^{at}$ | $ \frac{n!}{(s-a)^{n+1}}$ | $s > a$ |

### Example 13: Using Transform Table

Find $\mathcal{L}\{t^3e^{-t} + 2\sinh 2t\}$.

**Solution:**

Using table:

$$\mathcal{L}\{t^3e^{-t}\} = \frac{3!}{(s-(-1))^4} = \frac{6}{(s+1)^4}$$

$$\mathcal{L}\{2\sinh 2t\} = 2 \cdot \frac{2}{s^2-4} = \frac{4}{s^2-4}$$

By linearity:

$$\mathcal{L}\{t^3e^{-t} + 2\sinh 2t\} = \frac{6}{(s+1)^4} + \frac{4}{s^2-4}$$

**Answer:** $ \frac{6}{(s+1)^4} + \frac{4}{s^2-4}$

## Practice Problems

**Problem 1:** $\mathcal{L}\{5t^2\} = $

A) $ \frac{10}{s^2}$

B) $ \frac{10}{s^3}$

C) $ \frac{5}{s^3}$

D) $ \frac{2}{s^3}$

E) $ \frac{5}{s^2}$

**Problem 2:** $\mathcal{L}\{e^{4t}\} = $

A) $ \frac{1}{s+4}$

B) $ \frac{1}{s-4}$

C) $ \frac{4}{s}$

D) $e^{4s}$

E) $ \frac{s}{s-4}$

**Problem 3:** If $\mathcal{L}\{f(t)\} = F(s)$ and $f(0) = 3$, then $\mathcal{L}\{f'(t)\} = $

A) $sF(s)$

B) $F(s) - 3$

C) $sF(s) - 3$

D) $ \frac{F(s)}{s}$

E) $sF(s) + 3$

**Problem 4:** $\mathcal{L}\{\sin 5t\} = $

A) $ \frac{1}{s^2+25}$

B) $ \frac{s}{s^2+25}$

C) $ \frac{5}{s^2+25}$

D) $ \frac{5}{s^2+5}$

E) $ \frac{1}{s^2+5}$

**Problem 5:** $\mathcal{L}\{e^{2t}\cos 3t\} = $

A) $ \frac{s-2}{(s-2)^2+9}$

B) $ \frac{s+2}{(s+2)^2+9}$

C) $ \frac{3}{(s-2)^2+9}$

D) $ \frac{s}{s^2+9}$

E) $ \frac{2}{s^2+9}$

## Answer Key

**Problem 1: B**
$\mathcal{L}\{t^n\} =  \frac{n!}{s^{n+1}}$
For $n = 2$: $\mathcal{L}\{t^2\} =  \frac{2!}{s^3} = \frac{2}{s^3}$
By linearity: $\mathcal{L}\{5t^2\} = 5 \cdot  \frac{2}{s^3} = \frac{10}{s^3}$

**Problem 2: B**
$\mathcal{L}\{e^{at}\} =  \frac{1}{s-a}$
For $a = 4$: $\mathcal{L}\{e^{4t}\} =  \frac{1}{s-4}$
Valid for $s > 4$ (convergence condition)

**Problem 3: C**
Transform of derivative: $\mathcal{L}\{f'(t)\} = sF(s) - f(0)$
Given $f(0) = 3$: $\mathcal{L}\{f'(t)\} = sF(s) - 3$
Initial condition appears automatically in transform

**Problem 4: C**
$\mathcal{L}\{\sin at\} =  \frac{a}{s^2+a^2}$
For $a = 5$: $\mathcal{L}\{\sin 5t\} =  \frac{5}{s^2+25}$
Note: numerator is $a$, not 1 or $s$

**Problem 5: A**
First translation theorem: $\mathcal{L}\{e^{at}f(t)\} = F(s-a)$
$\mathcal{L}\{\cos 3t\} =  \frac{s}{s^2+9}$
With $a = 2$, replace $s$ with $s-2$:
$\mathcal{L}\{e^{2t}\cos 3t\} =  \frac{s-2}{(s-2)^2+9}$

# ODE Topic 3.2: Phase Plane Analysis

Imagine tracking a pendulum's motion. At each moment, you know two things: position and velocity. These two numbers $(x, v)$ define a point in the **phase plane**. As time evolves, this point traces a curve—a **trajectory** showing how the system moves through all possible states. Some trajectories spiral inward to a stable equilibrium. Others spiral outward. Some orbit forever in closed loops.

Phase plane analysis visualizes dynamics geometrically rather than algebraically. Instead of formulas, we see pictures. The **phase portrait** shows all possible trajectories, revealing at a glance whether solutions converge, diverge, or oscillate. Equilibrium points—where $\vec{x}' = \vec{0}$—are the stars of this geometric show. Their stability determines long-term behavior.

This article develops phase plane analysis for $2 \times 2$ linear systems. We'll learn to classify equilibrium points (nodes, saddles, spirals, centers) based on eigenvalues. The **trace-determinant plane** provides a complete classification diagram. These geometric insights extend to nonlinear systems through linearization, making phase plane analysis an essential tool for understanding any dynamic system.

## Phase Plane Basics

For $2 \times 2$ system $\vec{x}' = A\vec{x}$ with $ \vec{x} = \begin{bmatrix} x \\ y \end{bmatrix}$:

**Phase plane**: The $x$-$y$ plane (not $t$-$x$!)

**Trajectory**: Curve traced by $\vec{x}(t)$ as $t$ varies

**Equilibrium point**: Point $\vec{x}_0$ where $A\vec{x}_0 = \vec{0}$ (so $\vec{x}' = \vec{0}$)

For linear systems, only equilibrium is origin (assuming $\det A \neq 0$).

### Example 1: Computing Trajectories

For $ \vec{x} = c_1\begin{bmatrix} 1 \\ 1 \end{bmatrix}e^{3t} + c_2\begin{bmatrix} 1 \\ -1 \end{bmatrix}e^{-t}$ with $c_1 = 1$, $c_2 = 0$, describe trajectory.

**Solution:**

$$\vec{x}(t) = \begin{bmatrix} 1 \\ 1 \end{bmatrix}e^{3t} = \begin{bmatrix} e^{3t} \\ e^{3t} \end{bmatrix}$$

So $x(t) = e^{3t}$ and $y(t) = e^{3t}$

Thus $y = x$ (trajectory is ray $y = x$ from origin)

As $t \to \infty$: both $x, y \to \infty$ along this ray

As $t \to -\infty$: both $x, y \to 0$ (approaching origin)

**Answer:** Straight line $y = x$, moving away from origin exponentially.

### Example 2: Another Trajectory

Same system, $c_1 = 0$, $c_2 = 1$.

**Solution:**

$$\vec{x}(t) = \begin{bmatrix} 1 \\ -1 \end{bmatrix}e^{-t} = \begin{bmatrix} e^{-t} \\ -e^{-t} \end{bmatrix}$$

$x = e^{-t}$, $y = -e^{-t}$

$y = -x$ (ray $y = -x$ from origin)

As $t \to \infty$: $x, y \to 0$ (approaching origin)

As $t \to -\infty$: moving away from origin

**Answer:** Straight line $y = -x$, moving toward origin exponentially.

## Classification by Eigenvalues

For $2 \times 2$ system, equilibrium type depends on eigenvalues $\lambda_1, \lambda_2$:

**Real eigenvalues**:
- Both negative → **stable node** (all trajectories approach origin)
- Both positive → **unstable node** (all trajectories leave origin)
- Opposite signs → **saddle point** (unstable, hyperbolic)

**Complex eigenvalues** $\alpha \pm i\beta$:
- $\alpha < 0$ → **stable spiral** (spiral inward)
- $\alpha > 0$ → **unstable spiral** (spiral outward)
- $\alpha = 0$ → **center** (closed orbits, neutrally stable)

### Example 3: Classifying Equilibria

Classify equilibrium at origin for each:

(a) $\lambda_1 = -2$, $\lambda_2 = -5$

(b) $\lambda_1 = 3$, $\lambda_2 = 1$

(c) $\lambda_1 = 2$, $\lambda_2 = -3$

(d) $\lambda = -1 \pm 2i$

**Solution:**

(a) Both negative → **stable node**

(b) Both positive → **unstable node**

(c) Opposite signs → **saddle point**

(d) Complex with $\alpha = -1 < 0$ → **stable spiral**

**Answer:** (a) stable node, (b) unstable node, (c) saddle, (d) stable spiral

### Example 4: Determining Type from Matrix

For $ A = \begin{bmatrix} -1 & 2 \\ -2 & -1 \end{bmatrix}$, classify equilibrium.

**Solution:**

Eigenvalues: $\det(A - \lambda I) = (-1-\lambda)^2 + 4 = \lambda^2 + 2\lambda + 5 = 0$

$$\lambda = \frac{-2 \pm \sqrt{4-20}}{2} = -1 \pm 2i$$

Complex with $\alpha = -1 < 0$

**Answer:** Stable spiral (inward spiraling trajectories).

## Nodes and Saddle Points

**Node**: Both eigenvalues real, same sign

Trajectories approach (stable) or leave (unstable) origin along eigenvector directions.

**Saddle**: Real eigenvalues, opposite signs

Some trajectories approach origin (along stable eigendirection), others leave (along unstable eigendirection).

### Example 5: Node Behavior

For $ A = \begin{bmatrix} -3 & 0 \\ 0 & -1 \end{bmatrix}$, describe phase portrait.

**Solution:**

Diagonal matrix: eigenvalues $\lambda_1 = -3$, $\lambda_2 = -1$ (both negative)

Eigenvectors: $ \vec{v}_1 = \begin{bmatrix} 1 \\ 0 \end{bmatrix}$, $ \vec{v}_2 = \begin{bmatrix} 0 \\ 1 \end{bmatrix}$

**Stable node**

General solution: $x = c_1e^{-3t}$, $y = c_2e^{-t}$

For $c_1 = 1, c_2 = 0$: horizontal approach along $x$-axis

For $c_1 = 0, c_2 = 1$: vertical approach along $y$-axis

For general $c_1, c_2$: curved approach (faster decay in $x$-direction)

**Answer:** All trajectories approach origin, primarily tangent to slower eigendirection ($y$-axis).

### Example 6: Saddle Point

For $ A = \begin{bmatrix} 1 & 0 \\ 0 & -2 \end{bmatrix}$, describe phase portrait.

**Solution:**

Eigenvalues: $\lambda_1 = 1$ (positive), $\lambda_2 = -2$ (negative)

**Saddle point** (opposite signs!)

$ \vec{v}_1 = \begin{bmatrix} 1 \\ 0 \end{bmatrix}$ (unstable eigendirection)

$ \vec{v}_2 = \begin{bmatrix} 0 \\ 1 \end{bmatrix}$ (stable eigendirection)

**Stable manifold**: $y$-axis (trajectories approach origin along this)

**Unstable manifold**: $x$-axis (trajectories leave origin along this)

Most trajectories approach along $y$-axis, then curve away along $x$-axis.

**Answer:** Saddle—hyperbolic equilibrium with stable and unstable directions.

## Spirals and Centers

**Spiral**: Complex eigenvalues with $\alpha \neq 0$

Trajectories spiral around origin, either inward ($\alpha < 0$) or outward ($\alpha > 0$).

**Center**: Pure imaginary eigenvalues ($\alpha = 0$)

Trajectories are closed orbits (ellipses).

### Example 7: Stable Spiral

For $ A = \begin{bmatrix} -1 & 2 \\ -2 & -1 \end{bmatrix}$, sketch typical trajectory.

**Solution:**

From Example 4: $\lambda = -1 \pm 2i$ (stable spiral)

Solutions: $e^{-t}(\text{oscillations with frequency } 2)$

Trajectory spirals counterclockwise (determined by matrix structure) inward toward origin.

**Period of one spiral**: $T =  \frac{2\pi}{\beta} = \frac{2\pi}{2} = \pi$

**Answer:** Counterclockwise spiral with period $\pi$, exponentially decaying.

### Example 8: Center

For $ A = \begin{bmatrix} 0 & 1 \\ -4 & 0 \end{bmatrix}$, describe motion.

**Solution:**

$\det\begin{bmatrix} -\lambda & 1 \\ -4 & -\lambda \end{bmatrix} = \lambda^2 + 4 = 0$

$\lambda = \pm 2i$ (pure imaginary!)

**Center**

Solutions oscillate with frequency 2, no growth or decay.

Trajectories are ellipses around origin.

**Answer:** Center with period $\pi$ (neutrally stable—bounded but not asymptotically stable).

## Trace-Determinant Classification

For $ A = \begin{bmatrix} a & b \\ c & d \end{bmatrix}$:

**Trace**: $\tau = a + d$ (sum of eigenvalues)

**Determinant**: $\Delta = ad - bc$ (product of eigenvalues)

**Discriminant**: $D = \tau^2 - 4\Delta$

Classification:
- $\Delta < 0$: **saddle**
- $\Delta > 0$, $D > 0$, $\tau < 0$: **stable node**
- $\Delta > 0$, $D > 0$, $\tau > 0$: **unstable node**
- $\Delta > 0$, $D < 0$, $\tau < 0$: **stable spiral**
- $\Delta > 0$, $D < 0$, $\tau > 0$: **unstable spiral**
- $\Delta > 0$, $D = 0$: **borderline** (degenerate node or spiral)
- $\Delta > 0$, $\tau = 0$: **center**

### Example 9: Using Trace-Determinant

For $ A = \begin{bmatrix} 1 & 3 \\ 3 & 1 \end{bmatrix}$, classify without finding eigenvalues.

**Solution:**

$\tau = 1 + 1 = 2$

$\Delta = 1 \cdot 1 - 3 \cdot 3 = 1 - 9 = -8 < 0$

Since $\Delta < 0$: **saddle point**

(Can verify: $\det(A-\lambda I) = (1-\lambda)^2 - 9 = \lambda^2 - 2\lambda - 8 = 0$ gives $\lambda = 4, -2$, opposite signs ✓)

**Answer:** Saddle (determinant negative means opposite-sign eigenvalues).

### Example 10: Trace-Determinant for Spiral

For $ A = \begin{bmatrix} -2 & 5 \\ -5 & -2 \end{bmatrix}$, classify.

**Solution:**

$\tau = -2 + (-2) = -4 < 0$

$\Delta = (-2)(-2) - (5)(-5) = 4 + 25 = 29 > 0$

$D = \tau^2 - 4\Delta = 16 - 116 = -100 < 0$

$\Delta > 0$, $D < 0$, $\tau < 0$ → **stable spiral**

**Answer:** Stable spiral (complex eigenvalues with negative real part).

## Sketching Phase Portraits

**Steps**:
1. Find eigenvalues and classify equilibrium
2. Find eigenvectors (for real eigenvalues)
3. Draw eigendirections
4. Add typical trajectories based on type

### Example 11: Complete Phase Portrait

Sketch phase portrait for $ A = \begin{bmatrix} -2 & 0 \\ 0 & 1 \end{bmatrix}$.

**Solution:**

**Eigenvalues**: $\lambda_1 = -2$, $\lambda_2 = 1$ → **saddle**

**Eigenvectors**: $ \vec{v}_1 = \begin{bmatrix} 1 \\ 0 \end{bmatrix}$ (stable), $ \vec{v}_2 = \begin{bmatrix} 0 \\ 1 \end{bmatrix}$ (unstable)

**Sketch**:
- Draw $x$-axis (stable manifold): trajectories approach origin along this
- Draw $y$-axis (unstable manifold): trajectories leave origin along this
- Other trajectories: approach along $x$-axis direction, then curve away along $y$-axis direction

**Answer:** Saddle with horizontal stable manifold, vertical unstable manifold.

### Example 12: Application - Predator-Prey Linearization

Lotka-Volterra model linearized at equilibrium gives:
$$\vec{x}' = \begin{bmatrix} 0 & -a \\ b & 0 \end{bmatrix}\vec{x}$$

where $a, b > 0$. Classify equilibrium.

**Solution:**

$\tau = 0 + 0 = 0$

$\Delta = 0 \cdot 0 - (-a)(b) = ab > 0$

$\tau = 0$ and $\Delta > 0$ → **center**

Eigenvalues: $\lambda^2 + ab = 0$, so $\lambda = \pm i\sqrt{ab}$ (pure imaginary) ✓

**Answer:** Center—predator-prey oscillate in closed cycles (population cycles).

A) Decaying oscillations
B) Growing oscillations

A) Stable node
B) Unstable node
C) Saddle
D) Spiral
E) Center

## Answer Key

**Problem 1: C**
Phase plane: $(x, y)$ where $x, y$ are state variables
Horizontal axis: $x(t)$
Vertical axis: $y(t)$
NOT $(t, x)$ which would be time series plot
Trajectory shows path through state space as $t$ varies.

**Problem 2: C**
Saddle: one positive, one negative eigenvalue
Stable manifold (negative eigenvalue): trajectories approach
Unstable manifold (positive eigenvalue): trajectories leave
Hyperbolic equilibrium point.

**Problem 3: C**
Spiral: complex eigenvalues $\alpha \pm i\beta$
Stable: $\alpha < 0$ (decay factor $e^{\alpha t}$ with $\alpha < 0$)
Unstable: $\alpha > 0$
Imaginary part $\beta$ determines oscillation frequency.

**Problem 4: C**
Center: pure imaginary eigenvalues ($\alpha = 0$)
Solutions: periodic (sine/cosine without exponential factor)
Trajectories: closed elliptical orbits
Neutrally stable (bounded but not asymptotically stable).

**Problem 5: C**
Determinant = product of eigenvalues
$\det A < 0$ → $\lambda_1 \lambda_2 < 0$ → opposite signs
Opposite sign eigenvalues → saddle point
Always unstable (has unstable manifold).

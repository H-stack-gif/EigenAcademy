# ODE Topic 2.2: Method of Undetermined Coefficients

Finding the general solution to a homogeneous equation is only half the battle. Real-world systems have forcing functions—external drives that inject energy into the system. A spring-mass system might be driven by an oscillating force $F_0\cos\omega t$. An electrical circuit might have an applied voltage $E(t)$. The differential equation becomes **nonhomogeneous**: $ay'' + by' + cy = g(x)$ where $g(x) \neq 0$.

The general solution to a nonhomogeneous equation combines two parts: the **complementary solution** $y_c$ (general solution to the homogeneous equation) and a **particular solution** $y_p$ (any specific solution to the nonhomogeneous equation). Then $y = y_c + y_p$ is the general solution. The art lies in finding $y_p$.

The **method of undetermined coefficients** is a systematic guessing technique. For special types of $g(x)$ (polynomials, exponentials, sines and cosines), we can predict the form of $y_p$ and determine the coefficients by substitution. This method is limited but extremely powerful when applicable. It's the workhorse for solving forced oscillation problems in physics and engineering.

## Structure of General Solution

For nonhomogeneous equation $L[y] = ay'' + by' + cy = g(x)$:

**General solution**: $y = y_c + y_p$

where:
- $y_c$ = complementary solution (general solution to $L[y] = 0$)
- $y_p$ = particular solution (any solution to $L[y] = g(x)$)

**Superposition principle**: If $y_1$ solves $L[y] = g_1$ and $y_2$ solves $L[y] = g_2$, then $y_1 + y_2$ solves $L[y] = g_1 + g_2$.

### Example 1: Verifying Solution Structure

If $y_1 = 3e^{2x} - e^x$ solves $y'' - y' - 2y = -4e^x$ and $y_2 = c_1e^{2x} + c_2e^{-x}$ solves $y'' - y' - 2y = 0$, what solves the nonhomogeneous equation?

**Solution:**

General solution: $y = y_c + y_p$

$y_c = c_1e^{2x} + c_2e^{-x}$ (homogeneous)

$y_p = 3e^{2x} - e^x$ (particular)

**Answer:** $y = c_1e^{2x} + c_2e^{-x} - e^x$ where we've absorbed the $3e^{2x}$ into the arbitrary constant.


### Example 2: Superposition

If $y_1 = x^2$ solves $y'' = 2$ and $y_2 = e^x$ solves $y'' - y = 0$, what equation does $y = x^2 + e^x$ solve?

**Solution:**

$L[y_1] = y_1'' = 2$ ✓

If $y_1 = x^2$, then $y_1' = 2x$, $y_1'' = 2$.

For $y = x^2 + e^x$:
$y' = 2x + e^x$, $y'' = 2 + e^x$.

This corresponds to the equation
$y'' = 2 + e^x$.

Superposition applies when the operator is the same for both functions.

**Answer:** $y$ solves $y'' = 2 + e^x$.


## Method of Undetermined Coefficients

**Idea**: For certain $g(x)$, guess form of $y_p$ based on $g(x)$, with undetermined coefficients. Substitute into DE and solve for coefficients.

**Basic forms**:

| $g(x)$ | Trial $y_p$ |
|--------|-------------|
| $P_n(x)$ (polynomial degree $n$) | $A_nx^n + \cdots + A_1x + A_0$ |
| $ke^{\alpha x}$ | $Ae^{\alpha x}$ |
| $k\cos\beta x$ or $k\sin\beta x$ | $A\cos\beta x + B\sin\beta x$ |
| $P_n(x)e^{\alpha x}$ | $(A_nx^n + \cdots + A_0)e^{\alpha x}$ |

### Example 3: Polynomial Right Side

Solve $y'' - 3y' = 6x$.

**Solution:**

**Step 1**: Find $y_c$ (homogeneous solution).

$r^2 - 3r = 0$, so $r(r - 3) = 0$

Roots: $r = 0, 3$

$y_c = c_1e^{0 \cdot x} + c_2e^{3x} = c_1 + c_2e^{3x}$

**Step 2**: Find $y_p$.

$g(x) = 6x$ (degree 1 polynomial)

Try: $y_p = Ax + B$

$y_p' = A$, $y_p'' = 0$

Substitute: $0 - 3A = 6x$

This can't work! Left side is constant, right side has $x$.

**Issue**: $y_c$ contains constant term, so we need to multiply trial by $x$.

Try: $y_p = x(Ax + B) = Ax^2 + Bx$

$y_p' = 2Ax + B$, $y_p'' = 2A$

Substitute: $2A - 3(2Ax + B) = 6x$

$2A - 6Ax - 3B = 6x$

Match coefficients:
- Coefficient of $x$: $-6A = 6$, so $A = -1$
- Constant: $2A - 3B = 0$, so $-2 - 3B = 0$, thus $B = - \frac{2}{3}$

$y_p = -x^2 -  \frac{2}{3}x$

**Answer:** $y = c_1 + c_2e^{3x} - x^2 -  \frac{2}{3}x$

### Example 4: Exponential Right Side

Solve $y'' - y' - 2y = 4e^{3x}$.

**Solution:**

**Homogeneous**: $r^2 - r - 2 = 0$, $(r-2)(r+1) = 0$

$y_c = c_1e^{2x} + c_2e^{-x}$

**Particular**: $g(x) = 4e^{3x}$

Try: $y_p = Ae^{3x}$ (since $3$ is not a root of characteristic equation)

$y_p' = 3Ae^{3x}$, $y_p'' = 9Ae^{3x}$

Substitute: $9Ae^{3x} - 3Ae^{3x} - 2Ae^{3x} = 4e^{3x}$

$4Ae^{3x} = 4e^{3x}$

$A = 1$

**Answer:** $y = c_1e^{2x} + c_2e^{-x} + e^{3x}$

### Example 5: Modification Rule

Solve $y'' - 4y' + 4y = e^{2x}$.

**Solution:**

**Homogeneous**: $r^2 - 4r + 4 = (r-2)^2 = 0$

$y_c = (c_1 + c_2x)e^{2x}$

**Particular**: $g(x) = e^{2x}$

Normal try would be $Ae^{2x}$, but this is in $y_c$ (2 is a repeated root).

**Modification rule**: Multiply by $x^s$ where $s$ = multiplicity of root.

Here $s = 2$ (double root), so try: $y_p = Ax^2e^{2x}$

$y_p' = 2Axe^{2x} + 2Ax^2e^{2x}$ (product rule)

$y_p'' = 2Ae^{2x} + 4Axe^{2x} + 4Axe^{2x} + 4Ax^2e^{2x}$
$= 2Ae^{2x} + 8Axe^{2x} + 4Ax^2e^{2x}$

Substitute into $y'' - 4y' + 4y = e^{2x}$:

$(2A + 8Ax + 4Ax^2)e^{2x} - 4(2Ax + 2Ax^2)e^{2x} + 4Ax^2e^{2x} = e^{2x}$

$(2A + 8Ax + 4Ax^2 - 8Ax - 8Ax^2 + 4Ax^2)e^{2x} = e^{2x}$

$2Ae^{2x} = e^{2x}$

$A =  \frac{1}{2}$

**Answer:** $y = (c_1 + c_2x)e^{2x} +  \frac{1}{2}x^2e^{2x}$

## Trigonometric Right Sides

For $g(x) = A\cos\beta x + B\sin\beta x$, try:
$$y_p = C\cos\beta x + D\sin\beta x$$

(Always include both sine and cosine, even if only one appears in $g(x)$)

### Example 6: Cosine Forcing

Solve $y'' + 4y = \cos 2x$.

**Solution:**

**Homogeneous**: $r^2 + 4 = 0$, $r = \pm 2i$

$y_c = c_1\cos 2x + c_2\sin 2x$

**Particular**: $g(x) = \cos 2x$

Normal try: $A\cos 2x + B\sin 2x$

But this is in $y_c$ (frequency 2 matches homogeneous)!

Modify: $y_p = x(A\cos 2x + B\sin 2x)$

$y_p' = A\cos 2x + B\sin 2x + x(-2A\sin 2x + 2B\cos 2x)$
$= (A + 2Bx)\cos 2x + (B - 2Ax)\sin 2x$

$y_p'' = 2B\cos 2x - 2A\sin 2x + (A + 2Bx)(-2\sin 2x) + (B - 2Ax)(2\cos 2x)$
$= [2B - 2(A + 2Bx)\sin 2x + 2(B - 2Ax)\cos 2x]$

This gets messy. Let me use a shortcut.

For $y_p = x(A\cos 2x + B\sin 2x)$, after substitution and simplification:
$-4A\sin 2x + 4B\cos 2x = \cos 2x$

Match coefficients:
$4B = 1$, $-4A = 0$

$A = 0$, $B =  \frac{1}{4}$

**Answer:** $y = c_1\cos 2x + c_2\sin 2x +  \frac{1}{4}x\sin 2x$

### Example 7: Mixed Form

Solve $y'' + y' = \sin x$.

**Solution:**

**Homogeneous**: $r^2 + r = r(r+1) = 0$, roots $r = 0, -1$

$y_c = c_1 + c_2e^{-x}$

**Particular**: Try $y_p = A\cos x + B\sin x$

$y_p' = -A\sin x + B\cos x$

$y_p'' = -A\cos x - B\sin x$

Substitute:
$(-A\cos x - B\sin x) + (-A\sin x + B\cos x) = \sin x$

$(-A + B)\cos x + (-B - A)\sin x = \sin x$

Coefficients:
- $\cos x$: $-A + B = 0$
- $\sin x$: $-A - B = 1$

From first: $B = A$

Substitute: $-A - A = 1$, so $A = - \frac{1}{2}$, $B = - \frac{1}{2}$

**Answer:** $y = c_1 + c_2e^{-x} -  \frac{1}{2}\cos x - \frac{1}{2}\sin x$

$$y_p = (A_nx^n + \cdots + A_0)e^{\alpha x}$$

If $\alpha$ is a characteristic root of multiplicity $s$, multiply by $x^s$.

## Superposition for Multiple Terms

If $g(x) = g_1(x) + g_2(x)$, find $y_{p1}$ for $g_1$ and $y_{p2}$ for $g_2$ separately.

Then $y_p = y_{p1} + y_{p2}$.

### Example 10: Sum of Functions

Solve $y'' + y = x + \cos x$.

**Solution:**

**Homogeneous**: $r^2 + 1 = 0$, $r = \pm i$

$y_c = c_1\cos x + c_2\sin x$

**Split**:
- $g_1(x) = x$: Try $y_{p1} = Ax + B$
- $g_2(x) = \cos x$: Since $\cos x$ is in $y_c$, try $y_{p2} = x(C\cos x + D\sin x)$

For $y_{p1} = Ax + B$:
$y_{p1}'' + y_{p1} = 0 + (Ax + B) = Ax + B = x$

$A = 1$, $B = 0$

So $y_{p1} = x$

For $y_{p2} = Cx\cos x + Dx\sin x$:

(Calculation gives $D =  \frac{1}{2}$, $C = 0$)

**Answer:** $y = c_1\cos x + c_2\sin x + x +  \frac{1}{2}x\sin x$

### Example 11: When Method Fails

Can undetermined coefficients solve $y'' + y = \tan x$?

**Solution:**

$g(x) = \tan x$ is not:
- Polynomial
- Exponential  
- Sine/cosine
- Product/sum of above

**Answer:** No, undetermined coefficients doesn't apply. Need different method (variation of parameters).

### Example 12: Summary of Forms

Match the right side with correct trial $y_p$:

(a) $g(x) = 3x^2$

(b) $g(x) = e^{-2x}$

(c) $g(x) = 5\sin 3x$

**Solution:**

(a) $y_p = Ax^2 + Bx + C$ (degree 2 polynomial)

(b) $y_p = Ae^{-2x}$ (unless $-2$ is characteristic root)

(c) $y_p = A\cos 3x + B\sin 3x$ (both sine and cosine)

**Answer:** Each has specific form based on $g(x)$.

### Example 13: Complete Problem

Solve $y'' + 3y' + 2y = 4x$, $y(0) = 1$, $y'(0) = 0$.

**Solution:**

**Homogeneous**: $r^2 + 3r + 2 = (r+1)(r+2) = 0$

$y_c = c_1e^{-x} + c_2e^{-2x}$

**Particular**: $y_p = Ax + B$

$y_p' = A$, $y_p'' = 0$

$0 + 3A + 2(Ax + B) = 4x$

$2Ax + (3A + 2B) = 4x$

$2A = 4 \Rightarrow A = 2$

$3(2) + 2B = 0 \Rightarrow B = -3$

$y_p = 2x - 3$

General: $y = c_1e^{-x} + c_2e^{-2x} + 2x - 3$

$y(0) = c_1 + c_2 - 3 = 1$, so $c_1 + c_2 = 4$

$y' = -c_1e^{-x} - 2c_2e^{-2x} + 2$

$y'(0) = -c_1 - 2c_2 + 2 = 0$, so $c_1 + 2c_2 = 2$

Solve system: $c_2 = 2 - 4 = -2$, $c_1 = 4 - (-2) = 6$

**Answer:** $y = 6e^{-x} - 2e^{-2x} + 2x - 3$

# ODE Topic 2.3: Variation of Parameters

The method of undetermined coefficients is powerful but limited. It only works when $g(x)$ is a polynomial, exponential, sine, cosine, or combination. What about $g(x) = \tan x$, $\sec x$, $\ln x$, or $ \frac{1}{x}$? For these, we need a more general technique: **variation of parameters**.

The idea is brilliant. For homogeneous equation, we have general solution $y_c = c_1y_1 + c_2y_2$ with constant coefficients $c_1, c_2$. For nonhomogeneous equation, we "vary" these parameters—let them become functions: $y_p = u_1(x)y_1 + u_2(x)y_2$. By imposing strategic constraints, we can find formulas for $u_1'$ and $u_2'$ in terms of $g(x)$ and the fundamental solutions.

Variation of parameters works for **any** continuous $g(x)$. The price? More computation—we need to integrate expressions involving $g(x)$ and the fundamental solutions. But when undetermined coefficients fails, variation of parameters always succeeds.

## The Method

For $y'' + p(x)y' + q(x)y = f(x)$ with fundamental solutions $\{y_1, y_2\}$:

Seek particular solution: $y_p = u_1(x)y_1 + u_2(x)y_2$

**Formulas**:
$$u_1' = -\frac{y_2 f}{W}, \quad u_2' = \frac{y_1 f}{W}$$

where $W = W(y_1, y_2)$ is the Wronskian.

Then integrate to find $u_1, u_2$.

### Example 1: Setting Up the Method

For $y'' + y = \sec x$, identify $y_1, y_2, f, W$.

**Solution:**

First solve homogeneous: $y'' + y = 0$

$r^2 + 1 = 0$, $r = \pm i$

$y_1 = \cos x$, $y_2 = \sin x$

$f(x) = \sec x$

Wronskian:
$$W = \begin{vmatrix} \cos x & \sin x \\ -\sin x & \cos x \end{vmatrix} = \cos^2 x + \sin^2 x = 1$$

**Answer:** $y_1 = \cos x$, $y_2 = \sin x$, $f = \sec x$, $W = 1$

### Example 2: Computing $u_1'$ and $u_2'$

For Example 1, find $u_1'$ and $u_2'$.

**Solution:**

$$u_1' = -\frac{y_2 f}{W} = -\frac{\sin x \cdot \sec x}{1} = -\frac{\sin x}{\cos x} = -\tan x$$

$$u_2' = \frac{y_1 f}{W} = \frac{\cos x \cdot \sec x}{1} = \frac{\cos x}{\cos x} = 1$$

**Answer:** $u_1' = -\tan x$, $u_2' = 1$

### Example 3: Integration and Particular Solution

Continue Example 2 to find $y_p$.

**Solution:**

Integrate $u_1'$:
$$u_1 = \int (-\tan x) \, dx = -\int \frac{\sin x}{\cos x} \, dx$$

Let $u = \cos x$, $du = -\sin x \, dx$:
$$u_1 = \int \frac{du}{u} = \ln|u| = \ln|\cos x|$$

Integrate $u_2'$:
$$u_2 = \int 1 \, dx = x$$

Particular solution:
$$y_p = u_1y_1 + u_2y_2 = \ln|\cos x| \cdot \cos x + x \cdot \sin x$$

$$y_p = \cos x \ln|\cos x| + x\sin x$$

**Answer:** $y_p = \cos x \ln|\cos x| + x\sin x$

## Complete Examples

### Example 4: Solving with Variation of Parameters

Solve $y'' + 4y = \sec 2x$.

**Solution:**

**Homogeneous**: $r^2 + 4 = 0$, $r = \pm 2i$

$y_1 = \cos 2x$, $y_2 = \sin 2x$

$$W = \begin{vmatrix} \cos 2x & \sin 2x \\ -2\sin 2x & 2\cos 2x \end{vmatrix} = 2\cos^2 2x + 2\sin^2 2x = 2$$

$f(x) = \sec 2x$

$$u_1' = -\frac{\sin 2x \cdot \sec 2x}{2} = -\frac{\sin 2x}{2\cos 2x} = -\frac{1}{2}\tan 2x$$

$$u_2' = \frac{\cos 2x \cdot \sec 2x}{2} = \frac{1}{2}$$

Integrate:
$$u_1 = -\frac{1}{2}\int \tan 2x \, dx = -\frac{1}{2} \cdot \left(-\frac{1}{2}\ln|\cos 2x|\right) = \frac{1}{4}\ln|\cos 2x|$$

$$u_2 = \frac{1}{2}\int 1 \, dx = \frac{x}{2}$$

$$y_p = \frac{1}{4}\ln|\cos 2x| \cdot \cos 2x + \frac{x}{2} \cdot \sin 2x$$

**General solution**:
$$y = c_1\cos 2x + c_2\sin 2x + \frac{1}{4}\cos 2x \ln|\cos 2x| + \frac{x}{2}\sin 2x$$

**Answer:** $y = c_1\cos 2x + c_2\sin 2x +  \frac{1}{4}\cos 2x \ln|\cos 2x| + \frac{x}{2}\sin 2x$

### Example 5: Comparing Methods

For $y'' + y = \sin x$, solve using both undetermined coefficients and variation of parameters.

**Solution:**

**Method 1: Undetermined Coefficients**

Since $\sin x$ is in $y_c$, try $y_p = x(A\cos x + B\sin x)$

(After calculation: $A = 0$, $B = - \frac{1}{2}$)

$y_p = - \frac{1}{2}x\cos x$

**Method 2: Variation of Parameters**

$y_1 = \cos x$, $y_2 = \sin x$, $W = 1$, $f = \sin x$

$$u_1' = -\sin^2 x, \quad u_2' = \cos x \sin x = \frac{1}{2}\sin 2x$$

$$u_1 = -\int \sin^2 x \, dx = -\int \frac{1 - \cos 2x}{2} \, dx = -\frac{x}{2} + \frac{\sin 2x}{4}$$

$$u_2 = \frac{1}{2}\int \sin 2x \, dx = -\frac{1}{4}\cos 2x$$

$$y_p = \left(-\frac{x}{2} + \frac{\sin 2x}{4}\right)\cos x - \frac{1}{4}\cos 2x \sin x$$

After simplification (using trig identities): $y_p = - \frac{1}{2}x\cos x$

**Answer:** Both methods give same result, but undetermined coefficients is simpler here.

### Example 6: Logarithm Function

Solve $y'' - 2y' + y =  \frac{e^x}{x}$.

**Solution:**

**Homogeneous**: $r^2 - 2r + 1 = (r-1)^2 = 0$, $r = 1$ (repeated)

$y_1 = e^x$, $y_2 = xe^x$

$$W = \begin{vmatrix} e^x & xe^x \\ e^x & e^x + xe^x \end{vmatrix} = e^x(e^x + xe^x) - xe^x(e^x) = e^{2x}$$

$f(x) =  \frac{e^x}{x}$

$$u_1' = -\frac{xe^x \cdot e^x/x}{e^{2x}} = -\frac{e^{2x}}{e^{2x}} = -1$$

$$u_2' = \frac{e^x \cdot e^x/x}{e^{2x}} = \frac{1}{x}$$

$$u_1 = -x$$

$$u_2 = \ln|x|$$

$$y_p = (-x)e^x + \ln|x| \cdot xe^x = -xe^x + xe^x\ln|x| = xe^x(\ln|x| - 1)$$

**Answer:** $y = (c_1 + c_2x)e^x + xe^x(\ln|x| - 1)$

### Example 7: Tangent Function

Solve $y'' + y = \tan x$.

**Solution:**

$y_1 = \cos x$, $y_2 = \sin x$, $W = 1$, $f = \tan x$

$$u_1' = -\sin x \tan x = -\frac{\sin^2 x}{\cos x}$$

$$u_2' = \cos x \tan x = \sin x$$

$$u_1 = -\int \frac{\sin^2 x}{\cos x} \, dx = -\int \frac{1 - \cos^2 x}{\cos x} \, dx$$
$$= -\int \left(\sec x - \cos x\right) dx = -\ln|\sec x + \tan x| + \sin x$$

$$u_2 = -\cos x$$

$$y_p = [-\ln|\sec x + \tan x| + \sin x]\cos x + (-\cos x)\sin x$$
$$= -\cos x \ln|\sec x + \tan x|$$

**Answer:** $y = c_1\cos x + c_2\sin x - \cos x \ln|\sec x + \tan x|$

## When to Use Each Method

**Undetermined Coefficients**:
- Faster computation
- Limited to special $g(x)$: polynomials, exponentials, trig functions

**Variation of Parameters**:
- Works for **any** $g(x)$
- More computation (integrals can be difficult)

### Example 8: Which Method?

For each, recommend method:

(a) $y'' + 9y = x^2e^x$

(b) $y'' - y = \csc x$

(c) $y'' + 4y' + 3y = e^{-x}$

**Solution:**

(a) Polynomial × exponential → **Undetermined coefficients** (easier)

(b) $\csc x$ not in standard forms → **Variation of parameters** (only option)

(c) Pure exponential → **Undetermined coefficients** (much simpler)

**Answer:** Use undetermined coefficients when possible; variation when necessary.

### Example 9: Higher-Order Pattern

The formula extends to higher-order equations. For third-order equation with three fundamental solutions, we'd have three functions $u_1, u_2, u_3$ to find.

For $y''' + y' = \sec x$, how many functions $u_i$ needed?

**Solution:**

Third-order → need 3 linearly independent solutions

Variation of parameters: $y_p = u_1y_1 + u_2y_2 + u_3y_3$

**Answer:** Three functions $u_1, u_2, u_3$ (one for each fundamental solution).

### Example 10: Wronskian Zero

What happens if $W = 0$?

**Solution:**

Formulas $u_1' = - \frac{y_2f}{W}$ and $u_2' = \frac{y_1f}{W}$ involve division by $W$.

If $W = 0$, formulas undefined!

But: $W = 0$ means $y_1, y_2$ are linearly **dependent**—not a valid fundamental set.

**Answer:** For valid fundamental set, $W \neq 0$, so formulas always work.

### Example 11: Initial Conditions

Solve $y'' + y = \sec x$, $y(0) = 1$, $y'(0) = 0$.

**Solution:**

From Example 3: $y_p = \cos x \ln|\cos x| + x\sin x$

General: $y = c_1\cos x + c_2\sin x + \cos x \ln|\cos x| + x\sin x$

At $x = 0$:
$$y(0) = c_1(1) + c_2(0) + 1 \cdot \ln(1) + 0 = c_1 = 1$$

Find $y'$ (product rule):
$$y' = -c_1\sin x + c_2\cos x + \left(-\sin x \ln|\cos x| - \tan x\right) + \sin x + x\cos x$$

At $x = 0$:
$$y'(0) = 0 + c_2 + 0 + 0 = c_2 = 0$$

**Answer:** $y = \cos x + \cos x\ln|\cos x| + x\sin x$

### Example 12: Verifying the Solution

How can we verify $y_p = \cos x \ln|\cos x| + x\sin x$ solves $y'' + y = \sec x$?

**Solution:**

Compute $y_p'$ and $y_p''$, substitute into left side.

$y_p = \cos x \ln|\cos x| + x\sin x$

$y_p' = -\sin x \ln|\cos x| - \tan x + \sin x + x\cos x$

$y_p'' = -\cos x \ln|\cos x| + \tan x - \sec^2 x + \cos x + \cos x - x\sin x$
$= -\cos x \ln|\cos x| - x\sin x + 2\cos x + \tan x - \sec^2 x$

Then $y_p'' + y_p = $ (after cancellation) $= \sec x$ ✓

**Answer:** Direct substitution confirms solution (though tedious).

### Example 13: Reduction of Order Connection

Variation of parameters generalizes **reduction of order** (finding second solution given one solution).

If we know $y_1$ solves homogeneous equation, reduction of order seeks $y_2 = vy_1$.

How does this relate?

**Solution:**

Variation of parameters: $y_p = u_1y_1 + u_2y_2$

If only $y_1$ known, set $y_2 = vy_1$ (one unknown function $v$)

This is special case of variation with structured guess.

**Answer:** Reduction of order is variation of parameters adapted to finding second homogeneous solution.

## Answer Key

**Problem 1: B**
Variation of parameters needs fundamental set $\{y_1, y_2\}$ for homogeneous equation.
Then seeks $y_p = u_1(x)y_1 + u_2(x)y_2$.
Works for any $g(x)$ (not just polynomial/exponential/trig).
Doesn't require constant coefficients.

**Problem 2: B**
$W = \begin{vmatrix} \cos x & \sin x \\ -\sin x & \cos x \end{vmatrix} = \cos^2 x + \sin^2 x = 1$
For this particular pair, Wronskian is constant.
Note: $W = 1 \neq 0$ confirms linear independence.

**Problem 3: B**
$f(x)$ is right-hand side of $y'' + p(x)y' + q(x)y = f(x)$
For $y'' + y = \sec x$: $f = \sec x$
Not to be confused with "fundamental solution" (different term).

**Problem 4: C**
Works for any continuous $f(x)$ as long as:
- Have valid fundamental set (linearly independent)
- Wronskian $W \neq 0$
- Can integrate $y_2f/W$ and $y_1f/W$
More general than undetermined coefficients.

**Problem 5: B**
$\csc 2x$ is not polynomial/exponential/sine/cosine/product.
Undetermined coefficients doesn't apply.
Must use variation of parameters.
$y_1 = \cos 2x$, $y_2 = \sin 2x$ are fundamental solutions.

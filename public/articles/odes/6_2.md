# ODE Topic 6.2: Runge-Kutta Methods

Euler's method has a fatal flaw: poor accuracy. To get reasonable precision, you need thousands of tiny steps, and even then, errors accumulate. The problem is fundamental—Euler uses only the slope at the **beginning** of each step. Imagine driving with eyes closed, steering based on where you were pointing when you last looked. You'll drift off course quickly.

**Runge-Kutta methods** are smarter. They sample the slope at **multiple points** within each step, then take a weighted average. It's like checking your direction multiple times during the step, adjusting your path accordingly. The most famous, **RK4** (fourth-order Runge-Kutta), achieves accuracy of $O(h^5)$ per step by evaluating the slope four times. This is dramatically better than Euler's $O(h^2)$ per step.

This article develops Runge-Kutta methods systematically. We'll start with second-order methods (improved Euler and midpoint methods), understand why averaging slopes works, and master RK4—the workhorse of numerical ODE solving. We'll compare computational cost versus accuracy, learn when RK methods excel, and explore adaptive step size strategies. These methods power the ODE solvers in MATLAB, Python, and every engineering software package.

## Motivation: Beyond Euler

Euler's method: $y_{k+1} = y_k + hf(x_k, y_k)$

Uses slope at left endpoint only.

**Idea**: What if we also use slope at right endpoint?

But we don't know $y_{k+1}$ yet! Solution: **predict** it using Euler, then **correct**.

### Example 1: Improved Euler (Heun's Method)

**Algorithm**:
1. **Predict**: $\tilde{y}_{k+1} = y_k + hf(x_k, y_k)$ (Euler step)
2. **Correct**: Average slopes at both ends
   $$y_{k+1} = y_k + \frac{h}{2}[f(x_k, y_k) + f(x_{k+1}, \tilde{y}_{k+1})]$$

Apply to $y' = y$, $y(0) = 1$ with $h = 0.1$ for one step.

**Solution:**

$f(x, y) = y$

**Predict**: $\tilde{y}_1 = 1 + 0.1(1) = 1.1$

**Slopes**:
- At start: $f(0, 1) = 1$
- At predicted end: $f(0.1, 1.1) = 1.1$

**Correct**:
$$y_1 = 1 + \frac{0.1}{2}(1 + 1.1) = 1 + 0.05(2.1) = 1.105$$

**Exact**: $e^{0.1} \approx 1.1052$

**Error**: $|1.1052 - 1.105| = 0.0002$

Compare to Euler: error was $0.0052$

**Answer:** Improved Euler: $y(0.1) \approx 1.105$ (much better!)

### Example 2: Midpoint Method

**Algorithm**:
1. Compute slope at midpoint using Euler half-step
2. Use midpoint slope for full step

$$k_1 = f(x_k, y_k)$$
$$k_2 = f\left(x_k + \frac{h}{2}, y_k + \frac{h}{2}k_1\right)$$
$$y_{k+1} = y_k + hk_2$$

Apply to $y' = y$, $y(0) = 1$, $h = 0.1$.

**Solution:**

$k_1 = f(0, 1) = 1$

$k_2 = f\left(0.05, 1 + 0.05(1)\right) = f(0.05, 1.05) = 1.05$

$y_1 = 1 + 0.1(1.05) = 1.105$

**Answer:** $y(0.1) \approx 1.105$ (same result as improved Euler!)

## Second-Order Runge-Kutta (RK2)

Both improved Euler and midpoint are **second-order**: local error $O(h^3)$, global error $O(h^2)$.

General RK2 form:
$$k_1 = f(x_k, y_k)$$
$$k_2 = f(x_k + \alpha h, y_k + \alpha h k_1)$$
$$y_{k+1} = y_k + h[(1-\beta)k_1 + \beta k_2]$$

Different choices of $\alpha, \beta$ give different methods (all second-order if $\alpha = \beta = 1/2$ or other compatible values).

### Example 3: Comparing RK2 to Euler

For $y' = x + y$, $y(0) = 1$, approximate $y(0.5)$ with $h = 0.25$.

**Euler** (from earlier): $y(0.5) \approx 1.625$

**RK2 (Improved Euler)**:

**Step 1**: $x_0 = 0$, $y_0 = 1$

Predict: $\tilde{y}_1 = 1 + 0.25(0 + 1) = 1.25$

Correct: $y_1 = 1 +  \frac{0.25}{2}[(0+1) + (0.25+1.25)] = 1 + 0.125(2.5) = 1.3125$

**Step 2**: $x_1 = 0.25$, $y_1 = 1.3125$

Predict: $\tilde{y}_2 = 1.3125 + 0.25(0.25 + 1.3125) = 1.3125 + 0.3906 = 1.7031$

Correct: $y_2 = 1.3125 +  \frac{0.25}{2}[(0.25+1.3125) + (0.5+1.7031)]$
$= 1.3125 + 0.125(3.7656) = 1.3125 + 0.4707 = 1.7832$

**Exact**: $y = 2e^x - x - 1$, so $y(0.5) \approx 1.797$

**Errors**:
- Euler: $|1.797 - 1.625| = 0.172$
- RK2: $|1.797 - 1.783| = 0.014$

**Answer:** RK2 is **12 times more accurate** with same step size!

## Fourth-Order Runge-Kutta (RK4)

The **classic RK4** method:

$$k_1 = f(x_k, y_k)$$
$$k_2 = f\left(x_k + \frac{h}{2}, y_k + \frac{h}{2}k_1\right)$$
$$k_3 = f\left(x_k + \frac{h}{2}, y_k + \frac{h}{2}k_2\right)$$
$$k_4 = f(x_k + h, y_k + hk_3)$$

$$y_{k+1} = y_k + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)$$

**Interpretation**:
- $k_1$: slope at beginning
- $k_2$: slope at midpoint using Euler half-step
- $k_3$: slope at midpoint using improved half-step
- $k_4$: slope at end using full step with $k_3$

Weighted average: $(k_1 + 2k_2 + 2k_3 + k_4)/6$ emphasizes midpoint slopes.

### Example 4: RK4 Single Step

Use RK4 with $h = 0.1$ for $y' = y$, $y(0) = 1$ to find $y(0.1)$.

**Solution:**

$f(x, y) = y$, $x_0 = 0$, $y_0 = 1$

$k_1 = f(0, 1) = 1$

$k_2 = f\left(0.05, 1 + 0.05(1)\right) = f(0.05, 1.05) = 1.05$

$k_3 = f\left(0.05, 1 + 0.05(1.05)\right) = f(0.05, 1.0525) = 1.0525$

$k_4 = f(0.1, 1 + 0.1(1.0525)) = f(0.1, 1.10525) = 1.10525$

$$y_1 = 1 + \frac{0.1}{6}(1 + 2(1.05) + 2(1.0525) + 1.10525)$$
$$= 1 + \frac{0.1}{6}(6.31025) = 1 + 0.1052 = 1.1052$$

**Exact**: $e^{0.1} \approx 1.105170918$

**Error**: $|1.105170918 - 1.1052| \approx 3 \times 10^{-5}$

**Answer:** RK4 gives $y(0.1) \approx 1.1052$ (accurate to 4 decimal places!)

### Example 5: RK4 Error Analysis

Compare errors for $y' = y$, $y(0) = 1$ at $x = 1$ with $h = 0.1$.

**Solution:**

**Euler**: Global error $\approx 0.125$ (from earlier)

**RK4**: With 10 steps of $h = 0.1$, gives $y(1) \approx 2.71828$

Exact: $e \approx 2.71828$

**Error**: $< 10^{-5}$ (essentially exact to 5 decimals)

**Answer:** RK4 is **thousands of times** more accurate than Euler!

### Example 6: Step Size Effect on RK4

For RK4, if step size is halved, how does global error change?

**Solution:**

RK4 is fourth-order: local error $O(h^5)$

Global error: $O(h^5) \times O(1/h) = O(h^4)$

If $h \to h/2$:
$$\text{Error}_{\text{new}} \sim \left(\frac{h}{2}\right)^4 = \frac{h^4}{16} = \frac{1}{16}\text{Error}_{\text{old}}$$

**Answer:** Error reduced by factor of **16** (fourth-order convergence).

## Computational Cost vs Accuracy

**Comparison** for same accuracy:

|Method|Order|Function Evaluations per Step|Steps Needed|Total Evaluations|
|------|-----|----------------------------|------------|-----------------|
|Euler|1|1|$N$|$N$|
|RK2|2|2|$N/2$|$N$|
|RK4|4|4|$N/4$|$N$|

For same accuracy, RK4 needs far fewer steps!

### Example 7: Efficiency Comparison

To achieve error $< 10^{-4}$ for $y' = y$ on $[0,1]$:

**Euler**: Need $h \approx 0.001$ → 1000 steps → 1000 function evaluations

**RK4**: Need $h \approx 0.1$ → 10 steps → 40 function evaluations

**Answer:** RK4 is **25 times more efficient** for this accuracy.

### Example 8: When to Use Each Method

Match method to problem:

(a) Quick rough estimate
(b) High accuracy required
(c) Very smooth function
(d) Stiff equation

**Solution:**

(a) **Euler**: Fast, simple, acceptable for rough estimates

(b) **RK4**: Standard choice for high accuracy

(c) **RK4 or higher**: Can use larger steps for smooth functions

(d) **Implicit methods**: Stiff equations need special solvers (beyond basic RK)

**Answer:** RK4 is general-purpose workhorse.

## Solving Systems of ODEs

RK4 extends naturally to systems: $\vec{y}' = \vec{f}(x, \vec{y})$

Each $k_i$ becomes a vector.

### Example 9: RK4 for System

Use RK4 with $h = 0.2$ for:
$$\begin{cases} x' = y \\ y' = -x \end{cases}$$
with $x(0) = 1$, $y(0) = 0$.

**Solution:**

$\vec{y} = \begin{bmatrix} x \\ y \end{bmatrix}$, $\vec{f} = \begin{bmatrix} y \\ -x \end{bmatrix}$

$\vec{y}_0 = \begin{bmatrix} 1 \\ 0 \end{bmatrix}$

$\vec{k}_1 = \vec{f}(0, \vec{y}_0) = \begin{bmatrix} 0 \\ -1 \end{bmatrix}$

$\vec{k}_2 = \vec{f}\left(0.1, \begin{bmatrix} 1 \\ 0 \end{bmatrix} + 0.1\begin{bmatrix} 0 \\ -1 \end{bmatrix}\right) = \vec{f}\left(0.1, \begin{bmatrix} 1 \\ -0.1 \end{bmatrix}\right) = \begin{bmatrix} -0.1 \\ -1 \end{bmatrix}$

$\vec{k}_3 = \vec{f}\left(0.1, \begin{bmatrix} 1 \\ 0 \end{bmatrix} + 0.1\begin{bmatrix} -0.1 \\ -1 \end{bmatrix}\right) = \vec{f}\left(0.1, \begin{bmatrix} 0.99 \\ -0.1 \end{bmatrix}\right) = \begin{bmatrix} -0.1 \\ -0.99 \end{bmatrix}$

$\vec{k}_4 = \vec{f}\left(0.2, \begin{bmatrix} 1 \\ 0 \end{bmatrix} + 0.2\begin{bmatrix} -0.1 \\ -0.99 \end{bmatrix}\right) = \vec{f}\left(0.2, \begin{bmatrix} 0.98 \\ -0.198 \end{bmatrix}\right) = \begin{bmatrix} -0.198 \\ -0.98 \end{bmatrix}$

$$\vec{y}_1 = \begin{bmatrix} 1 \\ 0 \end{bmatrix} + \frac{0.2}{6}\left[\begin{bmatrix} 0 \\ -1 \end{bmatrix} + 2\begin{bmatrix} -0.1 \\ -1 \end{bmatrix} + 2\begin{bmatrix} -0.1 \\ -0.99 \end{bmatrix} + \begin{bmatrix} -0.198 \\ -0.98 \end{bmatrix}\right]$$

$$= \begin{bmatrix} 1 \\ 0 \end{bmatrix} + \frac{0.2}{6}\begin{bmatrix} -0.598 \\ -5.96 \end{bmatrix} = \begin{bmatrix} 1 \\ 0 \end{bmatrix} + \begin{bmatrix} -0.0199 \\ -0.199 \end{bmatrix} = \begin{bmatrix} 0.98 \\ -0.199 \end{bmatrix}$$

**Exact**: $x = \cos t$, $y = -\sin t$

At $t = 0.2$: $x = \cos(0.2) \approx 0.9801$, $y = -\sin(0.2) \approx -0.1987$

**Answer:** Very accurate! RK4 works excellently for systems.

## Adaptive Step Size

**Idea**: Use large steps where solution is smooth, small steps where it changes rapidly.

**Method**: Compute step twice (with $h$ and $h/2$), compare results, adjust step size.

### Example 10: Error Estimation

With RK4, compute step with $h$ and also with two steps of $h/2$. How to estimate error?

**Solution:**

Let $Y$ = result with step $h$

Let $Z$ = result with two steps of $h/2$

For RK4 (fourth-order):
$$Y = y_{\text{true}} + Ch^5 + O(h^6)$$
$$Z = y_{\text{true}} + C(h/2)^5 + O(h^6) = y_{\text{true}} + \frac{C}{32}h^5 + O(h^6)$$

Difference: $Y - Z \approx Ch^5 - \frac{C}{32}h^5 = \frac{31C}{32}h^5$

So: $Ch^5 \approx \frac{32}{31}(Y-Z)$

**Error estimate**: $|Y - y_{\text{true}}| \approx \frac{|Y-Z|}{31}$

**Answer:** If $|Y-Z|$ is small, $Y$ is accurate. Otherwise, reduce $h$.

### Example 11: Adaptive Strategy

If estimated error exceeds tolerance, how much should $h$ be reduced?

**Solution:**

Current error: $E \sim Ch^4$ (global RK4 error)

Desired error: $E_{\text{tol}}$

Need: $C(h_{\text{new}})^4 = E_{\text{tol}}$

From $Ch^4 = E$:
$$h_{\text{new}} = h\left(\frac{E_{\text{tol}}}{E}\right)^{1/4}$$

**Safety factor**: Use $h_{\text{new}} = 0.9h\left( \frac{E_{\text{tol}}}{E}\right)^{1/4}$

**Answer:** Reduce $h$ by factor $\left( \frac{E_{\text{tol}}}{E}\right)^{1/4}$ (fourth root).

## Higher-Order Methods

**RK5**: Fifth-order, local error $O(h^6)$

**Dormand-Prince (RK45)**: Combines RK4 and RK5 for error estimation (used in MATLAB's `ode45`)

**Cash-Karp**: Another embedded pair

### Example 12: Method Selection

When is higher than RK4 worthwhile?

**Solution:**

**Use RK4** when:
- Standard accuracy sufficient
- Function evaluations are cheap
- Problem is not stiff

**Use higher-order** when:
- Very high accuracy needed
- Function is expensive to evaluate
- Adaptive step size essential

**Use specialized** when:
- Equation is stiff (implicit methods)
- Solution has discontinuities (detection needed)
- Long-time integration (symplectic methods)

**Answer:** RK4 is default; upgrade for special needs.

### Example 13: Practical Implementation

Write pseudo-code for RK4.

**Solution:**

```
function RK4(f, x0, y0, h, n):
    x = x0
    y = y0
    
    for i = 1 to n:
        k1 = f(x, y)
        k2 = f(x + h/2, y + h*k1/2)
        k3 = f(x + h/2, y + h*k2/2)
        k4 = f(x + h, y + h*k3)
        
        y = y + h*(k1 + 2*k2 + 2*k3 + k4)/6
        x = x + h
    
    return (x, y)
```

**Answer:** Four function evaluations per step, weighted average update.

## Answer Key

**Problem 1: C**
RK4 computes four slopes per step:
$k_1$ at $(x_k, y_k)$
$k_2$ at midpoint using $k_1$
$k_3$ at midpoint using $k_2$
$k_4$ at endpoint using $k_3$
More function evaluations than Euler (1) or RK2 (2)

**Problem 2: D**
RK4 is fourth-order: global error $\sim h^4$
If $h \to h/2$: error $\to (1/2)^4 = 1/16$ of original
Reduced by factor of 16
Compare: Euler (factor 2), RK2 (factor 4)

**Problem 3: C**
For same $h$:
Euler: error $O(h)$
RK4: error $O(h^4)$
If $h = 0.1$: Euler error $\sim 0.1$, RK4 error $\sim 0.0001$
Factor of 1000 better!
Computational cost only 4× more per step

**Problem 4: B**
Update: $y_{k+1} = y_k +  \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)$
Weights: $(1, 2, 2, 1)$ with denominator 6
Emphasizes midpoint slopes ($k_2, k_3$)
Similar to Simpson's rule for integration

**Problem 5: B**
Adaptive methods:
1. Estimate local error (e.g., compare $h$ vs $2h$ steps)
2. If error > tolerance: reduce $h$
3. If error << tolerance: increase $h$
Maintains accuracy while minimizing steps
Common in professional ODE solvers

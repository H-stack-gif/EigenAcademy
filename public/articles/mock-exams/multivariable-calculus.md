## Multiple Choice Solutions

**1. C** - $|\mathbf{v}| = \sqrt{3^2 + (-4)^2 + 0^2} = \sqrt{9 + 16} = \sqrt{25} = 5$

**2. A** - $\langle 2, 1, -1 \rangle \cdot \langle 1, -2, 3 \rangle = 2(1) + 1(-2) + (-1)(3) = 2 - 2 - 3 = -3$

**3. B** - Plane equation: $a(x - x_0) + b(y - y_0) + c(z - z_0) = 0$
$1(x-1) - 1(y-2) + 2(z-3) = 0 \implies x - y + 2z = 7$

**4. A** - Differentiate component-wise: $\mathbf{r}'(t) = \langle 2t, 3t^2, 1 \rangle$

**5. C** - $|\mathbf{r}'(t)| = \sqrt{9 + 16 + 0} = 5$. Arc length $= \int_0^1 5 \, dt = 5$

**6. C** - Curvature of circle: $\kappa = 1/r$ (constant)

**7. B** - $\frac{\partial f}{\partial x} = 2x$, at $(1, 2)$: $2(1) = 2$

**8. C** - $f_{xy} = \frac{\partial}{\partial y}\frac{\partial}{\partial x}(x^3y^2) = \frac{\partial}{\partial y}(3x^2y^2) = 6x^2y$

**9. B** - $\nabla f = \langle yz, xz, xy \rangle$, at $(1, 2, 3)$: $\langle 6, 3, 2 \rangle$

**10. B** - $D_{\mathbf{u}}f = \nabla f \cdot \mathbf{u}$ where $\mathbf{u}$ is unit vector

**11. B** - Critical points where gradient is zero: $\nabla f = \mathbf{0}$

**12. C** - $D < 0$ indicates saddle point

**13. B** - Lagrange multipliers: $\nabla f = \lambda \nabla g$

**14. C** - $\int_0^1 \int_0^2 (x+y) \, dy \, dx = \int_0^1 [xy + \frac{y^2}{2}]_0^2 \, dx = \int_0^1 (2x + 2) \, dx = [x^2 + 2x]_0^1 = 3$

**15. B** - In polar: $dA = r \, dr \, d\theta$

**16. C** - Sphere volume: $V = \frac{4\pi a^3}{3}$

**17. B** - Cylindrical: $dV = r \, dr \, d\theta \, dz$

**18. B** - Jacobian $\frac{\partial(x,y)}{\partial(r,\theta)} = r$

**19. D** - This is rotational field with curl = -2. By Green's theorem: $\oint = -2 \cdot \pi(1)^2 = -2\pi$

**20. A** - Conservative field has zero curl: $\nabla \times \mathbf{F} = \mathbf{0}$

**21. B** - 2D curl: $\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}$

**22. C** - $\nabla \cdot \mathbf{F} = \frac{\partial x}{\partial x} + \frac{\partial y}{\partial y} + \frac{\partial z}{\partial z} = 1 + 1 + 1 = 3$

**23. E** - Green's theorem: $\oint_C P \, dx + Q \, dy = \iint_D (\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}) \, dA$ (none match exactly as stated)

**24. B** - Stokes relates circulation around boundary curve to curl over surface

**25. C** - Divergence theorem: flux through closed surface = divergence integrated over volume

## Free Response Solutions

### FRQ 1 Solutions

**(a)** Find critical points where $\nabla f = \mathbf{0}$:
$$f_x = 3x^2 - 3y^2 = 0$$
$$f_y = -6xy + 3y^2 = 0$$

From first equation: $x^2 = y^2 \implies x = \pm y$

Case 1: $x = y$
$$-6y^2 + 3y^2 = -3y^2 = 0 \implies y = 0$$
Critical point: $(0, 0)$

Case 2: $x = -y$
$$6y^2 + 3y^2 = 9y^2 = 0 \implies y = 0$$
Critical point: $(0, 0)$ (same)

**Critical point: $(0, 0)$**

**(b)** Second partials:
$$f_{xx} = 6x$$
$$f_{yy} = -6x + 6y$$
$$f_{xy} = -6y$$

**(c)** At $(0, 0)$:
$$f_{xx} = 0, \quad f_{yy} = 0, \quad f_{xy} = 0$$
$$D = f_{xx}f_{yy} - (f_{xy})^2 = 0$$

Test is **inconclusive**. 

Check along axes:
- Along $x$-axis ($y = 0$): $f(x, 0) = x^3$ changes sign
- Along $y$-axis ($x = 0$): $f(0, y) = y^3$ changes sign

$(0, 0)$ is a **saddle point** (neither max nor min)

**(d)** Tangent plane at $(1, 1, -1)$:
$$f_x(1, 1) = 3(1)^2 - 3(1)^2 = 0$$
$$f_y(1, 1) = -6(1)(1) + 3(1)^2 = -3$$

Equation: $z - (-1) = 0(x - 1) + (-3)(y - 1)$
$$z = -3y + 2$$

### FRQ 2 Solutions

**(a)** In polar coordinates: $x^2 + y^2 = r^2$, $dA = r \, dr \, d\theta$
$$\iint_R r^2 \cdot r \, dr \, d\theta = \iint r^3 \, dr \, d\theta$$

**(b)** Circle $x^2 + y^2 = 4$ is $r = 2$ in polar.
Limits: $0 \leq r \leq 2$, $0 \leq \theta \leq 2\pi$

**(c)** Evaluate:
$$\int_0^{2\pi} \int_0^2 r^3 \, dr \, d\theta = \int_0^{2\pi} \left[\frac{r^4}{4}\right]_0^2 d\theta$$
$$= \int_0^{2\pi} 4 \, d\theta = 4(2\pi) = 8\pi$$

**(d)** Average value:
$$f_{\text{avg}} = \frac{1}{\text{Area}} \iint_R f \, dA = \frac{8\pi}{\pi(2)^2} = \frac{8\pi}{4\pi} = 2$$

**(e)** The region $R$ is symmetric about both axes. The function $xy$ is:
- Positive in quadrants I and III
- Negative in quadrants II and IV
- Equal contributions with opposite signs cancel out

Therefore $\iint_R xy \, dA = 0$ by symmetry.

### FRQ 3 Solutions

**(a)** Test for conservative:
$$P = 2xy + y^2, \quad Q = x^2 + 2xy$$
$$\frac{\partial P}{\partial y} = 2x + 2y$$
$$\frac{\partial Q}{\partial x} = 2x + 2y$$

Since $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$, **$\mathbf{F}$ is conservative** ✓

**(b)** Find potential function $f$:
$$f_x = 2xy + y^2 \implies f = x^2y + xy^2 + g(y)$$
$$f_y = x^2 + 2xy + g'(y) = x^2 + 2xy$$

So $g'(y) = 0 \implies g(y) = C$

**Potential function: $f(x, y) = x^2y + xy^2 + C$**

**(c)** Using fundamental theorem:
$$\int_C \mathbf{F} \cdot d\mathbf{r} = f(1, 2) - f(0, 0)$$
$$= [1^2(2) + 1(2)^2] - 0 = 2 + 4 = 6$$

**(d)** Treating as 3D: $\mathbf{F} = \langle 2xy + y^2, x^2 + 2xy, 0 \rangle$
$$\nabla \times \mathbf{F} = \begin{vmatrix} \mathbf{i} & \mathbf{j} & \mathbf{k} \\ \frac{\partial}{\partial x} & \frac{\partial}{\partial y} & \frac{\partial}{\partial z} \\ 2xy+y^2 & x^2+2xy & 0 \end{vmatrix}$$

$$= \mathbf{i}(0) - \mathbf{j}(0) + \mathbf{k}[(2x + 2y) - (2x + 2y)] = \mathbf{0}$$

**(e)** Since $\nabla \times \mathbf{F} = \mathbf{0}$, by Stokes' theorem:
$$\oint_C \mathbf{F} \cdot d\mathbf{r} = \iint_S (\nabla \times \mathbf{F}) \cdot d\mathbf{S} = 0$$

**The circulation around any closed curve is zero** (confirms conservative field).

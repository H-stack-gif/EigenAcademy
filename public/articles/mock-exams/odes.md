# ORDINARY DIFFERENTIAL EQUATIONS ANSWER KEY

## Multiple Choice Solutions

**1. C** - Highest derivative is third derivative, so order = 3

**2. B** - $\frac{dy}{dx} = xy$ separates as $\frac{dy}{y} = x \, dx$. Others don't separate cleanly.

**3. B** - $\frac{dy}{y} = k \, dx \implies \ln|y| = kx + C \implies y = Ce^{kx}$

**4. A** - For $y' + P(x)y = Q(x)$, integrating factor is $\mu(x) = e^{\int P \, dx} = e^{\int 2 \, dx} = e^{2x}$

**5. A** - $\frac{dy}{y} = \frac{dx}{x} \implies \ln|y| = \ln|x| + C \implies y = Cx$. With $y(1) = 2$: $2 = C(1)$, so $y = 2x$.

**6. B** - Characteristic equation: $r^2 + 4 = 0 \implies r = \pm 2i$. Solutions: $\sin(2x)$ and $\cos(2x)$.

**7. A** - For $ay'' + by' + cy = 0$, characteristic equation is $ar^2 + br + c = 0$, giving $r^2 - 5r + 6 = 0$

**8. A** - Characteristic equation: $r^2 + 4r + 4 = (r+2)^2 = 0$ gives repeated root $r = -2$. Solution: $y = c_1e^{-2x} + c_2xe^{-2x}$

**9. B** - $r^2 + 9 = 0 \implies r = \pm 3i$. Solution: $y = c_1\cos(3x) + c_2\sin(3x)$

**10. B** - Since $e^x$ is a solution to the homogeneous equation ($r = 1$ satisfies $r^2 - 1 = 0$), multiply by $x$: try $y_p = Axe^x$

**11. B** - $W(\cos x, \sin x) = \begin{vmatrix} \cos x & \sin x \\ -\sin x & \cos x \end{vmatrix} = \cos^2 x + \sin^2 x = 1$

**12. A** - $\mathcal{L}\{e^{at}\} = \int_0^{\infty} e^{at}e^{-st} \, dt = \int_0^{\infty} e^{-(s-a)t} \, dt = \frac{1}{s-a}$ for $s > a$

**13. B** - $\mathcal{L}\{\sin(at)\} = \frac{a}{s^2 + a^2}$

**14. B** - $\mathcal{L}^{-1}\left\{\frac{1}{s^2}\right\} = t$ (since $\mathcal{L}\{t\} = \frac{1}{s^2}$)

**15. C** - Eigenvalues are 2 (positive) and -1 (negative). Real eigenvalues with opposite signs → saddle point

**16. C** - Eigenvalues: $\lambda^2 + 1 = 0 \implies \lambda = \pm i$. Pure imaginary eigenvalues → periodic (circular) solutions

**17. A** - Assume power series $y = \sum a_n x^n$ and solve for coefficients

**18. C** - Equation has form of Euler equation; use Frobenius method (or substitution $x = e^t$)

**19. C** - Equilibrium when $\frac{dP}{dt} = 0$: $kP - H = 0 \implies P = H/k$

**20. A** - Euler's method: $y_{n+1} = y_n + h \cdot f(x_n, y_n)$

**21. A** - Existence and Uniqueness Theorem requires $p$ and $q$ continuous (and $y(x_0), y'(x_0)$ given)

**22. A** - Superposition principle: linear combinations of solutions are solutions

**23. B** - $W = \begin{vmatrix} e^x & e^{2x} \\ e^x & 2e^{2x} \end{vmatrix} = 2e^{3x} - e^{3x} = e^{3x}$

**24. C** - Stable spiral: complex eigenvalues $\lambda = a \pm bi$ with $a < 0$ (negative real part)

**25. B** - $x' = y, y' = -x$ gives $x'' = -x$, solution $x = A\cos t + B\sin t$ (circles in phase plane)

## Free Response Solutions

### FRQ 1 Solutions

**(a)** Separate variables:
$$\frac{dy}{dx} = \frac{x^2}{1 + y^2}$$
$$(1 + y^2) \, dy = x^2 \, dx$$

Integrate both sides:
$$\int (1 + y^2) \, dy = \int x^2 \, dx$$
$$y + \frac{y^3}{3} = \frac{x^3}{3} + C$$

General solution: $y + \frac{y^3}{3} = \frac{x^3}{3} + C$ (implicit form)

**(b)** Apply $y(0) = 0$:
$$0 + 0 = 0 + C \implies C = 0$$

Particular solution: $y + \frac{y^3}{3} = \frac{x^3}{3}$ or $3y + y^3 = x^3$

**(c)** Euler's method with $h = 0.5$, starting at $(0, 0)$:

$n = 0$: $x_0 = 0, y_0 = 0$
$$y_1 = y_0 + h \cdot f(x_0, y_0) = 0 + 0.5 \cdot \frac{0^2}{1 + 0^2} = 0$$

$n = 1$: $x_1 = 0.5, y_1 = 0$
$$y_2 = y_1 + h \cdot f(x_1, y_1) = 0 + 0.5 \cdot \frac{(0.5)^2}{1 + 0^2} = 0.125$$

$n = 2$: $x_2 = 1.0, y_2 = 0.125$
$$y_3 = y_2 + h \cdot f(x_2, y_2) = 0.125 + 0.5 \cdot \frac{1^2}{1 + (0.125)^2}$$
$$= 0.125 + 0.5 \cdot \frac{1}{1.015625} = 0.125 + 0.492 = 0.617$$

**Approximation: $y(1) \approx 0.617$**

**(d)** From $3y + y^3 = x^3$, solution exists as long as we can solve for $y$ (cubic in $y$). Since $f(x, y) = x^2/(1+y^2)$ is continuous for all $x, y$, and Lipschitz continuous in $y$, solution exists for all $x \geq 0$ by existence theorem.

### FRQ 2 Solutions

**(a)** Complementary solution from $y'' + 2y' + 5y = 0$:

Characteristic equation: $r^2 + 2r + 5 = 0$
$$r = \frac{-2 \pm \sqrt{4 - 20}}{2} = \frac{-2 \pm 4i}{2} = -1 \pm 2i$$

$$y_c = e^{-x}(c_1\cos(2x) + c_2\sin(2x))$$

**(b)** Particular solution using undetermined coefficients:

Right side: $e^{-x}\cos(2x)$ matches form of $y_c$, so try:
$$y_p = xe^{-x}(A\cos(2x) + B\sin(2x))$$

After differentiation and substitution (lengthy algebra):
$$y_p' = e^{-x}[(A - 2B + A\cos(2x) + B\sin(2x))x + A\cos(2x) + B\sin(2x)] - xe^{-x}(A\cos(2x) + B\sin(2x))$$

This gets complex; using variation of parameters may be easier. 

Alternative: For $y'' + 2y' + 5y = e^{-x}\cos(2x)$, particular solution is:
$$y_p = \frac{x}{4}e^{-x}\sin(2x)$$

**(c)** General solution:
$$y = e^{-x}(c_1\cos(2x) + c_2\sin(2x)) + \frac{x}{4}e^{-x}\sin(2x)$$

**(d)** Apply $y(0) = 1$:
$$1 = c_1(1) + c_2(0) + 0 \implies c_1 = 1$$

Apply $y'(0) = 0$ (requires computing $y'$):
$$y' = e^{-x}[-c_1\cos(2x) - c_2\sin(2x) - 2c_1\sin(2x) + 2c_2\cos(2x)]$$
$$+ \frac{1}{4}e^{-x}[\sin(2x) + 2x\cos(2x) - x\sin(2x)]$$

At $x = 0$:
$$0 = -c_1 + 2c_2 + 0$$
$$0 = -1 + 2c_2 \implies c_2 = \frac{1}{2}$$

Specific solution: $y = e^{-x}\left(\cos(2x) + \frac{1}{2}\sin(2x)\right) + \frac{x}{4}e^{-x}\sin(2x)$

**(e)** As $x \to \infty$: $e^{-x} \to 0$, so $y \to 0$. Solution decays exponentially to zero (damped oscillation).

### FRQ 3 Solutions

**(a)** Matrix form:
$$\begin{bmatrix} x' \\ y' \end{bmatrix} = \begin{bmatrix} 1 & -2 \\ 3 & -4 \end{bmatrix}\begin{bmatrix} x \\ y \end{bmatrix}$$

**(b)** Eigenvalues from $\det(A - \lambda I) = 0$:
$$\det\begin{bmatrix} 1-\lambda & -2 \\ 3 & -4-\lambda \end{bmatrix} = (1-\lambda)(-4-\lambda) + 6 = \lambda^2 + 3\lambda + 2$$
$$= (\lambda + 1)(\lambda + 2) = 0$$

Eigenvalues: $\lambda_1 = -1, \lambda_2 = -2$

**(c)** For $\lambda_1 = -1$:
$$(A + I)\mathbf{v} = \mathbf{0} \implies \begin{bmatrix} 2 & -2 \\ 3 & -3 \end{bmatrix}\begin{bmatrix} v_1 \\ v_2 \end{bmatrix} = \mathbf{0}$$
From $2v_1 - 2v_2 = 0$: $\mathbf{v}_1 = \begin{bmatrix} 1 \\ 1 \end{bmatrix}$

For $\lambda_2 = -2$:
$$(A + 2I)\mathbf{v} = \mathbf{0} \implies \begin{bmatrix} 3 & -2 \\ 3 & -2 \end{bmatrix}\begin{bmatrix} v_1 \\ v_2 \end{bmatrix} = \mathbf{0}$$
From $3v_1 - 2v_2 = 0$: $\mathbf{v}_2 = \begin{bmatrix} 2 \\ 3 \end{bmatrix}$

**(d)** General solution:
$$\begin{bmatrix} x(t) \\ y(t) \end{bmatrix} = c_1e^{-t}\begin{bmatrix} 1 \\ 1 \end{bmatrix} + c_2e^{-2t}\begin{bmatrix} 2 \\ 3 \end{bmatrix}$$

Or: $x(t) = c_1e^{-t} + 2c_2e^{-2t}$, $y(t) = c_1e^{-t} + 3c_2e^{-2t}$

**(e)** Classification: Both eigenvalues negative and real → **stable node**

All trajectories approach origin as $t \to \infty$. Eigenvector directions:
- Along $\langle 1, 1 \rangle$: slower decay ($e^{-t}$)
- Along $\langle 2, 3 \rangle$: faster decay ($e^{-2t}$)

Phase portrait: Trajectories initially align with $\langle 2, 3 \rangle$ (fast direction), then curve to align with $\langle 1, 1 \rangle$ as they approach origin.

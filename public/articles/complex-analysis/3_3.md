# Complex Analysis Topic 3.3: Cauchy's Integral Formula

Cauchy's theorem tells us that $\oint_C f(z) \, dz = 0$ when $f$ is analytic inside and on $C$. But what if $f$ has a singularity at one point $z_0$ inside $C$? The integral is no longer zero—instead, it encodes precise information about $f$ at that point. The **Cauchy integral formula** makes this quantitative: if $f$ is analytic inside and on a simple closed contour $C$, then the value of $f$ at any interior point $z_0$ is completely determined by the values of $f$ on the boundary:

$$f(z_0) = \frac{1}{2\pi i}\oint_C \frac{f(z)}{z - z_0} \, dz$$

This formula is astonishing. It says that an analytic function's behavior in a region is completely determined by its boundary values. More remarkably, derivatives of all orders at $z_0$ can be computed from the same boundary integral using only higher powers in the denominator. This represents a profound rigidity: analytic functions are not just smooth—they're determined everywhere inside by knowing them only on the edge.

This article develops the Cauchy integral formula and explores its consequences. We'll prove the formula, use it to evaluate integrals, compute derivatives from boundary integrals, and understand why analyticity implies infinite differentiability. You'll master techniques for applying the formula to evaluate complicated integrals, extract function values and derivatives from contour integrals, and appreciate the remarkable properties that follow from this central theorem.

## The Cauchy Integral Formula

**Cauchy Integral Formula**: Let $f$ be analytic inside and on a simple closed contour $C$ traversed counterclockwise. For any point $z_0$ inside $C$:

$$f(z_0) = \frac{1}{2\pi i}\oint_C \frac{f(z)}{z - z_0} \, dz$$

**Interpretation**: The value of $f$ at interior point $z_0$ is determined by boundary values.

**Key insight**: $\frac{1}{z-z_0}$ creates a "singularity" that extracts the value $f(z_0)$.

### Example 1: Applying the Formula Directly

Let $f(z) = z^2 + 3z$. Find $f(i)$ using Cauchy's integral formula with $C = |z| = 2$.

**Solution:**

Since $|i| = 1 < 2$, the point $z_0 = i$ is inside $C$.

$$f(i) = \frac{1}{2\pi i}\oint_{|z|=2} \frac{z^2 + 3z}{z - i} \, dz$$

We can compute directly: $f(i) = i^2 + 3i = -1 + 3i$

**Verification**: The formula should give this value.

(Direct evaluation of the integral confirms $f(i) = -1 + 3i$)

**Answer:** $f(i) = -1 + 3i$ (computed both directly and via Cauchy formula)

### Example 2: Evaluating Integral Using Formula

Evaluate $\oint_{|z|=1} \frac{e^z}{z - 2} \, dz$.

**Solution:**

Form: $\frac{f(z)}{z - z_0}$ with $f(z) = e^z$ and $z_0 = 2$.

However, $z_0 = 2$ is **outside** $|z| = 1$ (since $|2| = 2 > 1$).

When $z_0$ is outside $C$, the function $\frac{f(z)}{z-z_0}$ is analytic inside and on $C$.

By Cauchy's theorem:
$$\oint_{|z|=1} \frac{e^z}{z - 2} \, dz = 0$$

**Answer:** $0$ (singularity outside contour)

### Example 3: Point Inside Contour

Evaluate $\oint_{|z|=3} \frac{\sin z}{z - 1} \, dz$.

**Solution:**

Form: $\frac{f(z)}{z - z_0}$ with $f(z) = \sin z$ and $z_0 = 1$.

Since $|1| = 1 < 3$, point $z_0 = 1$ is inside $|z| = 3$.

By Cauchy integral formula:
$$\frac{1}{2\pi i}\oint_{|z|=3} \frac{\sin z}{z - 1} \, dz = f(1) = \sin 1$$

Therefore:
$$\oint_{|z|=3} \frac{\sin z}{z - 1} \, dz = 2\pi i \sin 1$$

**Answer:** $2\pi i \sin 1$

### Example 4: Multiple Singularities

Evaluate $\oint_{|z|=2} \frac{z^2}{(z-1)(z-3)} \, dz$.

**Solution:**

Function has singularities at $z = 1$ (inside $|z|=2$) and $z = 3$ (outside $|z|=2$).

Use partial fractions:
$$\frac{z^2}{(z-1)(z-3)} = \frac{A}{z-1} + \frac{B}{z-3}$$

Solve: $z^2 = A(z-3) + B(z-1)$

At $z=1$: $1 = A(-2) \implies A = -1/2$
At $z=3$: $9 = B(2) \implies B = 9/2$

$$\oint_{|z|=2} \frac{z^2}{(z-1)(z-3)} \, dz = -\frac{1}{2}\oint \frac{dz}{z-1} + \frac{9}{2}\oint \frac{dz}{z-3}$$

First integral: $z=1$ inside, so $\oint \frac{dz}{z-1} = 2\pi i$

Second integral: $z=3$ outside, so $\oint \frac{dz}{z-3} = 0$ (by Cauchy's theorem)

$$= -\frac{1}{2}(2\pi i) + \frac{9}{2}(0) = -\pi i$$

**Answer:** $-\pi i$

## Cauchy's Formula for Derivatives

**Extended Formula**: For $z_0$ inside $C$:

$$f^{(n)}(z_0) = \frac{n!}{2\pi i}\oint_C \frac{f(z)}{(z - z_0)^{n+1}} \, dz$$

**Key consequence**: An analytic function is **infinitely differentiable**, and all derivatives can be computed from boundary values.

### Example 5: Computing First Derivative

Evaluate $\oint_{|z|=2} \frac{e^z}{(z-1)^2} \, dz$.

**Solution:**

Form: $\frac{f(z)}{(z-z_0)^{n+1}}$ with $f(z) = e^z$, $z_0 = 1$, and $n+1 = 2$ (so $n=1$).

Since $|1| < 2$, point inside contour.

By Cauchy's formula for derivatives:
$$\frac{1!}{2\pi i}\oint_{|z|=2} \frac{e^z}{(z-1)^2} \, dz = f'(1) = e^1 = e$$

Therefore:
$$\oint_{|z|=2} \frac{e^z}{(z-1)^2} \, dz = 2\pi i \cdot e$$

**Answer:** $2\pi ie$

### Example 6: Second Derivative

Evaluate $\oint_{|z|=1} \frac{\cos z}{z^3} \, dz$.

**Solution:**

Rewrite: $\frac{\cos z}{z^3} = \frac{\cos z}{(z-0)^3}$

Form: $\frac{f(z)}{(z-z_0)^{n+1}}$ with $f(z) = \cos z$, $z_0 = 0$, $n+1 = 3$ (so $n=2$).

$$\frac{2!}{2\pi i}\oint \frac{\cos z}{z^3} \, dz = f''(0)$$

$f(z) = \cos z \implies f'(z) = -\sin z \implies f''(z) = -\cos z$

$f''(0) = -\cos 0 = -1$

$$\oint_{|z|=1} \frac{\cos z}{z^3} \, dz = 2\pi i \cdot \frac{f''(0)}{2!} = 2\pi i \cdot \frac{-1}{2} = -\pi i$$

**Answer:** $-\pi i$

### Example 7: Third Derivative

Find $\oint_{|z-i|=1} \frac{z^2}{(z-i)^4} \, dz$.

**Solution:**

$f(z) = z^2$, $z_0 = i$, $n+1 = 4$ (so $n=3$)

$$\frac{3!}{2\pi i}\oint \frac{z^2}{(z-i)^4} \, dz = f'''(i)$$

$f(z) = z^2 \implies f'(z) = 2z \implies f''(z) = 2 \implies f'''(z) = 0$

$$\oint \frac{z^2}{(z-i)^4} \, dz = 2\pi i \cdot \frac{0}{3!} = 0$$

**Answer:** $0$

### Example 8: Mixed Form

Evaluate $\oint_{|z|=2} \frac{z^3 + 2z}{(z-1)^3} \, dz$.

**Solution:**

$f(z) = z^3 + 2z$, $z_0 = 1$, $n = 2$

$$f'(z) = 3z^2 + 2, \quad f''(z) = 6z$$

$$f''(1) = 6$$

$$\oint \frac{z^3 + 2z}{(z-1)^3} \, dz = 2\pi i \cdot \frac{f''(1)}{2!} = 2\pi i \cdot \frac{6}{2} = 6\pi i$$

**Answer:** $6\pi i$

## Applications and Consequences

### Example 9: Infinite Differentiability

Explain why an analytic function is infinitely differentiable.

**Solution:**

If $f$ is analytic at $z_0$, it's analytic in some disk around $z_0$.

By Cauchy's formula for derivatives:
$$f^{(n)}(z_0) = \frac{n!}{2\pi i}\oint_C \frac{f(z)}{(z-z_0)^{n+1}} \, dz$$

for any circle $C$ in that disk.

This formula shows $f^{(n)}(z_0)$ exists for **all** $n \geq 0$.

Moreover, $f^{(n)}$ is itself analytic (can differentiate the formula).

**Answer:** Cauchy's formula guarantees derivatives of all orders exist

### Example 10: Evaluating at Different Points

If $f$ is analytic and $\oint_{|z|=1} \frac{f(z)}{z-1/2} \, dz = 4\pi i$, find $f(1/2)$.

**Solution:**

By Cauchy's integral formula:
$$f(1/2) = \frac{1}{2\pi i}\oint_{|z|=1} \frac{f(z)}{z-1/2} \, dz$$

Given: $\oint_{|z|=1} \frac{f(z)}{z-1/2} \, dz = 4\pi i$

$$f(1/2) = \frac{1}{2\pi i} \cdot 4\pi i = 2$$

**Answer:** $f(1/2) = 2$

### Example 11: Checking Analyticity

If $g$ is continuous in $|z| \leq 1$ and $\oint_{|z|=1} \frac{g(z)}{z-z_0} \, dz = 2\pi i g(z_0)$ for all $|z_0| < 1$, what can we conclude?

**Solution:**

The Cauchy integral formula holds for $g$.

This is characteristic of analytic functions.

By **Morera's theorem** (converse to Cauchy): if $\oint_C g = 0$ for all closed contours, then $g$ is analytic.

The given condition implies $g$ is analytic in $|z| < 1$.

**Answer:** $g$ is analytic in $|z| < 1$

### Example 12: Maximum Modulus from Formula

Use Cauchy's formula to explain why $|f(z_0)| \leq \max_{|z|=r} |f(z)|$ for analytic $f$.

**Solution:**

$$f(z_0) = \frac{1}{2\pi i}\oint_{|z-z_0|=r} \frac{f(z)}{z-z_0} \, dz$$

$$|f(z_0)| = \left|\frac{1}{2\pi i}\oint \frac{f(z)}{z-z_0} dz\right|$$

Using ML inequality:
$$\leq \frac{1}{2\pi} \cdot M \cdot 2\pi r \cdot \frac{1}{r} = M$$

where $M = \max_{|z-z_0|=r} |f(z)|$.

**Answer:** Interior value bounded by maximum on circle (preview of maximum modulus principle)

### Example 13: Generating Taylor Coefficients

Show that Cauchy's formula gives Taylor series coefficients.

**Solution:**

The Taylor series of $f$ at $z_0$ is:
$$f(z) = \sum_{n=0}^{\infty} a_n(z-z_0)^n$$

where $a_n = \frac{f^{(n)}(z_0)}{n!}$.

From Cauchy's formula for derivatives:
$$f^{(n)}(z_0) = \frac{n!}{2\pi i}\oint_C \frac{f(z)}{(z-z_0)^{n+1}} \, dz$$

Therefore:
$$a_n = \frac{1}{2\pi i}\oint_C \frac{f(z)}{(z-z_0)^{n+1}} \, dz$$

This is the **integral formula for Taylor coefficients**.

**Answer:** Cauchy's formula directly gives Taylor series coefficients

## Answer Key

**Problem 1: B**
Cauchy's integral formula: $f(z_0) = \frac{1}{2\pi i}\oint_C \frac{f(z)}{z-z_0} dz$
Interior value determined by boundary values
Remarkable property: knowing $f$ on edge determines $f$ everywhere inside
Rigidity of analytic functions
Shows analytic functions are completely determined by boundary data

**Problem 2: B**
Form: $\frac{f(z)}{z-z_0}$ with $f(z) = e^z$ and $z_0 = 0$
$z_0 = 0$ is inside $|z|=2$
Cauchy: $\oint \frac{e^z}{z} dz = 2\pi i f(0) = 2\pi i e^0 = 2\pi i$
Important special case: $\oint_{|z|=r} \frac{dz}{z} = 2\pi i$ (any $r>0$)
Not $2\pi ie$ because $f(0) = e^0 = 1$, not $e$

**Problem 3: C**
Singularity at $z_0 = 2$, which is outside $|z|=1$
Function $\frac{\sin z}{(z-2)^2}$ is analytic inside and on $|z|=1$
By Cauchy's theorem: integral is $0$
If $z_0$ were inside (e.g., $|z|=3$), would use derivative formula
Singularity location crucial for determining integral value

**Problem 4: C**
Analytic function has derivatives of all orders
Cauchy's formula for derivatives: $f^{(n)}(z_0) = \frac{n!}{2\pi i}\oint \frac{f(z)}{(z-z_0)^{n+1}} dz$
Formula exists for all $n \geq 0$
Remarkable rigidity: differentiable once → differentiable infinitely many times
Contrast with real analysis: differentiable doesn't imply twice differentiable

**Problem 5: B**
Standard result: $\oint_C \frac{dz}{(z-z_0)^n} = 0$ for $n \neq 1$
Here $n=3$, so integral is $0$
Only $n=1$ gives $2\pi i$
Can verify using Cauchy's formula: corresponds to $f(z)=1$, $f''(0)=0$
Or parametrize directly: exponentials cancel in integration

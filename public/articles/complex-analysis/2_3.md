# Complex Analysis Topic 2.3: Harmonic Functions

In electrostatics, the electric potential in a charge-free region satisfies Laplace's equation $\nabla^2 \phi = 0$. In fluid dynamics, the velocity potential for irrotational incompressible flow satisfies the same equation. In heat conduction, steady-state temperature distributions are governed by $\nabla^2 T = 0$. These **harmonic functions**—solutions to Laplace's equation—appear throughout physics and engineering wherever equilibrium or potential theory matters. Complex analysis provides a powerful framework for understanding harmonic functions: every harmonic function is the real (or imaginary) part of some analytic function.

This connection between harmonic functions and analytic functions is profound. If $f = u + iv$ is analytic, then both $u$ and $v$ automatically satisfy Laplace's equation: $\nabla^2 u = 0$ and $\nabla^2 v = 0$. The Cauchy-Riemann equations ensure this relationship. Conversely, given a harmonic function $u$, we can construct its **harmonic conjugate** $v$ such that $f = u + iv$ is analytic. This construction transforms potential problems into complex function problems, where powerful techniques like conformal mapping become available.

This article explores harmonic functions through the lens of complex analysis. We'll prove that real and imaginary parts of analytic functions are harmonic, learn to find harmonic conjugates, understand the geometric meaning of harmonic functions, apply the maximum principle, and see how complex analysis solves boundary value problems in physics. You'll master the interplay between analytic and harmonic functions, gaining tools to solve Laplace's equation using complex methods.

## Definition and Basic Properties

A function $u(x,y)$ is **harmonic** in a domain $D$ if:
1. $u$ has continuous second partial derivatives in $D$
2. $u$ satisfies **Laplace's equation**: $\nabla^2 u = 0$

where $\nabla^2 u = u_{xx} + u_{yy}$ (the **Laplacian**).

### Example 1: Verifying Harmonic Function

Show that $u(x,y) = x^2 - y^2$ is harmonic.

**Solution:**

$$u_x = 2x \implies u_{xx} = 2$$
$$u_y = -2y \implies u_{yy} = -2$$

$$\nabla^2 u = u_{xx} + u_{yy} = 2 + (-2) = 0$$ ✓

**Answer:** $u = x^2 - y^2$ is harmonic

### Example 2: Non-harmonic Function

Show that $u(x,y) = x^2 + y^2$ is not harmonic.

**Solution:**

$$u_x = 2x \implies u_{xx} = 2$$
$$u_y = 2y \implies u_{yy} = 2$$

$$\nabla^2 u = u_{xx} + u_{yy} = 2 + 2 = 4 \neq 0$$ ✗

**Answer:** Not harmonic (Laplacian is 4, not zero)

### Example 3: Logarithm Function

Show that $u(x,y) = \ln(x^2 + y^2) = \ln|z|^2 = 2\ln|z|$ is harmonic for $z \neq 0$.

**Solution:**

$$u = \ln(x^2 + y^2)$$

$$u_x = \frac{2x}{x^2 + y^2}$$
$$u_{xx} = \frac{2(x^2+y^2) - 2x(2x)}{(x^2+y^2)^2} = \frac{2y^2 - 2x^2}{(x^2+y^2)^2}$$

$$u_y = \frac{2y}{x^2 + y^2}$$
$$u_{yy} = \frac{2(x^2+y^2) - 2y(2y)}{(x^2+y^2)^2} = \frac{2x^2 - 2y^2}{(x^2+y^2)^2}$$

$$\nabla^2 u = u_{xx} + u_{yy} = \frac{2y^2 - 2x^2 + 2x^2 - 2y^2}{(x^2+y^2)^2} = 0$$ ✓

**Answer:** Harmonic for $z \neq 0$

## Harmonic Functions from Analytic Functions

**Theorem**: If $f(z) = u(x,y) + iv(x,y)$ is analytic in domain $D$, then both $u$ and $v$ are harmonic in $D$.

**Proof**: From Cauchy-Riemann equations:
$$u_x = v_y \quad \text{and} \quad u_y = -v_x$$

Differentiate first equation with respect to $x$:
$$u_{xx} = v_{yx}$$

Differentiate second equation with respect to $y$:
$$u_{yy} = -v_{xy}$$

Since $v$ has continuous mixed partials: $v_{xy} = v_{yx}$

Therefore:
$$u_{xx} + u_{yy} = v_{yx} - v_{xy} = 0$$

Similarly for $v$: $v_{xx} + v_{yy} = 0$

### Example 4: Harmonic Components of $e^z$

Verify that real and imaginary parts of $e^z$ are harmonic.

**Solution:**

$$e^z = e^{x+iy} = e^x(\cos y + i\sin y)$$

$$u = e^x\cos y, \quad v = e^x\sin y$$

For $u$:
$$u_x = e^x\cos y, \quad u_{xx} = e^x\cos y$$
$$u_y = -e^x\sin y, \quad u_{yy} = -e^x\cos y$$
$$\nabla^2 u = e^x\cos y - e^x\cos y = 0$$ ✓

For $v$:
$$v_x = e^x\sin y, \quad v_{xx} = e^x\sin y$$
$$v_y = e^x\cos y, \quad v_{yy} = -e^x\sin y$$
$$\nabla^2 v = e^x\sin y - e^x\sin y = 0$$ ✓

**Answer:** Both components harmonic (as expected from analytic function)

### Example 5: Identifying Analytic Function

If $u(x,y) = x^3 - 3xy^2$, find an analytic function $f$ with $\text{Re}(f) = u$.

**Solution:**

First verify $u$ is harmonic:
$$u_x = 3x^2 - 3y^2, \quad u_{xx} = 6x$$
$$u_y = -6xy, \quad u_{yy} = -6x$$
$$\nabla^2 u = 6x - 6x = 0$$ ✓

Find harmonic conjugate using Cauchy-Riemann:
$$v_y = u_x = 3x^2 - 3y^2$$
$$v_x = -u_y = 6xy$$

Integrate $v_y$ with respect to $y$:
$$v = 3x^2y - y^3 + g(x)$$

Differentiate with respect to $x$:
$$v_x = 6xy + g'(x) = 6xy$$

So $g'(x) = 0 \implies g(x) = C$.

Taking $C = 0$: $v = 3x^2y - y^3$

$$f(z) = u + iv = (x^3 - 3xy^2) + i(3x^2y - y^3)$$

Factoring: Note that $x^3 - 3xy^2 = \text{Re}(z^3)$ and $3x^2y - y^3 = \text{Im}(z^3)$

$$f(z) = z^3$$

**Answer:** $f(z) = z^3$

## Harmonic Conjugates

Given harmonic function $u$, a function $v$ is the **harmonic conjugate** of $u$ if $f = u + iv$ is analytic.

**Method to find $v$**:
1. Verify $u$ is harmonic
2. Use Cauchy-Riemann to get $v_x$ and $v_y$
3. Integrate one equation
4. Use the other to determine arbitrary function
5. Verify result

### Example 6: Finding Harmonic Conjugate

Find the harmonic conjugate of $u(x,y) = 2x(1-y)$.

**Solution:**

Check harmonic:
$$u_x = 2(1-y), \quad u_{xx} = 0$$
$$u_y = -2x, \quad u_{yy} = 0$$
$$\nabla^2 u = 0$$ ✓

Cauchy-Riemann:
$$v_y = u_x = 2(1-y) = 2 - 2y$$
$$v_x = -u_y = 2x$$

From $v_x = 2x$, integrate with respect to $x$:
$$v = x^2 + h(y)$$

Differentiate with respect to $y$:
$$v_y = h'(y) = 2 - 2y$$

Integrate:
$$h(y) = 2y - y^2 + C$$

$$v = x^2 + 2y - y^2 + C$$

**Answer:** $v = x^2 - y^2 + 2y + C$

### Example 7: Non-uniqueness of Conjugate

Show that the harmonic conjugate is determined only up to an additive constant.

**Solution:**

If $v$ is harmonic conjugate of $u$, then $f = u + iv$ is analytic.

If we replace $v$ by $v + C$ where $C$ is constant:
$$f_1 = u + i(v + C) = (u + iv) + iC = f + iC$$

Since $(f + iC)' = f'$ (derivative of constant is zero), $f_1$ is also analytic.

Therefore $v + C$ is also a harmonic conjugate.

**Answer:** Harmonic conjugate unique up to additive constant

### Example 8: Conjugate in Polar Coordinates

Find the harmonic conjugate of $u(r,\theta) = r^2\cos(2\theta)$ for $r > 0$.

**Solution:**

Using polar Cauchy-Riemann:
$$u_r = 2r\cos(2\theta) \implies \frac{1}{r}v_\theta = 2r\cos(2\theta) \implies v_\theta = 2r^2\cos(2\theta)$$

$$\frac{1}{r}u_\theta = \frac{1}{r}(-2r^2\sin(2\theta)) = -2r\sin(2\theta)$$
$$-v_r = -2r\sin(2\theta) \implies v_r = 2r\sin(2\theta)$$

From $v_r = 2r\sin(2\theta)$, integrate with respect to $r$:
$$v = r^2\sin(2\theta) + g(\theta)$$

Check with $v_\theta$:
$$v_\theta = 2r^2\cos(2\theta) + g'(\theta) = 2r^2\cos(2\theta)$$

So $g'(\theta) = 0 \implies g = C$.

$$v = r^2\sin(2\theta) + C$$

**Note**: $f(z) = z^2 = r^2e^{i2\theta} = r^2(\cos 2\theta + i\sin 2\theta)$ ✓

**Answer:** $v = r^2\sin(2\theta) + C$

## Mean Value Property

**Mean Value Property**: If $u$ is harmonic in a disk, then $u$ at the center equals the average of $u$ on any circle:

$$u(z_0) = \frac{1}{2\pi}\int_0^{2\pi} u(z_0 + re^{i\theta}) \, d\theta$$

for any $r$ such that $|z - z_0| \leq r$ is in the domain.

### Example 9: Verifying Mean Value Property

Verify the mean value property for $u(x,y) = x$ on the circle $|z| = 1$ centered at origin.

**Solution:**

At center: $u(0,0) = 0$

On circle $z = e^{i\theta}$: $u(\cos\theta, \sin\theta) = \cos\theta$

Average:
$$\frac{1}{2\pi}\int_0^{2\pi} \cos\theta \, d\theta = \frac{1}{2\pi}[\sin\theta]_0^{2\pi} = 0$$ ✓

**Answer:** Mean value property verified

### Example 10: Application of Mean Value

If $u$ is harmonic and $u \geq 0$ everywhere, with $u(z_0) = 0$ for some interior point $z_0$, what can we conclude?

**Solution:**

By mean value property:
$$u(z_0) = \frac{1}{2\pi}\int_0^{2\pi} u(z_0 + re^{i\theta}) \, d\theta$$

If $u(z_0) = 0$ and $u \geq 0$ everywhere, then the average equals 0.

Since integrand $u(z_0 + re^{i\theta}) \geq 0$ and integral is 0, we must have:
$$u(z_0 + re^{i\theta}) = 0$$ for all $\theta$

This holds for any $r$, so $u = 0$ in entire disk around $z_0$.

By continuation: $u = 0$ everywhere in connected domain.

**Answer:** $u$ must be identically zero in the domain

## Maximum Principle

**Maximum Principle**: If $u$ is harmonic and non-constant in a domain $D$, then $u$ has no maximum in the interior of $D$. Any maximum occurs on the boundary.

Similarly for minimum (or apply to $-u$).

### Example 11: Using Maximum Principle

If $u$ is harmonic in $|z| < 1$ with $|u| \leq 1$ on $|z| = 1$, what is the maximum of $|u|$ in the disk?

**Solution:**

Apply maximum principle to both $u$ and $-u$:
- Maximum of $u$ occurs on boundary: $\max u \leq 1$
- Maximum of $-u$ (= minimum of $u$) occurs on boundary: $\min u \geq -1$

Therefore $|u| \leq 1$ throughout the disk, with maximum on boundary.

**Answer:** $\max |u| = 1$ (achieved on boundary)

### Example 12: Uniqueness via Maximum Principle

If $u_1$ and $u_2$ are harmonic in $D$ with $u_1 = u_2$ on $\partial D$, show $u_1 = u_2$ in $D$.

**Solution:**

Let $w = u_1 - u_2$. Then $w$ is harmonic (Laplacian is linear).

On boundary: $w = 0$.

By maximum principle: maximum of $w$ occurs on boundary, so $w \leq 0$ everywhere.

By minimum principle: minimum of $w$ occurs on boundary, so $w \geq 0$ everywhere.

Therefore $w = 0$ everywhere, i.e., $u_1 = u_2$.

**Answer:** Uniqueness proven (Dirichlet problem has unique solution)

### Example 13: Physical Interpretation

In steady-state heat conduction, temperature $T$ satisfies $\nabla^2 T = 0$. Why can't the hottest point be in the interior?

**Solution:**

By maximum principle, maximum temperature occurs on the boundary.

**Physical meaning**: In steady state, heat flows from hot to cold. If interior point were hottest, heat would flow away in all directions, causing temperature to decrease—contradicting steady state.

Interior temperatures are always **averages** of surrounding values (mean value property).

**Answer:** Maximum principle ensures heat flows inward from boundary; no interior maximum

$u_{xx} + u_{yy} = 0$ and $v_{xx} + v_{yy} = 0$
Converse: if $u$ is harmonic, can find $v$ making $f$ analytic
Real and imaginary parts of analytic function are harmonic

**Problem 2: B**
$u = x$

Holds for any radius within domain
Fundamental property distinguishing harmonic functions

**Problem 4: B**

Interior points cannot be maximum (except constant functions)
Physical: steady-state temperature can't be hottest in interior
Also minimum principle (apply to $-u$)
Used to prove uniqueness of Dirichlet problem

**Problem 5: C**
Definition: $v$ is harmonic conjugate of $u$ if $f = u + iv$ is analytic
Means Cauchy-Riemann equations satisfied
Both $u$ and $v$ are harmonic
$v$ determined by $u$ up to additive constant
Not true that $u = v$ or that $uv$ is harmonic

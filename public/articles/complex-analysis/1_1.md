# Complex Analysis Topic 1.1: The Complex Number System

When sixteenth-century mathematicians first encountered equations like $x^2 + 1 = 0$, they faced a crisis. No real number satisfies this equation—the square of any real number is non-negative, so $x^2 = -1$ seemed impossible. Yet imagining such numbers existed led to breakthroughs in solving cubic equations. The introduction of $i = \sqrt{-1}$ wasn't mathematical fantasy but pragmatic necessity. Complex numbers, initially called "imaginary" with suspicion, revealed themselves as natural extensions of the reals with profound geometric meaning.

Complex numbers aren't just formal algebraic objects—they represent points in a plane, transforming algebra into geometry. Every complex number $z = x + iy$ corresponds to the point $(x, y)$ in the complex plane, where addition becomes vector addition and multiplication becomes rotation and scaling. This geometric interpretation unlocks intuition: multiplying by $i$ rotates counterclockwise by $90°$, while the modulus $|z|$ measures distance from the origin. Euler's formula $e^{i\theta} = \cos\theta + i\sin\theta$ connects exponentials to trigonometry, revealing deep unity in mathematics.

This article develops the complex number system from foundations. We'll define complex arithmetic, explore geometric interpretations, master polar and exponential forms, prove fundamental identities, and solve equations in the complex plane. You'll learn to visualize complex operations geometrically, convert fluently between representations, and appreciate why complex numbers are more natural than real numbers for many purposes. These tools form the essential foundation for all of complex analysis.

## Definition and Arithmetic

A **complex number** is an expression of the form $z = x + iy$ where $x, y \in \mathbb{R}$ and $i^2 = -1$.

- **Real part**: $\text{Re}(z) = x$
- **Imaginary part**: $\text{Im}(z) = y$
- **Complex plane**: $z$ corresponds to point $(x, y)$

**Arithmetic operations**:

**Addition**: $(x_1 + iy_1) + (x_2 + iy_2) = (x_1 + x_2) + i(y_1 + y_2)$

**Multiplication**: $(x_1 + iy_1)(x_2 + iy_2) = (x_1x_2 - y_1y_2) + i(x_1y_2 + x_2y_1)$

**Complex conjugate**: $\overline{z} = x - iy$ (reflection across real axis)

### Example 1: Basic Arithmetic

Compute $(3 + 2i) + (1 - 4i)$ and $(3 + 2i)(1 - 4i)$.

**Solution:**

Addition:
$$(3 + 2i) + (1 - 4i) = (3 + 1) + i(2 - 4) = 4 - 2i$$

Multiplication:
$$(3 + 2i)(1 - 4i) = 3(1) + 3(-4i) + 2i(1) + 2i(-4i)$$
$$= 3 - 12i + 2i - 8i^2$$
$$= 3 - 10i - 8(-1)$$
$$= 3 - 10i + 8 = 11 - 10i$$

**Answer:** Sum is $4 - 2i$; product is $11 - 10i$

### Example 2: Complex Conjugate Properties

Prove that $\overline{z_1 + z_2} = \overline{z_1} + \overline{z_2}$ and $\overline{z_1 z_2} = \overline{z_1} \cdot \overline{z_2}$.

**Solution:**

Let $z_1 = x_1 + iy_1$ and $z_2 = x_2 + iy_2$.

**Addition**:
$$z_1 + z_2 = (x_1 + x_2) + i(y_1 + y_2)$$
$$\overline{z_1 + z_2} = (x_1 + x_2) - i(y_1 + y_2)$$
$$\overline{z_1} + \overline{z_2} = (x_1 - iy_1) + (x_2 - iy_2) = (x_1 + x_2) - i(y_1 + y_2)$$ ✓

**Multiplication**:
$$z_1z_2 = (x_1x_2 - y_1y_2) + i(x_1y_2 + x_2y_1)$$
$$\overline{z_1z_2} = (x_1x_2 - y_1y_2) - i(x_1y_2 + x_2y_1)$$
$$\overline{z_1} \cdot \overline{z_2} = (x_1 - iy_1)(x_2 - iy_2) = (x_1x_2 - y_1y_2) - i(x_1y_2 + x_2y_1)$$ ✓

**Answer:** Both properties verified; conjugation distributes over addition and multiplication

### Example 3: Division of Complex Numbers

Compute $\frac{2 + 3i}{1 - i}$.

**Solution:**

Multiply numerator and denominator by conjugate of denominator:
$$\frac{2 + 3i}{1 - i} = \frac{(2 + 3i)(1 + i)}{(1 - i)(1 + i)}$$

Numerator: $(2 + 3i)(1 + i) = 2 + 2i + 3i + 3i^2 = 2 + 5i - 3 = -1 + 5i$

Denominator: $(1 - i)(1 + i) = 1 - i^2 = 1 - (-1) = 2$

$$\frac{-1 + 5i}{2} = -\frac{1}{2} + \frac{5}{2}i$$

**Answer:** $-\frac{1}{2} + \frac{5}{2}i$

## Geometric Interpretation

Complex numbers represent points in the **complex plane** (or **Argand diagram**):
- Horizontal axis: real part
- Vertical axis: imaginary part

**Modulus** (absolute value): $|z| = \sqrt{x^2 + y^2}$ (distance from origin)

**Argument**: $\arg(z) = \theta$ where $\tan\theta = \frac{y}{x}$ (angle from positive real axis)

### Example 4: Computing Modulus and Argument

Find $|z|$ and $\arg(z)$ for $z = 1 + i$.

**Solution:**

$$|z| = \sqrt{1^2 + 1^2} = \sqrt{2}$$

$$\tan\theta = \frac{1}{1} = 1 \implies \theta = \frac{\pi}{4}$$ (since $z$ is in first quadrant)

**Answer:** $|z| = \sqrt{2}$, $\arg(z) = \frac{\pi}{4}$

### Example 5: Multiplication as Rotation and Scaling

Show that $|z_1z_2| = |z_1||z_2|$ and $\arg(z_1z_2) = \arg(z_1) + \arg(z_2)$.

**Solution:**

Using $z \overline{z} = |z|^2$:
$$|z_1z_2|^2 = (z_1z_2)\overline{(z_1z_2)} = z_1z_2\overline{z_1}\overline{z_2} = z_1\overline{z_1} \cdot z_2\overline{z_2} = |z_1|^2|z_2|^2$$

Therefore $|z_1z_2| = |z_1||z_2|$ ✓

For argument, convert to polar form (see next section). Multiplication in polar form adds angles.

**Geometric meaning**: Multiplying by $z$ scales by $|z|$ and rotates by $\arg(z)$.

**Answer:** Multiplication combines moduli (scaling) and adds arguments (rotation)

### Example 6: Triangle Inequality

Prove $|z_1 + z_2| \leq |z_1| + |z_2|$.

**Solution:**

Interpret geometrically: $z_1 + z_2$ is the vector sum. By triangle inequality for vectors, the length of one side cannot exceed the sum of the other two sides.

Algebraic proof:
$$|z_1 + z_2|^2 = (z_1 + z_2)\overline{(z_1 + z_2)} = (z_1 + z_2)(\overline{z_1} + \overline{z_2})$$
$$= z_1\overline{z_1} + z_1\overline{z_2} + z_2\overline{z_1} + z_2\overline{z_2}$$
$$= |z_1|^2 + |z_2|^2 + (z_1\overline{z_2} + \overline{z_1\overline{z_2}})$$
$$= |z_1|^2 + |z_2|^2 + 2\text{Re}(z_1\overline{z_2})$$

Since $\text{Re}(w) \leq |w|$:
$$\leq |z_1|^2 + |z_2|^2 + 2|z_1||z_2| = (|z_1| + |z_2|)^2$$

Therefore $|z_1 + z_2| \leq |z_1| + |z_2|$ ✓

**Answer:** Triangle inequality proven; equality when $z_1$ and $z_2$ have same argument

## Polar and Exponential Forms

**Polar form**: $z = r(\cos\theta + i\sin\theta)$ where $r = |z|$ and $\theta = \arg(z)$

**Exponential form** (Euler's formula): $z = re^{i\theta}$

**Euler's formula**: $e^{i\theta} = \cos\theta + i\sin\theta$

### Example 7: Converting to Polar Form

Express $z = -1 + i$ in polar form.

**Solution:**

$$r = |-1 + i| = \sqrt{(-1)^2 + 1^2} = \sqrt{2}$$

$$\tan\theta = \frac{1}{-1} = -1$$

Since $z$ is in second quadrant: $\theta = \frac{3\pi}{4}$

$$z = \sqrt{2}\left(\cos\frac{3\pi}{4} + i\sin\frac{3\pi}{4}\right) = \sqrt{2}e^{i3\pi/4}$$

**Answer:** $z = \sqrt{2}e^{i3\pi/4}$

### Example 8: Euler's Formula Verification

Verify Euler's formula $e^{i\pi} = -1$.

**Solution:**

$$e^{i\pi} = \cos\pi + i\sin\pi = -1 + i(0) = -1$$ ✓

This is **Euler's identity**: $e^{i\pi} + 1 = 0$

It connects five fundamental constants: $e$, $i$, $\pi$, $1$, and $0$.

**Answer:** $e^{i\pi} = -1$ verified; one of mathematics' most beautiful equations

### Example 9: Powers Using De Moivre's Theorem

Compute $(1 + i)^{10}$.

**Solution:**

First convert to polar form: $1 + i = \sqrt{2}e^{i\pi/4}$

**De Moivre's Theorem**: $(re^{i\theta})^n = r^ne^{in\theta}$

$$(1 + i)^{10} = (\sqrt{2})^{10}e^{i10\pi/4} = 2^5e^{i5\pi/2}$$

$$e^{i5\pi/2} = e^{i(2\pi + \pi/2)} = e^{i\pi/2} = \cos\frac{\pi}{2} + i\sin\frac{\pi}{2} = i$$

$$(1 + i)^{10} = 32i$$

**Answer:** $32i$

### Example 10: Product in Polar Form

If $z_1 = 2e^{i\pi/3}$ and $z_2 = 3e^{i\pi/6}$, find $z_1z_2$.

**Solution:**

$$z_1z_2 = (2e^{i\pi/3})(3e^{i\pi/6}) = 6e^{i(\pi/3 + \pi/6)} = 6e^{i\pi/2}$$

$$= 6(\cos\frac{\pi}{2} + i\sin\frac{\pi}{2}) = 6i$$

**Geometric interpretation**: Moduli multiply ($2 \times 3 = 6$), arguments add ($\frac{\pi}{3} + \frac{\pi}{6} = \frac{\pi}{2}$)

**Answer:** $6i$

## Roots of Complex Numbers

To solve $z^n = w$, use polar form: if $w = re^{i\theta}$, then

$$z_k = r^{1/n}e^{i(\theta + 2\pi k)/n}, \quad k = 0, 1, \ldots, n-1$$

There are exactly $n$ distinct $n$th roots, evenly spaced around a circle.

### Example 11: Cube Roots of Unity

Find all solutions to $z^3 = 1$.

**Solution:**

Write $1 = e^{i \cdot 0}$ (or $1 = e^{i2\pi k}$ for any integer $k$).

$$z_k = e^{i2\pi k/3}, \quad k = 0, 1, 2$$

$$z_0 = e^{i \cdot 0} = 1$$
$$z_1 = e^{i2\pi/3} = \cos\frac{2\pi}{3} + i\sin\frac{2\pi}{3} = -\frac{1}{2} + i\frac{\sqrt{3}}{2}$$
$$z_2 = e^{i4\pi/3} = \cos\frac{4\pi}{3} + i\sin\frac{4\pi}{3} = -\frac{1}{2} - i\frac{\sqrt{3}}{2}$$

**Geometric interpretation**: Three equally-spaced points on unit circle, separated by $120°$.

**Answer:** $1, -\frac{1}{2} + i\frac{\sqrt{3}}{2}, -\frac{1}{2} - i\frac{\sqrt{3}}{2}$

### Example 12: Square Roots of i

Find all solutions to $z^2 = i$.

**Solution:**

Write $i = e^{i\pi/2}$ (or $i = e^{i(\pi/2 + 2\pi k)}$).

$$z_k = e^{i(\pi/2 + 2\pi k)/2} = e^{i(\pi/4 + \pi k)}, \quad k = 0, 1$$

$$z_0 = e^{i\pi/4} = \cos\frac{\pi}{4} + i\sin\frac{\pi}{4} = \frac{1}{\sqrt{2}} + i\frac{1}{\sqrt{2}} = \frac{1 + i}{\sqrt{2}}$$

$$z_1 = e^{i5\pi/4} = \cos\frac{5\pi}{4} + i\sin\frac{5\pi}{4} = -\frac{1}{\sqrt{2}} - i\frac{1}{\sqrt{2}} = -\frac{1 + i}{\sqrt{2}}$$

**Verification**: $\left(\frac{1+i}{\sqrt{2}}\right)^2 = \frac{(1+i)^2}{2} = \frac{1 + 2i - 1}{2} = i$ ✓

**Answer:** $\pm\frac{1 + i}{\sqrt{2}}$

### Example 13: Fifth Roots

How many fifth roots does any nonzero complex number have? Where are they located?

**Solution:**

For $z^5 = w$ where $w = re^{i\theta}$:

$$z_k = r^{1/5}e^{i(\theta + 2\pi k)/5}, \quad k = 0, 1, 2, 3, 4$$

**Count**: Exactly 5 distinct roots

**Location**: On circle of radius $r^{1/5}$, equally spaced by angle $\frac{2\pi}{5} = 72°$

**Answer:** Every nonzero complex number has exactly 5 fifth roots, equally spaced at $72°$ intervals on a circle

## Regions in the Complex Plane

**Disk**: $|z - z_0| < r$ (interior of circle centered at $z_0$, radius $r$)

**Annulus**: $r_1 < |z - z_0| < r_2$ (region between two circles)

**Half-plane**: $\text{Re}(z) > a$ or $\text{Im}(z) > b$

### Example 14: Describing Regions

Describe the set $\{z : |z - 1| = |z + 1|\}$.

**Solution:**

$$|z - 1| = |z + 1|$$

means $z$ is equidistant from $1$ and $-1$.

This is the **perpendicular bisector** of the segment joining $1$ and $-1$.

Since these points are on the real axis, the perpendicular bisector is the imaginary axis: $\text{Re}(z) = 0$.

**Answer:** The imaginary axis

### Example 15: Interior of Region

Describe $\{z : 1 < |z - i| < 2\}$.

**Solution:**

$$1 < |z - i| < 2$$

This is an **annulus** centered at $z_0 = i$ with inner radius $1$ and outer radius $2$.

**Geometric interpretation**: Region between two circles, both centered at $i$.

**Answer:** Annulus centered at $i$, between circles of radius $1$ and $2$

## Practice Problems

**Problem 1:** The complex number $i^{43}$ equals:

A) $1$
B) $-1$
C) $i$
D) $-i$
E) $0$

**Problem 2:** If $z = 2 + 2i$, then $|z|$ equals:

A) $2$
B) $4$
C) $2\sqrt{2}$
D) $8$
E) $\sqrt{2}$

**Problem 3:** The principal argument of $z = -\sqrt{3} + i$ is:

A) $\frac{\pi}{6}$
B) $\frac{\pi}{3}$
C) $\frac{2\pi}{3}$
D) $\frac{5\pi}{6}$
E) $\frac{7\pi}{6}$

**Problem 4:** How many fourth roots does $16$ have?

A) $1$
B) $2$
C) $4$
D) $8$
E) Infinitely many

**Problem 5:** The conjugate of $(1 + i)^2$ is:

A) $2i$
B) $-2i$
C) $2$
D) $-2$
E) $1 - i$

## Answer Key

**Problem 1: D**
Powers of $i$ cycle with period $4$: $i^1 = i$, $i^2 = -1$, $i^3 = -i$, $i^4 = 1$, then repeat
$43 = 4(10) + 3$, so $i^{43} = i^3 = -i$
Alternatively: $i^{43} = i^{40} \cdot i^3 = (i^4)^{10} \cdot i^3 = 1^{10} \cdot i^3 = i^3 = -i$
Key pattern: $i^{4k} = 1$, $i^{4k+1} = i$, $i^{4k+2} = -1$, $i^{4k+3} = -i$

**Problem 2: C**
$z = 2 + 2i$
$|z| = \sqrt{2^2 + 2^2} = \sqrt{8} = \sqrt{4 \cdot 2} = 2\sqrt{2}$
Modulus formula: $|x + iy| = \sqrt{x^2 + y^2}$
Geometric interpretation: distance from origin to $(2, 2)$ in complex plane
Can also use: $|z|^2 = z\overline{z} = (2+2i)(2-2i) = 4 - 4i^2 = 8$, so $|z| = \sqrt{8}$

**Problem 3: D**
$z = -\sqrt{3} + i$ is in second quadrant
$|z| = \sqrt{3 + 1} = 2$
$\tan\theta = \frac{1}{-\sqrt{3}} = -\frac{1}{\sqrt{3}}$
Reference angle: $\frac{\pi}{6}$
Since $z$ is in quadrant II: $\theta = \pi - \frac{\pi}{6} = \frac{5\pi}{6}$
Alternatively: $z = 2(\cos\frac{5\pi}{6} + i\sin\frac{5\pi}{6})$ where $\cos\frac{5\pi}{6} = -\frac{\sqrt{3}}{2}$, $\sin\frac{5\pi}{6} = \frac{1}{2}$

**Problem 4: C**
$z^4 = 16$
Write $16 = 16e^{i \cdot 0}$
Fourth roots: $z_k = 16^{1/4}e^{i \cdot 2\pi k/4} = 2e^{i\pi k/2}$ for $k = 0, 1, 2, 3$
$z_0 = 2$, $z_1 = 2i$, $z_2 = -2$, $z_3 = -2i$
Every nonzero complex number has exactly $n$ distinct $n$th roots
Geometric: equally spaced on circle of radius $2$, separated by $90°$

**Problem 5: B**
$(1 + i)^2 = 1 + 2i + i^2 = 1 + 2i - 1 = 2i$
Conjugate of $2i$ is $-2i$ (change sign of imaginary part)
Note: $\overline{z^n} = (\overline{z})^n$, so could also compute $(\overline{1+i})^2 = (1-i)^2 = 1 - 2i + i^2 = -2i$
Conjugate operation: $\overline{x + iy} = x - iy$

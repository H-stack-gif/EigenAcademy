# Complex Analysis Topic 1.3: Elementary Functions

The exponential function $e^x$ on the real line grows monotonically, never repeating values. Extend it to the complex plane, and everything changes: $e^z$ becomes **periodic** with period $2\pi i$, wrapping the plane into a cylinder. The trigonometric functions $\sin$ and $\cos$, bounded between $-1$ and $1$ on the real line, explode to infinity along the imaginary axis. The logarithm, uniquely defined for positive reals, becomes **multivalued** for complex numbers—each nonzero complex number has infinitely many logarithms differing by multiples of $2\pi i$. Complex analysis doesn't just extend familiar functions; it transforms their fundamental character.

These elementary functions—exponential, trigonometric, hyperbolic, logarithm, and complex powers—are the building blocks of complex analysis. Their definitions, derived from power series or Euler's formula, reveal unexpected connections: $\sin z$ expressed through exponentials, logarithms related to arguments, powers requiring branch cuts. Understanding these functions deeply means mastering their periodicity, computing their values on the complex plane, and navigating the subtleties of multivalued functions.

This article explores elementary functions in the complex domain. We'll extend exponential and trigonometric functions to complex arguments using Euler's formula, discover their remarkable periodicity, define complex logarithms and their branch structure, construct complex powers, and relate hyperbolic to trigonometric functions. You'll learn to compute values, understand geometric behavior, and appreciate why complex elementary functions are both more general and more intricate than their real counterparts.

## The Complex Exponential Function

**Definition**: For $z = x + iy$:
$$e^z = e^{x+iy} = e^x e^{iy} = e^x(\cos y + i\sin y)$$

**Properties**:
- $|e^z| = e^x = e^{\text{Re}(z)}$ (modulus depends only on real part)
- $\arg(e^z) = y = \text{Im}(z)$ (argument is imaginary part)
- $e^{z_1 + z_2} = e^{z_1}e^{z_2}$ (exponential law)
- **Periodic**: $e^{z + 2\pi i} = e^z$ (period $2\pi i$)
- Never zero: $e^z \neq 0$ for all $z$

### Example 1: Computing Exponential Values

Compute $e^{i\pi}$, $e^{i\pi/2}$, and $e^{1+i\pi}$.

**Solution:**

$$e^{i\pi} = \cos\pi + i\sin\pi = -1 + i(0) = -1$$

$$e^{i\pi/2} = \cos\frac{\pi}{2} + i\sin\frac{\pi}{2} = 0 + i = i$$

$$e^{1+i\pi} = e^1 \cdot e^{i\pi} = e \cdot (-1) = -e$$

**Answer:** $e^{i\pi} = -1$, $e^{i\pi/2} = i$, $e^{1+i\pi} = -e$

### Example 2: Periodicity

Verify that $e^{z + 2\pi i} = e^z$.

**Solution:**

$$e^{z + 2\pi i} = e^z \cdot e^{2\pi i}$$

$$e^{2\pi i} = \cos(2\pi) + i\sin(2\pi) = 1 + i(0) = 1$$

$$e^{z + 2\pi i} = e^z \cdot 1 = e^z$$ ✓

**Geometric interpretation**: Adding $2\pi i$ to $z$ increases $\text{Im}(z)$ by $2\pi$, which completes one full rotation around unit circle in polar form.

**Answer:** $e^z$ has period $2\pi i$; fundamental difference from real exponential

### Example 3: Solving Exponential Equations

Solve $e^z = 1$.

**Solution:**

Need $e^{x+iy} = 1$, so $e^x(\cos y + i\sin y) = 1$.

$$|e^z| = e^x = 1 \implies x = 0$$
$$\arg(e^z) = y = 0 \implies y = 2\pi k$$ for $k \in \mathbb{Z}$

**Solutions**: $z = 2\pi ki$ for any integer $k$

**Answer:** $z = 2\pi ki$, $k \in \mathbb{Z}$ (infinitely many solutions due to periodicity)

### Example 4: Exponential Mapping

Where does $e^z$ map the vertical line $\text{Re}(z) = c$?

**Solution:**

Points on line: $z = c + iy$ for $y \in \mathbb{R}$

$$e^z = e^{c+iy} = e^c e^{iy} = e^c(\cos y + i\sin y)$$

As $y$ varies over $\mathbb{R}$, $e^{iy}$ traces the unit circle.

Multiplying by $e^c$ scales to circle of radius $e^c$.

**Image**: Circle $|w| = e^c$ (traced infinitely many times as $y$ varies)

**Answer:** Circle of radius $e^c$, traced infinitely often

## Complex Trigonometric Functions

**Definitions** (via Euler's formula):

$$\cos z = \frac{e^{iz} + e^{-iz}}{2}$$

$$\sin z = \frac{e^{iz} - e^{-iz}}{2i}$$

**Properties**:
- $\sin^2 z + \cos^2 z = 1$ (Pythagorean identity holds)
- $\sin(-z) = -\sin z$ (odd), $\cos(-z) = \cos z$ (even)
- **Periodic**: period $2\pi$ (same as real case)
- **Unbounded**: $|\sin z|$ and $|\cos z|$ can be arbitrarily large (unlike real case!)

### Example 5: Computing $\sin i$

Compute $\sin i$.

**Solution:**

$$\sin i = \frac{e^{i \cdot i} - e^{-i \cdot i}}{2i} = \frac{e^{-1} - e^{1}}{2i} = \frac{e^{-1} - e}{2i}$$

Multiply by $-i/-i$:
$$= \frac{-i(e^{-1} - e)}{2} = \frac{i(e - e^{-1})}{2}$$

Using $\sinh(1) = \frac{e - e^{-1}}{2}$:
$$\sin i = i\sinh(1)$$

**Answer:** $\sin i = i\sinh(1) \approx 1.175i$ (purely imaginary, unbounded)

### Example 6: Pythagorean Identity

Verify $\sin^2 z + \cos^2 z = 1$ using exponential definitions.

**Solution:**

$$\sin^2 z = \left(\frac{e^{iz} - e^{-iz}}{2i}\right)^2 = \frac{(e^{iz} - e^{-iz})^2}{-4}$$
$$= \frac{e^{2iz} - 2 + e^{-2iz}}{-4}$$

$$\cos^2 z = \left(\frac{e^{iz} + e^{-iz}}{2}\right)^2 = \frac{(e^{iz} + e^{-iz})^2}{4}$$
$$= \frac{e^{2iz} + 2 + e^{-2iz}}{4}$$

$$\sin^2 z + \cos^2 z = \frac{e^{2iz} - 2 + e^{-2iz}}{-4} + \frac{e^{2iz} + 2 + e^{-2iz}}{4}$$
$$= \frac{-(e^{2iz} - 2 + e^{-2iz}) + (e^{2iz} + 2 + e^{-2iz})}{4}$$
$$= \frac{4}{4} = 1$$ ✓

**Answer:** Identity verified; holds for all complex $z$

### Example 7: Solving $\cos z = 2$

Solve $\cos z = 2$.

**Solution:**

$$\frac{e^{iz} + e^{-iz}}{2} = 2$$
$$e^{iz} + e^{-iz} = 4$$

Let $w = e^{iz}$. Then:
$$w + \frac{1}{w} = 4$$
$$w^2 - 4w + 1 = 0$$

Quadratic formula:
$$w = \frac{4 \pm \sqrt{16 - 4}}{2} = \frac{4 \pm 2\sqrt{3}}{2} = 2 \pm \sqrt{3}$$

So $e^{iz} = 2 \pm \sqrt{3}$.

Taking logarithms: $iz = \ln(2 \pm \sqrt{3})$

$$z = \frac{\ln(2 \pm \sqrt{3})}{i} = -i\ln(2 \pm \sqrt{3})$$

**Answer:** $z = -i\ln(2 \pm \sqrt{3})$ (two families of solutions, accounting for periodicity)

## Hyperbolic Functions

**Definitions**:

$$\cosh z = \frac{e^z + e^{-z}}{2}$$

$$\sinh z = \frac{e^z - e^{-z}}{2}$$

**Relation to trigonometric functions**:

$$\cos(iz) = \cosh z$$
$$\sin(iz) = i\sinh z$$

Conversely:
$$\cosh(iz) = \cos z$$
$$\sinh(iz) = i\sin z$$

### Example 8: Computing Hyperbolic Values

Compute $\sinh(\pi i)$ and $\cosh(\pi i)$.

**Solution:**

$$\sinh(\pi i) = \frac{e^{\pi i} - e^{-\pi i}}{2}$$
$$= \frac{(\cos\pi + i\sin\pi) - (\cos\pi - i\sin\pi)}{2}$$
$$= \frac{-1 + 0 - (-1 + 0)}{2} = 0$$

$$\cosh(\pi i) = \frac{e^{\pi i} + e^{-\pi i}}{2}$$
$$= \frac{-1 + (-1)}{2} = -1$$

**Answer:** $\sinh(\pi i) = 0$, $\cosh(\pi i) = -1$

### Example 9: Identity

Verify $\cosh^2 z - \sinh^2 z = 1$.

**Solution:**

$$\cosh^2 z - \sinh^2 z = \left(\frac{e^z + e^{-z}}{2}\right)^2 - \left(\frac{e^z - e^{-z}}{2}\right)^2$$

$$= \frac{(e^z + e^{-z})^2 - (e^z - e^{-z})^2}{4}$$

$$= \frac{(e^{2z} + 2 + e^{-2z}) - (e^{2z} - 2 + e^{-2z})}{4}$$

$$= \frac{4}{4} = 1$$ ✓

**Answer:** Verified; hyperbolic analogue of Pythagorean identity

## The Complex Logarithm

For nonzero $z = re^{i\theta}$:
$$\log z = \ln r + i\theta$$

**Problem**: $\theta = \arg(z)$ is **multivalued** (determined up to $2\pi k$).

**Convention**: **Principal value** $\text{Log } z$ uses $\theta \in (-\pi, \pi]$.

**General logarithm**: $\log z = \text{Log } z + 2\pi ki$ for $k \in \mathbb{Z}$

### Example 10: Computing Logarithms

Find all values of $\log(-1)$.

**Solution:**

Write $-1 = e^{i\pi}$ (or $-1 = e^{i(\pi + 2\pi k)}$).

$$\log(-1) = \ln 1 + i(\pi + 2\pi k) = i\pi(1 + 2k)$$

for any integer $k$.

**Principal value**: $\text{Log}(-1) = i\pi$ (using $\theta = \pi$)

**Answer:** $\log(-1) = i\pi(2k+1)$, $k \in \mathbb{Z}$; principal value $i\pi$

### Example 11: Logarithm of i

Find $\text{Log } i$.

**Solution:**

$$i = e^{i\pi/2}$$
$$|i| = 1, \quad \arg(i) = \frac{\pi}{2}$$ (principal argument)

$$\text{Log } i = \ln 1 + i\frac{\pi}{2} = i\frac{\pi}{2}$$

**Answer:** $\text{Log } i = \frac{\pi i}{2}$

### Example 12: Logarithm Identity Failure

Show that $\text{Log}(z_1z_2)$ may not equal $\text{Log } z_1 + \text{Log } z_2$.

**Solution:**

Let $z_1 = z_2 = -1$.

$$\text{Log}(-1) = i\pi$$
$$\text{Log}(-1) + \text{Log}(-1) = 2i\pi$$

But:
$$(-1)(-1) = 1$$
$$\text{Log}(1) = 0$$

So $\text{Log}(z_1z_2) = 0 \neq 2i\pi = \text{Log } z_1 + \text{Log } z_2$

**Explanation**: Principal value wraps around at $\pi$; general identity $\log(z_1z_2) = \log z_1 + \log z_2$ holds for multivalued logarithm.

**Answer:** Principal Log doesn't satisfy logarithm product law; multivalued log does

### Example 13: Solving Exponential Equation

Solve $e^z = i$.

**Solution:**

Take logarithm: $z = \log i$

$$\log i = \ln|i| + i\arg(i) = 0 + i\left(\frac{\pi}{2} + 2\pi k\right)$$

$$z = i\frac{\pi}{2}(1 + 4k)$$

for $k \in \mathbb{Z}$.

**Answer:** $z = \frac{\pi i}{2} + 2\pi ki$, $k \in \mathbb{Z}$

## Complex Powers

For $z \neq 0$ and $\alpha \in \mathbb{C}$:
$$z^\alpha = e^{\alpha \log z}$$

Since $\log z$ is multivalued, $z^\alpha$ is generally **multivalued**.

**Exception**: If $\alpha$ is an integer, $z^\alpha$ is single-valued.

### Example 14: Computing $i^i$

Find the principal value of $i^i$.

**Solution:**

$$i^i = e^{i \log i} = e^{i \cdot \text{Log } i}$$

$$\text{Log } i = i\frac{\pi}{2}$$

$$i^i = e^{i \cdot i\pi/2} = e^{-\pi/2}$$

This is a **real number**!

$$e^{-\pi/2} \approx 0.208$$

**Answer:** Principal value $i^i = e^{-\pi/2} \approx 0.208$ (real and positive!)

### Example 15: Multivalued Power

How many values does $(-1)^{1/2}$ have?

**Solution:**

$$(-1)^{1/2} = e^{\frac{1}{2}\log(-1)} = e^{\frac{1}{2}[i\pi(2k+1)]}$$

$$= e^{i\pi(2k+1)/2}$$

For $k = 0$: $e^{i\pi/2} = i$
For $k = 1$: $e^{i3\pi/2} = e^{-i\pi/2} = -i$
For $k = 2$: $e^{i5\pi/2} = e^{i\pi/2} = i$ (repeats)

**Two distinct values**: $\pm i$

**Answer:** Two values: $i$ and $-i$ (the square roots of $-1$)

### Example 16: Principal Value Convention

Using the principal branch, compute $(1 + i)^{1+i}$.

**Solution:**

$$\text{Log}(1 + i) = \ln|1 + i| + i\arg(1 + i)$$
$$= \ln\sqrt{2} + i\frac{\pi}{4} = \frac{1}{2}\ln 2 + i\frac{\pi}{4}$$

$$(1 + i)^{1+i} = e^{(1+i)\text{Log}(1+i)}$$
$$= e^{(1+i)(\frac{1}{2}\ln 2 + i\frac{\pi}{4})}$$
$$= e^{\frac{1}{2}\ln 2 + i\frac{\pi}{4} + i\frac{1}{2}\ln 2 - \frac{\pi}{4}}$$
$$= e^{(\frac{1}{2}\ln 2 - \frac{\pi}{4}) + i(\frac{\pi}{4} + \frac{1}{2}\ln 2)}$$

**Answer:** $e^{(\ln\sqrt{2} - \pi/4)}e^{i(\pi/4 + \ln\sqrt{2}/2)}$ (complex number)

## Answer Key

**Problem 1: B**
$e^{2\pi i} = \cos(2\pi) + i\sin(2\pi) = 1 + 0i = 1$
This demonstrates periodicity: $e^{z + 2\pi i} = e^z$
Fundamental period is $2\pi i$ (not $2\pi$)
Compare: real exponential $e^x$ has no period
Geometric: adding $2\pi i$ completes one rotation

**Problem 2: B**
$\sin z = \frac{e^{iz} - e^{-iz}}{2i}$ is unbounded
For $z = iy$ (pure imaginary): $|\sin(iy)| = |\sinh y| \to \infty$ as $y \to \infty$
Unlike real sine (bounded by $\pm 1$)
Also: $\cos z$ is unbounded
$e^z$ has unbounded modulus but mentioned "modulus" in choice

**Problem 3: A**
$-i = e^{-i\pi/2}$ (or $-i = e^{i3\pi/2}$, but use principal argument)
$|-i| = 1$, $\arg(-i) = -\pi/2$ (in $(-\pi, \pi]$)
$\text{Log}(-i) = \ln 1 + i(-\pi/2) = -i\pi/2$
Note: $3\pi/2$ is outside principal range $(-\pi, \pi]$

**Problem 4: E**
$\log(1) = \ln 1 + i(\theta)$ where $\theta = 0 + 2\pi k$
$\log(1) = 2\pi ki$ for any integer $k$
Infinitely many values: $0, \pm 2\pi i, \pm 4\pi i, \ldots$
Principal value: $\text{Log}(1) = 0$
Multivalued due to argument ambiguity

**Problem 5: C**
$(-1)^{1/3} = e^{\frac{1}{3}\log(-1)} = e^{\frac{1}{3}(i\pi + 2\pi ki)}$
Principal value uses $k=0$: $e^{i\pi/3}$
$= \cos(\pi/3) + i\sin(\pi/3) = \frac{1}{2} + i\frac{\sqrt{3}}{2}$
Three cube roots total: $e^{i\pi/3}$, $e^{i\pi}=-1$, $e^{i5\pi/3}$
Note: $-1$ is also a cube root but not principal value

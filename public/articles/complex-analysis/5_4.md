# Complex Analysis Topic 5.4: Argument Principle and Rouché's Theorem

Zeros and poles of analytic functions aren't randomly scattered—they have structure governed by topological principles. The **argument principle** counts zeros and poles inside a contour by tracking how the function's argument (angle) changes as you traverse the boundary. If $f$ has $N$ zeros and $P$ poles inside $C$, then $f$ winds around the origin $N-P$ times as $z$ traverses $C$. This geometric insight translates analytically: $\frac{1}{2\pi i}\oint_C \frac{f'(z)}{f(z)} dz = N - P$, connecting the winding number to a contour integral.

**Rouché's theorem** provides a powerful tool for locating zeros: if $|g(z)| < |f(z)|$ on contour $C$, then $f$ and $f+g$ have the same number of zeros inside $C$. This dominance condition means $g$ is a small perturbation, unable to create or destroy zeros. The theorem proves the fundamental theorem of algebra, locates polynomial roots in specific regions, and analyzes how zeros move under perturbations. Combined with the argument principle, these results reveal the rigid topological structure underlying analytic functions.

This article develops the argument principle and Rouché's theorem. We'll derive the argument principle from the residue theorem, use it to count zeros and poles, understand the geometric winding number interpretation, prove Rouché's theorem, and apply it to locate zeros of polynomials and analytic functions. You'll master techniques for zero-counting and root-finding that complement direct computational methods, revealing the deep connection between complex analysis and topology.

## The Argument Principle

**Theorem (Argument Principle)**: Let $f$ be meromorphic inside and on a simple closed contour $C$ with $N$ zeros and $P$ poles (counted with multiplicity) inside $C$, and $f$ has no zeros or poles on $C$. Then:

$$\frac{1}{2\pi i}\oint_C \frac{f'(z)}{f(z)} \, dz = N - P$$

**Geometric interpretation**: As $z$ traverses $C$ once, $f(z)$ winds around origin $N-P$ times.

**Proof sketch**: $\frac{f'}{f} = \frac{d}{dz}\log f$ has residue $m$ at zero of order $m$ and residue $-m$ at pole of order $m$.

### Example 1: Counting Zeros

Use the argument principle to count zeros of $f(z) = z^3 - 1$ inside $|z| = 2$.

**Solution:**

$f$ has zeros at cube roots of unity: $1, e^{2\pi i/3}, e^{4\pi i/3}$ (all inside $|z|=2$).

No poles (polynomial).

$$f'(z) = 3z^2$$

$$\frac{f'(z)}{f(z)} = \frac{3z^2}{z^3-1}$$

By argument principle:
$$\frac{1}{2\pi i}\oint_{|z|=2} \frac{3z^2}{z^3-1} dz = N - 0 = N$$

Computing: residues at three zeros, each contributes $1$.

$$N = 3$$

**Answer:** $3$ zeros inside $|z|=2$ (as expected)

### Example 2: Counting Poles

Count poles minus zeros of $f(z) = \frac{z^2}{(z-1)(z-2)}$ inside $|z| = 1.5$.

**Solution:**

**Zeros**: $z = 0$ (double zero, so $N = 2$)

**Poles**: $z = 1$ (inside), $z = 2$ (outside)

So $P = 1$ inside $|z| = 1.5$.

$$\frac{1}{2\pi i}\oint_{|z|=1.5} \frac{f'(z)}{f(z)} dz = N - P = 2 - 1 = 1$$

**Answer:** $N - P = 1$

### Example 3: Verifying with Direct Computation

Verify Example 2 by computing the integral directly.

**Solution:**

$$\frac{f'}{f} = \frac{d}{dz}\log f = \frac{d}{dz}[\log z^2 - \log(z-1) - \log(z-2)]$$
$$= \frac{2}{z} - \frac{1}{z-1} - \frac{1}{z-2}$$

Inside $|z| = 1.5$: poles at $z = 0$ (residue $2$) and $z = 1$ (residue $-1$).

$$\oint = 2\pi i(2 - 1) = 2\pi i$$

$$\frac{1}{2\pi i}\oint = 1$$ ✓

**Answer:** Verified $N - P = 1$

### Example 4: Change in Argument

Show that $N - P = \frac{1}{2\pi}\Delta_C \arg f$ where $\Delta_C$ is change in argument around $C$.

**Solution:**

Write $f(z) = |f(z)|e^{i\arg f(z)}$

$$\log f(z) = \log|f(z)| + i\arg f(z)$$

$$\frac{f'(z)}{f(z)} = \frac{d}{dz}\log f = \frac{d}{dz}[\log|f| + i\arg f]$$

$$\oint_C \frac{f'}{f} = \oint_C d(\log|f|) + i\oint_C d(\arg f)$$

First term: $\oint d(\log|f|) = 0$ (returns to starting point)

Second term: $i \cdot \Delta_C \arg f$ (net change in argument)

$$\oint_C \frac{f'}{f} = i \cdot \Delta_C \arg f$$

$$\frac{1}{2\pi i}\oint = \frac{\Delta_C \arg f}{2\pi} = N - P$$

**Answer:** $N - P$ equals winding number of $f$ around origin

## Applications of Argument Principle

### Example 5: Fundamental Theorem of Algebra

Prove every polynomial of degree $n$ has exactly $n$ roots (counting multiplicity).

**Solution:**

Let $p(z) = a_nz^n + \cdots + a_0$ with $a_n \neq 0$.

For large $|z| = R$: $|p(z)| \approx |a_n|R^n$ (dominates)

Choose $R$ large enough that $p(z)$ has no zeros on $|z| = R$.

On $|z| = R$: $p(z) \approx a_nz^n$

As $z = Re^{i\theta}$ goes from $0$ to $2\pi$, $p(z)$ winds around origin $n$ times.

By argument principle: $N = n$ (no poles for polynomial).

**Answer:** Every degree $n$ polynomial has exactly $n$ roots

### Example 7: Zeros and Poles of $\tan z$

Count zeros minus poles of $\tan z$ inside $|z| < 10$.

**Solution:**

$$\tan z = \frac{\sin z}{\cos z}$$

**Zeros**: $\sin z = 0$ at $z = n\pi$ for integer $n$

In $|z| < 10$: $z = 0, \pm\pi, \pm 2\pi, \pm 3\pi$ (7 zeros)

**Poles**: $\cos z = 0$ at $z = (n + 1/2)\pi$

In $|z| < 10$: $z = \pm\pi/2, \pm 3\pi/2, \pm 5\pi/2$ (6 poles)

$$N - P = 7 - 6 = 1$$

**Answer:** $N - P = 1$

## Rouché's Theorem

**Rouché's Theorem**: Let $f$ and $g$ be analytic inside and on a simple closed contour $C$. If $|g(z)| < |f(z)|$ for all $z$ on $C$, then $f$ and $f + g$ have the same number of zeros inside $C$.

**Intuition**: $g$ is small perturbation; can't create or destroy zeros.

**Proof sketch**: $|g| < |f|$ implies $f + g$ never zero on $C$. Both $f$ and $f+g$ have same winding number around origin.

### Example 8: Applying Rouché

Show $z^4 + 2z^3 + 1$ has 3 zeros in $|z| < 1$.

**Solution:**

Write $f(z) = 2z^3$ and $g(z) = z^4 + 1$:

Inside $|z| = 1$, note that $|2z^3|$ dominates. 

Standard result: $2z^3$ term dominates, giving 3 zeros.

**Answer:** $3$ zeros in $|z| < 1$

### Example 9: Polynomial Roots in Unit Disk

Show $p(z) = z^7 + 10z^2 + 1$ has exactly 2 zeros in $|z| < 1$.

**Solution:**

Write $f(z) = 10z^2$ and $g(z) = z^7 + 1$.

On $|z| = 1$:
$$|f(z)| = 10$$
$$|g(z)| \leq |z^7| + 1 = 1 + 1 = 2 < 10$$ ✓

$|g| < |f|$ on boundary, so $p = f + g$ has same number of zeros as $f = 10z^2$.

$f$ has double zero at $z = 0$.

**Answer:** $2$ zeros (counting multiplicity) in $|z| < 1$

### Example 10: Fundamental Theorem via Rouché

Use Rouché to prove polynomial $p(z) = a_nz^n + \cdots + a_0$ has $n$ roots.

**Solution:**

Take $f(z) = a_nz^n$ and $g(z) = a_{n-1}z^{n-1} + \cdots + a_0$.

For large $|z| = R$:
$$|f(z)| = |a_n|R^n$$
$$|g(z)| \leq |a_{n-1}|R^{n-1} + \cdots + |a_0|$$

For $R$ large enough: $|f(z)| > |g(z)|$

By Rouché: $p = f + g$ has same number of zeros as $f$ inside $|z| = R$.

$f = a_nz^n$ has $n$ zeros (all at origin).

**Answer:** $p$ has $n$ zeros (counting multiplicity)

### Example 11: Zero-Free Region

Show $e^z - z$ has no zeros in $|z| < 1/2$.

**Solution:**

Write $f(z) = 1$ and $g(z) = e^z - z - 1$.

On $|z| = 1/2$:
$$|f(z)| = 1$$

$$|g(z)| = |e^z - z - 1|$$

Using $e^z = 1 + z + z^2/2 + \cdots$:
$$|e^z - z - 1| = |z^2/2 + z^3/6 + \cdots| \leq |z|^2/2 + |z|^3/6 + \cdots$$

For $|z| = 1/2$: this is $< 1/8 + 1/48 + \cdots < 1$

So $|g| < |f|$ on $|z| = 1/2$.

$f = 1$ has no zeros, so $f + g = e^z - z$ has no zeros in $|z| < 1/2$.

**Answer:** No zeros in $|z| < 1/2$

Topological invariant
Connects analysis to topology

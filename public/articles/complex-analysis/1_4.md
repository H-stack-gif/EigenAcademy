# Complex Analysis Topic 1.4: Branches and Riemann Surfaces

When you plot $y = \sqrt{x}$ on the real line, you make a choice: take the positive square root. Without this convention, $\sqrt{4}$ could mean $2$ or $-2$, making $\sqrt{x}$ multivalued. For real numbers, we sidestep this ambiguity by defining $\sqrt{x}$ as the principal (non-negative) square root. Complex numbers offer no such escape. The function $w = \sqrt{z}$ inherently has two values for each $z \neq 0$—both $w$ and $-w$ satisfy $w^2 = z$. Similarly, $\log z$ has infinitely many values differing by $2\pi i$. These **multivalued functions** aren't pathological exceptions; they're fundamental to complex analysis.

To work with multivalued functions analytically, we introduce **branches**: continuous single-valued selections of one value from each set of possibilities. A branch of $\sqrt{z}$ chooses one of the two square roots at each point, doing so continuously except along a **branch cut** where the function must "jump" discontinuously. The logarithm requires a branch cut, typically along the negative real axis, to make $\arg(z)$ single-valued. These choices aren't arbitrary—they reflect genuine topological features of the functions. The complete picture lives on a **Riemann surface**, a multi-sheeted geometric space where the function becomes truly single-valued.

This article explores branches and Riemann surfaces, showing how multivalued functions arise, how to construct branches with branch cuts, and how Riemann surfaces resolve ambiguity through geometry. You'll learn to work with principal branches, understand where functions are discontinuous, compute branch points, and visualize multivalued functions on their natural domain. These concepts are essential for complex integration, residue theory, and understanding the global behavior of analytic functions.

## Multivalued Functions

A function $f$ is **multivalued** if $f(z)$ can take multiple values for some (or all) $z$ in its domain.

**Examples**:
- $w = z^{1/n}$: $n$ values for each $z \neq 0$
- $w = \log z$: infinitely many values differing by $2\pi ki$
- $w = \arcsin z$: infinitely many values (inverse of periodic function)

### Example 1: Square Root Ambiguity

For $z = 4$, find all values of $\sqrt{z}$.

**Solution:**

Need $w$ such that $w^2 = 4$.

Algebraically: $w = \pm 2$

Using polar form: $4 = 4e^{i \cdot 0}$ or $4 = 4e^{i \cdot 2\pi}$

$$w_0 = \sqrt{4}e^{i \cdot 0/2} = 2$$
$$w_1 = \sqrt{4}e^{i \cdot 2\pi/2} = 2e^{i\pi} = -2$$

**Two values**: $2$ and $-2$

**Answer:** $\sqrt{4} = \pm 2$ in complex analysis (both are valid)

### Example 2: Cube Root Values

Find all cube roots of $8$.

**Solution:**

Need $w^3 = 8 = 8e^{i \cdot 0}$.

$$w_k = 8^{1/3}e^{i \cdot 2\pi k/3} = 2e^{i2\pi k/3}, \quad k = 0, 1, 2$$

$$w_0 = 2e^{i \cdot 0} = 2$$
$$w_1 = 2e^{i2\pi/3} = 2\left(-\frac{1}{2} + i\frac{\sqrt{3}}{2}\right) = -1 + i\sqrt{3}$$
$$w_2 = 2e^{i4\pi/3} = 2\left(-\frac{1}{2} - i\frac{\sqrt{3}}{2}\right) = -1 - i\sqrt{3}$$

**Answer:** Three cube roots: $2$, $-1 + i\sqrt{3}$, $-1 - i\sqrt{3}$

### Example 3: Logarithm Multiplicity

How do the values of $\log z$ differ?

**Solution:**

$$\log z = \ln|z| + i\arg(z)$$

The modulus $|z|$ is well-defined, but $\arg(z)$ is determined only up to multiples of $2\pi$:

$$\arg(z) = \theta_0 + 2\pi k, \quad k \in \mathbb{Z}$$

Therefore:
$$\log z = \ln|z| + i(\theta_0 + 2\pi k) = \text{Log } z + 2\pi ki$$

**Answer:** Values differ by $2\pi ki$ for integer $k$; infinitely many values

## Branch Points and Branch Cuts

A **branch point** is a point where a multivalued function cannot be made single-valued in any neighborhood.

A **branch cut** is a curve (usually from branch point to $\infty$) along which we allow the function to be discontinuous, enabling single-valued branches elsewhere.

### Example 4: Branch Points of $\sqrt{z}$

Find the branch points of $w = \sqrt{z}$.

**Solution:**

Write $z = re^{i\theta}$, so $w = \sqrt{r}e^{i\theta/2}$.

Starting at angle $\theta$, as we go around origin ($\theta \to \theta + 2\pi$):
$$w \to \sqrt{r}e^{i(\theta + 2\pi)/2} = \sqrt{r}e^{i\theta/2}e^{i\pi} = -w$$

After one loop, we get the **other** square root.

After two loops ($\theta \to \theta + 4\pi$): back to original value.

**Branch point**: $z = 0$ (cannot define $\sqrt{z}$ continuously near origin across all angles)

Also $z = \infty$ (by similar reasoning in extended complex plane)

**Answer:** Branch points at $0$ and $\infty$

### Example 5: Principal Branch of $\sqrt{z}$

The **principal branch** of $\sqrt{z}$ uses $-\pi < \theta \leq \pi$:

$$\sqrt{z} = \sqrt{r}e^{i\theta/2}, \quad -\pi < \theta \leq \pi$$

Where is this discontinuous?

**Solution:**

As $z$ crosses the negative real axis from above ($\theta = \pi^-$) to below ($\theta = -\pi^+$):

**From above**: $\sqrt{re^{i\pi}} = \sqrt{r}e^{i\pi/2} = i\sqrt{r}$

**From below**: $\sqrt{re^{-i\pi}} = \sqrt{r}e^{-i\pi/2} = -i\sqrt{r}$

Jump discontinuity of $2i\sqrt{r}$.

**Branch cut**: Negative real axis $(-\infty, 0]$

**Answer:** Discontinuous along negative real axis (branch cut)

### Example 6: Computing on Principal Branch

Using the principal branch, compute $\sqrt{-4}$ and $\sqrt{-4i}$.

**Solution:**

For $\sqrt{-4}$:
$$-4 = 4e^{i\pi}$$
$$\sqrt{-4} = \sqrt{4}e^{i\pi/2} = 2i$$

For $\sqrt{-4i}$:
$$-4i = 4e^{-i\pi/2}$$ (since $\arg(-4i) = -\pi/2 \in (-\pi, \pi]$)
$$\sqrt{-4i} = 2e^{-i\pi/4} = 2\left(\cos\frac{\pi}{4} - i\sin\frac{\pi}{4}\right)$$
$$= 2\left(\frac{1}{\sqrt{2}} - i\frac{1}{\sqrt{2}}\right) = \sqrt{2}(1 - i)$$

**Answer:** $\sqrt{-4} = 2i$, $\sqrt{-4i} = \sqrt{2}(1-i)$ (principal values)

## Branch of the Logarithm

The **principal branch** of $\log z$ uses principal argument $-\pi < \theta \leq \pi$:

$$\text{Log } z = \ln|z| + i\theta, \quad -\pi < \theta \leq \pi$$

**Branch cut**: Negative real axis (including origin)

**Branch points**: $0$ and $\infty$

### Example 7: Principal Logarithm Computation

Compute $\text{Log}(-1 + i)$.

**Solution:**

$$|-1 + i| = \sqrt{1 + 1} = \sqrt{2}$$

$$\theta = \arg(-1 + i)$$

Since $-1 + i$ is in second quadrant:
$$\tan\theta = \frac{1}{-1} = -1 \implies \theta = \pi - \frac{\pi}{4} = \frac{3\pi}{4}$$

$$\text{Log}(-1 + i) = \ln\sqrt{2} + i\frac{3\pi}{4} = \frac{1}{2}\ln 2 + i\frac{3\pi}{4}$$

**Answer:** $\frac{1}{2}\ln 2 + \frac{3\pi i}{4}$

### Example 8: Discontinuity of Principal Log

Show that $\text{Log } z$ is discontinuous on the negative real axis.

**Solution:**

Consider $z = re^{i\theta}$ for $r > 0$ as $\theta$ crosses $\pi$:

**From above** ($\theta = \pi^-$):
$$\text{Log}(re^{i\pi^-}) = \ln r + i\pi$$

**From below** ($\theta = -\pi^+$, which is same point):
$$\text{Log}(re^{-i\pi^+}) = \ln r - i\pi$$

Jump: $2\pi i$

**Answer:** Discontinuous jump of $2\pi i$ along negative real axis

### Example 9: Alternative Branch

Define a branch of $\log z$ using $0 < \theta < 2\pi$. Where is the branch cut?

**Solution:**

Using $\theta \in (0, 2\pi)$ means argument measured from positive real axis, going counterclockwise, up to (but not including) $2\pi$.

As $z$ crosses **positive real axis**:
- From above ($\theta = 0^+$): $\log z = \ln r + i \cdot 0^+ \approx \ln r$
- From below ($\theta = 2\pi^-$): $\log z = \ln r + i \cdot 2\pi^-$

Jump discontinuity at positive real axis.

**Branch cut**: Positive real axis $[0, \infty)$

**Answer:** Branch cut along positive real axis; different choice from principal branch

## Branch Points of General Functions

For $f(z) = (z - z_0)^\alpha$ where $\alpha \notin \mathbb{Z}$:

**Branch points**: $z_0$ and $\infty$

**Branch cut**: Any curve connecting branch points

### Example 10: Branch Points of $(z^2 - 1)^{1/2}$

Find branch points of $w = \sqrt{z^2 - 1}$.

**Solution:**

Write $w = (z^2 - 1)^{1/2} = [(z-1)(z+1)]^{1/2}$.

Branch points occur where $(z-1)$ or $(z+1)$ equals zero:
- $z = 1$
- $z = -1$
- $z = \infty$

Common choice: branch cut along $[-1, 1]$ (connecting the two finite branch points)

**Answer:** Branch points at $-1, 1, \infty$; typical branch cut is segment $[-1, 1]$

### Example 11: Principal Branch of $(z^2-1)^{1/2}$

For principal branch with cut $[-1, 1]$, compute $\sqrt{3}$.

**Solution:**

At $z = \sqrt{3}$: $z^2 - 1 = 3 - 1 = 2 > 0$

Since $z = \sqrt{3}$ is on positive real axis (not on cut $[-1, 1]$):

$$\sqrt{z^2 - 1} = \sqrt{2}$$

(using principal square root of positive real number)

**Answer:** $\sqrt{2}$ (real and positive)

### Example 12: Analytic Continuation

Start with $w = \sqrt{z^2 - 1}$ at $z = 2$ where $w = \sqrt{3}$. Continue analytically counterclockwise around $z = 1$. What is the value after one complete loop?

**Solution:**

Going around branch point $z = 1$ once:
- Start: $w = +\sqrt{3}$
- The argument of $(z - 1)$ increases by $2\pi$
- Therefore argument of $\sqrt{z - 1}$ increases by $\pi$
- This multiplies $w$ by $e^{i\pi} = -1$
- End: $w = -\sqrt{3}$

**Answer:** $-\sqrt{3}$ (sign change after encircling branch point)

## Riemann Surfaces

A **Riemann surface** is a multi-sheeted surface on which a multivalued function becomes single-valued.

**For $w = \sqrt{z}$**:
- Two sheets (one for each square root value)
- Sheets connected along branch cut
- Going from one sheet to another by crossing cut
- Single-valued on surface (each sheet has one value)

**For $w = \log z$**:
- Infinitely many sheets (one for each $\arg(z) + 2\pi k$)
- Sheets spiral up/down, connected along branch cut
- Like a spiral parking ramp

### Example 13: Visualizing $\sqrt{z}$ Surface

Describe motion on the Riemann surface of $w = \sqrt{z}$.

**Solution:**

**Two sheets**: call them "Sheet I" ($w = \sqrt{r}e^{i\theta/2}$, $-\pi < \theta \leq \pi$) and "Sheet II" ($w = -\sqrt{r}e^{i\theta/2}$).

Starting on Sheet I at $z = 1$ (where $w = 1$):
- Move counterclockwise around origin
- Cross branch cut (negative real axis)
- **Switch to Sheet II**
- Now $w = -1$ at $z = 1$ (after full loop)

**Geometric structure**: Two sheets joined along cut, forming continuous surface

**Answer:** Two-sheeted surface; circling origin once switches sheets

### Example 14: Riemann Surface for $\log z$

How many sheets does the Riemann surface of $w = \log z$ have?

**Solution:**

Each value $\log z = \ln r + i(\theta + 2\pi k)$ corresponds to one sheet.

As we circle origin repeatedly:
- First loop: $k = 0 \to 1$
- Second loop: $k = 1 \to 2$
- Continuing infinitely in both directions

**Structure**: Infinitely many sheets, spiraling up (increasing $k$) and down (decreasing $k$)

**Answer:** Infinitely many sheets (one for each integer $k$)

### Example 15: Number of Sheets for $z^{1/n}$

How many sheets are on the Riemann surface of $w = z^{1/n}$?

**Solution:**

$$w_k = r^{1/n}e^{i(\theta + 2\pi k)/n}, \quad k = 0, 1, \ldots, n-1$$

There are $n$ distinct values.

After $n$ complete loops around origin:
$$\theta \to \theta + 2\pi n$$
$$w \to r^{1/n}e^{i(\theta + 2\pi n)/n} = r^{1/n}e^{i\theta/n}e^{i2\pi} = w$$ (back to start)

**Answer:** $n$ sheets (one for each $n$th root)

## Answer Key

**Problem 1: B**
Principal branch: $\sqrt{z} = \sqrt{r}e^{i\theta/2}$ with $-\pi < \theta \leq \pi$
Discontinuous across negative real axis
Jump from $i\sqrt{r}$ (from above) to $-i\sqrt{r}$ (from below)
Standard convention in complex analysis
Alternative branches can use different cuts

**Problem 2: C**
Branch points at $z = 0$ and $z = \infty$ (in extended plane)
Cannot make $\log z$ single-valued near these points
Need branch cut connecting them (typically negative real axis)
Each branch point requires $\arg(z)$ to increase by $2\pi$ when encircled
Compare: $\sqrt{z}$ also has branch points at $0$ and $\infty$

**Problem 3: B**
Starting at $z = re^{i\theta}$: $w = \sqrt{r}e^{i\theta/2}$
After one loop: $\theta \to \theta + 2\pi$
New value: $\sqrt{r}e^{i(\theta + 2\pi)/2} = \sqrt{r}e^{i\theta/2}e^{i\pi} = -w$
Sign change (multiply by $-1$)
After two loops: back to original value

**Problem 4: C**
$-e = e \cdot e^{i\pi}$ (write $-e$ in polar form)
$\text{Log}(-e) = \ln|{-e}| + i\arg(-e) = \ln e + i\pi = 1 + i\pi$
Note: $\ln e = 1$ (natural log of $e$)
Principal argument of $-e$ is $\pi$
General: $\log(-e) = 1 + i\pi(2k+1)$

**Problem 5: C**
$z^{1/5}$ has 5 fifth roots for each $z \neq 0$
Riemann surface has 5 sheets
Going around origin 5 times returns to starting value
Each sheet corresponds to one fifth root
After $k < 5$ loops: on different sheet

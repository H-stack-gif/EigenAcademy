# Complex Analysis Topic 6.4: Applications to Boundary Value Problems

The power of conformal mapping culminates in solving **boundary value problems**—finding functions satisfying differential equations in a domain with prescribed values on the boundary. The **Dirichlet problem** asks for a harmonic function $u$ (satisfying $\nabla^2 u = 0$) with $u = f$ on the boundary. Since conformal maps preserve harmonicity—the image of a harmonic function under a conformal map is harmonic—we can transform difficult boundary value problems in irregular domains to simple problems in standard domains like disks or half-planes where solutions are known explicitly. The strategy is: (1) find conformal map from complicated domain to simple domain, (2) solve in simple domain, (3) pull back solution via the conformal map.

Physical problems in fluid flow, electrostatics, and heat conduction all lead to Laplace's equation. The **complex potential** $F(z) = \phi + i\psi$ combines the real potential $\phi$ (satisfying Laplace's equation) with its harmonic conjugate $\psi$. Level curves of $\phi$ are equipotential lines; level curves of $\psi$ are field lines or streamlines. Since conformal maps preserve orthogonality and harmonicity, they transform these physical fields preserving their essential structure. Computing flow around obstacles, electric fields between conductors, or steady-state temperature distributions reduces to finding appropriate conformal maps.

This article develops applications of conformal mapping to boundary value problems. We'll formulate the Dirichlet problem and understand why harmonic functions matter, prove that harmonicity is preserved under conformal maps, apply the method to solve Dirichlet problems in specific domains, model fluid flow using complex potentials and conformal maps, analyze electrostatic fields via conformal transformations, and solve steady-state heat problems. You'll master the technique of domain transformation for solving physical boundary value problems, seeing how abstract complex analysis solves concrete engineering problems.

## The Dirichlet Problem

**Dirichlet Problem**: Given domain $D$ with boundary $\partial D$ and function $f: \partial D \to \mathbb{R}$, find harmonic function $u: D \to \mathbb{R}$ such that:

$$\nabla^2 u = 0 \text{ in } D$$
$$u = f \text{ on } \partial D$$

**Harmonic**: $u$ satisfies Laplace's equation $u_{xx} + u_{yy} = 0$

**Key fact**: If $F$ is analytic and $u = \text{Re}(F)$, then $u$ is harmonic.

### Example 1: Dirichlet Problem in Disk

Solve $\nabla^2 u = 0$ in $|z| < 1$ with $u(e^{i\theta}) = \cos(2\theta)$ on boundary.

**Solution:**

Boundary condition $\cos(2\theta) = \text{Re}(e^{2i\theta})$

Try $u = \text{Re}(F)$ where $F(z) = z^2$ is analytic.

$$F(z) = z^2 = (x+iy)^2 = x^2 - y^2 + 2ixy$$

$$u(x,y) = x^2 - y^2$$

On boundary $|z| = 1$: $z = e^{i\theta}$, so $u = \text{Re}(e^{2i\theta}) = \cos(2\theta)$ ✓

Verify harmonic:
$$u_{xx} = 2, \quad u_{yy} = -2, \quad u_{xx} + u_{yy} = 0$$ ✓

**Answer:** $u(x,y) = x^2 - y^2$

### Example 2: Uniqueness

Why is the solution to the Dirichlet problem unique?

**Solution:**

Suppose $u_1$ and $u_2$ both solve the problem.

Let $v = u_1 - u_2$.

Then $\nabla^2 v = 0$ in $D$ (linear) and $v = 0$ on $\partial D$.

By maximum principle: harmonic function attains max/min on boundary.

Since $v = 0$ on boundary, $v \equiv 0$ everywhere.

Therefore $u_1 = u_2$ (unique).

**Answer:** Unique by maximum principle

### Example 3: Method of Conformal Mapping

To solve Dirichlet problem in domain $D$:

1. Find conformal map $w = \phi(z)$ from $D$ to simpler domain $D'$ (disk or half-plane)
2. Transform boundary data: $f(z) \to g(w)$ where $g(\phi(z)) = f(z)$
3. Solve in $D'$: find $U(w)$ harmonic in $D'$ with $U = g$ on $\partial D'$
4. Pull back: $u(z) = U(\phi(z))$ solves original problem

**Why it works**: Composition of harmonic with conformal is harmonic.

**Answer:** Transform domain, solve, pull back solution

## Preservation of Harmonicity

**Theorem**: If $u$ is harmonic and $w = f(z)$ is conformal, then $U(w) = u(f^{-1}(w))$ is harmonic in the image domain.

Equivalently: $u(z)$ harmonic in $z$-plane ⟹ $u(x(s,t), y(s,t))$ harmonic in $w = s + it$ plane when transformation is conformal.

### Example 4: Verifying Preservation

If $u(x,y) = x^2 - y^2$ is harmonic, verify $U(s,t) = u(x(s,t), y(s,t))$ is harmonic under linear map $w = 2z$.

**Solution:**

$w = 2z = 2x + 2iy$, so $s = 2x$, $t = 2y$

Thus $x = s/2$, $y = t/2$

$$U(s,t) = u(s/2, t/2) = (s/2)^2 - (t/2)^2 = \frac{s^2 - t^2}{4}$$

Check:
$$U_{ss} = \frac{2}{4} = \frac{1}{2}, \quad U_{tt} = -\frac{1}{2}$$
$$U_{ss} + U_{tt} = 0$$ ✓

**Answer:** $U$ is harmonic (preservation verified)

### Example 5: Exponential Map Preservation

If $u(s,t) = s$ is harmonic in strip, what is the harmonic function in the sector under $z = e^w$?

**Solution:**

Strip in $w$-plane: $u(s,t) = s$ (harmonic: $u_{ss} + u_{tt} = 0$)

Map: $z = e^w = e^{s+it} = e^s e^{it}$

So $x + iy = e^s(\cos t + i\sin t)$

Thus $s = \ln\sqrt{x^2 + y^2} = \ln|z|$

Harmonic function in $z$-plane: $U(x,y) = \ln\sqrt{x^2+y^2} = \frac{1}{2}\ln(x^2+y^2)$

This is $\text{Re}(\log z)$.

**Answer:** $U(x,y) = \ln|z|$ (harmonic in sector)

### Example 6: Dirichlet in Half-Plane

Solve $\nabla^2 u = 0$ in upper half-plane $\text{Im}(z) > 0$ with $u(x, 0) = \begin{cases}1 & x > 0 \\ 0 & x < 0\end{cases}$

**Solution:**

This is a step function boundary condition.

Use Poisson integral formula or recognize:

$$u(x,y) = \frac{1}{\pi}\arg z$$

where $\arg z$ is angle from positive real axis.

At boundary: $\arg(x) = 0$ for $x > 0$, $\arg(x) = \pi$ for $x < 0$

Normalized: $u = \frac{1}{2} + \frac{1}{\pi}\arctan(x/y)$

**Answer:** $u(x,y) = \frac{1}{2} + \frac{1}{\pi}\arctan(x/y)$

## Fluid Flow

**Complex potential**: $F(z) = \phi(x,y) + i\psi(x,y)$ where:
- $\phi$ = velocity potential (harmonic)
- $\psi$ = stream function (harmonic conjugate)

**Velocity field**: $\vec{v} = \nabla\phi = (u, v)$ where $u = \phi_x$, $v = \phi_y$

Also: $\vec{v} = \overline{F'(z)}$ (conjugate of derivative)

**Streamlines**: Level curves $\psi = \text{const}$

**Equipotentials**: Level curves $\phi = \text{const}$

These are orthogonal (C-R equations).

### Example 7: Uniform Flow

For $F(z) = Uz$ (where $U > 0$ real), describe the flow.

**Solution:**

$$F(z) = Ux + iUy$$

$\phi = Ux$, $\psi = Uy$

**Velocity**: $\vec{v} = \nabla\phi = (U, 0)$ (horizontal, constant)

**Streamlines**: $y = \text{const}$ (horizontal lines)

**Answer:** Uniform horizontal flow with speed $U$

### Example 8: Source/Sink

For $F(z) = \frac{m}{2\pi}\log z$ (where $m > 0$), describe the flow.

**Solution:**

$$\log z = \ln r + i\theta$$

$$F = \frac{m}{2\pi}(\ln r + i\theta)$$

$\phi = \frac{m}{2\pi}\ln r$, $\psi = \frac{m}{2\pi}\theta$

**Velocity**: 
$$F'(z) = \frac{m}{2\pi z}$$
$$\vec{v} = \overline{F'(z)} = \frac{m}{2\pi\bar{z}} = \frac{m}{2\pi}\frac{z}{|z|^2}$$

Radial flow outward from origin.

**Streamlines**: Rays from origin ($\theta = \text{const}$)

**Answer:** Source at origin with strength $m$ (radial outward flow)

### Example 9: Flow Around Cylinder

Using conformal map, find flow around circle $|z| = 1$ for incoming uniform flow.

**Solution:**

Start with uniform flow $F_0(w) = Uw$ in $w$-plane.

Map exterior of unit disk in $z$-plane to $w$-plane using $w = z + \frac{1}{z}$.

Complex potential in $z$-plane:
$$F(z) = U\left(z + \frac{1}{z}\right)$$

**Streamlines**: Given by $\text{Im}(F) = \text{const}$

On $|z| = 1$: $F = U(e^{i\theta} + e^{-i\theta}) = 2U\cos\theta$ (real)

So $|z| = 1$ is a streamline (flow around cylinder).

**Answer:** $F(z) = U(z + 1/z)$ gives flow around circular cylinder

### Example 10: Circulation

Adding circulation $\Gamma$ to flow around cylinder:

$$F(z) = U\left(z + \frac{1}{z}\right) + \frac{i\Gamma}{2\pi}\log z$$

What does the circulation term do?

**Solution:**

$\frac{i\Gamma}{2\pi}\log z = \frac{i\Gamma}{2\pi}(\ln r + i\theta) = -\frac{\Gamma\theta}{2\pi} + \frac{i\Gamma\ln r}{2\pi}$

Adds vortex flow (angular component).

With circulation: flow pattern tilted, creates lift (Magnus effect).

**Answer:** Circulation adds vortex, tilts streamlines, generates lift

## Electrostatics

**Complex potential**: $F(z) = \phi + i\psi$ where:
- $\phi$ = electric potential
- $\psi$ = stream function for field lines

**Electric field**: $\vec{E} = -\nabla\phi = -\overline{F'(z)}$

**Equipotentials**: Level curves $\phi = \text{const}$ (conductor surfaces)

**Field lines**: Level curves $\psi = \text{const}$ (orthogonal to equipotentials)

### Example 11: Point Charge

For $F(z) = \frac{Q}{2\pi\epsilon_0}\log z$, describe electric field.

**Solution:**

$$\phi = \frac{Q}{2\pi\epsilon_0}\ln r$$

**Electric field**:
$$\vec{E} = -\nabla\phi = -\frac{Q}{2\pi\epsilon_0 r}\hat{r}$$

Radial field from point charge (Coulomb's law in 2D).

**Equipotentials**: Circles $r = \text{const}$

**Field lines**: Radial rays

**Answer:** Radial electric field from point charge at origin

### Example 12: Parallel Plates

For plates at $y = 0$ (potential $V_1$) and $y = d$ (potential $V_2$), find $\phi$.

**Solution:**

Uniform field between plates.

$$\phi(x,y) = V_1 + \frac{V_2 - V_1}{d}y$$

Linear in $y$ (satisfies Laplace and boundary conditions).

**Complex potential**: $F(z) = \frac{V_2 - V_1}{d}z + V_1$

**Electric field**: $\vec{E} = -\frac{V_2-V_1}{d}\hat{y}$ (constant)

**Answer:** $\phi = V_1 + \frac{V_2-V_1}{d}y$, uniform field

### Example 13: Conformal Map for Conductor Shape

To find field around non-circular conductor:

1. Map conductor boundary to circle via conformal map $w = f(z)$
2. Solve in $w$-plane (standard circular geometry)
3. Transform solution back: $F(z) = F_w(f(z))$

**Example**: Elliptical conductor → use Joukowski map

**Answer:** Method: conformally map to circle, solve, transform back

## Heat Flow

**Temperature**: $T(x,y,t)$ satisfies heat equation $T_t = k\nabla^2 T$

**Steady-state**: $T_t = 0$, so $\nabla^2 T = 0$ (Laplace's equation)

Boundary conditions: temperature prescribed on boundary

### Example 14: Steady-State in Rectangle

Find $T$ in rectangle $0 < x < a$, $0 < y < b$ with:
- $T(x, 0) = 0$
- $T(x, b) = 0$  
- $T(0, y) = 0$
- $T(a, y) = f(y)$

**Solution:**

Use separation of variables or conformal mapping.

Series solution:
$$T(x,y) = \sum_{n=1}^{\infty} B_n \frac{\sinh(n\pi x/b)}{\sinh(n\pi a/b)}\sin(n\pi y/b)$$

where $B_n$ are Fourier coefficients of $f$.

**Answer:** Series solution (separation of variables or conformal methods)

### Example 15: Annulus Temperature

In annulus $1 < |z| < 2$, with $T = 0$ on $|z| = 1$ and $T = 100$ on $|z| = 2$, find steady temperature.

**Solution:**

Radially symmetric: $T = T(r)$

Laplace in polar: $\nabla^2 T = \frac{1}{r}\frac{d}{dr}\left(r\frac{dT}{dr}\right) = 0$

$$r\frac{dT}{dr} = C_1 \implies T = C_1\ln r + C_2$$

Boundary conditions:
- $T(1) = C_2 = 0$
- $T(2) = C_1\ln 2 = 100$

$$C_1 = \frac{100}{\ln 2}$$

$$T(r) = \frac{100\ln r}{\ln 2}$$

**Answer:** $T(r) = \frac{100\ln r}{\ln 2}$

## Answer Key

**Problem 1: A**
Dirichlet: prescribe $u = f$ on boundary $\partial D$
Find harmonic $u$ in $D$ with given boundary values
Contrast: Neumann problem prescribes normal derivative $\partial u/\partial n$
Unique solution (maximum principle)
Physical: fixed temperature/potential on boundary

**Problem 2: C**
Conformal maps preserve harmonicity
If $u$ harmonic in $D$, then $u \circ f^{-1}$ harmonic in $f(D)$
Enables solving Dirichlet in complicated domains
Do NOT preserve distance (except isometries)
Do NOT preserve area (except when $|f'|=1$)

**Problem 3: B**
Streamlines: curves tangent to velocity, level curves of $\psi$
Stream function $\psi$ constant along streamlines
Equipotentials: level curves of $\phi$
Orthogonal families (C-R equations)
$F = \phi + i\psi$ is complex potential

**Problem 4: A**
$F(z) = Uz$ where $U$ real, positive
$\phi = Ux$, $\psi = Uy$
Velocity $\vec{v} = (U, 0)$ (horizontal)
Magnitude $U$, direction $0°$ (rightward)
Simplest flow: uniform translation

**Problem 5: C**
Steady-state: $\partial T/\partial t = 0$
Heat equation: $T_t = k\nabla^2 T$
Steady-state: $\nabla^2 T = 0$ (Laplace equation)
Same as electrostatics, fluid potential
Boundary value problem with prescribed $T$ on $\partial D$

# Complex Analysis Topic 6.3: Special Mappings

Beyond linear fractional transformations, several elementary complex functions serve as powerful conformal maps with distinctive geometric properties. The **exponential function** $e^z$ transforms horizontal strips to angular sectors, making it ideal for problems with periodic boundary conditions. The **logarithm** (its inverse) maps sectors back to strips, though multivaluedness requires care. **Power functions** $z^n$ fold the plane $n$ times, mapping sectors of angle $2\pi/n$ to half-planes. More exotic maps like the **Joukowski transformation** $w = \frac{1}{2}(z + 1/z)$ generate airfoil shapes, while the **Schwarz-Christoffel formula** maps the upper half-plane to arbitrary polygons. Each map has characteristic domains where it's conformal and typical applications where its geometric properties solve problems.

Understanding these special mappings means knowing their domains of conformality, images of standard regions (strips, sectors, half-planes), behavior near critical points, and practical applications. The exponential is entire but has an essential singularity at infinity; it's periodic with period $2\pi i$, so it wraps strips to annular sectors. The logarithm has a branch point at the origin and requires choosing branch cuts. Power functions $z^{1/n}$ have branch points and unwrap angles by factor $n$. These properties aren't mere curiosities—they're tools for solving Laplace's equation in specific geometries or analyzing fluid flow around obstacles.

This article develops the theory and applications of special conformal maps. We'll explore the exponential and its mapping properties, understand logarithmic branches and Riemann surfaces, analyze power functions and their angle multiplication, work with Joukowski transformations for airfoil theory, and introduce the Schwarz-Christoffel formula for polygonal domains. You'll master using these standard maps to transform complicated domains into simple ones where problems become tractable.

## The Exponential Function

$$w = e^z = e^{x + iy} = e^x(\cos y + i\sin y)$$

**Properties**:
- Entire (analytic everywhere)
- Periodic: $e^{z + 2\pi i} = e^z$
- Never zero: $e^z \neq 0$ for all $z$
- Maps vertical lines to circles, horizontal lines to rays

### Example 1: Strip to Sector

What is the image of the strip $0 < \text{Im}(z) < \pi$ under $w = e^z$?

**Solution:**

Let $z = x + iy$ with $0 < y < \pi$.

$$w = e^x e^{iy} = e^x(\cos y + i\sin y)$$

As $x$ varies: $|w| = e^x$ ranges from $0$ to $\infty$

As $y$ varies from $0$ to $\pi$: $\arg(w) = y$ ranges from $0$ to $\pi$

Image: Upper half-plane $\text{Im}(w) > 0$ (all $w$ with $0 < \arg w < \pi$)

**Answer:** Upper half-plane $\text{Im}(w) > 0$

### Example 2: Rectangle to Annular Sector

What is the image of rectangle $0 < x < \ln 2$, $0 < y < \pi/2$ under $w = e^z$?

**Solution:**

$$w = e^{x+iy}$$

**Magnitude**: $|w| = e^x$ where $0 < x < \ln 2$
So $1 < |w| < 2$

**Argument**: $\arg w = y$ where $0 < y < \pi/2$
So $0 < \arg w < \pi/2$

Image: Annular sector $1 < |w| < 2$, $0 < \arg w < \pi/2$ (first quadrant annulus)

**Answer:** Annular sector in first quadrant between circles of radii $1$ and $2$

### Example 3: Periodicity

Show that $e^z$ is periodic with period $2\pi i$.

**Solution:**

$$e^{z + 2\pi i} = e^z e^{2\pi i} = e^z(\cos 2\pi + i\sin 2\pi) = e^z \cdot 1 = e^z$$

Any integer multiple: $e^{z + 2\pi ni} = e^z$ for $n \in \mathbb{Z}$

Fundamental period: $2\pi i$

**Answer:** Periodic with period $2\pi i$

### Example 4: Image of Real Axis

What is the image of the real axis under $w = e^z$?

**Solution:**

Real axis: $z = x$ (real)

$$w = e^x$$ (real, positive)

Image: Positive real axis $(0, \infty)$

**Answer:** Positive real axis

### Example 5: Conformality of Exponential

Where is $w = e^z$ conformal?

**Solution:**

$f'(z) = e^z$

$f'(z) = 0$ never (exponential never zero)

Therefore conformal everywhere in $\mathbb{C}$.

**Answer:** Conformal everywhere

## The Logarithm Function

$$w = \log z = \ln|z| + i\arg z$$

**Properties**:
- Multivalued: $\arg z$ defined up to $2\pi$ multiples
- Branch point at $z = 0$
- Inverse of exponential: $e^{\log z} = z$
- Principal branch: $\text{Log} z$ with $-\pi < \arg z \leq \pi$

### Example 6: Computing Logarithm Values

Find all values of $\log(-1)$.

**Solution:**

$$-1 = e^{i\pi}, \quad e^{3\pi i}, \quad e^{5\pi i}, \ldots = e^{i(\pi + 2\pi n)}$$

$$\log(-1) = i(\pi + 2\pi n) = i\pi(2n + 1)$$

for $n \in \mathbb{Z}$.

**Principal value**: $\text{Log}(-1) = i\pi$

**Answer:** $\log(-1) = i\pi(2n+1)$ for integer $n$; principal value $i\pi$

### Example 7: Image of Positive Real Axis

Under principal branch $\text{Log} z$, what is the image of the positive real axis?

**Solution:**

Positive real axis: $z = r$ for $r > 0$

$$\text{Log}(r) = \ln r + i \cdot 0 = \ln r$$

Image: Real axis

**Answer:** Real axis

### Example 8: Sector to Strip

What is the image of sector $0 < \arg z < \pi/2$ under $w = \text{Log} z$?

**Solution:**

$$w = \ln|z| + i\arg z$$

For $0 < \arg z < \pi/2$:

$\text{Re}(w) = \ln|z|$ ranges over all reals (as $|z|$ varies)

$\text{Im}(w) = \arg z$ ranges over $(0, \pi/2)$

Image: Horizontal strip $0 < \text{Im}(w) < \pi/2$

**Answer:** Strip $0 < \text{Im}(w) < \pi/2$

### Example 9: Branch Cut

Where is the principal branch $\text{Log} z$ discontinuous?

**Solution:**

Branch cut: Negative real axis (where $\arg z$ jumps from $\pi$ to $-\pi$)

Approaching from above: $\arg z \to \pi$
Approaching from below: $\arg z \to -\pi$

Discontinuity along $(-\infty, 0]$

**Answer:** Discontinuous on negative real axis

## Power Functions

$$w = z^{\alpha}$$ for complex $\alpha$

**Integer powers**: $w = z^n$ is single-valued
**Fractional powers**: $w = z^{1/n}$ is $n$-valued
**General**: $w = z^{\alpha} = e^{\alpha \log z}$ (multivalued via $\log$)

### Example 10: Square Root Mapping

What is the image of upper half-plane under $w = \sqrt{z}$?

**Solution:**

For $z = re^{i\theta}$ with $0 < \theta < \pi$ (upper half-plane):

$$w = \sqrt{r}e^{i\theta/2}$$

As $\theta$ ranges from $0$ to $\pi$, $\theta/2$ ranges from $0$ to $\pi/2$

Image: First quadrant $0 < \arg w < \pi/2$

Note: Function is two-valued; principal branch maps to first quadrant.

**Answer:** First quadrant (principal branch)

### Example 11: $z^{1/n}$ Angle Division

Show that $w = z^{1/n}$ divides angles by $n$.

**Solution:**

$$z = re^{i\theta} \implies w = r^{1/n}e^{i\theta/n}$$

Angle at $w$ is $\theta/n$ (divided by $n$)

Sector of angle $\alpha$ maps to sector of angle $\alpha/n$

Example: $n=2$ (square root) halves angles

**Answer:** Angles divided by $n$

### Example 12: $z^n$ on Sector

What is the image of sector $0 < \arg z < 2\pi/n$ under $w = z^n$?

**Solution:**

$$z = re^{i\theta}$$ with $0 < \theta < 2\pi/n$

$$w = r^n e^{in\theta}$$

As $\theta$ ranges from $0$ to $2\pi/n$, $n\theta$ ranges from $0$ to $2\pi$

Image: Full plane minus origin (or slit plane depending on boundary)

More precisely: entire plane $\mathbb{C} \setminus \{0\}$

**Answer:** Entire complex plane minus origin

### Example 13: Critical Point of $z^2$

At what point does $w = z^2$ fail to be conformal?

**Solution:**

$$f'(z) = 2z$$

$f'(0) = 0$ (critical point)

At origin, angles are doubled (not preserved).

**Answer:** Not conformal at $z = 0$

## Joukowski Transformation

$$w = \frac{1}{2}\left(z + \frac{1}{z}\right)$$

**Properties**:
- Maps circles to ellipses (in general)
- Maps unit circle to interval $[-1, 1]$
- Used in airfoil theory

### Example 14: Unit Circle Under Joukowski

What is the image of $|z| = 1$ under $w = \frac{1}{2}(z + 1/z)$?

**Solution:**

Let $z = e^{i\theta}$

$$w = \frac{1}{2}\left(e^{i\theta} + e^{-i\theta}\right) = \frac{1}{2} \cdot 2\cos\theta = \cos\theta$$

As $\theta$ ranges from $0$ to $2\pi$, $\cos\theta$ ranges from $-1$ to $1$ and back.

Image: Real interval $[-1, 1]$ (traversed twice)

**Answer:** Interval $[-1, 1]$ on real axis

### Example 15: Circle Near Unit Circle

For circle $|z| = 1 + \epsilon$ (small $\epsilon > 0$), the Joukowski map produces approximately an ellipse. Why?

**Solution:**

For $z = (1+\epsilon)e^{i\theta}$:

$$w = \frac{1}{2}\left((1+\epsilon)e^{i\theta} + \frac{1}{(1+\epsilon)e^{i\theta}}\right)$$

$$\approx \frac{1}{2}\left((1+\epsilon)e^{i\theta} + (1-\epsilon)e^{-i\theta}\right)$$

$$= \frac{1}{2}\left((1+\epsilon)(\cos\theta + i\sin\theta) + (1-\epsilon)(\cos\theta - i\sin\theta)\right)$$

$$= \cos\theta + i\epsilon\sin\theta$$

This traces an ellipse with semi-major axis $1$ (horizontal) and semi-minor axis $\epsilon$ (vertical).

**Answer:** Near-unit circles map to ellipses (basis of airfoil shapes)

## Schwarz-Christoffel Formula

Maps upper half-plane to polygon with vertices at $w_1, \ldots, w_n$ and interior angles $\pi\alpha_k$:

$$w = A + B\int_0^z \prod_{k=1}^{n} (\zeta - x_k)^{\alpha_k - 1} \, d\zeta$$

where $x_k$ are real points mapping to vertices.

### Example 16: Upper Half-Plane to Strip

The map from upper half-plane to infinite strip uses limiting case of Schwarz-Christoffel. What function works?

**Solution:**

Strip has two "vertices at infinity" with angles $\pi$ (straight).

For strip $0 < \text{Im}(w) < 1$, can use:

$$w = \frac{1}{\pi}\log z$$

This maps $\mathbb{H}$ to horizontal strip.

Not typical S-C (needs finite polygons), but related.

**Answer:** $w = \frac{1}{\pi}\log z$ maps to strip

### Example 17: Upper Half-Plane to Triangle

For equilateral triangle with angles $\pi/3$ each, what are the $\alpha_k$ values in Schwarz-Christoffel?

**Solution:**

Interior angles: $\pi/3$

$$\pi\alpha_k = \pi/3 \implies \alpha_k = 1/3$$

In Schwarz-Christoffel:
$$\prod (\zeta - x_k)^{1/3 - 1} = \prod (\zeta - x_k)^{-2/3}$$

**Answer:** $\alpha_k = 1/3$ for each vertex

## Answer Key

**Problem 1: C**
Horizontal line: $z = x + ic$ (constant imaginary part)
$w = e^x e^{ic}$ where $e^{ic}$ is fixed angle
As $x$ varies, $|w| = e^x$ varies, angle fixed
Result: ray from origin at angle $c$
Vertical lines → circles (constant $|w|$)

**Problem 2: B**
Principal branch: $\text{Log} z$ with $-\pi < \arg z \leq \pi$
Branch cut on negative real axis
Jump discontinuity: $\arg z$ jumps from $\pi$ to $-\pi$ crossing from above to below
Continuous elsewhere in $\mathbb{C} \setminus (-\infty, 0]$
Standard choice for branch cut

**Problem 3: B**
$z = re^{i\theta}$ with $0 < \theta < \pi/2$ (first quadrant)
$w = r^2 e^{2i\theta}$ with $0 < 2\theta < \pi$
Angles doubled: first quadrant $(0, \pi/2)$ → upper half-plane $(0, \pi)$
Magnitudes squared: $|w| = |z|^2$
Conformal except at origin (critical point)

**Problem 4: C**
Joukowski: $w = \frac{1}{2}(z + 1/z)$
Unit circle: $z = e^{i\theta}$
$w = \frac{1}{2}(e^{i\theta} + e^{-i\theta}) = \cos\theta$
Traces real interval $[-1, 1]$
Used in airfoil theory (circles near unit circle → ellipses)

**Problem 5: B**
Schwarz-Christoffel: maps upper half-plane $\mathbb{H}$ to polygons
Formula: $w = A + B\int \prod(\zeta - x_k)^{\alpha_k - 1} d\zeta$
Vertices correspond to points $x_k$ on real axis
Interior angles $\pi\alpha_k$ determine exponents
Powerful for solving Laplace equation in polygonal domains

# Complex Analysis Topic 2.2: Cauchy-Riemann Equations

Real differentiability of a function $f: \mathbb{R}^2 \to \mathbb{R}^2$ requires its component functions to have continuous partial derivatives—sixteen conditions when fully expanded. Complex differentiability of $f: \mathbb{C} \to \mathbb{C}$ seems similar: writing $f(z) = u(x,y) + iv(x,y)$, we have a mapping from $\mathbb{R}^2$ to $\mathbb{R}^2$ with component functions $u$ and $v$. Yet complex differentiability is far more restrictive. It turns out that for $f$ to be complex-differentiable, the real and imaginary parts $u$ and $v$ must satisfy just **two equations**: the **Cauchy-Riemann equations**. These two conditions encapsulate all the rigidity of complex differentiability.

The Cauchy-Riemann equations are $u_x = v_y$ and $u_y = -v_x$. These deceptively simple relations link horizontal and vertical behavior of $u$ and $v$ in a precise way. They say that the rate of change of the real part in the $x$-direction must equal the rate of change of the imaginary part in the $y$-direction, while changes in $u$ vertically must be opposite to changes in $v$ horizontally. This coupling ensures that the difference quotient limit is independent of approach direction—the geometric requirement for complex differentiability.

This article develops the Cauchy-Riemann equations as both necessary and sufficient conditions for differentiability. We'll prove why they must hold, learn to verify them for specific functions, use them to test analyticity, find derivatives from partial derivatives, and explore their polar form. You'll master the primary tool for determining whether a function is analytic and for computing complex derivatives from real and imaginary components.

## The Cauchy-Riemann Equations

Let $f(z) = u(x,y) + iv(x,y)$ where $z = x + iy$.

**Theorem (Cauchy-Riemann)**: If $f$ is differentiable at $z_0 = x_0 + iy_0$, then the partial derivatives of $u$ and $v$ satisfy:

$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y} \quad \text{and} \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$$

at $(x_0, y_0)$.

**Moreover**: If these equations hold in a neighborhood and the partial derivatives are continuous, then $f$ is analytic.

### Example 1: Deriving Cauchy-Riemann from Derivative

Show that if $f'(z_0)$ exists, then the Cauchy-Riemann equations must hold.

**Solution:**

$$f'(z_0) = \lim_{h \to 0} \frac{f(z_0 + h) - f(z_0)}{h}$$

**Approach 1**: Let $h = \Delta x$ (real, $\Delta x \to 0$):
$$f'(z_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x + iy_0) - f(x_0 + iy_0)}{\Delta x}$$
$$= \lim_{\Delta x \to 0} \frac{[u(x_0+\Delta x, y_0) - u(x_0,y_0)] + i[v(x_0+\Delta x,y_0) - v(x_0,y_0)]}{\Delta x}$$
$$= \frac{\partial u}{\partial x}(x_0, y_0) + i\frac{\partial v}{\partial x}(x_0, y_0)$$

**Approach 2**: Let $h = i\Delta y$ (imaginary, $\Delta y \to 0$):
$$f'(z_0) = \lim_{\Delta y \to 0} \frac{f(x_0 + i(y_0 + \Delta y)) - f(x_0 + iy_0)}{i\Delta y}$$
$$= \lim_{\Delta y \to 0} \frac{[u(x_0, y_0+\Delta y) - u(x_0,y_0)] + i[v(x_0,y_0+\Delta y) - v(x_0,y_0)]}{i\Delta y}$$
$$= \frac{1}{i}\left[\frac{\partial u}{\partial y} + i\frac{\partial v}{\partial y}\right]$$
$$= -i\frac{\partial u}{\partial y} + \frac{\partial v}{\partial y}$$

For these to be equal:
$$\frac{\partial u}{\partial x} + i\frac{\partial v}{\partial x} = \frac{\partial v}{\partial y} - i\frac{\partial u}{\partial y}$$

**Equating real and imaginary parts**:
$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \quad \frac{\partial v}{\partial x} = -\frac{\partial u}{\partial y}$$

**Answer:** Cauchy-Riemann equations derived from direction-independence

### Example 2: Verifying Cauchy-Riemann for $f(z) = z^2$

Verify the Cauchy-Riemann equations for $f(z) = z^2$.

**Solution:**

$$f(z) = (x+iy)^2 = x^2 - y^2 + i(2xy)$$

So $u(x,y) = x^2 - y^2$ and $v(x,y) = 2xy$.

**Compute partial derivatives**:
$$u_x = 2x, \quad u_y = -2y$$
$$v_x = 2y, \quad v_y = 2x$$

**Check Cauchy-Riemann**:
$$u_x = 2x = v_y$$ ✓
$$u_y = -2y = -v_x$$ ✓

Both equations satisfied everywhere.

**Answer:** Cauchy-Riemann equations hold; $f$ is entire

### Example 3: Testing Analyticity of $\overline{z}$

Show that $f(z) = \overline{z}$ does not satisfy Cauchy-Riemann equations.

**Solution:**

$$f(z) = \overline{z} = x - iy$$

So $u(x,y) = x$ and $v(x,y) = -y$.

$$u_x = 1, \quad u_y = 0$$
$$v_x = 0, \quad v_y = -1$$

**Check Cauchy-Riemann**:
$$u_x = 1 \neq -1 = v_y$$ ✗

First equation fails.

**Answer:** Cauchy-Riemann equations not satisfied; $\overline{z}$ not analytic anywhere

### Example 4: Computing Derivative from Partial Derivatives

If $f$ is analytic and $u(x,y) = e^x\cos y$, find $f'(z)$ in terms of partial derivatives.

**Solution:**

From derivation in Example 1:
$$f'(z) = u_x + iv_x = v_y - iu_y$$

We have $u(x,y) = e^x\cos y$:
$$u_x = e^x\cos y, \quad u_y = -e^x\sin y$$

Using $f'(z) = u_x + iv_x$:

Need $v_x$. From Cauchy-Riemann $u_y = -v_x$:
$$v_x = -u_y = -(-e^x\sin y) = e^x\sin y$$

Therefore:
$$f'(z) = e^x\cos y + ie^x\sin y = e^x(\cos y + i\sin y) = e^x e^{iy} = e^{x+iy} = e^z$$

**Answer:** $f'(z) = e^z$

## Using Cauchy-Riemann to Find Functions

### Example 5: Finding Harmonic Conjugate

If $u(x,y) = x^2 - y^2$, find $v(x,y)$ such that $f(z) = u + iv$ is analytic.

**Solution:**

From Cauchy-Riemann equations:
$$v_y = u_x = 2x$$
$$v_x = -u_y = -(-2y) = 2y$$

From first equation, integrate with respect to $y$:
$$v = \int 2x \, dy = 2xy + g(x)$$

where $g(x)$ is an arbitrary function of $x$ alone.

Differentiate with respect to $x$:
$$v_x = 2y + g'(x)$$

From second Cauchy-Riemann equation:
$$2y + g'(x) = 2y \implies g'(x) = 0 \implies g(x) = C$$

Therefore: $v = 2xy + C$

Choosing $C = 0$: $v = 2xy$

**Verification**: $f(z) = x^2 - y^2 + i(2xy) = (x+iy)^2 = z^2$ ✓

**Answer:** $v(x,y) = 2xy$ (plus arbitrary constant)

### Example 6: Determining Analyticity

Is $f(z) = e^x(\cos y - i\sin y)$ analytic?

**Solution:**

$$u(x,y) = e^x\cos y, \quad v(x,y) = -e^x\sin y$$

$$u_x = e^x\cos y, \quad u_y = -e^x\sin y$$
$$v_x = -e^x\sin y, \quad v_y = -e^x\cos y$$

**Check Cauchy-Riemann**:
$$u_x = e^x\cos y \neq -e^x\cos y = v_y$$ ✗

First equation fails (unless $\cos y = 0$ everywhere, which is impossible).

**Answer:** Not analytic (Cauchy-Riemann not satisfied)

### Example 7: Where is $|z|^2$ Analytic?

At what points (if any) is $f(z) = |z|^2$ analytic?

**Solution:**

$$f(z) = |z|^2 = x^2 + y^2$$

$$u(x,y) = x^2 + y^2, \quad v(x,y) = 0$$

$$u_x = 2x, \quad u_y = 2y$$
$$v_x = 0, \quad v_y = 0$$

**Cauchy-Riemann**:
$$u_x = v_y \implies 2x = 0 \implies x = 0$$
$$u_y = -v_x \implies 2y = 0 \implies y = 0$$

Both conditions hold only at $(0,0)$ (i.e., $z = 0$).

However, analytic requires differentiability in a **neighborhood**, not just at a single point.

**Answer:** Not analytic anywhere (differentiable only at origin as isolated point)

## Sufficient Conditions for Analyticity

**Theorem**: If $u$ and $v$ have continuous first partial derivatives satisfying Cauchy-Riemann equations in an open region $D$, then $f = u + iv$ is analytic in $D$.

### Example 8: Verifying Sufficient Conditions

Show that $f(z) = \sin z$ is entire using Cauchy-Riemann.

**Solution:**

$$\sin z = \sin(x+iy) = \sin x \cosh y + i\cos x \sinh y$$

$$u = \sin x \cosh y, \quad v = \cos x \sinh y$$

$$u_x = \cos x \cosh y, \quad u_y = \sin x \sinh y$$
$$v_x = -\sin x \sinh y, \quad v_y = \cos x \cosh y$$

**Check Cauchy-Riemann**:
$$u_x = \cos x \cosh y = v_y$$ ✓
$$u_y = \sin x \sinh y = -v_x$$ ✓

All partial derivatives continuous everywhere.

**Answer:** Cauchy-Riemann satisfied everywhere with continuous partials; $\sin z$ is entire

### Example 9: Piecewise Function

Consider
$$f(z) = \begin{cases} z^2/\overline{z} & z \neq 0 \\ 0 & z = 0 \end{cases}$$

Is $f$ differentiable at $z = 0$?

**Solution:**

For $z \neq 0$:
$$f(z) = \frac{z^2}{\overline{z}} = \frac{(x+iy)^2}{x-iy} = \frac{x^2 - y^2 + 2ixy}{x-iy}$$

This is complicated. Test derivative at origin:
$$\lim_{h \to 0}\frac{f(h) - f(0)}{h} = \lim_{h \to 0}\frac{h^2/\overline{h}}{h} = \lim_{h \to 0}\frac{h}{\overline{h}}$$

**Real approach** ($h = t$): $\frac{t}{t} = 1$

**Imaginary approach** ($h = it$): $\frac{it}{-it} = -1$

Different limits.

**Answer:** Not differentiable at origin

## Polar Form of Cauchy-Riemann

In polar coordinates $z = re^{i\theta}$, write $f(z) = u(r,\theta) + iv(r,\theta)$.

**Polar Cauchy-Riemann equations**:
$$\frac{\partial u}{\partial r} = \frac{1}{r}\frac{\partial v}{\partial \theta}, \quad \frac{1}{r}\frac{\partial u}{\partial \theta} = -\frac{\partial v}{\partial r}$$

### Example 10: Verifying Polar Cauchy-Riemann

Verify polar Cauchy-Riemann for $f(z) = z^n$ where $n$ is a positive integer.

**Solution:**

In polar form: $z = re^{i\theta}$, so $z^n = r^ne^{in\theta}$

$$u(r,\theta) = r^n\cos(n\theta), \quad v(r,\theta) = r^n\sin(n\theta)$$

$$\frac{\partial u}{\partial r} = nr^{n-1}\cos(n\theta)$$
$$\frac{1}{r}\frac{\partial v}{\partial \theta} = \frac{1}{r} \cdot r^n \cdot n\cos(n\theta) = nr^{n-1}\cos(n\theta)$$ ✓

$$\frac{1}{r}\frac{\partial u}{\partial \theta} = \frac{1}{r} \cdot r^n \cdot (-n\sin(n\theta)) = -nr^{n-1}\sin(n\theta)$$
$$-\frac{\partial v}{\partial r} = -nr^{n-1}\sin(n\theta)$$ ✓

**Answer:** Polar Cauchy-Riemann equations satisfied

### Example 11: Using Polar Form

Is $f(z) = \ln|z|$ analytic (except at origin)?

**Solution:**

In polar form: $f(re^{i\theta}) = \ln r$ (purely real)

$$u(r,\theta) = \ln r, \quad v(r,\theta) = 0$$

$$\frac{\partial u}{\partial r} = \frac{1}{r}, \quad \frac{1}{r}\frac{\partial v}{\partial \theta} = 0$$

**First polar Cauchy-Riemann**:
$$\frac{1}{r} \neq 0$$ ✗

Equation fails.

**Answer:** Not analytic (real part alone; Cauchy-Riemann fails)

### Example 12: Finding Derivative in Polar Form

If $f$ satisfies polar Cauchy-Riemann and $u_r, v_r$ are known, express $f'(z)$.

**Solution:**

From rectangular form: $f'(z) = u_x + iv_x$

Converting to polar using chain rule (derivation omitted):
$$f'(z) = e^{-i\theta}\left(\frac{\partial u}{\partial r} + i\frac{\partial v}{\partial r}\right)$$

Or equivalently:
$$f'(z) = \frac{e^{-i\theta}}{1}\left(u_r + iv_r\right)$$

**Answer:** $f'(z) = e^{-i\theta}(u_r + iv_r)$

B) No points

## Answer Key

**Problem 1: B**
Cauchy-Riemann equations: $u_x = v_y$ and $u_y = -v_x$
These link partial derivatives of real and imaginary parts
Necessary for complex differentiability
Also sufficient when partials are continuous
Key insight: couples horizontal/vertical behavior
These equations ensure direction-independence of difference quotient

**Problem 2: C**
$f(z) = iz = i(x+iy) = ix - y = -y + ix$
$u = -y$, $v = x$
$u_x = 0$, $u_y = -1$
$v_x = 1$, $v_y = 0$
Check: $u_x = 0 = v_y$ ✓ and $u_y = -1 = -v_x = -1$ ✓
Both equations satisfied everywhere
This confirms $f(z) = iz$ is entire (multiplication by constant is analytic)

**Problem 3: A**
$u = x^3 - 3xy^2$
$u_x = 3x^2 - 3y^2$, $u_y = -6xy$
Cauchy-Riemann: $v_y = u_x = 3x^2 - 3y^2$ and $v_x = -u_y = 6xy$
From $v_y = 3x^2 - 3y^2$, integrate: $v = 3x^2y - y^3 + g(x)$
From $v_x = 6xy$: $6xy + g'(x) = 6xy$ ⟹ $g'(x) = 0$ ⟹ $g = C$
Therefore $v = 3x^2y - y^3 + C$
Note: $f(z) = z^3$ gives this

**Problem 4: B**
$f(z) = \text{Im}(z) = y$
$u = y$, $v = 0$ (or assign differently, but $f$ is real-valued)
$u_x = 0$, $u_y = 1$
$v_x = 0$, $v_y = 0$
Check: $u_x = 0 = v_y$ ✓ but $u_y = 1 \neq 0 = -v_x$ ✗
Second equation fails everywhere
Real-valued function (except constant) cannot be analytic

**Problem 5: C**
Polar form: $u_r = \frac{1}{r}v_\theta$ and $\frac{1}{r}u_\theta = -v_r$
Involves both radial ($r$) and angular ($\theta$) derivatives
Factor of $1/r$ appears due to polar coordinate Jacobian
Equivalent to rectangular Cauchy-Riemann
Used when function naturally expressed in polar form

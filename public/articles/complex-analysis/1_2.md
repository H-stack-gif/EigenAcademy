# Complex Analysis Topic 1.2: Complex Functions and Mappings

In calculus, a function $f: \mathbb{R} \to \mathbb{R}$ transforms numbers into numbers—a one-dimensional input produces a one-dimensional output. Complex functions are fundamentally different: they map the plane to itself. A function $f: \mathbb{C} \to \mathbb{C}$ takes a point in the complex plane and produces another point, transforming entire regions into new shapes. This geometric perspective reveals complex functions as **mappings** or **transformations** of the plane, where we can visualize how domains deform, rotate, and reshape under the action of $f$.

Understanding complex functions geometrically unlocks intuition that pure formulas obscure. The function $f(z) = z^2$ doesn't just square numbers—it doubles angles from the origin and squares distances, wrapping the plane around itself. The function $f(z) = 1/z$ performs inversion through the unit circle, swapping interior and exterior. Linear fractional transformations map circles to circles, preserving angle structure. This visual understanding, combined with rigorous limits and continuity, prepares us for differentiation in the complex plane.

This article explores complex functions as mappings. We'll define limits and continuity in the complex plane, discover how functions transform curves and regions, analyze basic mappings geometrically, and investigate how compositions build complex transformations from simple ones. You'll learn to visualize functions beyond formulas, predict mapping behavior, and understand why complex function theory is fundamentally more rigid and beautiful than real analysis.

## Complex Functions as Mappings

A **complex function** $f: \mathbb{C} \to \mathbb{C}$ assigns to each $z$ in its domain a unique value $w = f(z)$.

Writing $z = x + iy$ and $w = u + iv$:
$$f(z) = u(x, y) + iv(x, y)$$

where $u$ and $v$ are real-valued functions of two real variables.

**Geometric interpretation**: $f$ maps points $(x, y)$ in the $z$-plane to points $(u, v)$ in the $w$-plane.

### Example 1: Real and Imaginary Parts

For $f(z) = z^2$, find $u(x, y)$ and $v(x, y)$.

**Solution:**

$$f(z) = z^2 = (x + iy)^2 = x^2 + 2ixy + (iy)^2$$
$$= x^2 + 2ixy - y^2 = (x^2 - y^2) + i(2xy)$$

Therefore:
$$u(x, y) = x^2 - y^2$$
$$v(x, y) = 2xy$$

**Geometric meaning**: Real part $u$ depends on difference of squares; imaginary part $v$ is hyperbolic.

**Answer:** $u(x, y) = x^2 - y^2$, $v(x, y) = 2xy$

### Example 2: Function Evaluation

Evaluate $f(z) = z^2 + 2z$ at $z = 1 + i$.

**Solution:**

$$f(1 + i) = (1 + i)^2 + 2(1 + i)$$
$$= (1 + 2i - 1) + (2 + 2i)$$
$$= 2i + 2 + 2i = 2 + 4i$$

Alternatively, using $u$ and $v$ with $x = 1, y = 1$:
$$u = x^2 - y^2 + 2x = 1 - 1 + 2 = 2$$
$$v = 2xy + 2y = 2 + 2 = 4$$
$$f(1 + i) = 2 + 4i$$ ✓

**Answer:** $2 + 4i$

### Example 3: Image of a Set

Find the image of the line $x = 1$ under $f(z) = z^2$.

**Solution:**

Points on $x = 1$: $z = 1 + iy$ for $y \in \mathbb{R}$

$$f(1 + iy) = (1 + iy)^2 = 1 + 2iy - y^2 = (1 - y^2) + i(2y)$$

So $u = 1 - y^2$ and $v = 2y$.

Eliminate parameter $y$: From $v = 2y$, we have $y = v/2$.
$$u = 1 - (v/2)^2 = 1 - \frac{v^2}{4}$$
$$v^2 = 4(1 - u)$$
$$v^2 = -4(u - 1)$$

This is a **parabola** opening left, vertex at $(1, 0)$ in $w$-plane.

**Answer:** Parabola $v^2 = -4(u - 1)$

## Limits and Continuity

**Limit**: $\lim_{z \to z_0} f(z) = L$ means: for every $\epsilon > 0$, there exists $\delta > 0$ such that
$$0 < |z - z_0| < \delta \implies |f(z) - L| < \epsilon$$

**Continuity**: $f$ is continuous at $z_0$ if $\lim_{z \to z_0} f(z) = f(z_0)$.

**Key difference from real analysis**: $z \to z_0$ can approach from **infinitely many directions** in the complex plane.

### Example 4: Computing a Limit

Find $\lim_{z \to i} (z^2 + 1)$.

**Solution:**

Since $f(z) = z^2 + 1$ is a polynomial, it's continuous everywhere.

$$\lim_{z \to i} (z^2 + 1) = i^2 + 1 = -1 + 1 = 0$$

**Answer:** $0$

### Example 5: Limit That Doesn't Exist

Show that $\lim_{z \to 0} \frac{\text{Re}(z)}{|z|}$ does not exist.

**Solution:**

Approach along real axis ($z = x$, $x \to 0^+$):
$$\frac{\text{Re}(x)}{|x|} = \frac{x}{|x|} = \frac{x}{x} = 1$$

Approach along imaginary axis ($z = iy$, $y \to 0$):
$$\frac{\text{Re}(iy)}{|iy|} = \frac{0}{|y|} = 0$$

Different limits along different paths means limit doesn't exist.

**Answer:** Limit does not exist (path-dependent)

### Example 6: Continuity of Conjugate

Is $f(z) = \overline{z}$ continuous?

**Solution:**

Need to show $\lim_{z \to z_0} \overline{z} = \overline{z_0}$.

$$|\overline{z} - \overline{z_0}| = |\overline{z - z_0}| = |z - z_0|$$

Given $\epsilon > 0$, choose $\delta = \epsilon$. Then:
$$|z - z_0| < \delta \implies |\overline{z} - \overline{z_0}| = |z - z_0| < \delta = \epsilon$$ ✓

**Answer:** Yes, continuous everywhere

## Geometric Behavior of Basic Functions

### Example 7: Linear Function

Describe the mapping $f(z) = az + b$ where $a, b \in \mathbb{C}$ with $a \neq 0$.

**Solution:**

Write $a = re^{i\alpha}$ in polar form.

$$f(z) = re^{i\alpha}z + b$$

**Effect**: 
1. Multiply by $r$: scale by factor $r$
2. Multiply by $e^{i\alpha}$: rotate by angle $\alpha$
3. Add $b$: translate by vector $b$

**Geometric interpretation**: Rotation, scaling, then translation (rigid motion if $r = 1$)

**Properties**:
- Maps lines to lines
- Maps circles to circles
- Preserves angles and ratios of lengths

**Answer:** Composition of rotation, scaling, and translation; preserves shapes

### Example 8: Squaring Function

How does $f(z) = z^2$ transform the ray $\arg(z) = \theta_0$?

**Solution:**

Points on ray: $z = re^{i\theta_0}$ for $r \geq 0$

$$f(z) = z^2 = (re^{i\theta_0})^2 = r^2e^{i2\theta_0}$$

**Effect**:
- Modulus: $|f(z)| = r^2$ (quadratic in distance)
- Argument: $\arg(f(z)) = 2\theta_0$ (double the angle)

The ray at angle $\theta_0$ maps to ray at angle $2\theta_0$.

**Geometric interpretation**: $z^2$ **doubles angles** from positive real axis and **squares distances** from origin.

**Answer:** Ray at angle $\theta_0$ maps to ray at angle $2\theta_0$

### Example 9: Sector Mapping

Describe the image of the sector $0 \leq \arg(z) \leq \pi/4$ under $f(z) = z^2$.

**Solution:**

For $z$ in sector: $0 \leq \theta \leq \pi/4$

Since $\arg(z^2) = 2\theta$:
$$0 \leq 2\theta \leq \pi/2$$

The sector with angle $\pi/4$ maps to sector with angle $\pi/2$ (right half-plane with $\text{Re}(w) \geq 0$, $\text{Im}(w) \geq 0$).

**Answer:** First quadrant (sector $0 \leq \arg(w) \leq \pi/2$)

### Example 10: Reciprocal Function

Describe key features of $f(z) = 1/z$.

**Solution:**

$$f(z) = \frac{1}{z} = \frac{1}{re^{i\theta}} = \frac{1}{r}e^{-i\theta}$$

**Effect**:
- Modulus: $|f(z)| = 1/r$ (inverts distance: far becomes near)
- Argument: $\arg(f(z)) = -\theta$ (reflects across real axis)

**Properties**:
- Maps unit circle to itself
- Swaps inside and outside of unit circle ($|z| < 1 \leftrightarrow |w| > 1$)
- Reflects across real axis and inverts
- Undefined at $z = 0$ (singularity)

**Answer:** Inversion: $w = 1/z$ inverts distances and reflects angles

## Mapping Circles and Lines

### Example 11: Image of Circle Under $z^2$

What is the image of the circle $|z| = 2$ under $f(z) = z^2$?

**Solution:**

For $|z| = 2$: $z = 2e^{i\theta}$, $\theta \in [0, 2\pi)$

$$f(z) = (2e^{i\theta})^2 = 4e^{i2\theta}$$

As $\theta$ varies from $0$ to $2\pi$, $2\theta$ varies from $0$ to $4\pi$, tracing the circle **twice**.

**Modulus**: $|f(z)| = 4$ (constant)

**Image**: Circle $|w| = 4$, traced twice

**Answer:** Circle of radius $4$, covered twice

### Example 12: Image of Unit Circle Under $1/z$

Find the image of $|z| = 1$ under $f(z) = 1/z$.

**Solution:**

For $|z| = 1$: $z = e^{i\theta}$

$$f(z) = \frac{1}{e^{i\theta}} = e^{-i\theta}$$

$$|f(z)| = 1$$

**Image**: Unit circle $|w| = 1$ (maps to itself, but with reversed orientation)

**Answer:** Unit circle (mapped to itself with reversed orientation)

### Example 13: Image of Vertical Line

Find the image of the line $\text{Re}(z) = 1$ under $f(z) = 1/z$.

**Solution:**

Points: $z = 1 + iy$, $y \in \mathbb{R}$

$$f(z) = \frac{1}{1 + iy} = \frac{1 - iy}{(1 + iy)(1 - iy)} = \frac{1 - iy}{1 + y^2}$$

$$u = \frac{1}{1 + y^2}, \quad v = \frac{-y}{1 + y^2}$$

Eliminate $y$: From $v = -yu$, we have $y = -v/u$ (if $u \neq 0$).

Substitute into $u = \frac{1}{1 + y^2}$:
$$u = \frac{1}{1 + v^2/u^2}$$
$$u(1 + v^2/u^2) = 1$$
$$u + v^2/u = 1$$
$$u^2 + v^2 = u$$
$$(u - 1/2)^2 + v^2 = 1/4$$

This is a **circle** centered at $(1/2, 0)$ with radius $1/2$.

**Answer:** Circle $(u - 1/2)^2 + v^2 = 1/4$

## Composition of Functions

If $f: D_1 \to D_2$ and $g: D_2 \to D_3$, then composition $g \circ f: D_1 \to D_3$ is defined by
$$(g \circ f)(z) = g(f(z))$$

### Example 14: Computing Composition

If $f(z) = z^2$ and $g(z) = z + 1$, find $(g \circ f)(z)$ and $(f \circ g)(z)$.

**Solution:**

$$(g \circ f)(z) = g(f(z)) = g(z^2) = z^2 + 1$$

$$(f \circ g)(z) = f(g(z)) = f(z + 1) = (z + 1)^2 = z^2 + 2z + 1$$

Note: $g \circ f \neq f \circ g$ (composition not commutative)

**Answer:** $(g \circ f)(z) = z^2 + 1$; $(f \circ g)(z) = z^2 + 2z + 1$

### Example 15: Geometric Composition

Describe the mapping $h(z) = (z - i)^2$ as a composition.

**Solution:**

$$h(z) = (z - i)^2 = f(g(z))$$

where:
- $g(z) = z - i$ (translate down by $i$)
- $f(w) = w^2$ (square)

**Geometric effect**:
1. Translate: shift plane down by $1$ unit
2. Square: double angles from origin, square distances

**Answer:** Composition of translation by $-i$ followed by squaring

### Example 16: Continuity of Composition

If $f$ and $g$ are continuous, is $g \circ f$ continuous?

**Solution:**

**Theorem**: If $f$ is continuous at $z_0$ and $g$ is continuous at $f(z_0)$, then $g \circ f$ is continuous at $z_0$.

**Proof sketch**: Given $\epsilon > 0$:
- Continuity of $g$: $\exists \delta_1$ such that $|w - f(z_0)| < \delta_1 \implies |g(w) - g(f(z_0))| < \epsilon$
- Continuity of $f$: $\exists \delta$ such that $|z - z_0| < \delta \implies |f(z) - f(z_0)| < \delta_1$
- Combining: $|z - z_0| < \delta \implies |(g \circ f)(z) - (g \circ f)(z_0)| < \epsilon$ ✓

**Answer:** Yes, composition of continuous functions is continuous

## Practice Problems

**Problem 1:** For $f(z) = z^2$, the real part $u(x,y)$ equals:

**Problem 2:** The function $f(z) = |z|^2$ can be written as:

A) $z^2$
B) $z\overline{z}$
C) $\overline{z}^2$
D) $2z$
E) $z + \overline{z}$

**Problem 3:** Under $f(z) = z^2$, the ray $\arg(z) = \pi/3$ maps to:

A) $\arg(w) = \pi/6$
B) $\arg(w) = \pi/3$
C) $\arg(w) = 2\pi/3$
D) $\arg(w) = \pi$
E) A circle

**Problem 4:** The function $f(z) = 1/z$ maps the circle $|z| = 2$ to:

A) $|w| = 1/2$
B) $|w| = 2$
C) $|w| = 4$
D) A line
E) A parabola

**Problem 5:** If $f$ and $g$ are continuous, then $f + g$ is:

A) Always continuous
B) Never continuous
C) Continuous only at origin
D) Continuous only on real axis
E) Sometimes continuous

## Answer Key

**Problem 1: B**
$f(z) = z^2 = (x + iy)^2 = x^2 + 2ixy - y^2$
Real part: $u(x, y) = x^2 - y^2$
Imaginary part: $v(x, y) = 2xy$
Note: $u^2 - v^2 = (x^2 - y^2)^2 - (2xy)^2$ relates to fourth powers
Geometric: level curves of $u$ are rectangular hyperbolas

**Problem 2: B**
$|z|^2 = z\overline{z}$
For $z = x + iy$: $|z|^2 = x^2 + y^2$
And $z\overline{z} = (x+iy)(x-iy) = x^2 + y^2$ ✓
Note: $z^2 = (x+iy)^2 = x^2 - y^2 + 2ixy$ (different!)
This identity fundamental for many proofs

**Problem 3: C**
$z^2$ doubles arguments: $\arg(z^2) = 2\arg(z)$
If $\arg(z) = \pi/3$, then $\arg(w) = 2(\pi/3) = 2\pi/3$
Geometric: sector of angle $\alpha$ maps to sector of angle $2\alpha$
Applies to any ray or sector
Multiple angles: $z^n$ multiplies argument by $n$

**Problem 4: A**
$f(z) = 1/z$ inverts modulus: $|f(z)| = 1/|z|$
Circle $|z| = 2$ maps to $|w| = 1/2$
General: circle $|z| = r$ maps to circle $|w| = 1/r$
Also reflects across real axis: $\arg(w) = -\arg(z)$
Unit circle maps to itself

**Problem 5: A**
Sum of continuous functions is continuous
Proof: $|(f+g)(z) - (f+g)(z_0)| = |f(z) - f(z_0) + g(z) - g(z_0)|$
$\leq |f(z) - f(z_0)| + |g(z) - g(z_0)| < \epsilon/2 + \epsilon/2 = \epsilon$
Also: products, quotients (where defined), compositions are continuous
Fundamental for building complex continuous functions

# Complex Analysis Topic 3.1: Contour Integrals

Integration in real calculus follows a one-dimensional path along the number line, accumulating area under a curve. Complex integration follows paths—**contours**—through the two-dimensional complex plane, accumulating contributions of a function along curves that can wind, loop, and traverse regions in intricate patterns. Unlike real integrals where changing the interval changes the result, complex contour integrals can be **path-independent** when the integrand is analytic, making the integral depend only on endpoints, not the route between them. This remarkable property stems from Cauchy's theorem and transforms complex integration from geometric calculation into topological reasoning.

A contour integral $\int_C f(z) \, dz$ sums infinitesimal contributions $f(z) \, dz$ along curve $C$, where both $f(z)$ and $dz$ are complex. The integral's value depends on the function, the path, and crucially, on what singularities the path encircles. For analytic functions in simply connected domains, integrals around closed loops vanish—a profoundly different behavior from real integration. When functions have singularities, contours that encircle them yield non-zero values encoding deep information about the function's local behavior.

This article develops contour integration from foundations. We'll define complex line integrals, learn to parametrize and evaluate them, discover when path independence holds, estimate integral magnitudes, and understand how contours interact with singularities. You'll master the computational techniques for evaluating contour integrals and gain intuition for when and why path matters, preparing for Cauchy's theorem and the residue calculus that follows.

## Definition of Contour Integral

A **contour** (or **path**) $C$ in the complex plane is a continuous curve, typically smooth or piecewise smooth.

**Parametrization**: $z(t) = x(t) + iy(t)$ for $a \leq t \leq b$

The **contour integral** of $f(z)$ along $C$ is:

$$\int_C f(z) \, dz = \int_a^b f(z(t))z'(t) \, dt$$

where $z'(t) = \frac{dz}{dt}$ is the derivative of the parametrization.

**Interpretation**: Accumulate $f(z)$ weighted by differential displacement $dz$ along path.

### Example 1: Integrating Along Line Segment

Evaluate $\int_C z \, dz$ where $C$ is the straight line from $0$ to $1+i$.

**Solution:**

**Parametrization**: $z(t) = t(1+i)$ for $0 \leq t \leq 1$

$$z'(t) = 1 + i$$

$$\int_C z \, dz = \int_0^1 t(1+i) \cdot (1+i) \, dt$$
$$= (1+i)^2\int_0^1 t \, dt$$
$$= (1 + 2i - 1)\cdot \frac{1}{2}$$
$$= 2i \cdot \frac{1}{2} = i$$

**Answer:** $i$

### Example 2: Integral Around Circle

Evaluate $\int_C \frac{1}{z} \, dz$ where $C$ is the circle $|z| = 1$ traversed counterclockwise.

**Solution:**

**Parametrization**: $z(t) = e^{it}$ for $0 \leq t \leq 2\pi$

$$z'(t) = ie^{it}$$

$$\int_C \frac{1}{z} \, dz = \int_0^{2\pi} \frac{1}{e^{it}} \cdot ie^{it} \, dt$$
$$= \int_0^{2\pi} i \, dt = i \cdot 2\pi = 2\pi i$$

**Important result**: $\oint_{|z|=1} \frac{dz}{z} = 2\pi i$ (fundamental in complex analysis)

**Answer:** $2\pi i$

### Example 3: Path Dependence Example

Evaluate $\int_C \overline{z} \, dz$ from $0$ to $1+i$ along:
(a) The straight line
(b) The path going first to $1$, then to $1+i$

**Solution:**

**(a) Straight line**: $z(t) = t(1+i)$, $z'(t) = 1+i$ for $0 \leq t \leq 1$

$$\overline{z(t)} = t(1-i)$$

$$\int_C \overline{z} \, dz = \int_0^1 t(1-i)(1+i) \, dt = \int_0^1 t[(1-i)(1+i)] \, dt$$
$$= \int_0^1 t(1 - i^2) \, dt = \int_0^1 2t \, dt = 1$$

**(b) Two segments**:
- First: $z = t$ for $0 \leq t \leq 1$ (real axis)
  $$\int_0^1 \overline{t} \cdot 1 \, dt = \int_0^1 t \, dt = \frac{1}{2}$$

- Second: $z = 1 + it$ for $0 \leq t \leq 1$ (vertical line)
  $$\int_0^1 (1-it) \cdot i \, dt = \int_0^1 (i + t) \, dt = i + \frac{1}{2}$$

Total: $\frac{1}{2} + i + \frac{1}{2} = 1 + i$

Different paths give different results!

**Answer:** (a) $1$, (b) $1+i$ (path-dependent because $\overline{z}$ not analytic)

## Properties of Contour Integrals

**Linearity**: $\int_C [af(z) + bg(z)] \, dz = a\int_C f(z) \, dz + b\int_C g(z) \, dz$

**Additivity**: If $C = C_1 + C_2$ (concatenation), then $\int_C f = \int_{C_1} f + \int_{C_2} f$

**Reversal**: $\int_{-C} f(z) \, dz = -\int_C f(z) \, dz$ (reverse orientation)

**Bounds**: $\left|\int_C f(z) \, dz\right| \leq ML$ where $|f(z)| \leq M$ on $C$ and $L$ = length of $C$ (**ML inequality**)

### Example 4: Using Linearity

Evaluate $\int_C (2z + 3) \, dz$ where $C$ goes from $0$ to $i$.

**Solution:**

$$\int_C (2z + 3) \, dz = 2\int_C z \, dz + 3\int_C 1 \, dz$$

For any path from $z_1$ to $z_2$:
- $\int_C z \, dz = \frac{1}{2}[z^2]_{z_1}^{z_2}$ (antiderivative exists)
- $\int_C 1 \, dz = [z]_{z_1}^{z_2} = z_2 - z_1$

$$\int_C z \, dz = \frac{1}{2}[i^2 - 0^2] = \frac{1}{2}(-1) = -\frac{1}{2}$$

$$\int_C 1 \, dz = i - 0 = i$$

$$\int_C (2z + 3) \, dz = 2\left(-\frac{1}{2}\right) + 3(i) = -1 + 3i$$

**Answer:** $-1 + 3i$

### Example 5: Path Reversal

If $\int_C f(z) \, dz = 5 + 2i$, find $\int_{-C} f(z) \, dz$.

**Solution:**

Reversing orientation negates the integral:

$$\int_{-C} f(z) \, dz = -\int_C f(z) \, dz = -(5 + 2i) = -5 - 2i$$

**Answer:** $-5 - 2i$

### Example 6: ML Inequality Application

Estimate $\left|\int_C e^z \, dz\right|$ where $C$ is the arc of $|z| = 2$ in the first quadrant.

**Solution:**

On $|z| = 2$: $z = 2e^{i\theta}$ where $0 \leq \theta \leq \pi/2$

$$|e^z| = |e^{x+iy}| = e^x = e^{2\cos\theta}$$

Maximum when $\cos\theta = 1$ (at $\theta = 0$):
$$M = e^2$$

Arc length: $L = 2 \cdot \frac{\pi}{2} = \pi$ (quarter circle of radius 2)

**ML inequality**:
$$\left|\int_C e^z \, dz\right| \leq e^2 \cdot \pi = \pi e^2$$

**Answer:** $\left|\int_C e^z \, dz\right| \leq \pi e^2$

## Antiderivatives and Path Independence

If $f$ has an **antiderivative** $F$ (i.e., $F'(z) = f(z)$) in a domain, then:

$$\int_C f(z) \, dz = F(z_2) - F(z_1)$$

where $z_1$ and $z_2$ are the endpoints of $C$.

This integral is **path-independent** (depends only on endpoints).

### Example 7: Using Antiderivative

Evaluate $\int_C z^3 \, dz$ from $z = 0$ to $z = 1+i$ along any path.

**Solution:**

$F(z) = \frac{z^4}{4}$ is an antiderivative of $z^3$.

$$\int_C z^3 \, dz = \left[\frac{z^4}{4}\right]_0^{1+i} = \frac{(1+i)^4}{4}$$

$$(1+i)^2 = 2i$$
$$(1+i)^4 = (2i)^2 = -4$$

$$\int_C z^3 \, dz = \frac{-4}{4} = -1$$

**Answer:** $-1$ (independent of path)

### Example 8: When No Antiderivative Exists

Does $f(z) = \frac{1}{z}$ have an antiderivative in the punctured plane $\mathbb{C} \setminus \{0\}$?

**Solution:**

If $F'(z) = \frac{1}{z}$ existed globally, then for any closed contour:
$$\oint_C \frac{dz}{z} = F(z) - F(z) = 0$$

But from Example 2: $\oint_{|z|=1} \frac{dz}{z} = 2\pi i \neq 0$

Contradiction! No antiderivative exists in the punctured plane (though $\log z$ works locally on branches).

**Answer:** No global antiderivative in $\mathbb{C} \setminus \{0\}$

### Example 9: Path Independence Test

Show that $\int_C (2z + 3) \, dz$ is path-independent.

**Solution:**

$f(z) = 2z + 3$ has antiderivative $F(z) = z^2 + 3z$.

Since $F'(z) = 2z + 3 = f(z)$ everywhere, the integral is path-independent:

$$\int_C (2z + 3) \, dz = [z^2 + 3z]_{z_1}^{z_2}$$

**Answer:** Path-independent (polynomial has antiderivative)

## Integrals of $1/(z-z_0)^n$

For integer $n$ and contour $C = $ circle $|z - z_0| = r$ traversed counterclockwise:

$$\oint_C \frac{dz}{(z-z_0)^n} = \begin{cases} 2\pi i & \text{if } n = 1 \\ 0 & \text{if } n \neq 1 \end{cases}$$

### Example 10: Computing Standard Integral

Evaluate $\oint_{|z|=2} \frac{dz}{z^2}$.

**Solution:**

Parametrize: $z = 2e^{it}$, $dz = 2ie^{it} dt$ for $0 \leq t \leq 2\pi$

$$\oint \frac{dz}{z^2} = \int_0^{2\pi} \frac{2ie^{it} dt}{(2e^{it})^2} = \int_0^{2\pi} \frac{2ie^{it}}{4e^{i2t}} dt$$
$$= \frac{i}{2}\int_0^{2\pi} e^{-it} dt = \frac{i}{2}\left[\frac{e^{-it}}{-i}\right]_0^{2\pi}$$
$$= \frac{i}{2} \cdot \frac{1}{-i}[e^{-i2\pi} - e^0] = \frac{1}{2}[1 - 1] = 0$$

**Answer:** $0$ (since $n = 2 \neq 1$)

### Example 11: Shifted Center

Evaluate $\oint_{|z-i|=1} \frac{dz}{z-i}$.

**Solution:**

This is $\frac{1}{(z-z_0)^1}$ with $z_0 = i$ and $n = 1$.

By the standard result:
$$\oint_{|z-i|=1} \frac{dz}{z-i} = 2\pi i$$

**Answer:** $2\pi i$

### Example 12: Multiple Loops

Evaluate $\oint_C \frac{dz}{z}$ where $C$ is the circle $|z| = 1$ traversed twice counterclockwise.

**Solution:**

One loop: $\oint \frac{dz}{z} = 2\pi i$

Two loops: $\int_C = 2 \cdot 2\pi i = 4\pi i$

**Answer:** $4\pi i$

## Real and Imaginary Parts

Writing $f = u + iv$ and $dz = dx + idy$:

$$\int_C f(z) \, dz = \int_C (u + iv)(dx + idy)$$
$$= \int_C (u \, dx - v \, dy) + i\int_C (v \, dx + u \, dy)$$

This connects to real line integrals.

### Example 13: Computing via Real Parts

Evaluate $\int_C z \, dz$ from $0$ to $1+i$ along the straight line using real components.

**Solution:**

$z = x + iy$, so $f(z) = z$ means $u = x$ and $v = y$.

Line: $y = x$ for $0 \leq x \leq 1$, so $dy = dx$.

$$\int_C z \, dz = \int_C (x \, dx - y \, dy) + i\int_C (y \, dx + x \, dy)$$

Real part:
$$\int_0^1 (x \, dx - x \, dx) = 0$$

Imaginary part:
$$\int_0^1 (x \, dx + x \, dx) = \int_0^1 2x \, dx = 1$$

$$\int_C z \, dz = 0 + i(1) = i$$

**Answer:** $i$ (matches Example 1)

### Example 14: Green's Theorem Connection

For closed contour $C$ enclosing region $D$:

$$\oint_C f(z) \, dz = \iint_D \left(-\frac{\partial v}{\partial x} - \frac{\partial u}{\partial y}\right) dA + i\iint_D \left(\frac{\partial u}{\partial x} - \frac{\partial v}{\partial y}\right) dA$$

If $f$ is analytic (Cauchy-Riemann holds), what happens?

**Solution:**

From Cauchy-Riemann: $u_x = v_y$ and $u_y = -v_x$

Real part integrand: $-v_x - u_y = -v_x - (-v_x) = 0$

Imaginary part integrand: $u_x - v_y = v_y - v_y = 0$

Both integrands vanish, so:
$$\oint_C f(z) \, dz = 0$$

This previews **Cauchy's theorem**.

**Answer:** Integral vanishes for analytic $f$ (Cauchy's theorem preview)

## Answer Key

**Problem 1: C**
Contour integral depends on both function $f$ and path $C$
Formula: $\int_C f(z) dz = \int_a^b f(z(t))z'(t) dt$
Exception: path-independent when $f$ has antiderivative
Example: $\int_C \overline{z} dz$ depends on path (Example 3)
Example: $\int_C z^2 dz$ depends only on endpoints (has antiderivative)

**Problem 2: B**
Polynomials have antiderivatives (higher-degree polynomials)
For closed contour: $\oint_C p(z) dz = P(z)|_{\text{back to start}} = 0$
Example: $p(z) = z^2$ has $P(z) = z^3/3$
Around any closed loop: $P(z_0) - P(z_0) = 0$
General principle: analytic functions with antiderivatives give zero on closed contours

**Problem 3: C**
Standard result: $\oint_{|z-z_0|=r} \frac{dz}{(z-z_0)^n} = 0$ for $n \neq 1$
Here $n = 3$, so integral is $0$
Only $n = 1$ (first power) gives $2\pi i$
Can verify by direct parametrization: $z = e^{it}$
Integration shows exponentials cancel to give zero

**Problem 4: B**
ML inequality: $|\int_C f dz| \leq ML$
$M = \max|f(z)|$ on contour $C$
$L =$ arc length of $C$
Used for estimation without computing integral exactly
Example: if $|f| \leq 3$ and $L = 5$, then $|\int_C f| \leq 15$

**Problem 5: C**
If antiderivative exists: $\int_C f(z) dz = F(z_2) - F(z_1)$
Depends only on endpoints $z_1, z_2$, not path between them
Called path-independent or conservative
Example: $f(z) = z^n$ has $F(z) = z^{n+1}/(n+1)$
Not zero unless endpoints coincide (closed contour)

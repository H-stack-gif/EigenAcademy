 # Linear Algebra Topic 1.4: Matrix Inverses

 Division isn't defined for matrices. If you want to solve $ax = b$ for real numbers, you divide: $x = b/a$. But what's $\vec{x}$ in the matrix equation $A\vec{x} = \vec{b}$? We can't "divide by $A$."

 Instead, we use the **matrix inverse**. When $A$ has an inverse $A^{-1}$, we can multiply both sides: $A^{-1}A\vec{x} = A^{-1}\vec{b}$, giving $\vec{x} = A^{-1}\vec{b}$. The inverse "undoes" what $A$ does, just like reciprocals undo multiplication for numbers.

 But not every matrix has an inverse—just as not every number has a reciprocal (zero doesn't). Understanding which matrices are invertible and how to compute inverses is fundamental. Invertibility connects to uniqueness of solutions, linear independence, determinants, and the geometry of linear transformations. In this topic, we'll develop both computational techniques and theoretical understanding of this crucial concept.

 ## Definition of Matrix Inverse

 A square $n \times n$ matrix $A$ is **invertible** (or **nonsingular**) if there exists a matrix $A^{-1}$ such that:

 $$ AA^{-1} = I \quad \text{and} \quad A^{-1}A = I$$

 where $I$ is the $n \times n$ identity matrix.

 If $A$ is not invertible, we call it **singular**.

 **Key facts:**
 - Only square matrices can have inverses
 - If $A^{-1}$ exists, it's unique
 - $(A^{-1})^{-1} = A$ (inverse of inverse gives back original)
 - If $A$ and $B$ are invertible, then $(AB)^{-1} = B^{-1}A^{-1}$ (note the reversal!)

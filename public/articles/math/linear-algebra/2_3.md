 # Linear Algebra Topic 2.3: Bases and Dimension

 A GPS coordinate requires three numbers: latitude, longitude, altitude. Not two, not four—exactly three. This isn't arbitrary. Three-dimensional space has **dimension three**, and any coordinate system needs exactly three independent reference directions. This is the power of the concept of a **basis**: a minimal set of vectors that provides a complete coordinate system.

 Bases unify two ideas: spanning (reaching all vectors) and independence (no redundancy). They're the Goldilocks sets—not too many vectors (which would create dependence), not too few (which wouldn't span), but just right. Every vector space has bases, and remarkably, all bases for the same space have the same size. This common size is the **dimension**.

 Understanding bases and dimension transforms vague geometric intuition into precise mathematics. We'll see how to construct bases for column spaces and null spaces, how dimension governs the structure of vector spaces, and how the rank-nullity theorem connects the dimensions of fundamental subspaces. These tools are essential for everything from solving differential equations to analyzing data.

 ## Definition of a Basis

 A **basis** for vector space $V$ is a set of vectors $\mathcal{B} = \{\vec{b}_1, \vec{b}_2, \ldots, \vec{b}_n\}$ that is:
 1. **Linearly independent**
 2. **Spans** $V$

 Every vector in $V$ can be written uniquely as a linear combination of basis vectors.

 # Linear Algebra Topic 2.1: Vector Spaces and Subspaces

 Vectors aren't just arrows. Polynomials, functions, matrices—these can all be "vectors" in an abstract sense. The power of linear algebra comes from recognizing that diverse mathematical objects often share the same structural properties. When we add two polynomials or scale a function, we're performing operations that behave exactly like vector addition and scalar multiplication in $\mathbb{R}^n$.

 This abstraction might seem unnecessary at first. Why complicate things by calling polynomials "vectors"? Because once we prove a theorem about abstract vector spaces, it applies automatically to all examples: geometric vectors, polynomial spaces, function spaces, solution sets to differential equations. The investment in abstraction pays enormous dividends.

 In this topic, we'll formalize what makes something a "vector space" and explore subspaces—vector spaces living inside other vector spaces. We'll see that solution sets to homogeneous systems, column spaces, and null spaces all share common structure. Understanding this abstraction transforms isolated computational techniques into a unified theory with far-reaching applications.

 ## Definition of a Vector Space

 A **vector space** over the real numbers consists of a set $V$ with two operations:
 - **Vector addition**: assigns to each pair $\vec{u}, \vec{v} \in V$ a sum $\vec{u} + \vec{v} \in V$
 - **Scalar multiplication**: assigns to each scalar $c \in \mathbb{R}$ and vector $\vec{v} \in V$ a product $c\vec{v} \in V$

 These operations must satisfy ten axioms:

 **Addition axioms:**
 1. Closure: $\vec{u} + \vec{v} \in V$
 2. Commutativity: $\vec{u} + \vec{v} = \vec{v} + \vec{u}$
 3. Associativity: $(\vec{u} + \vec{v}) + \vec{w} = \vec{u} + (\vec{v} + \vec{w})$
 4. Zero vector: There exists $\vec{0} \in V$ such that $\vec{v} + \vec{0} = \vec{v}$ for all $\vec{v}$
 5. Additive inverses: For each $\vec{v} \in V$, there exists $-\vec{v} \in V$ such that $\vec{v} + (-\vec{v}) = \vec{0}$

 **Scalar multiplication axioms:**
 6. Closure: $c\vec{v} \in V$
 7. Distributivity over vector addition: $c(\vec{u} + \vec{v}) = c\vec{u} + c\vec{v}$
 8. Distributivity over scalar addition: $(c + d)\vec{v} = c\vec{v} + d\vec{v}$
 9. Associativity: $c(d\vec{v}) = (cd)\vec{v}$
 10. Scalar identity: $1\vec{v} = \vec{v}$

 These axioms capture the essential algebraic structure that makes linear algebra work.

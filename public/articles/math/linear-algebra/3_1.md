 # Linear Algebra Topic 3.1: Introduction to Linear Transformations

 When you rotate an image on your phone, scale a CAD drawing, or apply a filter to a photograph, you're using linear transformations. These operations take input vectors and produce output vectors in a way that preserves the fundamental structure of vector spaces. A linear transformation doesn't just arbitrarily scramble data—it respects addition and scalar multiplication, the two operations that define vector spaces.

 This seemingly simple requirement—preserving vector space operations—has profound consequences. Linear transformations can be represented by matrices, making abstract mappings concrete and computable. They connect geometry to algebra, allowing us to analyze rotations, reflections, projections, and dilations using matrix multiplication. In data science, linear transformations reduce dimensions while preserving relationships. In physics, they describe coordinate changes and symmetries.

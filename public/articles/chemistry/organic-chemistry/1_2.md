# Organic Chemistry — Topic 1.2: Alkanes and Functional Groups

Introduction to common functional groups (alkanes, alkenes, alkynes, alcohols, amines, carbonyls) and simple properties/reactions of each class.

## Practice Problems

1. Identify functional groups in a set of small molecules and predict basic reactivity (e.g., nucleophiles vs electrophiles).
2. Describe IUPAC rules for naming straight-chain alkanes up to 8 carbons.

## Answer Key

1. Short answers mapping functional groups to molecules.
2. Rules: longest chain, numbering, substituents, prefixes/suffixes.

# Multivariable Calculus Topic 3.1: Functions of Several Variables

Temperature in a room varies with position—warmer near the heater, cooler by the window. Elevation on Earth's surface depends on both latitude and longitude. Production output in economics depends on labor and capital inputs. These situations require **functions of several variables**—a single output determined by multiple inputs. We write $z = f(x, y)$ or $w = f(x, y, z)$, extending the familiar $y = f(x)$ from single-variable calculus.

Visualizing these functions is challenging. The graph of $z = f(x, y)$ is a **surface** in three-dimensional space—imagine terrain rising and falling over a map. When we can't draw the surface, we use **level curves** (like contour lines on topographic maps) or **level surfaces** to understand the function's behavior. These tools let us see how functions change without needing four-dimensional vision.

This article develops the foundations for multivariable functions. We'll learn to identify domains and ranges, sketch graphs as surfaces, draw and interpret level curves, understand level surfaces, and work with limits and continuity in multiple variables. These concepts generalize single-variable ideas but introduce new subtleties—limits can depend on the path of approach, and continuity becomes more delicate. Mastering visualization and geometric intuition here pays dividends throughout multivariable calculus.

## Functions of Two Variables

**Definition**: Function $f$ of two variables assigns to each ordered pair $(x, y)$ in domain $D$ a unique value $z = f(x, y)$.

**Domain**: Set of all points $(x, y)$ for which $f$ is defined

**Range**: Set of all possible output values $z$

### Example 1: Finding Domain

Find the domain of $f(x, y) = \sqrt{4 - x^2 - y^2}$.

**Solution:**

Need $4 - x^2 - y^2 \geq 0$ (for square root to be real)

$$x^2 + y^2 \leq 4$$

**Domain**: Disk of radius 2 centered at origin (including boundary)

$D = \{(x, y) : x^2 + y^2 \leq 4\}$

**Answer:** Closed disk of radius 2

### Example 2: Domain with Restrictions

Find the domain of $ f(x, y) = \frac{\ln(y - x^2)}{x}$.

**Solution:**

Need:
1. $y - x^2 > 0$ (argument of ln must be positive) → $y > x^2$
2. $x \neq 0$ (denominator nonzero)

**Domain**: Region above parabola $y = x^2$, excluding $y$-axis

$D = \{(x, y) : y > x^2 \text{ and } x \neq 0\}$

**Answer:** Above parabola $y = x^2$, excluding $y$-axis

## Graphs of Functions of Two Variables

**Graph**: Surface in 3D given by points $(x, y, z)$ where $z = f(x, y)$

Common surfaces:
- **Planes**: $z = ax + by + c$ (linear functions)
- **Paraboloids**: $z = x^2 + y^2$ (elliptic paraboloid)
- **Saddle**: $z = x^2 - y^2$ (hyperbolic paraboloid)

### Example 3: Linear Function

Describe the graph of $f(x, y) = 2x + 3y - 6$.

**Solution:**

This is equation of a plane: $z = 2x + 3y - 6$

**Intercepts**:
- $x$-intercept (set $y = z = 0$): $x = 3$
- $y$-intercept (set $x = z = 0$): $y = 2$
- $z$-intercept (set $x = y = 0$): $z = -6$

**Normal vector**: $\langle 2, 3, -1 \rangle$ (from coefficients)

**Answer:** Plane with normal $\langle 2, 3, -1 \rangle$

### Example 4: Paraboloid

Describe the graph of $f(x, y) = x^2 + y^2$.

**Solution:**

**Surface**: $z = x^2 + y^2$ (circular paraboloid)

**Cross-sections**:
- For $z = c > 0$: $x^2 + y^2 = c$ (circles of radius $\sqrt{c}$)
- For $x = 0$: $z = y^2$ (parabola)
- For $y = 0$: $z = x^2$ (parabola)

**Shape**: Bowl opening upward, vertex at origin

**Answer:** Circular paraboloid opening upward

## Level Curves

**Level curve**: Set of points $(x, y)$ where $f(x, y) = c$ (constant)

**Contour map**: Collection of level curves for various values of $c$

**Interpretation**: Points on same level curve have same function value (like elevation on topographic map)

### Example 5: Level Curves of Paraboloid

Sketch level curves of $f(x, y) = x^2 + y^2$ for $c = 0, 1, 4, 9$.

**Solution:**

$$x^2 + y^2 = c$$

- $c = 0$: Point $(0, 0)$
- $c = 1$: Circle of radius 1
- $c = 4$: Circle of radius 2
- $c = 9$: Circle of radius 3

**Level curves**: Concentric circles, spacing increases (like topographic map of cone)

**Answer:** Concentric circles with radii $0, 1, 2, 3$

### Example 6: Hyperbolic Paraboloid

Sketch level curves of $f(x, y) = x^2 - y^2$ for $c = -4, -1, 0, 1, 4$.

**Solution:**

$$x^2 - y^2 = c$$

- $c = 0$: $x^2 = y^2$, so $y = \pm x$ (two lines)
- $c > 0$: $ \frac{x^2}{c} - \frac{y^2}{c} = 1$ (hyperbola opening horizontally)
- $c < 0$: $ \frac{y^2}{|c|} - \frac{x^2}{|c|} = 1$ (hyperbola opening vertically)

**Answer:** Hyperbolas with perpendicular axes (saddle surface)

### Example 7: Linear Function Contours

Sketch level curves of $f(x, y) = 2x - y$ for $c = -2, 0, 2, 4$.

**Solution:**

$$2x - y = c$$
$$y = 2x - c$$

Each level curve is a line with slope 2:
- $c = -2$: $y = 2x + 2$
- $c = 0$: $y = 2x$
- $c = 2$: $y = 2x - 2$
- $c = 4$: $y = 2x - 4$

**Level curves**: Parallel lines with slope 2, equally spaced

**Answer:** Family of parallel lines with slope 2

### Example 8: Reading Contour Maps

A contour map shows curves for $f = 10, 20, 30, 40$ as concentric circles with radii $1, 2, 3, 4$ respectively. What can you conclude about $f$?

**Solution:**

**Pattern**: As radius doubles ($1 \to 2$), function increases by 10

Suggests: $f \propto r^2$ where $r = \sqrt{x^2 + y^2}$

Try: $f(x, y) = k(x^2 + y^2)$

At $r = 1$: $f = 10$, so $k = 10$

**Check**: $f(x, y) = 10(x^2 + y^2)$
- At $r = 2$: $f = 40$ ✓
- At $r = 3$: $f = 90$ ✗

**Answer:** $f(x, y) = 10\sqrt{x^2 + y^2}$ (cone)

## Functions of Three Variables

**Definition**: $w = f(x, y, z)$ assigns value to each point $(x, y, z)$ in domain $D \subset \mathbb{R}^3$

**Graph**: Cannot visualize in 3D (would require 4D)

**Level surfaces**: Sets where $f(x, y, z) = c$

### Example 9: Domain in Three Variables

Find the domain of $f(x, y, z) = \sqrt{9 - x^2 - y^2 - z^2}$.

**Solution:**

Need $9 - x^2 - y^2 - z^2 \geq 0$

$$x^2 + y^2 + z^2 \leq 9$$

**Domain**: Solid ball of radius 3 centered at origin

$D = \{(x, y, z) : x^2 + y^2 + z^2 \leq 9\}$

**Answer:** Ball of radius 3

### Example 10: Level Surfaces

Describe level surfaces of $f(x, y, z) = x^2 + y^2 + z^2$ for $c = 1, 4, 9$.

**Solution:**

$$x^2 + y^2 + z^2 = c$$

- $c = 1$: Sphere of radius 1
- $c = 4$: Sphere of radius 2
- $c = 9$: Sphere of radius 3

**Level surfaces**: Concentric spheres

**Answer:** Family of concentric spheres

## Limits and Continuity

**Limit**: $ \lim_{(x,y) \to (a,b)} f(x, y) = L$ if $f(x, y)$ approaches $L$ as $(x, y)$ approaches $(a, b)$ from **all directions**

**Continuity**: $f$ continuous at $(a, b)$ if:
1. $f(a, b)$ is defined
2. $ \lim_{(x,y) \to (a,b)} f(x, y)$ exists
3. $ \lim_{(x,y) \to (a,b)} f(x, y) = f(a, b)$

### Example 11: Computing Limits

Find $ \lim_{(x,y) \to (1,2)} (x^2 + y^2)$.

**Solution:**

Since $f(x, y) = x^2 + y^2$ is continuous everywhere:

$$\lim_{(x,y) \to (1,2)} (x^2 + y^2) = 1^2 + 2^2 = 5$$

**Answer:** 5

### Example 12: Path-Dependent Limit

Show that $ \lim_{(x,y) \to (0,0)} \frac{xy}{x^2 + y^2}$ does not exist.

**Solution:**

**Along $x$-axis** ($y = 0$):
$$\lim_{x \to 0} \frac{x \cdot 0}{x^2 + 0} = \lim_{x \to 0} 0 = 0$$

**Along $y = x$**:
$$\lim_{x \to 0} \frac{x \cdot x}{x^2 + x^2} = \lim_{x \to 0} \frac{x^2}{2x^2} = \frac{1}{2}$$

Different paths give different limits!

**Answer:** Limit does not exist (path-dependent)

### Example 13: Two-Path Test

Use the two-path test to show $ \lim_{(x,y) \to (0,0)} \frac{x^2y}{x^4 + y^2}$ does not exist.

**Solution:**

**Along $x$-axis** ($y = 0$):
$$\lim_{x \to 0} \frac{x^2 \cdot 0}{x^4 + 0} = 0$$

**Along $y = x^2$**:
$$\lim_{x \to 0} \frac{x^2 \cdot x^2}{x^4 + x^4} = \lim_{x \to 0} \frac{x^4}{2x^4} = \frac{1}{2}$$

**Answer:** Limit does not exist

## Practice Problems

**Problem 1:** The domain of $f(x, y) = \ln(x^2 + y^2 - 1)$ is:

A) All $(x, y)$ with $x^2 + y^2 > 1$
B) All $(x, y)$ with $x^2 + y^2 < 1$
C) All $(x, y)$ with $x^2 + y^2 = 1$
D) All $(x, y)$
E) Circle of radius 1

**Problem 2:** Level curves of $f(x, y) = x^2 + 4y^2$ are:

A) Circles
B) Ellipses
C) Hyperbolas
D) Parabolas
E) Lines

**Problem 3:** The graph of $f(x, y) = 1 - x - y$ is:

A) Sphere
B) Paraboloid
C) Plane
D) Cylinder
E) Cone

**Problem 4:** If $ \lim_{(x,y) \to (a,b)} f(x, y)$ gives different values along different paths, then:

A) The limit exists
B) The limit does not exist
C) The function is continuous
D) The function is undefined
E) More information needed

**Problem 5:** Level surfaces of $f(x, y, z) = x + 2y + 3z$ are:

A) Spheres
B) Planes
C) Cylinders
D) Paraboloids
E) Cones

## Answer Key

**Problem 1: A**
Need argument of ln to be positive: $x^2 + y^2 - 1 > 0$
$x^2 + y^2 > 1$
Domain: exterior of unit circle (not including circle itself)
Not option B (that's interior)
Not option E (that's the boundary only)

**Problem 2: B**
$x^2 + 4y^2 = c$
$ \frac{x^2}{c} + \frac{y^2}{c/4} = 1$ (for $c > 0$)
Ellipses with semi-axes $\sqrt{c}$ and $\sqrt{c}/2$
Not circles (coefficients different)
Special case $c = 0$ gives single point

**Problem 3: C**
$z = 1 - x - y$ or $x + y + z = 1$
Linear equation → plane
Not paraboloid (would have squared terms)
Intercepts: $(1,0,0)$, $(0,1,0)$, $(0,0,1)$

**Problem 4: B**
If different paths give different limit values, limit doesn't exist
This is the two-path test
For limit to exist, must approach same value from ALL paths
Path-dependence proves non-existence

**Problem 5: B**
$x + 2y + 3z = c$
Linear equation in 3 variables → plane
Each value of $c$ gives different plane
Planes are parallel (same normal vector $\langle 1, 2, 3 \rangle$)
Not spheres (would be $x^2 + y^2 + z^2 = c$)

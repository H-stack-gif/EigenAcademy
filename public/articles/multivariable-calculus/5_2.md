# Multivariable Calculus Topic 5.2: Conservative Vector Fields and Potential Functions

Some vector fields have a special property: the work done moving between two points is **path-independent**—it depends only on the starting and ending points, not the route taken. These are **conservative vector fields**, named because they conserve mechanical energy. Gravity is conservative: lifting a rock requires the same energy regardless of whether you lift it straight up or carry it up a winding staircase. The work depends only on the change in height.

Conservative fields have **potential functions** $f$ such that $\mathbf{F} = \nabla f$. The gradient of the potential gives the field. The **fundamental theorem for line integrals** says that for conservative fields, $\int_C \nabla f \cdot d\mathbf{r} = f(\text{end}) - f(\text{start})$—just like how the fundamental theorem of calculus evaluates $\int_a^b f'(x) \, dx = f(b) - f(a)$. This makes computing work trivial: evaluate the potential at endpoints.

This article develops the theory of conservative fields. We'll learn to test whether a field is conservative, find potential functions when they exist, apply the fundamental theorem to compute line integrals instantly, and understand why path independence, conservative fields, and potential functions are all equivalent concepts. These ideas unify vector calculus with physics—potential energy, voltage in circuits, and gravitational potential all arise from conservative vector fields.

## Conservative Vector Fields

**Conservative vector field**: $\mathbf{F}$ is conservative if $\mathbf{F} = \nabla f$ for some scalar function $f$ (called **potential function**)

**Equivalent conditions**:
1. $\mathbf{F} = \nabla f$ for some $f$
2. $\int_C \mathbf{F} \cdot d\mathbf{r}$ is path-independent
3. $\oint_C \mathbf{F} \cdot d\mathbf{r} = 0$ for all closed curves $C$

### Example 1: Gradient Field

Show that $\mathbf{F}(x, y) = \langle 2x, 2y \rangle$ is conservative by finding a potential function.

**Solution:**

Need $f$ such that $\nabla f = \mathbf{F}$.

$$\frac{\partial f}{\partial x} = 2x \implies f(x, y) = x^2 + g(y)$$

$$\frac{\partial f}{\partial y} = g'(y) = 2y \implies g(y) = y^2 + C$$

**Potential function**: $f(x, y) = x^2 + y^2 + C$

**Verify**: $\nabla f = \langle 2x, 2y \rangle = \mathbf{F}$ ✓

**Answer:** $f(x, y) = x^2 + y^2$ is a potential function

### Example 2: Testing Path Independence

Show that $\mathbf{F} = \langle y, x \rangle$ is conservative and verify path independence.

**Solution:**

**Find potential**:
$$\frac{\partial f}{\partial x} = y \implies f = xy + g(y)$$
$$\frac{\partial f}{\partial y} = x + g'(y) = x \implies g'(y) = 0$$

So $f(x, y) = xy + C$

**Verify path independence**: Compute $\int_C \mathbf{F} \cdot d\mathbf{r}$ from $(0,0)$ to $(1,1)$ along two paths.

**Path 1**: Straight line $\mathbf{r}(t) = \langle t, t \rangle$, $0 \leq t \leq 1$

$$\int_{C_1} = \int_0^1 \langle t, t \rangle \cdot \langle 1, 1 \rangle \, dt = \int_0^1 2t \, dt = 1$$

**Path 2**: Along axes — $(0,0) \to (1,0) \to (1,1)$

First leg: $\int_0^1 \langle 0, x \rangle \cdot \langle 1, 0 \rangle \, dx = 0$
Second leg: $\int_0^1 \langle y, 1 \rangle \cdot \langle 0, 1 \rangle \, dy = \int_0^1 1 \, dy = 1$
Total: $0 + 1 = 1$ ✓

**Answer:** Same value by both paths; field is conservative with $f = xy$

## Fundamental Theorem for Line Integrals

**Theorem**: If $\mathbf{F} = \nabla f$ is conservative and $C$ is smooth curve from point $A$ to point $B$:

$$\int_C \mathbf{F} \cdot d\mathbf{r} = f(B) - f(A)$$

**Application**: Reduces line integral to evaluation at endpoints

### Example 3: Using Fundamental Theorem

Evaluate $\int_C \nabla f \cdot d\mathbf{r}$ where $f(x, y) = x^2y$ and $C$ is any path from $(1, 1)$ to $(2, 4)$.

**Solution:**

$$\int_C \nabla f \cdot d\mathbf{r} = f(2, 4) - f(1, 1)$$

$$= 2^2(4) - 1^2(1) = 16 - 1 = 15$$

**Answer:** $15$ (independent of path!)

### Example 4: Work in Gravitational Field

Find work done by gravity $\mathbf{F} = \langle 0, -mg \rangle$ moving from $(0, 0)$ to $(5, 10)$.

**Solution:**

**Find potential**: 
$$\frac{\partial f}{\partial x} = 0 \implies f = g(y)$$
$$\frac{\partial f}{\partial y} = g'(y) = -mg \implies g(y) = -mgy + C$$

**Potential**: $f(x, y) = -mgy$ (gravitational potential energy)

$$W = f(5, 10) - f(0, 0) = -mg(10) - (-mg \cdot 0) = -10mg$$

**Answer:** $W = -10mg$ (negative because work is done against gravity in upward motion)

### Example 5: Closed Path

If $\mathbf{F}$ is conservative, what is $\oint_C \mathbf{F} \cdot d\mathbf{r}$ for any closed curve $C$?

**Solution:**

For closed curve, start = end.

$$\oint_C \mathbf{F} \cdot d\mathbf{r} = f(\text{end}) - f(\text{start}) = f(P) - f(P) = 0$$

**Answer:** $0$ (no net work around closed path in conservative field)

## Test for Conservative Fields

**Test in 2D**: $\mathbf{F} = \langle P, Q \rangle$ is conservative if $ \frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$

(This is necessary and sufficient on simply connected domains)

**Test in 3D**: $\mathbf{F} = \langle P, Q, R \rangle$ is conservative if $\nabla \times \mathbf{F} = \mathbf{0}$ (curl is zero)

### Example 6: Conservative Test

Determine if $\mathbf{F}(x, y) = \langle 2xy, x^2 + 1 \rangle$ is conservative.

**Solution:**

$$P = 2xy, \quad Q = x^2 + 1$$

$$\frac{\partial P}{\partial y} = 2x$$
$$\frac{\partial Q}{\partial x} = 2x$$

Since $ \frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$, field is conservative ✓

**Answer:** Conservative

### Example 7: Non-Conservative Example

Show that $\mathbf{F}(x, y) = \langle -y, x \rangle$ is not conservative.

**Solution:**

$$P = -y, \quad Q = x$$

$$\frac{\partial P}{\partial y} = -1$$
$$\frac{\partial Q}{\partial x} = 1$$

Since $-1 \neq 1$, field is **not conservative**.

**Verification**: From Example 8 in previous article, $\oint_C \mathbf{F} \cdot d\mathbf{r} = 2\pi \neq 0$ around unit circle.

**Answer:** Not conservative

### Example 8: Finding Potential Function

Find potential function for $\mathbf{F}(x, y) = \langle e^x\cos y, -e^x\sin y \rangle$.

**Solution:**

**Test**: $ \frac{\partial}{\partial y}[e^x\cos y] = -e^x\sin y = \frac{\partial}{\partial x}[-e^x\sin y]$ ✓ Conservative

**Find $f$**:
$$f_x = e^x\cos y \implies f = e^x\cos y + g(y)$$

$$f_y = -e^x\sin y + g'(y) = -e^x\sin y$$

So $g'(y) = 0$, thus $g(y) = C$

**Answer:** $f(x, y) = e^x\cos y + C$

## Finding Potential Functions: General Method

**Procedure**:
1. Check if conservative: $ \frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$
2. Integrate $P$ with respect to $x$: $ f = \int P \, dx + g(y)$
3. Differentiate with respect to $y$ and set equal to $Q$: $f_y = Q$
4. Solve for $g(y)$

### Example 9: Method Demonstration

Find potential for $\mathbf{F}(x, y) = \langle 3x^2 + y, x + 2y \rangle$.

**Solution:**

**Test**: $ \frac{\partial P}{\partial y} = 1 = \frac{\partial Q}{\partial x}$ ✓

**Step 1**: $ f = \int (3x^2 + y) \, dx = x^3 + xy + g(y)$

**Step 2**: $f_y = x + g'(y) = x + 2y$

So $g'(y) = 2y$, thus $g(y) = y^2 + C$

**Answer:** $f(x, y) = x^3 + xy + y^2$

### Example 10: Three Variables

Find potential for $\mathbf{F}(x, y, z) = \langle yz, xz, xy \rangle$.

**Solution:**

**Integrate with respect to $x$**:
$$f = \int yz \, dx = xyz + g(y, z)$$

**Partial with respect to $y$**:
$$f_y = xz + \frac{\partial g}{\partial y} = xz$$

So $ \frac{\partial g}{\partial y} = 0 \implies g = h(z)$

**Partial with respect to $z$**:
$$f_z = xy + h'(z) = xy$$

So $h'(z) = 0 \implies h = C$

**Answer:** $f(x, y, z) = xyz + C$

## Applications to Physics

**Gravitational potential**: $ f(x, y, z) = -\frac{GM}{\sqrt{x^2+y^2+z^2}}$

**Electric potential**: $ V(\mathbf{r}) = k\frac{q}{|\mathbf{r}|}$

**Relationship**: $\mathbf{F} = -\nabla f$ (force is negative gradient of potential energy)

### Example 11: Gravitational Potential Energy

For gravitational field $\mathbf{F} = \langle 0, -mg \rangle$, verify that potential energy $U = mgy$ gives $\mathbf{F} = -\nabla U$.

**Solution:**

$$\nabla U = \left\langle \frac{\partial}{\partial x}(mgy), \frac{\partial}{\partial y}(mgy) \right\rangle = \langle 0, mg \rangle$$

$$-\nabla U = \langle 0, -mg \rangle = \mathbf{F}$$ ✓

**Answer:** Verified; force is negative gradient of potential energy

### Example 12: Work-Energy Theorem

If particle moves from $A$ to $B$ in conservative field with potential $f$, relate work to change in potential energy.

**Solution:**

$$W = \int_C \mathbf{F} \cdot d\mathbf{r} = f(B) - f(A)$$

If $\mathbf{F} = -\nabla U$ (force is negative gradient of potential energy):

$$W = -U(B) + U(A) = -\Delta U$$

**Conservation of energy**: $W = \Delta K$ (kinetic energy)

So $\Delta K = -\Delta U$, giving $K + U = \text{constant}$

**Answer:** Work equals negative change in potential energy

### Example 13: Escape Velocity

Gravitational potential for Earth: $ U(r) = -\frac{GMm}{r}$ where $r$ is distance from center.

Find minimum speed to escape Earth's gravity from surface (radius $R$).

**Solution:**

**Energy at surface**: $E_i = \frac{1}{2}mv^2 - \frac{GMm}{R}$

**Energy at infinity**: $E_f = 0$ (just escapes, so $v = 0$ at $r = \infty$)

**Conservation**: $E_i = E_f$

$$\frac{1}{2}mv^2 - \frac{GMm}{R} = 0$$

$$v^2 = \frac{2GM}{R}$$

$$v_{\text{escape}} = \sqrt{\frac{2GM}{R}}$$

For Earth: $v \approx 11.2$ km/s

**Answer:** $ v_{\text{escape}} = \sqrt{\frac{2GM}{R}} \approx 11.2 \text{ km/s}$

## Answer Key

**Problem 1: B**
Conservative field: $\mathbf{F} = \nabla f$ (gradient of potential)
Equivalent: path-independent line integrals
Not about constant magnitude (radial field $\mathbf{r}/r^3$ is conservative)
Not about rotation (conservative fields have zero curl)

**Problem 2: C**
$\oint_C \mathbf{F} \cdot d\mathbf{r} = f(\text{end}) - f(\text{start}) = 0$ for closed curve
No net work around closed path
Key property of conservative fields
Contrast with $\langle -y, x \rangle$ where integral $= 2\pi$

**Problem 3: B**
$\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$ tests if $\mathbf{F} = \langle P, Q \rangle$ conservative
Necessary and sufficient (on simply connected domain)
Related to curl being zero
Fails for $\langle -y, x \rangle$: $-1 \neq 1$

**Problem 4: B**
Fundamental theorem: $\int_C \nabla f \cdot d\mathbf{r} = f(B) - f(A)$
Final value minus initial value
Like FTC: $\int_a^b f'(x) \, dx = f(b) - f(a)$
Not $f(A) - f(B)$ (wrong sign)

**Problem 5: B**
Conservative forces have potential energy
$\mathbf{F} = -\nabla U$ (force = negative gradient of potential)
Gravity, electrostatic, spring forces are conservative
Friction is non-conservative (dissipates energy)
Conservation of mechanical energy: $K + U = $ constant

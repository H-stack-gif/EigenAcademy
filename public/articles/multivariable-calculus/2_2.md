# Multivariable Calculus Topic 2.2: Derivatives and Integrals

In single-variable calculus, the derivative $f'(x)$ measures the rate of change—how fast the function is changing at each point. For vector-valued functions describing motion, the derivative has beautiful geometric meaning: it's the **velocity vector**. The direction of $\mathbf{r}'(t)$ points where you're heading, and its magnitude tells how fast you're going. This connects abstract mathematics to physical reality—every moving object has position, velocity, and acceleration described by vectors.

Differentiation of vector functions is remarkably simple: differentiate each component separately. But the geometric interpretation is profound. The derivative $\mathbf{r}'(t)$ is **tangent to the curve** at each point—it gives the instantaneous direction of motion. The second derivative $\mathbf{r}''(t)$ is the **acceleration**, showing how velocity changes. Newton's second law $\mathbf{F} = m\mathbf{a}$ becomes a vector differential equation, the foundation of classical mechanics.

This article develops differentiation and integration of vector-valued functions. We'll compute derivatives using component-wise differentiation, find tangent vectors and tangent lines, apply differentiation rules (sum, product, chain rules for vectors), and integrate vector functions to recover position from velocity. We'll see how projectile motion, planetary orbits, and particle physics all reduce to solving vector differential equations. The calculus you learned for scalar functions generalizes beautifully to vectors—same techniques, deeper meaning.

## Derivative of Vector Function

**Derivative**: $ \mathbf{r}'(t) = \lim_{h \to 0} \frac{\mathbf{r}(t+h) - \mathbf{r}(t)}{h}$

**Component-wise differentiation**:
$$\mathbf{r}'(t) = \langle f'(t), g'(t), h'(t) \rangle$$

**Alternative notations**: $\mathbf{r}'(t) =  \frac{d\mathbf{r}}{dt} = \dot{\mathbf{r}}(t)$

**Geometric meaning**: Tangent vector to curve at $\mathbf{r}(t)$

### Example 1: Computing Derivatives

Find $\mathbf{r}'(t)$ for $\mathbf{r}(t) = \langle t^2, e^t, \sin t \rangle$.

**Solution:**

$$\mathbf{r}'(t) = \langle 2t, e^t, \cos t \rangle$$

**Answer:** $\mathbf{r}'(t) = \langle 2t, e^t, \cos t \rangle$

### Example 2: Higher Derivatives

For $\mathbf{r}(t) = \langle t^3, \cos t, t \rangle$, find $\mathbf{r}''(t)$.

**Solution:**

$$\mathbf{r}'(t) = \langle 3t^2, -\sin t, 1 \rangle$$

$$\mathbf{r}''(t) = \langle 6t, -\cos t, 0 \rangle$$

**Answer:** $\mathbf{r}''(t) = \langle 6t, -\cos t, 0 \rangle$

## Tangent Vectors and Tangent Lines

**Unit tangent vector**: $ \mathbf{T}(t) = \frac{\mathbf{r}'(t)}{|\mathbf{r}'(t)|}$

**Tangent line** at $t = t_0$: $\mathbf{L}(s) = \mathbf{r}(t_0) + s\mathbf{r}'(t_0)$

### Example 3: Tangent Line to Helix

Find the tangent line to $\mathbf{r}(t) = \langle \cos t, \sin t, t \rangle$ at $t = \pi/2$.

**Solution:**

$$\mathbf{r}(\pi/2) = \langle 0, 1, \pi/2 \rangle$$

$$\mathbf{r}'(t) = \langle -\sin t, \cos t, 1 \rangle$$

$$\mathbf{r}'(\pi/2) = \langle -1, 0, 1 \rangle$$

**Tangent line**:
$$\mathbf{L}(s) = \langle 0, 1, \pi/2 \rangle + s\langle -1, 0, 1 \rangle = \langle -s, 1, \pi/2 + s \rangle$$

**Answer:** $\mathbf{L}(s) = \langle -s, 1, \pi/2 + s \rangle$

### Example 4: Unit Tangent Vector

Find $\mathbf{T}(0)$ for $\mathbf{r}(t) = \langle t^2, t^3, t \rangle$.

**Solution:**

$$\mathbf{r}'(t) = \langle 2t, 3t^2, 1 \rangle$$

$$\mathbf{r}'(0) = \langle 0, 0, 1 \rangle$$

$$|\mathbf{r}'(0)| = 1$$

$$\mathbf{T}(0) = \frac{\langle 0, 0, 1 \rangle}{1} = \langle 0, 0, 1 \rangle = \mathbf{k}$$

**Answer:** $\mathbf{T}(0) = \mathbf{k}$ (points along positive $z$-axis)

## Differentiation Rules

Let $\mathbf{u}(t)$ and $\mathbf{v}(t)$ be vector functions, $f(t)$ scalar function, $c$ constant.

1. **Constant**: $ \frac{d}{dt}[\mathbf{c}] = \mathbf{0}$

2. **Sum**: $ \frac{d}{dt}[\mathbf{u}(t) + \mathbf{v}(t)] = \mathbf{u}'(t) + \mathbf{v}'(t)$

3. **Scalar multiple**: $ \frac{d}{dt}[f(t)\mathbf{u}(t)] = f'(t)\mathbf{u}(t) + f(t)\mathbf{u}'(t)$ (product rule)

4. **Dot product**: $ \frac{d}{dt}[\mathbf{u}(t) \cdot \mathbf{v}(t)] = \mathbf{u}'(t) \cdot \mathbf{v}(t) + \mathbf{u}(t) \cdot \mathbf{v}'(t)$

5. **Cross product**: $ \frac{d}{dt}[\mathbf{u}(t) \times \mathbf{v}(t)] = \mathbf{u}'(t) \times \mathbf{v}(t) + \mathbf{u}(t) \times \mathbf{v}'(t)$

6. **Chain rule**: $ \frac{d}{dt}[\mathbf{u}(f(t))] = f'(t)\mathbf{u}'(f(t))$

### Example 5: Product Rule for Dot Product

Let $\mathbf{r}(t) = \langle t, t^2, t^3 \rangle$. Verify $ \frac{d}{dt}[\mathbf{r}(t) \cdot \mathbf{r}(t)] = 2\mathbf{r}(t) \cdot \mathbf{r}'(t)$.

**Solution:**

**Method 1**: Direct computation
$$\mathbf{r}(t) \cdot \mathbf{r}(t) = t^2 + t^4 + t^6$$

$$\frac{d}{dt}[t^2 + t^4 + t^6] = 2t + 4t^3 + 6t^5$$

**Method 2**: Using product rule
$$\mathbf{r}'(t) = \langle 1, 2t, 3t^2 \rangle$$

$$\mathbf{r}(t) \cdot \mathbf{r}'(t) = t + 2t^3 + 3t^5$$

$$2\mathbf{r}(t) \cdot \mathbf{r}'(t) = 2t + 4t^3 + 6t^5$$ ✓

**Answer:** Verified.

### Example 6: Constant Magnitude

If $|\mathbf{r}(t)| = c$ (constant), show that $\mathbf{r}(t) \perp \mathbf{r}'(t)$.

**Solution:**

$$|\mathbf{r}(t)|^2 = \mathbf{r}(t) \cdot \mathbf{r}(t) = c^2$$

Differentiate both sides:
$$\frac{d}{dt}[\mathbf{r}(t) \cdot \mathbf{r}(t)] = 0$$

By product rule:
$$\mathbf{r}'(t) \cdot \mathbf{r}(t) + \mathbf{r}(t) \cdot \mathbf{r}'(t) = 0$$

$$2\mathbf{r}(t) \cdot \mathbf{r}'(t) = 0$$

$$\mathbf{r}(t) \cdot \mathbf{r}'(t) = 0$$

**Answer:** Therefore $\mathbf{r}(t) \perp \mathbf{r}'(t)$ (position vector perpendicular to velocity).

## Integrals of Vector Functions

**Indefinite integral**:
$$\int \mathbf{r}(t) \, dt = \left\langle \int f(t) \, dt, \int g(t) \, dt, \int h(t) \, dt \right\rangle + \mathbf{C}$$

where $\mathbf{C} = \langle C_1, C_2, C_3 \rangle$ is constant vector.

**Definite integral**:
$$\int_a^b \mathbf{r}(t) \, dt = \left\langle \int_a^b f(t) \, dt, \int_a^b g(t) \, dt, \int_a^b h(t) \, dt \right\rangle$$

### Example 7: Indefinite Integral

Find $ \int \langle t^2, e^t, \sin t \rangle \, dt$.

**Solution:**

$$\int \langle t^2, e^t, \sin t \rangle \, dt = \left\langle \frac{t^3}{3}, e^t, -\cos t \right\rangle + \mathbf{C}$$

**Answer:** $\left\langle  \frac{t^3}{3} + C_1, e^t + C_2, -\cos t + C_3 \right\rangle$

### Example 8: Definite Integral

Evaluate $ \int_0^1 \langle 2t, t^2, 1 \rangle \, dt$.

**Solution:**

$$\int_0^1 \langle 2t, t^2, 1 \rangle \, dt = \left\langle \int_0^1 2t \, dt, \int_0^1 t^2 \, dt, \int_0^1 1 \, dt \right\rangle$$

$$= \left\langle t^2 \Big|_0^1, \frac{t^3}{3}\Big|_0^1, t\Big|_0^1 \right\rangle = \left\langle 1, \frac{1}{3}, 1 \right\rangle$$

**Answer:** $\left\langle 1,  \frac{1}{3}, 1 \right\rangle$

## Motion in Space: Velocity and Acceleration

**Position**: $\mathbf{r}(t)$

**Velocity**: $\mathbf{v}(t) = \mathbf{r}'(t)$

**Speed**: $v(t) = |\mathbf{v}(t)| = |\mathbf{r}'(t)|$

**Acceleration**: $\mathbf{a}(t) = \mathbf{v}'(t) = \mathbf{r}''(t)$

### Example 9: Finding Velocity and Acceleration

A particle moves with position $\mathbf{r}(t) = \langle t^2, 2t, t^3 \rangle$. Find velocity and acceleration at $t = 1$.

**Solution:**

$$\mathbf{v}(t) = \mathbf{r}'(t) = \langle 2t, 2, 3t^2 \rangle$$

$$\mathbf{v}(1) = \langle 2, 2, 3 \rangle$$

$$\mathbf{a}(t) = \mathbf{v}'(t) = \langle 2, 0, 6t \rangle$$

$$\mathbf{a}(1) = \langle 2, 0, 6 \rangle$$

**Speed**: $v(1) = |\mathbf{v}(1)| = \sqrt{4 + 4 + 9} = \sqrt{17}$

**Answer:** $\mathbf{v}(1) = \langle 2, 2, 3 \rangle$, $\mathbf{a}(1) = \langle 2, 0, 6 \rangle$, speed $= \sqrt{17}$

### Example 10: Finding Position from Velocity

Given $\mathbf{v}(t) = \langle 3t^2, 2t, 1 \rangle$ and $\mathbf{r}(0) = \langle 1, 0, -1 \rangle$, find $\mathbf{r}(t)$.

**Solution:**

$$\mathbf{r}(t) = \int \mathbf{v}(t) \, dt = \int \langle 3t^2, 2t, 1 \rangle \, dt = \langle t^3, t^2, t \rangle + \mathbf{C}$$

Use initial condition:
$$\mathbf{r}(0) = \langle 0, 0, 0 \rangle + \mathbf{C} = \langle 1, 0, -1 \rangle$$

So $\mathbf{C} = \langle 1, 0, -1 \rangle$

**Answer:** $\mathbf{r}(t) = \langle t^3 + 1, t^2, t - 1 \rangle$

## Projectile Motion

Under constant gravity $\mathbf{g} = \langle 0, 0, -g \rangle$ (with $z$ vertical):

**Acceleration**: $\mathbf{a}(t) = \langle 0, 0, -g \rangle$

**Velocity**: $\mathbf{v}(t) = \langle v_0\cos\alpha, v_0\sin\alpha, v_0\sin\beta - gt \rangle$

(where $\alpha$ is horizontal angle, $\beta$ is elevation angle)

### Example 11: Projectile Trajectory

A projectile is launched from origin with initial velocity $\mathbf{v}_0 = \langle 10, 0, 20 \rangle$ m/s. Find position function (use $g = 10$ m/s²).

**Solution:**

$$\mathbf{a}(t) = \langle 0, 0, -10 \rangle$$

Integrate:
$$\mathbf{v}(t) = \langle 0, 0, -10t \rangle + \mathbf{C}_1$$

At $t=0$: $\mathbf{v}(0) = \langle 10, 0, 20 \rangle$

So $\mathbf{C}_1 = \langle 10, 0, 20 \rangle$

$$\mathbf{v}(t) = \langle 10, 0, 20-10t \rangle$$

Integrate again:
$$\mathbf{r}(t) = \langle 10t, 0, 20t - 5t^2 \rangle + \mathbf{C}_2$$

At $t=0$: $\mathbf{r}(0) = \langle 0, 0, 0 \rangle$, so $\mathbf{C}_2 = \mathbf{0}$

**Answer:** $\mathbf{r}(t) = \langle 10t, 0, 20t - 5t^2 \rangle$

### Example 12: Range and Time of Flight

For Example 11, find:
(a) Time when projectile hits ground
(b) Range (horizontal distance)

**Solution:**

**(a)** Hits ground when $z = 0$:
$$20t - 5t^2 = 0$$
$$5t(4 - t) = 0$$

$t = 0$ (launch) or $t = 4$ s

**(b)** At $t = 4$:
$$x = 10(4) = 40 \text{ m}$$

**Answer:** (a) 4 seconds, (b) 40 meters

### Example 13: Maximum Height

For the projectile in Example 11, find maximum height.

**Solution:**

Maximum height when $v_z = 0$:
$$20 - 10t = 0$$
$$t = 2 \text{ s}$$

At $t = 2$:
$$z = 20(2) - 5(4) = 40 - 20 = 20 \text{ m}$$

**Answer:** Maximum height = 20 meters at $t = 2$ seconds

## Practice Problems

**Problem 1:** If $\mathbf{r}(t) = \langle \cos t, \sin t, t^2 \rangle$, then $\mathbf{r}'(t)$ equals:

A) $\langle -\sin t, \cos t, 2t \rangle$
B) $\langle \sin t, -\cos t, 2t \rangle$
C) $\langle \cos t, \sin t, 2t \rangle$
D) $\langle -\cos t, -\sin t, 2 \rangle$
E) $\langle -\sin t, \cos t, t \rangle$

**Problem 2:** The unit tangent vector $\mathbf{T}(t)$ to a curve $\mathbf{r}(t)$ is:

A) $\mathbf{r}(t)$
B) $\mathbf{r}'(t)$
C) $ \frac{\mathbf{r}'(t)}{|\mathbf{r}'(t)|}$
D) $|\mathbf{r}'(t)|$
E) $\mathbf{r}''(t)$

**Problem 3:** $ \int_0^{\pi} \langle \sin t, \cos t, 1 \rangle \, dt$ equals:

A) $\langle 0, 0, \pi \rangle$
B) $\langle 2, 0, \pi \rangle$
C) $\langle 1, 1, \pi \rangle$
D) $\langle -1, 0, \pi \rangle$
E) $\langle \pi, 0, \pi \rangle$

**Problem 4:** If $|\mathbf{r}(t)|$ is constant, then $\mathbf{r}(t) \cdot \mathbf{r}'(t)$ equals:

A) $|\mathbf{r}(t)|^2$
B) $|\mathbf{r}'(t)|$
C) 1
D) 0
E) $|\mathbf{r}(t)|$

**Problem 5:** For motion with constant acceleration $\mathbf{a}$, velocity is:

A) $\mathbf{v}(t) = \mathbf{a}t$
B) $\mathbf{v}(t) = \mathbf{v}_0 + \mathbf{a}t$
C) $\mathbf{v}(t) =  \frac{1}{2}\mathbf{a}t^2$
D) $\mathbf{v}(t) = \mathbf{a}$
E) $\mathbf{v}(t) = t\mathbf{v}_0$

## Answer Key

**Problem 1: A**
Differentiate component-wise:
$\frac{d}{dt}[\cos t] = -\sin t$
$\frac{d}{dt}[\sin t] = \cos t$
$\frac{d}{dt}[t^2] = 2t$
Result: $\langle -\sin t, \cos t, 2t \rangle$

**Problem 2: C**
Unit tangent vector defined as normalized derivative:
$\mathbf{T}(t) =  \frac{\mathbf{r}'(t)}{|\mathbf{r}'(t)|}$
Points in direction of motion with magnitude 1
Not $\mathbf{r}'(t)$ itself (that's tangent but not necessarily unit length)

**Problem 3: B**
Integrate component-wise:
$\int_0^{\pi} \sin t \, dt = -\cos t \Big|_0^{\pi} = -(-1-1) = 2$
$\int_0^{\pi} \cos t \, dt = \sin t \Big|_0^{\pi} = 0 - 0 = 0$
$\int_0^{\pi} 1 \, dt = t\Big|_0^{\pi} = \pi$
Result: $\langle 2, 0, \pi \rangle$

**Problem 4: D**
If $|\mathbf{r}(t)| = c$ constant, then $\mathbf{r}(t) \cdot \mathbf{r}(t) = c^2$
Differentiate: $2\mathbf{r}(t) \cdot \mathbf{r}'(t) = 0$
Therefore $\mathbf{r}(t) \cdot \mathbf{r}'(t) = 0$
Position vector perpendicular to velocity (motion on sphere)

**Problem 5: B**
$\mathbf{a}(t) = \mathbf{a}$ (constant)
Integrate: $\mathbf{v}(t) = \mathbf{a}t + \mathbf{C}$
At $t=0$: $\mathbf{v}(0) = \mathbf{v}_0$, so $\mathbf{C} = \mathbf{v}_0$
Result: $\mathbf{v}(t) = \mathbf{v}_0 + \mathbf{a}t$
Classic kinematic equation generalized to vectors

# Multivariable Calculus Topic 1.1: Vectors in Space

Imagine you're giving directions to a friend. "Walk two blocks north, then three blocks east" specifies not just distances but **directions**. This is fundamentally different from saying "walk five blocks"—the path matters, not just the magnitude. Quantities that require both magnitude and direction appear everywhere: velocity, force, displacement, electric fields. **Vectors** are the mathematical objects that encode this dual nature.

In single-variable calculus, we lived on a number line. Position meant a single coordinate. But the real world is three-dimensional—position requires three coordinates $(x, y, z)$. Motion happens along curves in space. Forces act in arbitrary directions. **Vector algebra** provides the language for describing these phenomena. Just as real numbers let us quantify "how much," vectors let us quantify "how much and which way."

This article develops vectors from the ground up. We'll see how vectors are represented geometrically as directed arrows and algebraically as ordered triples. We'll master vector addition and scalar multiplication—the building blocks for all vector operations. We'll learn to compute magnitudes and distances in three-dimensional space. These foundational skills prepare us for dot products, cross products, and eventually the machinery of multivariable calculus. Every physicist, engineer, and applied mathematician uses vectors daily—this is where it all begins.

## Three-Dimensional Coordinate System

**Rectangular coordinates** in 3D: Point $P$ has coordinates $(x, y, z)$

**Right-hand rule**: 
- Curl fingers from $x$-axis toward $y$-axis
- Thumb points along $z$-axis

**Coordinate planes**:
- $xy$-plane: $z = 0$
- $xz$-plane: $y = 0$
- $yz$-plane: $x = 0$

### Example 1: Plotting Points

Plot the points $A(2, 3, 4)$, $B(0, -1, 2)$, $C(3, 0, 0)$.

**Solution:**

**Point $A(2, 3, 4)$**: 
- Move 2 units along $x$-axis
- Then 3 units parallel to $y$-axis  
- Then 4 units parallel to $z$-axis

**Point $B(0, -1, 2)$**:
- Stay at origin in $x$
- Move $-1$ along $y$ (negative direction)
- Move 2 along $z$

**Point $C(3, 0, 0)$**:
- On the $x$-axis (since $y = z = 0$)

**Answer:** $A$ is in first octant, $B$ is in $yz$-plane offset negatively in $y$, $C$ is on positive $x$-axis.

### Example 2: Distance Formula

Find the distance between points $P(1, 2, 3)$ and $Q(4, -1, 5)$.

**Solution:**

**Distance formula in 3D**:
$$d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$$

$$d = \sqrt{(4-1)^2 + (-1-2)^2 + (5-3)^2}$$

$$= \sqrt{9 + 9 + 4} = \sqrt{22}$$

**Answer:** $d = \sqrt{22} \approx 4.69$ units

## Vectors: Definition and Representation

**Vector**: Quantity with magnitude and direction

**Notation**: $\mathbf{v}$ or $\vec{v}$ or boldface $\textbf{v}$

**Geometric representation**: Arrow from initial point to terminal point

**Component form**: $\mathbf{v} = \langle v_1, v_2, v_3 \rangle$ (angle brackets)

**Position vector**: Arrow from origin to point $(a, b, c)$ is $\langle a, b, c \rangle$

### Example 3: Vector from Two Points

Find the vector from $A(1, 2, 3)$ to $B(4, 0, -1)$.

**Solution:**

**Formula**: Vector from $A$ to $B$ is $\overrightarrow{AB} = \langle x_2 - x_1, y_2 - y_1, z_2 - z_1 \rangle$

$$\overrightarrow{AB} = \langle 4-1, 0-2, -1-3 \rangle = \langle 3, -2, -4 \rangle$$

**Answer:** $\overrightarrow{AB} = \langle 3, -2, -4 \rangle$

### Example 4: Magnitude of a Vector

Find the magnitude of $\mathbf{v} = \langle 2, -3, 6 \rangle$.

**Solution:**

**Magnitude** (or **length** or **norm**):
$$|\mathbf{v}| = \sqrt{v_1^2 + v_2^2 + v_3^2}$$

$$|\mathbf{v}| = \sqrt{4 + 9 + 36} = \sqrt{49} = 7$$

**Answer:** $|\mathbf{v}| = 7$

## Vector Addition and Scalar Multiplication

**Vector addition**: $\mathbf{u} + \mathbf{v} = \langle u_1 + v_1, u_2 + v_2, u_3 + v_3 \rangle$

**Geometric interpretation**: Parallelogram law or tip-to-tail

**Scalar multiplication**: $c\mathbf{v} = \langle cv_1, cv_2, cv_3 \rangle$

**Properties**:
- Commutative: $\mathbf{u} + \mathbf{v} = \mathbf{v} + \mathbf{u}$
- Associative: $(\mathbf{u} + \mathbf{v}) + \mathbf{w} = \mathbf{u} + (\mathbf{v} + \mathbf{w})$
- Identity: $\mathbf{v} + \mathbf{0} = \mathbf{v}$
- Distributive: $c(\mathbf{u} + \mathbf{v}) = c\mathbf{u} + c\mathbf{v}$

### Example 5: Vector Operations

Let $\mathbf{u} = \langle 1, -2, 3 \rangle$ and $\mathbf{v} = \langle 4, 0, -1 \rangle$. Find:
(a) $\mathbf{u} + \mathbf{v}$
(b) $3\mathbf{u} - 2\mathbf{v}$

**Solution:**

**(a)** $\mathbf{u} + \mathbf{v} = \langle 1+4, -2+0, 3+(-1) \rangle = \langle 5, -2, 2 \rangle$

**(b)** 
$$3\mathbf{u} = \langle 3, -6, 9 \rangle$$
$$2\mathbf{v} = \langle 8, 0, -2 \rangle$$
$$3\mathbf{u} - 2\mathbf{v} = \langle 3-8, -6-0, 9-(-2) \rangle = \langle -5, -6, 11 \rangle$$

**Answer:** (a) $\langle 5, -2, 2 \rangle$, (b) $\langle -5, -6, 11 \rangle$

### Example 6: Parallel Vectors

Show that $\mathbf{v} = \langle 2, -4, 6 \rangle$ and $\mathbf{w} = \langle -3, 6, -9 \rangle$ are parallel.

**Solution:**

Vectors are **parallel** if one is scalar multiple of other.

Check: Is $\mathbf{w} = c\mathbf{v}$ for some scalar $c$?

$$\langle -3, 6, -9 \rangle = c\langle 2, -4, 6 \rangle$$

From first component: $-3 = 2c$, so $c = -3/2$

Check other components:
- $6 = -4c = -4(-3/2) = 6$ ✓
- $-9 = 6c = 6(-3/2) = -9$ ✓

**Answer:** Yes, parallel with $\mathbf{w} = - \frac{3}{2}\mathbf{v}$

## Unit Vectors

**Unit vector**: Vector with magnitude 1

**Finding unit vector** in direction of $\mathbf{v}$:
$$\mathbf{u} = \frac{\mathbf{v}}{|\mathbf{v}|}$$

**Standard basis vectors**:
$$\mathbf{i} = \langle 1, 0, 0 \rangle, \quad \mathbf{j} = \langle 0, 1, 0 \rangle, \quad \mathbf{k} = \langle 0, 0, 1 \rangle$$

**Alternative notation**: $\mathbf{v} = \langle v_1, v_2, v_3 \rangle = v_1\mathbf{i} + v_2\mathbf{j} + v_3\mathbf{k}$

### Example 7: Finding Unit Vector

Find a unit vector in the direction of $\mathbf{v} = \langle 3, -4, 0 \rangle$.

**Solution:**

First, find magnitude:
$$|\mathbf{v}| = \sqrt{9 + 16 + 0} = \sqrt{25} = 5$$

Unit vector:
$$\mathbf{u} = \frac{\mathbf{v}}{|\mathbf{v}|} = \frac{1}{5}\langle 3, -4, 0 \rangle = \left\langle \frac{3}{5}, -\frac{4}{5}, 0 \right\rangle$$

**Verify**: $ |\mathbf{u}| = \sqrt{\frac{9}{25} + \frac{16}{25} + 0} = \sqrt{\frac{25}{25}} = 1$ ✓

**Answer:** $\mathbf{u} = \left\langle  \frac{3}{5}, -\frac{4}{5}, 0 \right\rangle$

### Example 8: Component Form

Write $\mathbf{v} = 2\mathbf{i} - 3\mathbf{j} + 5\mathbf{k}$ in component form.

**Solution:**

$$\mathbf{v} = 2\langle 1, 0, 0 \rangle - 3\langle 0, 1, 0 \rangle + 5\langle 0, 0, 1 \rangle$$

$$= \langle 2, 0, 0 \rangle + \langle 0, -3, 0 \rangle + \langle 0, 0, 5 \rangle = \langle 2, -3, 5 \rangle$$

**Answer:** $\mathbf{v} = \langle 2, -3, 5 \rangle$

## Midpoint Formula

**Midpoint** of segment from $P(x_1, y_1, z_1)$ to $Q(x_2, y_2, z_2)$:
$$M = \left( \frac{x_1+x_2}{2}, \frac{y_1+y_2}{2}, \frac{z_1+z_2}{2} \right)$$

### Example 9: Finding Midpoint

Find the midpoint of the segment from $A(2, -1, 3)$ to $B(4, 5, -1)$.

**Solution:**

$$M = \left( \frac{2+4}{2}, \frac{-1+5}{2}, \frac{3+(-1)}{2} \right) = (3, 2, 1)$$

**Answer:** $M = (3, 2, 1)$

## Spheres

**Sphere** with center $(h, k, \ell)$ and radius $r$:
$$(x-h)^2 + (y-k)^2 + (z-\ell)^2 = r^2$$

**Standard form** (center at origin): $x^2 + y^2 + z^2 = r^2$

### Example 10: Equation of Sphere

Find the equation of the sphere with center $C(1, -2, 3)$ and radius 4.

**Solution:**

$$(x-1)^2 + (y-(-2))^2 + (z-3)^2 = 16$$

$$(x-1)^2 + (y+2)^2 + (z-3)^2 = 16$$

**Answer:** $(x-1)^2 + (y+2)^2 + (z-3)^2 = 16$

### Example 11: Completing the Square

Find the center and radius of $x^2 + y^2 + z^2 - 2x + 4y - 6z = 11$.

**Solution:**

Group and complete the square:
$$(x^2 - 2x) + (y^2 + 4y) + (z^2 - 6z) = 11$$

For $x$: $x^2 - 2x + 1 = (x-1)^2$, add 1
For $y$: $y^2 + 4y + 4 = (y+2)^2$, add 4
For $z$: $z^2 - 6z + 9 = (z-3)^2$, add 9

$$(x-1)^2 + (y+2)^2 + (z-3)^2 = 11 + 1 + 4 + 9 = 25$$

**Answer:** Center $(1, -2, 3)$, radius $r = 5$

## Applications of Vectors

### Example 12: Force Resultant

Two forces act on an object: $\mathbf{F}_1 = \langle 3, -2, 1 \rangle$ N and $\mathbf{F}_2 = \langle -1, 4, 2 \rangle$ N. Find the resultant force and its magnitude.

**Solution:**

**Resultant**:
$$\mathbf{F} = \mathbf{F}_1 + \mathbf{F}_2 = \langle 3+(-1), -2+4, 1+2 \rangle = \langle 2, 2, 3 \rangle \text{ N}$$

**Magnitude**:
$$|\mathbf{F}| = \sqrt{4 + 4 + 9} = \sqrt{17} \approx 4.12 \text{ N}$$

**Answer:** $\mathbf{F} = \langle 2, 2, 3 \rangle$ N with magnitude $\sqrt{17}$ N

### Example 13: Velocity Vectors

A particle moves from $P(1, 2, -1)$ to $Q(3, -1, 2)$ in 2 seconds. Find its average velocity vector.

**Solution:**

**Displacement**:
$$\Delta \mathbf{r} = \overrightarrow{PQ} = \langle 3-1, -1-2, 2-(-1) \rangle = \langle 2, -3, 3 \rangle$$

**Average velocity**:
$$\mathbf{v}_{\text{avg}} = \frac{\Delta \mathbf{r}}{\Delta t} = \frac{\langle 2, -3, 3 \rangle}{2} = \langle 1, -1.5, 1.5 \rangle \text{ units/s}$$

**Speed** (magnitude):
$$|\mathbf{v}_{\text{avg}}| = \sqrt{1 + 2.25 + 2.25} = \sqrt{5.5} \approx 2.35 \text{ units/s}$$

**Answer:** $\mathbf{v}_{\text{avg}} = \langle 1, -1.5, 1.5 \rangle$ units/s

## Practice Problems

**Problem 1:** The distance from point $(2, -1, 3)$ to the origin is:

A) $\sqrt{6}$
B) $\sqrt{14}$
C) $\sqrt{10}$
D) 4
E) $\sqrt{12}$

**Problem 2:** A unit vector in the direction of $\mathbf{v} = \langle 4, -3, 0 \rangle$ is:

A) $\langle 1, 1, 0 \rangle$
B) $\langle 4/5, -3/5, 0 \rangle$
C) $\langle 4/7, -3/7, 0 \rangle$
D) $\langle 2, -1.5, 0 \rangle$
E) $\langle 0.4, -0.3, 0 \rangle$

**Problem 3:** If $\mathbf{u} = \langle 2, -1, 3 \rangle$ and $\mathbf{v} = \langle 1, 4, -2 \rangle$, then $2\mathbf{u} - \mathbf{v}$ equals:

A) $\langle 3, -6, 8 \rangle$
B) $\langle 3, 3, 1 \rangle$
C) $\langle 5, 2, 4 \rangle$
D) $\langle 1, 2, 4 \rangle$
E) $\langle 3, -2, 4 \rangle$

**Problem 4:** The sphere $(x-3)^2 + (y+1)^2 + (z-2)^2 = 9$ has:

A) Center $(3, 1, 2)$ and radius 9
B) Center $(-3, 1, -2)$ and radius 3
C) Center $(3, -1, 2)$ and radius 3
D) Center $(3, -1, 2)$ and radius 9
E) Center $(0, 0, 0)$ and radius 3

**Problem 5:** Two vectors are parallel if and only if:

A) They have the same magnitude
B) One is a scalar multiple of the other
C) Their sum is the zero vector
D) They point in opposite directions
E) They are perpendicular

## Answer Key

**Problem 1: B**
Distance from $(x, y, z)$ to origin: $\sqrt{x^2 + y^2 + z^2}$
$d = \sqrt{4 + 1 + 9} = \sqrt{14}$
Not $\sqrt{10}$ (that would be $\sqrt{2^2 + 1^2 + 3}$, wrong)
Not $\sqrt{6}$ (that's $2 + 1 + 3$ without squaring)

**Problem 2: B**
First find magnitude: $|\mathbf{v}| = \sqrt{16 + 9 + 0} = \sqrt{25} = 5$
Unit vector: $\mathbf{u} = \mathbf{v}/5 = \langle 4/5, -3/5, 0 \rangle$
Check: $(4/5)^2 + (-3/5)^2 = 16/25 + 9/25 = 1$ ✓
Options D and E are just scalar multiples, not unit vectors

**Problem 3: A**
$2\mathbf{u} = \langle 4, -2, 6 \rangle$
$2\mathbf{u} - \mathbf{v} = \langle 4, -2, 6 \rangle - \langle 1, 4, -2 \rangle$
$= \langle 4-1, -2-4, 6-(-2) \rangle = \langle 3, -6, 8 \rangle$
Common error: forgetting negative sign in subtraction

**Problem 4: C**
Standard form: $(x-h)^2 + (y-k)^2 + (z-\ell)^2 = r^2$
Center: $(h, k, \ell) = (3, -1, 2)$
Note: $y+1 = y-(-1)$, so $k = -1$, not $+1$
Radius: $r = \sqrt{9} = 3$, not 9

**Problem 5: B**
Definition: $\mathbf{v}$ and $\mathbf{w}$ parallel iff $\mathbf{w} = c\mathbf{v}$ for scalar $c$
$c > 0$: same direction
$c < 0$: opposite directions
Both cases are parallel
Equal magnitude doesn't imply parallel (e.g., $\langle 1, 0, 0 \rangle$ and $\langle 0, 1, 0 \rangle$)

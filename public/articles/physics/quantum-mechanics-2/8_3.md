# Quantum Mechanics Topic 8.3: Density Matrix Formalism

Quantum mechanics as typically presented describes **pure states**—systems in definite quantum state $|\psi\rangle$. But real systems are often **mixed**—statistical ensembles where the system is in state $|\psi_i\rangle$ with classical probability $p_i$. A decohered qubit might be 50% $|0\rangle$ and 50% $|1\rangle$ (mixed state) rather than the superposition $\frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$ (pure state). These are fundamentally different: the superposition exhibits interference; the mixture does not. The **density matrix** formalism treats both pure and mixed states uniformly, providing essential language for statistical quantum mechanics, decoherence, and quantum information.

The density operator $\hat{\rho}$ generalizes the state vector: $\hat{\rho} = |\psi\rangle\langle\psi|$ for pure states, $\hat{\rho} = \sum_i p_i|\psi_i\rangle\langle\psi_i|$ for mixed states. All observables compute via $\langle\hat{A}\rangle = \text{Tr}(\hat{\rho}\hat{A})$—the trace operation replaces inner products. Time evolution follows the **von Neumann equation**, a quantum Liouville equation. Most powerfully, the **reduced density matrix** describes subsystems of entangled systems. When two systems are entangled in a pure state, each subsystem alone appears mixed—the hallmark of quantum correlation. The von Neumann entropy $S = -\text{Tr}(\hat{\rho}\ln\hat{\rho})$ quantifies this mixedness, vanishing for pure states and reaching maximum for completely mixed states.

This article develops density matrix formalism systematically. We'll define density operators and their properties, derive the von Neumann equation, understand reduced density matrices and entanglement, compute von Neumann entropy, and see applications to decoherence and quantum information. The density matrix is essential for realistic quantum systems—it describes how quantum systems become classical through environmental interaction.

## Density Matrix Definition and Properties

The density operator is defined differently for pure and mixed states, but has universal properties.

### Example 1: Pure State Density Matrix

For pure state $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$ (qubit), construct density matrix $\hat{\rho} = |\psi\rangle\langle\psi|$.

**Solution:**

$$\hat{\rho} = (\alpha|0\rangle + \beta|1\rangle)(\alpha^*\langle 0| + \beta^*\langle 1|)$$

$$= |\alpha|^2|0\rangle\langle 0| + \alpha\beta^*|0\rangle\langle 1| + \beta\alpha^*|1\rangle\langle 0| + |\beta|^2|1\rangle\langle 1|$$

**Matrix form:**

$$\hat{\rho} = \begin{pmatrix} |\alpha|^2 & \alpha\beta^* \\ \beta\alpha^* & |\beta|^2 \end{pmatrix}$$

**Properties:**
- Hermitian: $\hat{\rho}^\dagger = \hat{\rho}$ ✓
- $\text{Tr}(\hat{\rho}) = |\alpha|^2 + |\beta|^2 = 1$ ✓ (normalization)
- $\text{Tr}(\hat{\rho}^2) = |\alpha|^4 + 2|\alpha\beta|^2 + |\beta|^4 = (|\alpha|^2 + |\beta|^2)^2 = 1$ ✓ (pure)

**Off-diagonal terms:** $\alpha\beta^*$ contain **coherence** information (phase relations).

**Answer:** $\rho_{ij} = \langle i|\psi\rangle\langle\psi|j\rangle$; off-diagonal terms encode coherence

### Example 2: Mixed State Density Matrix

Consider mixture: 50% $|0\rangle$, 50% $|1\rangle$ (classical statistical mixture).

$$\hat{\rho}_{mixed} = \frac{1}{2}|0\rangle\langle 0| + \frac{1}{2}|1\rangle\langle 1|$$

Compare to pure superposition $|\psi\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$.

**Solution:**

**Mixed state:**

$$\hat{\rho}_{mixed} = \begin{pmatrix} 1/2 & 0 \\ 0 & 1/2 \end{pmatrix}$$

**Pure superposition:**

$$\hat{\rho}_{pure} = \frac{1}{2}\begin{pmatrix} 1 & 1 \\ 1 & 1 \end{pmatrix}$$

**Difference:** Off-diagonal elements!

- Mixed: diagonal only (no coherence)
- Pure: off-diagonal non-zero (coherence between $|0\rangle$ and $|1\rangle$)

**Measurement:** Measuring $\sigma_z$ gives same result (50-50) for both. But measuring $\sigma_x$:
- Pure: definite outcome $+1$ (eigenstate)
- Mixed: random 50-50

**Physical meaning:** Mixture has **classical** uncertainty; superposition has **quantum** coherence.

**Answer:** Mixed state diagonal; pure state has off-diagonal coherences—fundamentally different!

The key insight: density matrix distinguishes classical mixtures from quantum superpositions, which measurement in one basis cannot.

### Example 3: Purity Criterion

Prove that $\text{Tr}(\hat{\rho}^2) = 1$ if and only if state is pure.

**Solution:**

For mixed state: $\hat{\rho} = \sum_i p_i|\psi_i\rangle\langle\psi_i|$

$$\hat{\rho}^2 = \sum_{i,j}p_ip_j|\psi_i\rangle\langle\psi_i|\psi_j\rangle\langle\psi_j|$$

If states orthogonal ($\langle\psi_i|\psi_j\rangle = \delta_{ij}$):

$$\hat{\rho}^2 = \sum_i p_i^2|\psi_i\rangle\langle\psi_i|$$

$$\text{Tr}(\hat{\rho}^2) = \sum_i p_i^2$$

Since $0 \leq p_i \leq 1$ and $\sum_i p_i = 1$:

$$\sum_i p_i^2 \leq \left(\sum_i p_i\right)^2 = 1$$

**Equality:** Only when one $p_i = 1$, others $= 0$ → pure state.

**Answer:** $\text{Tr}(\hat{\rho}^2) < 1$ for mixed states; $= 1$ only for pure states

This provides operational test: compute $\text{Tr}(\hat{\rho}^2)$ to determine if state is pure or mixed.

## Expectation Values and von Neumann Equation

All quantum observables can be computed from density matrix using trace operation.

### Example 4: Computing Expectation Values

For observable $\hat{A}$ and density matrix $\hat{\rho}$, show that:

$$\langle\hat{A}\rangle = \text{Tr}(\hat{\rho}\hat{A})$$

**Solution:**

For pure state $\hat{\rho} = |\psi\rangle\langle\psi|$:

$$\text{Tr}(\hat{\rho}\hat{A}) = \text{Tr}(|\psi\rangle\langle\psi|\hat{A})$$

Using cyclic property of trace: $\text{Tr}(ABC) = \text{Tr}(CAB)$

$$= \text{Tr}(\langle\psi|\hat{A}|\psi\rangle) = \langle\psi|\hat{A}|\psi\rangle$$

Recovers standard expectation value!

For mixed state $\hat{\rho} = \sum_i p_i|\psi_i\rangle\langle\psi_i|$:

$$\text{Tr}(\hat{\rho}\hat{A}) = \sum_i p_i\text{Tr}(|\psi_i\rangle\langle\psi_i|\hat{A}) = \sum_i p_i\langle\psi_i|\hat{A}|\psi_i\rangle$$

This is **classical average** of quantum expectation values—correct for mixture!

**Answer:** $\langle\hat{A}\rangle = \text{Tr}(\hat{\rho}\hat{A})$ unifies pure and mixed state expectations

### Example 5: Time Evolution (von Neumann Equation)

Derive equation of motion for density matrix.

**Solution:**

For pure state: $\hat{\rho}(t) = |\psi(t)\rangle\langle\psi(t)|$

Time derivative:

$$\frac{d\hat{\rho}}{dt} = \frac{d|\psi\rangle}{dt}\langle\psi| + |\psi\rangle\frac{d\langle\psi|}{dt}$$

Using Schrödinger equation: $i\hbar\frac{d|\psi\rangle}{dt} = \hat{H}|\psi\rangle$

$$\frac{d\hat{\rho}}{dt} = \frac{1}{i\hbar}\hat{H}|\psi\rangle\langle\psi| + |\psi\rangle\langle\psi|\left(-\frac{1}{i\hbar}\hat{H}\right)$$

$$= \frac{1}{i\hbar}(\hat{H}\hat{\rho} - \hat{\rho}\hat{H}) = -\frac{i}{\hbar}[\hat{\rho}, \hat{H}]$$

**Von Neumann equation:**

$$i\hbar\frac{\partial\hat{\rho}}{\partial t} = [\hat{H}, \hat{\rho}]$$

For mixed state: linearity gives same equation.

**Classical analog:** Liouville equation in classical statistical mechanics.

**Answer:** $i\hbar\frac{\partial\hat{\rho}}{\partial t} = [\hat{H}, \hat{\rho}]$ (quantum Liouville equation)

### Example 6: Stationary States

For stationary state $|\psi_n\rangle$ with energy $E_n$, density matrix is:

$$\hat{\rho}_n = |\psi_n\rangle\langle\psi_n|$$

Show that $[\hat{H}, \hat{\rho}_n] = 0$.

**Solution:**

$$[\hat{H}, \hat{\rho}_n] = \hat{H}|\psi_n\rangle\langle\psi_n| - |\psi_n\rangle\langle\psi_n|\hat{H}$$

$$= E_n|\psi_n\rangle\langle\psi_n| - E_n|\psi_n\rangle\langle\psi_n| = 0$$

**Physical meaning:** Stationary states have time-independent density matrices (no evolution).

For thermal ensemble at temperature $T$:

$$\hat{\rho} = \frac{e^{-\beta\hat{H}}}{Z}$$ where $\beta = 1/(k_BT)$, $Z = \text{Tr}(e^{-\beta\hat{H}})$

This also commutes with $\hat{H}$ → time-independent (equilibrium).

**Answer:** Stationary states and thermal equilibrium have $[\hat{H}, \hat{\rho}] = 0$ (no time evolution)

## Reduced Density Matrix and Entanglement

For composite system $AB$ in pure state $|\psi_{AB}\rangle$, subsystem $A$ described by **reduced density matrix**:

$$\hat{\rho}_A = \text{Tr}_B(\hat{\rho}_{AB})$$

This traces out (averages over) subsystem $B$.

### Example 7: Bell State Reduced Density Matrix

For maximally entangled state (Bell state):

$$|\psi_{AB}\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)$$

Compute $\hat{\rho}_A = \text{Tr}_B(|\psi\rangle\langle\psi|)$.

**Solution:**

Full density matrix:

$$\hat{\rho}_{AB} = \frac{1}{2}(|00\rangle\langle 00| + |00\rangle\langle 11| + |11\rangle\langle 00| + |11\rangle\langle 11|)$$

Trace over $B$: $\text{Tr}_B = \langle 0_B|\cdot|0_B\rangle + \langle 1_B|\cdot|1_B\rangle$

$$\hat{\rho}_A = \frac{1}{2}(\langle 0_B|00\rangle\langle 00|0_B\rangle + \langle 0_B|00\rangle\langle 11|0_B\rangle + \langle 1_B|11\rangle\langle 00|1_B\rangle + \langle 1_B|11\rangle\langle 11|1_B\rangle)$$

$$= \frac{1}{2}(|0_A\rangle\langle 0_A| \cdot 1 + 0 + 0 + |1_A\rangle\langle 1_A| \cdot 1)$$

$$= \frac{1}{2}|0\rangle\langle 0| + \frac{1}{2}|1\rangle\langle 1| = \frac{1}{2}\mathbb{I}$$

**Result:** Completely mixed state (maximally unpolarized)!

**Physical meaning:** Although $|\psi_{AB}\rangle$ is **pure**, subsystem $A$ alone appears **mixed** due to entanglement.

No measurement on $A$ alone can distinguish from thermal state.

**Answer:** $\hat{\rho}_A = \frac{1}{2}\mathbb{I}$ (maximally mixed); pure entangled state → mixed subsystem

### Example 8: Product State (No Entanglement)

For product state $|\psi_{AB}\rangle = |\phi_A\rangle \otimes |\chi_B\rangle$, compute reduced density matrix.

**Solution:**

Full: $\hat{\rho}_{AB} = |\phi_A\rangle\langle\phi_A| \otimes |\chi_B\rangle\langle\chi_B|$

Trace over $B$:

$$\hat{\rho}_A = \text{Tr}_B(|\phi_A\rangle\langle\phi_A| \otimes |\chi_B\rangle\langle\chi_B|)$$

$$= |\phi_A\rangle\langle\phi_A| \cdot \text{Tr}(|\chi_B\rangle\langle\chi_B|)$$

$$= |\phi_A\rangle\langle\phi_A| \cdot 1 = |\phi_A\rangle\langle\phi_A|$$

**Pure state!** Subsystem $A$ is pure.

**Physical meaning:** No entanglement → subsystems independent → each has definite pure state.

**General criterion:** $\hat{\rho}_A$ pure ↔ no entanglement between $A$ and $B$.

**Answer:** Product state gives pure $\hat{\rho}_A$; entanglement creates mixedness

This provides operational definition of entanglement: composite pure state is entangled if and only if reduced density matrix is mixed.

### Example 9: von Neumann Entropy

Define entropy: $S(\hat{\rho}) = -\text{Tr}(\hat{\rho}\ln\hat{\rho})$

For qubit $\hat{\rho} = \begin{pmatrix} p & 0 \\ 0 & 1-p \end{pmatrix}$, compute $S$.

**Solution:**

Eigenvalues: $\lambda_1 = p$, $\lambda_2 = 1-p$

$$S = -\text{Tr}(\hat{\rho}\ln\hat{\rho}) = -\sum_i\lambda_i\ln\lambda_i$$

$$= -p\ln p - (1-p)\ln(1-p)$$

This is **Shannon entropy** (binary)!

**Special cases:**
- $p = 0$ or $1$: $S = 0$ (pure state, no uncertainty)
- $p = 1/2$: $S = \ln 2$ (maximum, completely mixed)

**Properties:**
- $S \geq 0$ (non-negative)
- $S = 0$ ↔ pure state
- $S = \ln d$ for maximally mixed state in $d$ dimensions

**Answer:** $S = -p\ln p - (1-p)\ln(1-p)$ (von Neumann entropy for mixed qubit)

### Example 10: Decoherence Example

Initially pure superposition $|\psi\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$ interacts with environment.

After decoherence: $\hat{\rho} = \frac{1}{2}|0\rangle\langle 0| + \frac{1}{2}|1\rangle\langle 1|$

Compute entropy change.

**Solution:**

**Initial:** Pure state → $S_i = 0$

**Final:** Mixed state → $S_f = -\frac{1}{2}\ln\frac{1}{2} - \frac{1}{2}\ln\frac{1}{2} = \ln 2$

**Change:** $\Delta S = \ln 2$ (entropy increased)

**Physical meaning:** 
- Environment entangled with system
- Tracing out environment → system appears mixed
- Entropy measures loss of information about quantum state

**Irreversibility:** Cannot recover pure state without accessing environment.

This is **decoherence**—how quantum systems become classical through environmental interaction.

**Answer:** Entropy increases from $0$ to $\ln 2$; decoherence destroys coherence

## Practice Problems

**Problem 1:** For pure state, $\text{Tr}(\hat{\rho}^2)$ equals:

A) 0
B) 1/2
C) 1
D) 2
E) $\infty$

**Problem 2:** Off-diagonal elements of density matrix represent:

A) Energy
B) Probability
C) Coherence between states
D) Temperature
E) Nothing physical

**Problem 3:** The von Neumann equation is:

A) $i\hbar\frac{\partial\hat{\rho}}{\partial t} = \hat{H}\hat{\rho}$
B) $i\hbar\frac{\partial\hat{\rho}}{\partial t} = [\hat{H}, \hat{\rho}]$
C) $\frac{\partial\hat{\rho}}{\partial t} = 0$
D) $\hat{\rho} = |\psi\rangle\langle\psi|$
E) $\text{Tr}(\hat{\rho}) = 1$

**Problem 4:** For Bell state, reduced density matrix is:

A) Pure
B) Maximally mixed
C) Zero
D) Identity times 2
E) Undefined

**Problem 5:** von Neumann entropy is zero for:

A) All states
B) Mixed states only
C) Pure states only
D) Thermal states
E) Entangled states

## Answer Key

**Problem 1: C**
Pure state: $\hat{\rho} = |\psi\rangle\langle\psi|$ satisfies $\hat{\rho}^2 = \hat{\rho}$ (projection operator). Therefore $\text{Tr}(\hat{\rho}^2) = \text{Tr}(\hat{\rho}) = 1$. Mixed state: $\text{Tr}(\hat{\rho}^2) = \sum_i p_i^2 < (\sum_i p_i)^2 = 1$ (strictly less than 1 unless one $p_i = 1$). **Purity test:** $\text{Tr}(\hat{\rho}^2) = 1$ ↔ pure; $< 1$ ↔ mixed. Maximum mixedness: $\hat{\rho} = \mathbb{I}/d$ gives $\text{Tr}(\hat{\rho}^2) = 1/d$ (minimum purity).

**Problem 2: C**
Diagonal elements $\rho_{ii} = $ probability of being in state $|i\rangle$ (populations). Off-diagonal $\rho_{ij}$ (i≠j) = coherences = quantum phase relationships between states. Pure superposition: non-zero off-diagonal (quantum interference possible). Mixed state: diagonal only (classical mixture, no coherence). Decoherence: off-diagonals decay to zero. Measurable: interference experiments detect coherences. Example: double-slit pattern from $\rho_{12} \neq 0$; no pattern if $\rho_{12} = 0$.

**Problem 3: B**
von Neumann equation: $i\hbar\frac{\partial\hat{\rho}}{\partial t} = [\hat{H}, \hat{\rho}]$ (quantum Liouville equation). Analogous to classical Liouville equation for phase space density. Derived from Schrödinger equation for $|\psi\rangle$. **Properties:** (1) Preserves $\text{Tr}(\hat{\rho}) = 1$, (2) Preserves $\text{Tr}(\hat{\rho}^2)$ (purity conserved), (3) Unitary evolution. If $[\hat{H}, \hat{\rho}] = 0$: stationary state (no time evolution). Thermal equilibrium: $\hat{\rho} \propto e^{-\beta\hat{H}}$ satisfies this.

**Problem 4: B**
Bell state $|\psi\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)$ is maximally entangled. Reduced density matrix: $\hat{\rho}_A = \text{Tr}_B(|\psi\rangle\langle\psi|) = \frac{1}{2}\mathbb{I}$ (completely mixed). **Paradox:** Total system pure, but subsystem maximally mixed! This is signature of entanglement. No measurement on $A$ alone distinguishes from thermal state. Full information only in correlations. Product states give pure reduced matrices. Entanglement measure: $S(\hat{\rho}_A)$ quantifies entanglement.

**Problem 5: C**
von Neumann entropy $S = -\text{Tr}(\hat{\rho}\ln\hat{\rho}) = -\sum_i\lambda_i\ln\lambda_i$ where $\lambda_i$ = eigenvalues of $\hat{\rho}$. **Pure state:** Single $\lambda = 1$, others $= 0$ → $S = 0$ (no uncertainty). **Mixed state:** Multiple non-zero $\lambda_i$ → $S > 0$. Maximum: $S = \ln d$ for $\hat{\rho} = \mathbb{I}/d$ (maximally mixed). Measures: (1) Information loss, (2) Entanglement (for subsystem), (3) Thermodynamic entropy connection. Zero entropy ↔ complete knowledge ↔ pure state.

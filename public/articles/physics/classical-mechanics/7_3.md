# Article 7.3: Hamiltonian Mechanics

Hamiltonian mechanics recasts dynamics in phase space—the space of positions and momenta $(q, p)$—through Hamilton's equations. Where Lagrangian formulation uses $(q, \dot{q})$, Hamiltonian formulation uses $(q, p)$ as independent variables, yielding first-order differential equations elegant in structure and profound in implications. The Hamiltonian $H(q, p, t)$ typically equals total energy, with dynamics flowing along level surfaces of constant energy in phase space.

The geometric structure of Hamiltonian mechanics—symplectic geometry—reveals deep properties: phase space volume preservation (Liouville's theorem), canonical transformations preserving Poisson bracket structure, and connections to quantum mechanics through canonical quantization. Hamilton's equations exhibit time-reversal symmetry and provide the classical foundation for quantum mechanics, statistical mechanics, and chaos theory.

This article develops Hamiltonian mechanics from Legendre transformation, derives Hamilton's equations, introduces phase space geometry, establishes Poisson bracket formalism, and explores conservation laws. The mathematics employs partial differential equations, multivariable calculus, and differential geometry concepts. Applications span integrable systems, action-angle variables, and the bridge to quantum mechanics.

## Legendre Transformation

The **Legendre transformation** connects Lagrangian and Hamiltonian formulations.

**Generalized momentum:** $p_i = \frac{\partial L}{\partial \dot{q}_i}$

**Hamiltonian:**
$$H(q, p, t) = \sum_i p_i\dot{q}_i - L(q, \dot{q}, t)$$

where $\dot{q}_i$ is expressed in terms of $(q, p, t)$ by inverting $p_i = \partial L/\partial \dot{q}_i$.

**For natural systems:** $L = T - V$ with $T$ quadratic in $\dot{q}$:

$$T = \frac{1}{2}\sum_{ij} m_{ij}(q)\dot{q}_i\dot{q}_j$$

Then: $H = T + V$ (total energy).

### Example 1: Harmonic Oscillator Hamiltonian

Find Hamiltonian for $L = \frac{1}{2}m\dot{x}^2 - \frac{1}{2}kx^2$.

**Solution:**

**Generalized momentum:**
$$p = \frac{\partial L}{\partial \dot{x}} = m\dot{x}$$

Invert: $\dot{x} = p/m$

**Hamiltonian:**
$$H = p\dot{x} - L = p \cdot \frac{p}{m} - \left[\frac{1}{2}m\left(\frac{p}{m}\right)^2 - \frac{1}{2}kx^2\right]$$

$$= \frac{p^2}{m} - \frac{p^2}{2m} + \frac{1}{2}kx^2 = \frac{p^2}{2m} + \frac{1}{2}kx^2$$

This is kinetic plus potential energy!

**Answer:** $H = \frac{p^2}{2m} + \frac{1}{2}kx^2 = T + V$

## Hamilton's Equations

From $H(q, p, t)$, the equations of motion are:

$$\dot{q}_i = \frac{\partial H}{\partial p_i}$$

$$\dot{p}_i = -\frac{\partial H}{\partial q_i}$$

These are **Hamilton's canonical equations** (or simply **Hamilton's equations**).

**Derivation:** From $dH = \sum_i (\partial H/\partial q_i) dq_i + \sum_i (\partial H/\partial p_i) dp_i + (\partial H/\partial t) dt$ and $H = \sum_i p_i\dot{q}_i - L$:

$$dH = \sum_i \dot{q}_i dp_i + \sum_i p_i d\dot{q}_i - \frac{\partial L}{\partial q_i}dq_i - \frac{\partial L}{\partial \dot{q}_i}d\dot{q}_i - \frac{\partial L}{\partial t}dt$$

Using $p_i = \partial L/\partial \dot{q}_i$ and Euler-Lagrange $\dot{p}_i = \partial L/\partial q_i$:

$$dH = \sum_i \dot{q}_i dp_i - \sum_i \dot{p}_i dq_i - \frac{\partial L}{\partial t}dt$$

Comparing coefficients:
$$\dot{q}_i = \frac{\partial H}{\partial p_i}, \quad \dot{p}_i = -\frac{\partial H}{\partial q_i}$$ ∎

### Example 2: Harmonic Oscillator via Hamilton's Equations

Solve harmonic oscillator using $H = \frac{p^2}{2m} + \frac{1}{2}kx^2$.

**Solution:**

$$\dot{x} = \frac{\partial H}{\partial p} = \frac{p}{m}$$

$$\dot{p} = -\frac{\partial H}{\partial x} = -kx$$

Differentiate first equation:
$$\ddot{x} = \frac{\dot{p}}{m} = \frac{-kx}{m}$$

$$\ddot{x} + \frac{k}{m}x = 0$$

$$\ddot{x} + \omega_0^2 x = 0$$

where $\omega_0 = \sqrt{k/m}$. ✓

**Answer:** Same equation as before, but from first-order system

## Phase Space

**Phase space** is the $2n$-dimensional space with coordinates $(q_1, ..., q_n, p_1, ..., p_n)$.

**Phase space trajectory:** A solution $(q(t), p(t))$ traces a curve in phase space.

**Energy surface:** For time-independent $H$, energy $E = H(q, p) = $ constant defines a $(2n-1)$-dimensional surface in phase space.

**Flow:** Hamilton's equations define a vector field:
$$\mathbf{v} = (\dot{q}_1, ..., \dot{q}_n, \dot{p}_1, ..., \dot{p}_n)$$

Trajectories never cross (uniqueness of solutions).

### Example 3: Phase Space for Harmonic Oscillator

Describe phase space trajectories for $H = \frac{p^2}{2m} + \frac{1}{2}kx^2 = E$.

**Solution:**

Energy surface:
$$\frac{p^2}{2mE} + \frac{kx^2}{2E} = 1$$

$$\frac{x^2}{(2E/k)} + \frac{p^2}{(2mE)} = 1$$

This is an ellipse in $(x, p)$ plane with semi-axes:
- $a = \sqrt{2E/k}$ (position axis)
- $b = \sqrt{2mE}$ (momentum axis)

Higher energy → larger ellipse.

Motion is periodic with period $T = 2\pi/\omega_0 = 2\pi\sqrt{m/k}$ (time to complete one loop).

**Answer:** Ellipses in phase space, nested by energy

## Poisson Brackets

For any two functions $f(q, p, t)$ and $g(q, p, t)$, the **Poisson bracket** is:

$$\{f, g\} = \sum_i \left(\frac{\partial f}{\partial q_i}\frac{\partial g}{\partial p_i} - \frac{\partial f}{\partial p_i}\frac{\partial g}{\partial q_i}\right)$$

**Properties:**
1. Antisymmetry: $\{f, g\} = -\{g, f\}$
2. Linearity: $\{af + bg, h\} = a\{f, h\} + b\{g, h\}$
3. Leibniz rule: $\{fg, h\} = f\{g, h\} + \{f, h\}g$
4. Jacobi identity: $\{f, \{g, h\}\} + \{g, \{h, f\}\} + \{h, \{f, g\}\} = 0$

**Fundamental Poisson brackets:**
$$\{q_i, q_j\} = 0, \quad \{p_i, p_j\} = 0, \quad \{q_i, p_j\} = \delta_{ij}$$

**Time evolution:** For any observable $f(q, p, t)$:
$$\frac{df}{dt} = \{f, H\} + \frac{\partial f}{\partial t}$$

**Hamilton's equations from Poisson brackets:**
$$\dot{q}_i = \{q_i, H\}, \quad \dot{p}_i = \{p_i, H\}$$

### Example 4: Poisson Bracket Calculation

Compute $\{x, p_x\}$, $\{L_z, x\}$, and $\{L_z, p_x\}$ where $L_z = xp_y - yp_x$.

**Solution:**

**(a)** $\{x, p_x\}$:
$$\{x, p_x\} = \frac{\partial x}{\partial x}\frac{\partial p_x}{\partial p_x} - \frac{\partial x}{\partial p_x}\frac{\partial p_x}{\partial x} = 1 \cdot 1 - 0 \cdot 0 = 1$$

**(b)** $\{L_z, x\}$:
$$\{L_z, x\} = \frac{\partial L_z}{\partial x}\frac{\partial x}{\partial p_x} - \frac{\partial L_z}{\partial p_x}\frac{\partial x}{\partial x}$$

$$= p_y \cdot 0 - (-y) \cdot 1 = y$$

**(c)** $\{L_z, p_x\}$:
$$\{L_z, p_x\} = \frac{\partial L_z}{\partial x}\frac{\partial p_x}{\partial p_x} - \frac{\partial L_z}{\partial p_x}\frac{\partial p_x}{\partial x}$$

$$= p_y \cdot 1 - (-y) \cdot 0 = p_y$$

**Answer:** (a) $1$, (b) $y$, (c) $p_y$

## Conservation Laws

**Theorem:** If $f$ doesn't depend explicitly on time and $\{f, H\} = 0$, then $f$ is conserved.

**Proof:**
$$\frac{df}{dt} = \{f, H\} + \frac{\partial f}{\partial t} = 0 + 0 = 0$$ ∎

**Energy conservation:** If $\partial H/\partial t = 0$:
$$\frac{dH}{dt} = \{H, H\} + \frac{\partial H}{\partial t} = 0 + 0 = 0$$

### Example 5: Angular Momentum Conservation

Show that if $H$ is rotationally invariant, then $L_z$ is conserved.

**Solution:**

Rotational invariance means $H$ doesn't change under rotation, which means:
$$\{L_z, H\} = 0$$

Therefore:
$$\frac{dL_z}{dt} = \{L_z, H\} = 0$$

So $L_z$ is conserved. ✓

**Answer:** Rotational symmetry → angular momentum conserved (Noether's theorem)

# Article 7.1: Calculus of Variations

The calculus of variations extends differential calculus from functions to functionals—mappings from functions to real numbers. Where calculus finds extrema of functions $f(x)$, variational calculus finds functions $y(x)$ that extremize integrals like $\int F(x, y, y') dx$. This mathematical framework underpins all of modern physics: Fermat's principle (optics), Hamilton's principle (mechanics), path integrals (quantum mechanics), and the Einstein-Hilbert action (general relativity) all emerge from extremizing appropriate functionals.

The fundamental result—the Euler-Lagrange equation—transforms a variational problem into a differential equation. A function $y(x)$ extremizes the functional $I[y] = \int_{x_1}^{x_2} F(x, y, y') dx$ if and only if it satisfies $\frac{\partial F}{\partial y} - \frac{d}{dx}\frac{\partial F}{\partial y'} = 0$. This powerful result reduces infinite-dimensional optimization (finding the optimal function among all possible functions) to solving ODEs. Physical laws expressed through variational principles reveal deep connections between symmetries and conservation laws.

This article develops the calculus of variations systematically: defining functionals and variations, deriving the Euler-Lagrange equation, handling various boundary conditions, incorporating constraints through Lagrange multipliers, and applying these techniques to physical problems. The mathematics employs functional analysis concepts, variational derivatives, and differential equations. Applications span brachistochrone problems, geodesics, and the path to Lagrangian mechanics.

## Functionals and Variations

A **functional** $I[y]$ maps functions to real numbers:
$$I[y] = \int_{x_1}^{x_2} F(x, y(x), y'(x)) dx$$

where $F$ is called the **integrand** and $y' = dy/dx$.

**Variation:** Consider a family of functions $y(x, \alpha) = y(x) + \alpha\eta(x)$ where $\eta(x)$ is an arbitrary function (the **variation**) and $\alpha$ is a small parameter.

The functional becomes: $I(\alpha) = I[y + \alpha\eta]$

**First variation:**
$$\delta I = \frac{d I}{d\alpha}\Big|_{\alpha=0} = \int_{x_1}^{x_2} \left(\frac{\partial F}{\partial y}\eta + \frac{\partial F}{\partial y'}\eta'\right) dx$$

**Extremum condition:** $\delta I = 0$ for all admissible $\eta(x)$.

### Example 1: Functional Evaluation

Evaluate the functional $I[y] = \int_0^1 (y'^2 + y^2) dx$ for $y(x) = x^2$.

**Solution:**

With $y = x^2$: $y' = 2x$

$$I[y] = \int_0^1 [(2x)^2 + (x^2)^2] dx = \int_0^1 (4x^2 + x^4) dx$$

$$= \left[\frac{4x^3}{3} + \frac{x^5}{5}\right]_0^1 = \frac{4}{3} + \frac{1}{5} = \frac{20 + 3}{15} = \frac{23}{15}$$

**Answer:** $I = 23/15 \approx 1.53$

## The Euler-Lagrange Equation

**Theorem:** A function $y(x)$ extremizes $I[y] = \int_{x_1}^{x_2} F(x, y, y') dx$ if and only if it satisfies the **Euler-Lagrange equation:**

$$\frac{\partial F}{\partial y} - \frac{d}{dx}\left(\frac{\partial F}{\partial y'}\right) = 0$$

**Derivation:** From $\delta I = 0$:

$$\int_{x_1}^{x_2} \left(\frac{\partial F}{\partial y}\eta + \frac{\partial F}{\partial y'}\eta'\right) dx = 0$$

Integrate second term by parts:
$$\int_{x_1}^{x_2} \frac{\partial F}{\partial y'}\eta' dx = \left[\frac{\partial F}{\partial y'}\eta\right]_{x_1}^{x_2} - \int_{x_1}^{x_2} \frac{d}{dx}\left(\frac{\partial F}{\partial y'}\right)\eta \, dx$$

For fixed endpoints: $\eta(x_1) = \eta(x_2) = 0$, so boundary term vanishes.

$$\int_{x_1}^{x_2} \left[\frac{\partial F}{\partial y} - \frac{d}{dx}\left(\frac{\partial F}{\partial y'}\right)\right]\eta \, dx = 0$$

Since this holds for **all** $\eta(x)$, the integrand must vanish:

$$\frac{\partial F}{\partial y} - \frac{d}{dx}\left(\frac{\partial F}{\partial y'}\right) = 0$$ ∎

### Example 2: Shortest Path in Plane

Find the curve of shortest length connecting $(x_1, y_1)$ and $(x_2, y_2)$.

**Solution:**

Arc length: $s = \int_{x_1}^{x_2} \sqrt{1 + y'^2} \, dx$

Integrand: $F(x, y, y') = \sqrt{1 + y'^2}$

Note: $F$ doesn't depend on $y$ explicitly, so $\partial F/\partial y = 0$.

$$\frac{\partial F}{\partial y'} = \frac{y'}{\sqrt{1 + y'^2}}$$

Euler-Lagrange equation:
$$\frac{d}{dx}\left(\frac{y'}{\sqrt{1 + y'^2}}\right) = 0$$

This means:
$$\frac{y'}{\sqrt{1 + y'^2}} = c \quad \text{(constant)}$$

Square both sides:
$$\frac{y'^2}{1 + y'^2} = c^2$$

$$y'^2 = c^2(1 + y'^2)$$

$$y'^2(1 - c^2) = c^2$$

$$y' = \frac{c}{\sqrt{1-c^2}} = k \quad \text{(constant)}$$

Therefore: $y = kx + b$ (straight line!)

**Answer:** Shortest path is a straight line

## Special Cases of Euler-Lagrange Equation

**1. $F$ doesn't depend on $y$:** $\frac{\partial F}{\partial y} = 0$

Euler-Lagrange becomes:
$$\frac{d}{dx}\left(\frac{\partial F}{\partial y'}\right) = 0$$

So $\frac{\partial F}{\partial y'} = $ constant (first integral).

**2. $F$ doesn't depend on $x$ explicitly:** 

Then the **Beltrami identity** holds:
$$F - y'\frac{\partial F}{\partial y'} = \text{constant}$$

**Proof:** Differentiate total derivative:
$$\frac{dF}{dx} = \frac{\partial F}{\partial x} + \frac{\partial F}{\partial y}y' + \frac{\partial F}{\partial y'}y''$$

If $\partial F/\partial x = 0$ and Euler-Lagrange holds:
$$\frac{dF}{dx} = \frac{d}{dx}\left(\frac{\partial F}{\partial y'}\right)y' + \frac{\partial F}{\partial y'}y''$$

$$= \frac{d}{dx}\left(y'\frac{\partial F}{\partial y'}\right)$$

Therefore:
$$\frac{d}{dx}\left(F - y'\frac{\partial F}{\partial y'}\right) = 0$$ ∎

### Example 3: Brachistochrone Problem

Find the curve of fastest descent under gravity between two points.

**Solution:**

Time to descend: $T = \int \frac{ds}{v} = \int \frac{\sqrt{1+y'^2}}{v} dx$

From energy conservation: $\frac{1}{2}mv^2 = mgy$, so $v = \sqrt{2gy}$.

$$T = \int_{x_1}^{x_2} \sqrt{\frac{1+y'^2}{2gy}} dx$$

Integrand: $F = \sqrt{\frac{1+y'^2}{2gy}}$

Since $F$ doesn't depend on $x$, use Beltrami identity:
$$F - y'\frac{\partial F}{\partial y'} = c$$

$$\frac{\partial F}{\partial y'} = \frac{1}{\sqrt{2gy}} \cdot \frac{y'}{\sqrt{1+y'^2}}$$

After substantial algebra:
$$\frac{1}{\sqrt{2gy}}\sqrt{\frac{1}{1+y'^2}} = c$$

$$\frac{1}{2gy(1+y'^2)} = c^2$$

$$1 + y'^2 = \frac{1}{2gyc^2} = \frac{k}{y}$$

where $k = 1/(2gc^2)$.

This is the differential equation for a **cycloid**:
$$x = k(\theta - \sin\theta), \quad y = k(1 - \cos\theta)$$

**Answer:** Fastest descent is along a cycloid

## Multiple Variables

For functionals of multiple functions:
$$I[y_1, ..., y_n] = \int_{x_1}^{x_2} F(x, y_1, ..., y_n, y_1', ..., y_n') dx$$

**Euler-Lagrange equations (one for each $y_i$):**
$$\frac{\partial F}{\partial y_i} - \frac{d}{dx}\left(\frac{\partial F}{\partial y_i'}\right) = 0, \quad i = 1, ..., n$$

### Example 4: Geodesic on Sphere

Find geodesic (shortest path) on sphere of radius $R$ between two points.

**Solution:**

Parameterize by angles $(\theta, \phi)$. Line element:
$$ds^2 = R^2(d\theta^2 + \sin^2\theta \, d\phi^2)$$

Arc length as functional:
$$s = \int R\sqrt{\theta'^2 + \sin^2\theta \, \phi'^2} \, dt$$

where primes denote $d/dt$.

This is complex. Simpler: use calculus result that geodesics on sphere are **great circles**.

For equatorial path: $\theta = \pi/2$ (constant), any $\phi$.

For general case: solve two coupled Euler-Lagrange equations.

**Answer:** Geodesics are great circles

### Example 5: Constrained Variation with Lagrange Multiplier

Extremize $I[y] = \int_0^1 y^2 dx$ subject to $\int_0^1 y dx = 1$ (constraint).

**Solution:**

Use Lagrange multiplier $\lambda$:
$$J[y] = \int_0^1 (y^2 + \lambda y) dx$$

Euler-Lagrange:
$$\frac{\partial}{\partial y}(y^2 + \lambda y) = 2y + \lambda = 0$$

$$y = -\frac{\lambda}{2} = \text{constant}$$

Apply constraint:
$$\int_0^1 y dx = y \cdot 1 = 1$$

So $y = 1$.

**Answer:** $y(x) = 1$ (constant function)

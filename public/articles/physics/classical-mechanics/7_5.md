# Article 7.5: Canonical Transformations

Canonical transformations are coordinate changes in phase space that preserve Hamilton's equations' form. Where general transformations $(q, p) \to (Q, P)$ might destroy the Hamiltonian structure, canonical transformations maintain it: if $(q, p)$ satisfy Hamilton's equations with Hamiltonian $H$, then $(Q, P)$ satisfy Hamilton's equations with transformed Hamiltonian $K$. The key mathematical structure preserved is the **symplectic form**—canonical transformations are precisely symplectic transformations preserving Poisson brackets.

Generating functions construct canonical transformations systematically, mixing old and new coordinates to define the transformation implicitly. Action-angle variables exemplify canonical transformations' power: for integrable systems, these coordinates make the Hamiltonian depend only on actions, with angles evolving linearly in time. Canonical transformations also provide the classical foundation for quantum mechanics: canonical quantization replaces Poisson brackets with commutators, $\{f,g\} \to (i/\hbar)[f,g]$.

This article develops canonical transformation theory: defining canonical transformations through Poisson bracket preservation, introducing generating functions, deriving the symplectic condition, exploring action-angle variables, and connecting to quantum mechanics. The mathematics emphasizes transformation theory, symplectic linear algebra, and differential forms. Applications span perturbation theory, integrable systems, and the classical-quantum correspondence.

## Definition and Symplectic Form

A transformation $(q, p) \to (Q, P)$ is **canonical** if it preserves Poisson brackets:

$$\{Q_i, Q_j\}_{q,p} = 0, \quad \{P_i, P_j\}_{q,p} = 0, \quad \{Q_i, P_j\}_{q,p} = \delta_{ij}$$

Or equivalently, if $(Q, P)$ satisfy Hamilton's equations with some Hamiltonian $K(Q, P, t)$.

**Matrix formulation:** Define phase space coordinates $\mathbf{z} = (q_1, ..., q_n, p_1, ..., p_n)^T$.

**Symplectic matrix:**
$$\mathbf{J} = \begin{pmatrix} \mathbf{0} & \mathbf{I} \\ -\mathbf{I} & \mathbf{0} \end{pmatrix}$$

where $\mathbf{I}$ is $n \times n$ identity.

**Poisson bracket:** $\{f, g\} = \nabla f \cdot \mathbf{J} \cdot \nabla g$

**Canonical condition:** Transformation $\mathbf{z} \to \mathbf{Z}$ is canonical if its Jacobian $\mathbf{S} = \partial\mathbf{Z}/\partial\mathbf{z}$ satisfies:

$$\mathbf{S}^T\mathbf{J}\mathbf{S} = \mathbf{J}$$

This is the **symplectic condition**.

### Example 1: Testing Canonical Transformation

Is the transformation $Q = p$, $P = -q$ canonical?

**Solution:**

Jacobian:
$$\mathbf{S} = \begin{pmatrix} \partial Q/\partial q & \partial Q/\partial p \\ \partial P/\partial q & \partial P/\partial p \end{pmatrix} = \begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}$$

Check symplectic condition:
$$\mathbf{S}^T\mathbf{J}\mathbf{S} = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}\begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}\begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}$$

$$= \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}\begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix} = \begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix} = \mathbf{J}$$ ✓

**Or check Poisson brackets:**
$$\{Q, P\}_{q,p} = \{p, -q\}_{q,p} = -\{p, q\}_{q,p} = -(-\{q, p\}_{q,p}) = 1$$ ✓

**Answer:** Yes, canonical (this is 90° rotation in phase space)

## Generating Functions

Canonical transformations can be generated by functions mixing old and new coordinates.

**Type 1:** $F_1(q, Q, t)$ generates transformation via:
$$p_i = \frac{\partial F_1}{\partial q_i}, \quad P_i = -\frac{\partial F_1}{\partial Q_i}$$

**Type 2:** $F_2(q, P, t)$ generates via:
$$p_i = \frac{\partial F_2}{\partial q_i}, \quad Q_i = \frac{\partial F_2}{\partial P_i}$$

**New Hamiltonian:**
$$K = H + \frac{\partial F}{\partial t}$$

### Example 2: Identity Transformation

What generating function gives identity transformation $Q = q$, $P = p$?

**Solution:**

Try $F_2(q, P) = \sum_i q_i P_i$:

$$p_i = \frac{\partial F_2}{\partial q_i} = P_i$$

$$Q_i = \frac{\partial F_2}{\partial P_i} = q_i$$

So $Q = q$ and $P = p$. ✓

**Answer:** $F_2 = \sum q_i P_i$ generates identity

### Example 3: Point Transformation

For transformation $Q = Q(q, t)$ (point transformation), find generating function.

**Solution:**

Use Type 2: $F_2(q, P, t) = \sum_i Q_i(q, t) P_i$

Then:
$$p_i = \frac{\partial F_2}{\partial q_i} = \sum_j \frac{\partial Q_j}{\partial q_i} P_j$$

$$Q_i = \frac{\partial F_2}{\partial P_i}$$

This gives the transformation and determines $p \to P$ relationship.

**Answer:** $F_2 = \sum Q_i(q, t) P_i$

## Liouville's Theorem

**Theorem:** Phase space volume is preserved by Hamiltonian flow.

**Statement:** For region $\Omega$ in phase space with volume $V = \int_\Omega dq_1...dq_n dp_1...dp_n$:

$$\frac{dV}{dt} = 0$$

**Proof:** The flow velocity in phase space is $\mathbf{v} = (\dot{q}_1, ..., \dot{q}_n, \dot{p}_1, ..., \dot{p}_n)$.

Volume changes according to:
$$\frac{dV}{dt} = \int_\Omega \nabla \cdot \mathbf{v} \, d^{2n}z$$

where $d^{2n}z = dq_1...dq_n dp_1...dp_n$.

$$\nabla \cdot \mathbf{v} = \sum_i \left(\frac{\partial \dot{q}_i}{\partial q_i} + \frac{\partial \dot{p}_i}{\partial p_i}\right)$$

From Hamilton's equations:
$$\frac{\partial \dot{q}_i}{\partial q_i} = \frac{\partial^2 H}{\partial q_i \partial p_i}, \quad \frac{\partial \dot{p}_i}{\partial p_i} = -\frac{\partial^2 H}{\partial p_i \partial q_i}$$

$$\nabla \cdot \mathbf{v} = \sum_i \left(\frac{\partial^2 H}{\partial q_i \partial p_i} - \frac{\partial^2 H}{\partial p_i \partial q_i}\right) = 0$$

Therefore $dV/dt = 0$. ∎

### Example 4: Phase Space Volume Conservation

A cloud of points in phase space has initial volume $V_0$. After time $t$, each point evolves via Hamilton's equations. What is the volume?

**Solution:**

By Liouville's theorem, phase space volume is preserved.

$$V(t) = V_0$$

The cloud may distort, stretch, or fold, but total volume remains constant.

**Answer:** $V(t) = V_0$ (volume conserved)

## Action-Angle Variables

For **integrable systems** (conserved quantities equal to degrees of freedom), **action-angle variables** $(I, \theta)$ are canonical coordinates where:

**Action variables:** $I_i = \frac{1}{2\pi}\oint p_i dq_i$ (integrals over closed cycles)

**Angle variables:** $\theta_i$ conjugate to $I_i$, varying $0$ to $2\pi$ over cycle

In these coordinates, Hamiltonian depends only on actions:
$$H = H(I_1, ..., I_n)$$

Hamilton's equations become:
$$\dot{I}_i = -\frac{\partial H}{\partial \theta_i} = 0 \quad \text{(actions constant)}$$

$$\dot{\theta}_i = \frac{\partial H}{\partial I_i} = \omega_i(I) \quad \text{(angles evolve linearly)}$$

**Solution:**
$$I_i(t) = I_i^{(0)}, \quad \theta_i(t) = \omega_i t + \theta_i^{(0)}$$

### Example 5: Harmonic Oscillator in Action-Angle Variables

For harmonic oscillator $H = \frac{p^2}{2m} + \frac{1}{2}kx^2$, find action-angle variables.

**Solution:**

Energy: $E = H = $ constant

Phase space trajectory is ellipse:
$$\frac{x^2}{(2E/k)} + \frac{p^2}{(2mE)} = 1$$

**Action:**
$$I = \frac{1}{2\pi}\oint p dx$$

Using $x = A\cos(\omega t)$, $p = -mA\omega\sin(\omega t)$ where $\omega = \sqrt{k/m}$:

$$I = \frac{1}{2\pi}\int_0^T p \dot{x} dt = \frac{1}{2\pi}\int_0^T p^2/m \, dt$$

After calculation (or using $\oint p dx = $ ellipse area $= \pi \sqrt{2E/k} \sqrt{2mE}$):

$$I = \frac{E}{\omega}$$

**Hamiltonian in action variables:**
$$H = \omega I$$

**Angle variable:** $\theta = \omega t + $ const

**Answer:** $I = E/\omega$, $H = \omega I$, $\dot{\theta} = \omega$

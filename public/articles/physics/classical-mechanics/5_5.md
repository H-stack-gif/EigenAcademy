# Article 5.5: Introduction to Wave Motion

Waves represent the propagation of disturbances through continuous media—strings, air, water, electromagnetic fields. Where coupled oscillators involve discrete masses, waves emerge in the continuum limit where infinitely many oscillators couple locally. The wave equation, $\partial^2 u/\partial t^2 = v^2 \partial^2 u/\partial x^2$, governs diverse phenomena: sound waves, seismic waves, light, quantum wavefunctions. Solutions describe traveling disturbances that transport energy and momentum without net material flow.

The mathematics of wave motion involves partial differential equations (PDEs), d'Alembert's solution revealing the general structure, and harmonic analysis decomposing arbitrary disturbances into sinusoidal components. Standing waves arise from boundary conditions, producing discrete allowed frequencies—a precursor to quantum mechanical energy quantization. Dispersion relations $\omega = \omega(k)$ connect frequency to wavelength, determining wave packet evolution and group velocity.

This article develops the wave equation from first principles, solves it using d'Alembert's method and separation of variables, analyzes standing waves and boundary conditions, introduces dispersion relations and group velocity, and examines energy transport in waves. The mathematics employs PDEs, Fourier analysis, boundary value problems, and vector calculus. Applications span mechanical waves, acoustics, and electromagnetic radiation.

## Derivation of the Wave Equation

Consider a flexible string under tension $T$, mass per unit length $\mu$. For small transverse displacement $u(x,t)$:

**Forces on element $dx$:**

Vertical component of tension: $T\sin\theta_2 - T\sin\theta_1 \approx T(\tan\theta_2 - \tan\theta_1) = T\left(\frac{\partial u}{\partial x}\Big|_{x+dx} - \frac{\partial u}{\partial x}\Big|_x\right)$

$$= T\frac{\partial^2 u}{\partial x^2}dx$$

**Newton's second law:**
$$\mu dx \frac{\partial^2 u}{\partial t^2} = T\frac{\partial^2 u}{\partial x^2}dx$$

$$\frac{\partial^2 u}{\partial t^2} = \frac{T}{\mu}\frac{\partial^2 u}{\partial x^2}$$

Define **wave speed:** $v = \sqrt{T/\mu}$

**Wave equation:**
$$\frac{\partial^2 u}{\partial t^2} = v^2\frac{\partial^2 u}{\partial x^2}$$

### Example 1: Wave Speed on String

A string has tension $T = 80$ N and mass per unit length $\mu = 0.02$ kg/m. Find wave speed.

**Solution:**
$$v = \sqrt{\frac{T}{\mu}} = \sqrt{\frac{80}{0.02}} = \sqrt{4000} = 63.2 \text{ m/s}$$

**Answer:** $v = 63.2$ m/s

## D'Alembert Solution: Traveling Waves

**General solution** to wave equation:
$$u(x,t) = f(x - vt) + g(x + vt)$$

where $f$ and $g$ are arbitrary functions.

**Interpretation:**
- $f(x - vt)$: right-moving wave (shape $f$ traveling at speed $v$ in $+x$ direction)
- $g(x + vt)$: left-moving wave (shape $g$ traveling at speed $v$ in $-x$ direction)

**Verification:** Let $\xi = x - vt$:
$$\frac{\partial u}{\partial t} = -v f'(\xi), \quad \frac{\partial^2 u}{\partial t^2} = v^2 f''(\xi)$$
$$\frac{\partial u}{\partial x} = f'(\xi), \quad \frac{\partial^2 u}{\partial x^2} = f''(\xi)$$

Therefore: $\frac{\partial^2 u}{\partial t^2} = v^2\frac{\partial^2 u}{\partial x^2}$ ✓

### Example 2: Traveling Pulse

A Gaussian pulse $u(x,0) = Ae^{-x^2/a^2}$ moves to the right at speed $v$. Write $u(x,t)$.

**Solution:**

Since pulse moves right with no left-moving component: $g = 0$.

$$u(x,t) = f(x-vt) = Ae^{-(x-vt)^2/a^2}$$

At $t = 0$: $u(x,0) = Ae^{-x^2/a^2}$ ✓

At time $t$: pulse centered at $x = vt$ with same shape.

**Answer:** $u(x,t) = Ae^{-(x-vt)^2/a^2}$

## Harmonic Waves

**Sinusoidal solution:**
$$u(x,t) = A\cos(kx - \omega t + \phi)$$

where:
- $A$ = amplitude
- $k = 2\pi/\lambda$ = wave number
- $\omega = 2\pi f$ = angular frequency
- $\lambda$ = wavelength
- $f$ = frequency

**Dispersion relation:** From wave equation:
$$\omega^2 = v^2 k^2 \implies \omega = vk$$

**Phase velocity:**
$$v_p = \frac{\omega}{k} = v$$

### Example 3: Harmonic Wave Parameters

A wave $u = 0.05\cos(2x - 6t)$ m (SI units). Find: (a) amplitude, (b) wavelength, (c) frequency, (d) wave speed.

**Solution:**

From $u = A\cos(kx - \omega t)$:
- $A = 0.05$ m
- $k = 2$ rad/m
- $\omega = 6$ rad/s

**(a) Amplitude:** $A = 0.05$ m

**(b) Wavelength:** $\lambda = 2\pi/k = 2\pi/2 = \pi$ m

**(c) Frequency:** $f = \omega/(2\pi) = 6/(2\pi) = 0.955$ Hz

**(d) Wave speed:** $v = \omega/k = 6/2 = 3$ m/s

**Answer:** (a) $0.05$ m, (b) $\pi$ m, (c) $0.955$ Hz, (d) $3$ m/s

## Standing Waves and Boundary Conditions

For string fixed at both ends ($x = 0$ and $x = L$):

**Boundary conditions:** $u(0,t) = 0$ and $u(L,t) = 0$

**Trial solution (separation of variables):**
$$u(x,t) = X(x)T(t)$$

Substituting into wave equation:
$$X(x)\ddot{T}(t) = v^2 \ddot{X}(x)T(t)$$

$$\frac{\ddot{T}}{T} = v^2\frac{\ddot{X}}{X} = -\omega^2$$

(Separation constant must be negative for oscillatory solutions)

**Spatial equation:**
$$\ddot{X} + k^2 X = 0$$

where $k = \omega/v$.

**Solution:** $X(x) = A\sin(kx) + B\cos(kx)$

**Apply boundary conditions:**
- $X(0) = 0$: $B = 0$
- $X(L) = 0$: $A\sin(kL) = 0$

For non-trivial solution: $\sin(kL) = 0$, so $kL = n\pi$ where $n = 1, 2, 3, ...$

**Allowed wave numbers:**
$$k_n = \frac{n\pi}{L}$$

**Allowed frequencies:**
$$\omega_n = v k_n = \frac{n\pi v}{L}, \quad f_n = \frac{nv}{2L}$$

**Standing wave modes:**
$$u_n(x,t) = A_n\sin\left(\frac{n\pi x}{L}\right)\cos(\omega_n t + \phi_n)$$

### Example 4: Guitar String

A guitar string of length $L = 0.65$ m has wave speed $v = 400$ m/s. Find the fundamental frequency and first three harmonics.

**Solution:**

**Fundamental** ($n = 1$):
$$f_1 = \frac{v}{2L} = \frac{400}{2(0.65)} = 308 \text{ Hz}$$

**Second harmonic** ($n = 2$):
$$f_2 = 2f_1 = 616 \text{ Hz}$$

**Third harmonic** ($n = 3$):
$$f_3 = 3f_1 = 924 \text{ Hz}$$

**Answer:** $f_1 = 308$ Hz (fundamental), $f_2 = 616$ Hz, $f_3 = 924$ Hz

## Energy in Waves

**Energy density** (energy per unit length):

**Kinetic:** $dK = \frac{1}{2}\mu dx \left(\frac{\partial u}{\partial t}\right)^2$

**Potential:** $dU = \frac{1}{2}T dx \left(\frac{\partial u}{\partial x}\right)^2$

**Total energy density:**
$$\mathcal{E} = \frac{1}{2}\mu\left(\frac{\partial u}{\partial t}\right)^2 + \frac{1}{2}T\left(\frac{\partial u}{\partial x}\right)^2$$

For harmonic wave $u = A\cos(kx - \omega t)$:
$$\mathcal{E} = \frac{1}{2}\mu\omega^2 A^2\sin^2(kx-\omega t) + \frac{1}{2}Tk^2A^2\sin^2(kx-\omega t)$$

Using $\omega = vk$ and $v^2 = T/\mu$:
$$\mathcal{E} = \mu\omega^2 A^2\sin^2(kx-\omega t)$$

**Time-averaged energy density:**
$$\langle\mathcal{E}\rangle = \frac{1}{2}\mu\omega^2 A^2$$

**Power transmitted:**
$$P = \mathcal{E} \cdot v = \frac{1}{2}\mu v\omega^2 A^2$$

### Example 5: Power in Wave

A wave on string ($\mu = 0.01$ kg/m, $v = 50$ m/s) has amplitude $A = 0.02$ m and frequency $f = 100$ Hz. Find average power transmitted.

**Solution:**

$$\omega = 2\pi f = 2\pi(100) = 628 \text{ rad/s}$$

$$P = \frac{1}{2}\mu v\omega^2 A^2 = \frac{1}{2}(0.01)(50)(628)^2(0.02)^2$$

$$= \frac{1}{2}(0.01)(50)(394400)(0.0004) = 39.4 \text{ W}$$

**Answer:** $P = 39.4$ W

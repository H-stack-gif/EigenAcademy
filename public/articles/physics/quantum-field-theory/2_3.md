# Quantum Field Theory Topic 2.3: Feynman Diagrams and Rules

Wick's theorem reduces time-ordered products to sums of contractions—products of propagators. But keeping track of all possible contractions and their combinatorial factors becomes unwieldy beyond the simplest cases. **Feynman diagrams** provide the solution: a graphical language where each mathematical term corresponds to a picture. Lines represent propagators (contractions), vertices represent interaction points from $\hat{H}_{int}$, and external lines represent incoming/outgoing particles. The Dyson series expansion becomes a systematic enumeration of diagrams, and each diagram has **Feynman rules** prescribing exactly which mathematical expression it represents. This isn't merely a calculational trick—Feynman diagrams encode the physics of scattering processes, revealing which virtual particle exchanges contribute and how quantum corrections emerge from loops.

Different theories have different Feynman rules, but the general structure remains universal. For $\phi^4$ theory with $\hat{H}_{int} = \frac{\lambda}{4!}\int d^3x \, \phi^4$, vertices have four legs meeting at a spacetime point, internal lines are scalar propagators $i/(p^2 - m^2 + i\epsilon)$, and external lines represent asymptotic particle states. Tree diagrams (no loops) give classical scattering, while loop diagrams introduce quantum corrections—and ultraviolet divergences requiring renormalization. **Symmetry factors** account for diagram automorphisms, and **connected diagrams** dominate physical processes. The topology of diagrams—their connectivity structure—determines their physical interpretation.

This article develops Feynman diagrams from their graphical definition through the Feynman rules to practical calculations. We'll construct Feynman rules for $\phi^4$ theory, understand internal vs. external lines, compute tree-level amplitudes, recognize loop diagrams, calculate symmetry factors, distinguish connected from disconnected graphs, and see how diagram topology encodes physics.

## Feynman Diagram Elements

### Example 1: Basic Diagram Components

Define the graphical elements of Feynman diagrams for $\phi^4$ theory.

**Solution:**

**Interaction vertex**: Four lines meeting at a point.
```
    |
    |
----+----
    |
    |
```
Represents: $\frac{-i\lambda}{4!}$ at spacetime point $x$.

From $\hat{H}_{int} = \frac{\lambda}{4!}\int d^4x \, \phi^4(x)$, each $\phi$ becomes a line.

**Propagator** (internal line):
```
----->-----
```
Represents: $\frac{i}{p^2 - m^2 + i\epsilon}$ in momentum space.

This is a contraction $\wick{\c\phi(x)\c\phi(y)} = D_F(x-y)$.

Arrow indicates momentum direction (convention; not physical for scalars).

**External line** (incoming/outgoing particle):
```
-----> (incoming: momentum $p$, on-shell $p^2 = m^2$)
<----- (outgoing: momentum $p$, on-shell $p^2 = m^2$)
```

Represents asymptotic free particle states. Not propagators—external legs are "amputated" in amplitude.

**Answer:** Diagrams: Vertices ($-i\lambda/4!$), propagators ($i/(p^2-m^2+i\epsilon)$), external lines (particles).

### Example 2: Feynman Rules for φ⁴ Theory

State the complete Feynman rules in momentum space.

**Solution:**

**Feynman rules for $\phi^4$ theory** (momentum space):

1. **External lines**: Draw one line per initial/final particle, label momentum $p_i$.

2. **Vertices**: Draw $-i\lambda/4!$ at each 4-point vertex.

3. **Internal propagators**: $\frac{i}{p^2 - m^2 + i\epsilon}$ for each internal line with momentum $p$.

4. **Momentum conservation**: At each vertex, impose $\delta^4(\sum p_i)$ (sum of momenta = 0).

5. **Integration**: For each internal momentum not fixed by conservation, integrate $\int \frac{d^4p}{(2\pi)^4}$.

6. **Symmetry factor**: Divide by $S$ (symmetry factor of diagram).

7. **Overall factor**: $(2\pi)^4\delta^4(P_f - P_i)$ (overall momentum conservation).

Result: **Invariant amplitude** $i\mathcal{M}$.

For scattering $a + b \to c + d$:
$$i\mathcal{M} = (\text{sum of all connected diagrams})$$

**Answer:** Rules: Vertices ($-i\lambda/4!$), propagators ($i/(p^2-m^2+i\epsilon)$), momentum conservation, integrate internal momenta.

## Tree-Level Diagrams

### Example 3: 2→2 Scattering at Tree Level

Calculate the tree-level amplitude for $\phi + \phi \to \phi + \phi$ scattering.

**Solution:**

**Tree-level**: Diagrams with no loops (lowest order in $\lambda$).

For 2→2 scattering, only one tree diagram:
```
  p₁ ----\    /---- p₃
          \  /
           \/
           /\
          /  \
  p₂ ----/    \---- p₄
```

All four momenta meet at a single vertex.

**Feynman rules**:
- Vertex: $-i\lambda/4!$
- Momentum conservation: $(2\pi)^4\delta^4(p_1 + p_2 - p_3 - p_4)$
- No internal propagators (tree diagram)

**Amplitude**:
$$i\mathcal{M}_{tree} = -i\lambda$$

(The $1/4!$ combines with symmetry factor $4! = 24$ from permuting identical external lines.)

**Cross section** (center-of-mass frame):
$$\frac{d\sigma}{d\Omega} = \frac{\lambda^2}{64\pi^2 s}$$

where $s = (p_1 + p_2)^2$ (Mandelstam variable).

Simple! This is **classical scattering** at leading order.

**Answer:** Tree-level 2→2: $\mathcal{M} = -\lambda$ (single vertex, no propagators).

### Example 4: Higher-Order Tree Diagrams

Construct tree diagrams for 2→4 process.

**Solution:**

2→4 scattering: Two incoming, four outgoing particles.

**Tree diagrams**: Two vertices connected by one propagator.

Example diagram:
```
  p₁ ----\         /---- p₃
          \       /
           \-----/ ---- p₄
           /     \
          /       \
  p₂ ----/         \---- p₅
                    \---- p₆
```

Two vertices: $(-i\lambda/4!)^2 = -\lambda^2/(4!)^2$

Internal propagator: $\frac{i}{q^2 - m^2 + i\epsilon}$ where $q = p_1 + p_2 - p_3$ (or similar).

**Amplitude**:
$$i\mathcal{M} = \frac{(-i\lambda)^2}{(4!)^2} \cdot \frac{i}{q^2 - m^2 + i\epsilon} \cdot (\text{symmetry factors})$$

Multiple diagrams contribute (different ways to connect particles to vertices).

**Higher order in $\lambda$**: More vertices → more complex processes.

**Answer:** 2→4 tree: Two vertices, one propagator, amplitude $\sim \lambda^2/(q^2-m^2)$.

## Loop Diagrams and Quantum Corrections

### Example 5: One-Loop Diagram Structure

Identify the simplest loop diagram in $\phi^4$ theory.

**Solution:**

**One-loop diagram**: Simplest quantum correction.

Example: 2→2 scattering with loop correction.
```
  p₁ ----\         /---- p₃
          \   +---+   /
           \  |   |  /
            \-+---+-/
            / |   | \
           /  +---+  \
  p₂ ----/         \---- p₄
```

Two vertices connected by **two propagators forming a loop**.

**Loop momentum** $k$: Not fixed by external momenta, must integrate.

**Amplitude**:
$$i\mathcal{M}_{loop} = \frac{(-i\lambda)^2}{(4!)^2}\int\frac{d^4k}{(2\pi)^4}\frac{i}{k^2 - m^2 + i\epsilon}\cdot\frac{i}{(p_1 - k)^2 - m^2 + i\epsilon}$$

This integral is **divergent** as $k \to \infty$ (UV divergence)!

**Physical interpretation**:
- Virtual particle created and annihilated
- Quantum fluctuation in vacuum
- Correction to tree-level amplitude

Loops require **renormalization** (handled in Unit 5).

**Answer:** One-loop: Two propagators forming closed path, integral over loop momentum, UV divergent.

## Symmetry Factors and Topology

### Example 6: Symmetry Factor Calculation

Calculate the symmetry factor for a vacuum bubble diagram.

**Solution:**

**Vacuum bubble**: Diagram with no external lines.
```
  +---+
  |   |
  +---+
```

Two vertices connected by two propagators, forming a closed loop.

**Automorphisms**: Symmetries of the diagram.
1. Exchange two vertices: Factor of $2!$
2. Exchange two propagators: Factor of $2!$

Total automorphisms: $S = 2! \times 2! = 4$

**Rule**: Divide amplitude by $S$ to avoid overcounting.

From Dyson series:
$$\frac{(-i)^2}{2!}\left(\frac{\lambda}{4!}\right)^2\int d^4x_1 d^4x_2 \, T[\phi^4(x_1)\phi^4(x_2)]$$

Wick contractions create multiple equivalent diagrams → symmetry factor removes redundancy.

For **physical diagrams** with distinct external particles, symmetry factors are usually 1.

**Answer:** Symmetry factor $S$ = number of diagram automorphisms (exchanges leaving diagram invariant).

### Example 7: Connected vs. Disconnected Diagrams

Distinguish connected and disconnected diagrams.

**Solution:**

**Connected diagram**: All parts joined by propagators.
```
  p₁ ----\    /---- p₃
          \  /
           \/
           /\
          /  \
  p₂ ----/    \---- p₄
```
(One connected piece.)

**Disconnected diagram**: Separates into independent subdiagrams.
```
  p₁ ----\    /---- p₃
          \  /
           \/
           
           
  p₂ ----\    /---- p₄
          \  /
           \/
```
(Two separate 2→2 scatterings, no interaction between them.)

**Physical importance**:
- Connected: Describes actual scattering $a + b \to c + d$
- Disconnected: Product of independent processes (factorizes)

**S-matrix**:
$$\langle f|\hat{S}|i\rangle = \text{connected} + \text{disconnected}$$

**LSZ formula** (next topic): Only connected diagrams contribute to scattering amplitude $\mathcal{M}$.

Disconnected diagrams cancel in cross section calculations.

**Answer:** Connected diagrams: All external lines linked by propagators, describe true interactions.

## Answer Key

**Problem 1: C**
Vertex: Factor $-i\lambda/4!$
From interaction Hamiltonian $\hat{H}_{int} = \frac{\lambda}{4!}\int d^4x \phi^4$
Four legs meeting at point
Each $\phi$ becomes a line in diagram
Coupling constant $\lambda$ determines strength

**Problem 2: B**
Internal propagators: Off-shell $p^2 \neq m^2$
Virtual particles (not real asymptotic states)
Momentum not constrained by mass-shell condition
External lines: On-shell $p^2 = m^2$ (real particles)
Internal: Integrated over, external: Fixed

**Problem 3: C**
Tree diagrams: No closed loops
Lowest order in coupling (classical)
$\mathcal{O}(\lambda^n)$ where $n$ = number of vertices
No loop integrals (finite)
Give leading contribution to scattering

**Problem 4: B**
Loops: Integral $\int d^4k$ over loop momentum
UV divergent as $k \to \infty$
Quantum corrections to tree-level
Order $\hbar$ (vanish in classical limit)
Require renormalization to make sense

**Problem 5: B**
Symmetry factor $S$: Divide by number of automorphisms
Prevents overcounting equivalent Wick contractions
Example: Vacuum bubble $S = 4$
Diagrams with distinct external particles: $S = 1$ typically
Combinatorics from Dyson series expansion

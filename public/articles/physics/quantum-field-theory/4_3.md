# Quantum Field Theory Topic 4.3: Grassmann Path Integrals for Fermions

Fermions—electrons, quarks, neutrinos—obey anticommutation relations $\{\hat{\psi}_a, \hat{\psi}^\dagger_b\} = \delta_{ab}$, fundamentally different from bosonic commutation. How do we formulate path integrals for fermions? Classical fermionic fields can't be ordinary c-numbers since that would give commutation, not anticommutation. The solution: **Grassmann variables**—anticommuting numbers satisfying $\theta_i\theta_j = -\theta_j\theta_i$, which immediately implies $\theta^2 = 0$ (any Grassmann variable squared vanishes). These bizarre mathematical objects provide the classical analog of fermionic operators, enabling path integral quantization of spinor fields. Grassmann integration, defined through **Berezin integration** rules $\int d\theta = 0$ and $\int d\theta \, \theta = 1$, has properties opposite to ordinary integration—differentiation and integration are identical operations.

The fermionic path integral $Z[\bar{\eta}, \eta] = \int \mathcal{D}\bar{\psi}\mathcal{D}\psi \, e^{i\int[\bar{\psi}(i\not\!\partial - m)\psi + \bar{\eta}\psi + \bar{\psi}\eta]}$ generates fermionic correlation functions through Grassmann functional derivatives. For free fermions, the Gaussian Grassmann integral yields the fermion propagator $S_F(x-y)$. But there's a crucial sign difference from bosons: fermionic path integrals give **determinants** rather than inverse determinants. A fermion loop contributes $\det(i\not\!\partial - m)$ while a boson loop gives $\det^{-1}(-\Box - m^2)$. This explains the **extra minus sign** from fermion loops in Feynman diagrams—it's built into the Grassmann integration measure. Understanding Grassmann integration is essential for any serious study of QED, QCD, or the Standard Model.

This article develops Grassmann path integrals from Grassmann algebra through Berezin integration to fermionic generating functionals. We'll define Grassmann variables and their algebra, establish Berezin integration rules, construct the fermionic path integral, compute the fermion propagator, understand determinants vs. inverse determinants, derive the fermion loop minus sign, handle Grassmann functional derivatives, and see how this formalism reproduces canonical anticommutation relations.

## Grassmann Algebra and Anticommutation

Grassmann variables provide the mathematical framework for classical fermionic fields, embodying anticommutation at the classical level.

### Example 1: Grassmann Variable Definition

Define Grassmann variables and their anticommutation properties.

**Solution:**

**Grassmann numbers** $\{\theta_1, \theta_2, \ldots, \theta_n\}$ satisfy:
$$\theta_i\theta_j = -\theta_j\theta_i \quad \text{for all } i, j$$

**Consequences**:
$$\theta_i^2 = -\theta_i^2 \implies \theta_i^2 = 0$$

Any Grassmann variable **squared vanishes**.

**Grassmann algebra**: Generated by $\theta_i$ and ordinary c-numbers.

General element:
$$f(\theta) = a_0 + \sum_i a_i\theta_i + \sum_{i<j}a_{ij}\theta_i\theta_j + \cdots$$

Maximum degree = $n$ (can't have $\theta^{n+1}$ terms—some $\theta_i$ would repeat).

**Two Grassmann variables**:
$$f(\theta_1, \theta_2) = a + b\theta_1 + c\theta_2 + d\theta_1\theta_2$$

Only 4 independent terms (Taylor series terminates).

**Properties**:
- Nilpotent: $\theta^n = 0$ for $n \geq 2$
- Anticommute with each other
- Commute with c-numbers: $\alpha\theta = \theta\alpha$

**Physical role**: Classical fermionic fields $\psi(x), \bar{\psi}(x)$ are Grassmann-valued.

$$\psi_a(x)\psi_b(y) = -\psi_b(y)\psi_a(x)$$

**Answer:** Grassmann variables: $\theta_i\theta_j = -\theta_j\theta_i$, implies $\theta^2 = 0$ (anticommutation algebra).

### Example 2: Grassmann Derivatives

Define differentiation for Grassmann variables.

**Solution:**

**Left derivative**: $\frac{\partial}{\partial\theta_i}$ acting from left.

**Rules**:
1. $\frac{\partial\theta_i}{\partial\theta_j} = \delta_{ij}$

2. $\frac{\partial\theta_i\theta_j}{\partial\theta_k} = \delta_{ik}\theta_j - \delta_{jk}\theta_i$ (anticommute past other $\theta$'s)

**Leibniz rule** (with sign):
$$\frac{\partial}{\partial\theta}(AB) = \left(\frac{\partial A}{\partial\theta}\right)B + (-1)^{|A|}A\left(\frac{\partial B}{\partial\theta}\right)$$

where $|A|$ is the Grassmann degree of $A$ (0 for c-number, 1 for single $\theta$, etc.).

**Example**:
$$\frac{\partial}{\partial\theta_1}(\theta_1\theta_2) = \theta_2$$

$$\frac{\partial}{\partial\theta_2}(\theta_1\theta_2) = -\theta_1$$

(Sign from anticommutation!)

**Higher derivatives**:
$$\frac{\partial^2}{\partial\theta_i\partial\theta_j} = -\frac{\partial^2}{\partial\theta_j\partial\theta_i}$$

**Exponentials** (finite Taylor series):
$$e^{\theta_1\theta_2} = 1 + \theta_1\theta_2$$

**Answer:** Grassmann derivative: $\frac{\partial\theta_i}{\partial\theta_j} = \delta_{ij}$, anticommutes past other variables with signs.

## Berezin Integration

Grassmann integration has bizarre but consistent properties, opposite to ordinary integration in key respects.

### Example 3: Berezin Integration Rules

Define integration for Grassmann variables.

**Solution:**

**Berezin integration** over single Grassmann variable $\theta$:

**Definition**:
$$\int d\theta = 0, \quad \int d\theta \, \theta = 1$$

These two rules define the integral completely (since any function is $f(\theta) = a + b\theta$).

**Key property**: Integration = differentiation!
$$\int d\theta \, \theta = \frac{\partial\theta}{\partial\theta} = 1$$

**Multiple variables**: Integrate one at a time.
$$\int d\theta_1 d\theta_2 \, \theta_1\theta_2 = \int d\theta_1 \, \theta_1 \int d\theta_2 \, \theta_2 = 1 \cdot 1 = 1$$

**Anticommutation of measures**:
$$d\theta_1 d\theta_2 = -d\theta_2 d\theta_1$$

So:
$$\int d\theta_1 d\theta_2 \, \theta_2\theta_1 = -\int d\theta_1 d\theta_2 \, \theta_1\theta_2 = -1$$

**Change of variables**: $\theta' = a\theta$ (c-number $a$)
$$\int d\theta' \, \theta' = \int d(a\theta) \, a\theta = \frac{1}{a}\int d\theta \, a\theta = 1$$

Jacobian: $d\theta' = \frac{1}{a}d\theta$ (inverse of ordinary integration!).

**Answer:** Berezin: $\int d\theta = 0$, $\int d\theta \, \theta = 1$ (integration = differentiation).

### Example 4: Gaussian Grassmann Integrals

Evaluate Gaussian integrals over Grassmann variables.
    
**Solution:**

**Single variable**:
$$\int d\theta d\bar{\theta} \, e^{-\bar{\theta}A\theta} = \int d\theta d\bar{\theta}(1 - \bar{\theta}A\theta)$$

(Exponential truncates: $(\bar{\theta}\theta)^2 = 0$)

$$= -A\int d\theta d\bar{\theta} \, \bar{\theta}\theta = -A \cdot 1 = -A$$

Notice: convention matters. Typically:
$$\int d\bar{\theta}d\theta \, e^{-\bar{\theta}A\theta} = A$$

(Order of integration defines sign.)

**Multiple variables** $\{\theta_i, \bar{\theta}_i\}_{i=1}^n$:
$$\int \prod_i d\bar{\theta}_i d\theta_i \, e^{-\bar{\theta}_i A_{ij}\theta_j} = \det(A)$$

Compare to bosons:
$$\int \prod_i dx_i \, e^{-x_i A_{ij}x_j/2} \propto \det(A)^{-1/2}$$

**Fermions give determinant**, bosons give **inverse determinant**!

**Physical meaning**: Fermion loops contribute $\det$, boson loops $\det^{-1}$ in path integrals.

**Answer:** Gaussian Grassmann: $\int d\bar{\theta}d\theta \, e^{-\bar{\theta}A\theta} = \det(A)$ (determinant, not inverse).

## Fermionic Path Integrals

### Example 5: Free Fermion Path Integral

Construct the path integral for free Dirac fermions.

**Solution:**

**Dirac action** (Euclidean for simplicity):
$$S_E[\bar{\psi}, \psi] = \int d^4x_E \, \bar{\psi}(x)(\gamma_\mu\partial_\mu + m)\psi(x)$$

**Path integral**:
$$Z_0 = \int \mathcal{D}\bar{\psi}\mathcal{D}\psi \, e^{-S_E[\bar{\psi}, \psi]}$$

where $\mathcal{D}\bar{\psi}\mathcal{D}\psi = \prod_{x, a}d\bar{\psi}_a(x)d\psi_a(x)$ (Grassmann measure).

**Gaussian form**: Action quadratic in fermions.
$$S_E = \int d^4x d^4y \, \bar{\psi}(x)D^{-1}(x, y)\psi(y)$$

where $D^{-1}(x, y) = (\gamma_\mu\partial_\mu + m)\delta^4(x-y)$.

**Grassmann Gaussian integral**:
$$Z_0 = \det(D^{-1}) = \det(\gamma_\mu\partial_\mu + m)$$

**Contrast with bosons**:
- Bosons: $Z_0 \propto \det^{-1/2}(-\Box - m^2)$ (inverse determinant)
- Fermions: $Z_0 \propto \det(\gamma_\mu\partial_\mu + m)$ (determinant)

**Fermion loop**: Closed fermion loop in Feynman diagram contributes $\det$, giving $(-1)$ relative to bosons (from ratio of determinants).

**Answer:** Free fermion path integral: $Z_0 = \int \mathcal{D}\bar{\psi}\mathcal{D}\psi \, e^{-\bar{\psi}D^{-1}\psi} = \det(D^{-1})$ (determinant).

### Example 6: Fermion Propagator from Path Integral

Derive the fermion propagator using Grassmann sources.

**Solution:**

**Add sources**: $\bar{\eta}(x), \eta(x)$ (Grassmann-valued).

$$Z[\bar{\eta}, \eta] = \int \mathcal{D}\bar{\psi}\mathcal{D}\psi \, e^{-\bar{\psi}D^{-1}\psi + \bar{\eta}\psi + \bar{\psi}\eta}$$

**Complete the square**:
$$-\bar{\psi}D^{-1}\psi + \bar{\eta}\psi + \bar{\psi}\eta = -(\bar{\psi} - \bar{\eta}D)D^{-1}(\psi - D\eta) + \bar{\eta}D\eta$$

**Shift**: $\psi' = \psi - D\eta$, $\bar{\psi}' = \bar{\psi} - \bar{\eta}D$

$$Z[\bar{\eta}, \eta] = \det(D^{-1})e^{\bar{\eta}D\eta}$$

**Fermion propagator**: Grassmann functional derivative.
$$S_F(x, y) = \langle\psi(x)\bar{\psi}(y)\rangle = \frac{1}{Z_0}\frac{\delta}{\delta\eta(x)}\frac{\delta}{\delta\bar{\eta}(y)}Z[\bar{\eta}, \eta]\bigg|_{\eta=\bar{\eta}=0}$$

$$= \frac{\delta}{\delta\eta(x)}\frac{\delta}{\delta\bar{\eta}(y)}e^{\bar{\eta}D\eta}\bigg|_{\eta=0} = D(x, y)$$

So: $S_F(x-y) = D(x-y)$ where $D$ is the kernel of $(\gamma_\mu\partial_\mu + m)^{-1}$.

**Momentum space**:
$$S_F(p) = \frac{i(\gamma_\mu p_\mu + m)}{p^2 - m^2 + i\epsilon}$$

**Answer:** Fermion propagator from path integral: $S_F = \frac{\delta^2 Z}{\delta\eta\delta\bar{\eta}}\big|_{\eta=0}$, gives $\frac{i(\not\!p+m)}{p^2-m^2+i\epsilon}$.

### Example 7: Fermion Loop Minus Sign

Explain the origin of the fermion loop $(-1)$ factor.

**Solution:**

**Fermion loop**: Closed fermion path in Feynman diagram.

**Path integral**: Trace over fermion propagators.
$$\text{Loop} = \int d^4x \, \text{Tr}[S_F(x-x)] = \text{Tr}\left[\int\frac{d^4p}{(2\pi)^4}S_F(p)\right]$$

**From Grassmann integration**: Fermion path integral gives $\det(D^{-1})$.

Compare boson loop (propagator product) vs. fermion loop (trace of propagator):

**Boson**: $\ln Z_{\text{boson}} = -\frac{1}{2}\text{Tr}\ln(D_{\text{boson}}^{-1})$

One-loop: $\sim \int \frac{d^4p}{(2\pi)^4}\ln D_{\text{boson}}(p)$

**Fermion**: $\ln Z_{\text{fermion}} = \text{Tr}\ln(D_{\text{fermion}}^{-1})$

One-loop: $\sim \int \frac{d^4p}{(2\pi)^4}\ln D_{\text{fermion}}(p)$

**Relative sign**: Fermion loop has **opposite sign** from boson loop.

In Feynman rules: Fermion loop contributes $(-1) \times (\text{trace of propagators})$.

**Origin**: Grassmann integration gives $\det$ not $\det^{-1}$, plus trace over spinor indices with anticommutation.

**Answer:** Fermion loop $(-1)$: From Grassmann integration giving $\det$ instead of $\det^{-1}$, built into fermion path integral measure.

## Answer Key

**Problem 1: B**
Grassmann: $\theta_i\theta_j = -\theta_j\theta_i$ (anticommutation)
Classical analog of fermion operators
Different from c-numbers (commute)
Implies $\theta^2 = 0$ (nilpotent)
Foundation for fermionic path integrals

**Problem 2: C**
$\theta^2 = 0$ for any Grassmann variable
From anticommutation: $\theta^2 = -\theta^2 \implies \theta^2 = 0$
All products with repeated $\theta$ vanish
Taylor series terminate (no $\theta^n$ for $n \geq 2$)
Essential property

**Problem 3: C**
Berezin: $\int d\theta = 0$ (integral of constant)
$\int d\theta \, \theta = 1$ (integral of linear term)
These two rules define integration completely
Integration = differentiation for Grassmann
Opposite to ordinary calculus

**Problem 4: C**
Gaussian Grassmann: $\int d\bar{\theta}d\theta \, e^{-\bar{\theta}A\theta} = \det(A)$
Determinant (not inverse!)
Opposite to bosons: $\int dx \, e^{-xAx/2} \propto \det(A)^{-1/2}$
Crucial for fermion loops
Multiple variables: $\det$ of matrix

**Problem 5: B**
Fermion loops: Factor of $(-1)$ relative to bosons
From Grassmann integration $\det$ vs. boson $\det^{-1}$
Trace over spinor indices with anticommutation
Built into path integral measure
Essential for cancellations (anomalies)

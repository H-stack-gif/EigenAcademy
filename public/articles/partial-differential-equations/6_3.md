# Partial Differential Equations Topic 6.3: Polar Coordinates

A circular disk has temperature specified around its circumference. What is the steady-state temperature inside? Rectangular coordinates are useless here—the circular boundary doesn't align with $x$ and $y$ axes. **Polar coordinates** $(r, \theta)$ are the natural choice, transforming Laplace's equation into a form where separation of variables works beautifully for circular geometry.

In polar coordinates, Laplace's equation becomes $u_{rr} + \frac{1}{r}u_r + \frac{1}{r^2}u_{\theta\theta} = 0$. Separation yields two ODEs: one for the angular variation ($\Theta'' + n^2\Theta = 0$, giving trigonometric functions) and one for the radial variation (Euler equation, giving power-law solutions $r^n$). The periodicity condition $u(r, \theta) = u(r, \theta + 2\pi)$ quantizes the angular frequencies.

This article develops Laplace's equation in polar coordinates from scratch. We'll derive the transformed PDE, separate variables, understand why only integer powers appear, solve the Dirichlet problem for a disk, and extend to annular regions (rings). These methods are essential for any problem with circular or spherical symmetry—from electrostatics around cylinders to temperature in circular plates.

## Laplace's Equation in Polar Coordinates

### Example 1: Coordinate Transformation

Polar coordinates: $x = r\cos\theta$, $y = r\sin\theta$

Transform $\nabla^2 u = u_{xx} + u_{yy}$ to polar form.

**Solution:**

Using chain rule (tedious but straightforward):
$$u_x = u_r\cos\theta - \frac{u_\theta\sin\theta}{r}$$
$$u_y = u_r\sin\theta + \frac{u_\theta\cos\theta}{r}$$

Computing second derivatives and simplifying:
$$u_{xx} + u_{yy} = u_{rr} + \frac{1}{r}u_r + \frac{1}{r^2}u_{\theta\theta}$$

**Laplace's equation in polar coordinates**:
$$\nabla^2 u = u_{rr} + \frac{1}{r}u_r + \frac{1}{r^2}u_{\theta\theta} = 0$$

**Answer:** $u_{rr} + \frac{1}{r}u_r + \frac{1}{r^2}u_{\theta\theta} = 0$

### Example 2: Separation of Variables

Assume $u(r, \theta) = R(r)\Theta(\theta)$.

**Solution:**

Substitute into Laplace's equation:
$$R''\Theta + \frac{1}{r}R'\Theta + \frac{1}{r^2}R\Theta'' = 0$$

Multiply by $r^2/(R\Theta)$:
$$\frac{r^2R'' + rR'}{R} + \frac{\Theta''}{\Theta} = 0$$

$$\frac{r^2R'' + rR'}{R} = -\frac{\Theta''}{\Theta} = \lambda$$

**Two ODEs**:
$$\Theta'' + \lambda\Theta = 0$$
$$r^2R'' + rR' - \lambda R = 0$$

**Answer:** Angular ODE: $\Theta'' + \lambda\Theta = 0$; Radial ODE: $r^2R'' + rR' - \lambda R = 0$

### Example 3: Periodicity Condition

$u(r, \theta)$ must be periodic: $u(r, \theta + 2\pi) = u(r, \theta)$

What does this imply for $\Theta$?

**Solution:**

$$\Theta(\theta + 2\pi) = \Theta(\theta)$$

For $\Theta'' + \lambda\Theta = 0$:

**Only $\lambda = n^2$ (perfect squares) work!**

$$\Theta_n(\theta) = A_n\cos(n\theta) + B_n\sin(n\theta)$$

with $n = 0, 1, 2, 3, \ldots$

**Answer:** Periodicity requires $\lambda = n^2$, integer $n$

### Example 4: Radial Solutions

For $\lambda = n^2$, solve $r^2R'' + rR' - n^2R = 0$.

**Solution:**

This is **Euler equation**. Try $R = r^m$:
$$r^2 \cdot m(m-1)r^{m-2} + r \cdot mr^{m-1} - n^2r^m = 0$$
$$m(m-1) + m - n^2 = 0$$
$$m^2 = n^2$$
$$m = \pm n$$

**General solution**:
$$R_n(r) = C_nr^n + D_nr^{-n}$$

**For $n = 0$**: $R_0 = C_0 + D_0\ln r$

**Answer:** $R_n = C_nr^n + D_nr^{-n}$ (or $C_0 + D_0\ln r$ for $n=0$)

## Dirichlet Problem on Disk

### Example 5: Disk of Radius $a$

Find $u(r, \theta)$ inside disk $r < a$ with $u(a, \theta) = f(\theta)$.

**Solution:**

**Product solutions**:
$$u_n(r, \theta) = r^n[A_n\cos(n\theta) + B_n\sin(n\theta)]$$

(Drop $r^{-n}$ term—would blow up at origin!)

**General solution**:
$$u(r, \theta) = \frac{a_0}{2} + \sum_{n=1}^{\infty} r^n[a_n\cos(n\theta) + b_n\sin(n\theta)]$$

**Answer:** $u = \frac{a_0}{2} + \sum r^n[a_n\cos(n\theta) + b_n\sin(n\theta)]$

### Example 6: Matching Boundary Data

Apply $u(a, \theta) = f(\theta)$:

**Solution:**

$$\frac{a_0}{2} + \sum_{n=1}^{\infty} a^n[a_n\cos(n\theta) + b_n\sin(n\theta)] = f(\theta)$$

This is **Fourier series** for $f(\theta)$!

$$a_n a^n = \frac{1}{\pi}\int_0^{2\pi} f(\theta)\cos(n\theta) \, d\theta$$

$$b_n a^n = \frac{1}{\pi}\int_0^{2\pi} f(\theta)\sin(n\theta) \, d\theta$$

$$a_n = \frac{1}{\pi a^n}\int_0^{2\pi} f(\theta)\cos(n\theta) \, d\theta$$

$$b_n = \frac{1}{\pi a^n}\int_0^{2\pi} f(\theta)\sin(n\theta) \, d\theta$$

**Answer:** Coefficients from Fourier series of $f(\theta)$, scaled by $1/a^n$

### Example 7: Specific Example

Disk of radius 1 with $f(\theta) = \cos\theta$.

**Solution:**

$$f(\theta) = \cos\theta$$ is already single Fourier term ($n = 1$).

$$a_1 = 1, \quad a_n = 0 \text{ for } n \neq 1, \quad b_n = 0 \text{ for all } n$$

Solution:
$$u(r, \theta) = r\cos\theta$$

**In Cartesian**: $u = r\cos\theta = x$ (linear function!)

**Answer:** $u(r,\theta) = r\cos\theta = x$

### Example 8: Constant Boundary

$f(\theta) = T_0$ (constant temperature on boundary).

**Solution:**

$$f(\theta) = T_0$$ has only $n = 0$ term.

$$a_0 = \frac{1}{\pi}\int_0^{2\pi} T_0 \, d\theta = 2T_0$$

All other coefficients zero.

$$u(r, \theta) = \frac{a_0}{2} = T_0$$

**Uniform** temperature throughout disk!

**Physical**: Constant boundary → constant interior (no gradients).

**Answer:** $u = T_0$ (constant everywhere)

### Example 9: Poisson Integral Formula

General solution can be written as:

**Solution:**

$$u(r, \theta) = \frac{1}{2\pi}\int_0^{2\pi} \frac{a^2 - r^2}{a^2 - 2ar\cos(\theta - \phi) + r^2} f(\phi) \, d\phi$$

This is **Poisson integral formula** for disk.

**Kernel**: $P_r(\theta - \phi) = \frac{a^2 - r^2}{a^2 - 2ar\cos(\theta - \phi) + r^2}$ (Poisson kernel)

**Properties**:
- $P_r \geq 0$
- $\int_0^{2\pi} P_r d\phi = 2\pi$
- As $r \to a$, $P_r$ concentrates near $\phi = \theta$

**Answer:** Poisson formula expresses solution as integral of boundary data

## Annular Regions

### Example 10: Ring: $a < r < b$

Temperature specified on both inner ($r = a$) and outer ($r = b$) circles.

**Solution:**

Now **keep both** $r^n$ and $r^{-n}$ terms!

$$u(r, \theta) = \frac{a_0 + c_0\ln r}{2} + \sum_{n=1}^{\infty} [(a_nr^n + c_nr^{-n})\cos(n\theta) + (b_nr^n + d_nr^{-n})\sin(n\theta)]$$

**Four coefficients per mode** (match two boundary conditions).

**Complexity**: Fourier series on inner AND outer boundaries.

**Answer:** General form includes both $r^n$ and $r^{-n}$ terms

### Example 11: Logarithmic Term

When does $\ln r$ term appear?

**Solution:**

For $n = 0$ mode: $R_0 = C_0 + D_0\ln r$

**Appears when**:
- Annular region (two boundaries)
- Or when solution not required to be bounded at origin

**Physical example**: Coaxial cylinders with different voltages.

**Answer:** $\ln r$ term appears for $n=0$ mode in annular regions

### Example 12: Axisymmetric Solution

If $f(\theta)$ constant (independent of $\theta$):

**Solution:**

Only $n = 0$ mode excited.

**Disk**: $u = \text{const}$

**Annulus**: $u = A + B\ln r$

Match boundaries:
$$u(a) = f_a, \quad u(b) = f_b$$

$$A + B\ln a = f_a$$
$$A + B\ln b = f_b$$

$$B = \frac{f_b - f_a}{\ln(b/a)}, \quad A = f_a - B\ln a$$

**Logarithmic** variation between boundaries.

**Answer:** Axisymmetric: $u = A + B\ln r$

### Example 13: Multipole Expansion

Far from disk ($r \gg a$), solution behaves as:

**Solution:**

$$u(r, \theta) \approx \frac{a_0}{2} + \frac{a_1a}{r}\cos\theta + \frac{b_1a}{r}\sin\theta + O(1/r^2)$$

**Leading terms**:
- $a_0/2$: monopole (average)
- $(a_1a/r)\cos\theta + (b_1a/r)\sin\theta$: dipole
- Higher terms: quadrupole, octupole, ...

**Physics**: Far-field expansion in electrostatics/gravity.

**Answer:** Far-field: multipole expansion, decays as powers of $1/r$

## Practice Problems

**Problem 1:** Laplace's equation in polar coordinates is:

A) $u_{rr} + u_{\theta\theta} = 0$
B) $u_{rr} + \frac{1}{r}u_r + \frac{1}{r^2}u_{\theta\theta} = 0$
C) $\frac{1}{r}(ru_r)_r + u_{\theta\theta} = 0$
D) $u_r + u_\theta = 0$
E) $u_{rr} = 0$

**Problem 2:** Periodicity requires eigenvalues:

A) $\lambda = n$ (any real)
B) $\lambda = n^2$ (perfect squares)
C) $\lambda < 0$ only
D) $\lambda = n!$
E) Any $\lambda$

**Problem 3:** Radial solutions for $\lambda = n^2$ are:

A) $\sin(nr)$, $\cos(nr)$
B) $e^{nr}$, $e^{-nr}$
C) $r^n$, $r^{-n}$
D) $J_n(r)$
E) Polynomials

**Problem 4:** For disk (bounded at origin), keep:

A) Both $r^n$ and $r^{-n}$
B) Only $r^n$
C) Only $r^{-n}$
D) Neither
E) $\ln r$ only

**Problem 5:** Constant boundary temperature on disk gives:

A) Linear $u$
B) Constant $u$
C) Logarithmic $u$
D) Exponential $u$
E) Periodic $u$

## Answer Key

**Problem 1: B**
Correct form: $u_{rr} + \frac{1}{r}u_r + \frac{1}{r^2}u_{\theta\theta} = 0$
Extra terms from coordinate transformation
$\frac{1}{r}u_r$ from $\nabla \cdot \nabla u$ in polar
Can also write: $\frac{1}{r}\frac{\partial}{\partial r}(r\frac{\partial u}{\partial r}) + \frac{1}{r^2}u_{\theta\theta} = 0$

**Problem 2: B**
Periodicity: $\Theta(\theta + 2\pi) = \Theta(\theta)$
$\Theta'' + \lambda\Theta = 0$ with periodicity
Solutions: $\cos(n\theta)$, $\sin(n\theta)$
Requires $\lambda = n^2$ for integer $n = 0, 1, 2, \ldots$
Non-integer $\lambda$ violates periodicity

**Problem 3: C**
Euler equation: $r^2R'' + rR' - n^2R = 0$
Try $R = r^m$: gives $m^2 = n^2$, so $m = \pm n$
Solutions: $R = Ar^n + Br^{-n}$
For $n=0$: $R = A + B\ln r$
Power-law behavior in $r$

**Problem 4: B**
Disk: solution must be bounded at $r = 0$
$r^{-n}$ blows up as $r \to 0$ (for $n > 0$)
Keep only $r^n$ terms
For $n=0$: drop $\ln r$ (unbounded at origin)
Annulus: keep both terms (no singularity concern)

**Problem 5: B**
$f(\theta) = T_0$ constant
Only $n=0$ mode: $a_0 = 2T_0$
Solution: $u = a_0/2 = T_0$ everywhere
Harmonic function with constant boundary is constant
No internal variations for uniform boundary

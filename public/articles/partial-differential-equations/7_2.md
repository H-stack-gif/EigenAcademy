# Partial Differential Equations Topic 7.2: Solving PDEs with Fourier Transform

The Fourier transform converts differential equations into algebraic equations. Consider the heat equation on an infinite line: $u_t = ku_{xx}$. Taking the Fourier transform in $x$ converts the spatial derivative $u_{xx}$ to multiplication by $-\omega^2$, leaving an ordinary differential equation in time: $\hat{u}_t = -k\omega^2\hat{u}$. This ODE is trivial to solve! Transform back, and you have the solution to the PDE.

This technique—**transform, solve, invert**—works whenever the domain is infinite or periodic and the PDE has constant coefficients. The Fourier transform is particularly powerful for problems on $(-\infty, \infty)$ where separation of variables would require continuous spectra rather than discrete eigenvalues. The method reveals the physical mechanism: each frequency component evolves independently according to simple exponential laws.

This article applies Fourier transforms to solve PDEs systematically. We'll solve the heat equation on infinite domains, tackle the wave equation and d'Alembert's formula, handle inhomogeneous problems with Green's functions, and understand dispersion relations. These techniques are essential for modern PDE theory and countless applications in physics and engineering.

## Heat Equation on Infinite Line

### Example 1: Initial Value Problem

Solve $u_t = ku_{xx}$ on $-\infty < x < \infty$, $t > 0$ with $u(x,0) = f(x)$.

**Solution:**

**Step 1**: Take Fourier transform in $x$:
$$\hat{u}_t = k\mathcal{F}\{u_{xx}\} = k(i\omega)^2\hat{u} = -k\omega^2\hat{u}$$

**Step 2**: Solve ODE in $t$:
$$\frac{d\hat{u}}{dt} = -k\omega^2\hat{u}$$

$$\hat{u}(\omega, t) = \hat{u}(\omega, 0)e^{-k\omega^2 t} = \hat{f}(\omega)e^{-k\omega^2 t}$$

**Step 3**: Inverse transform (convolution theorem):
$$u(x, t) = \frac{1}{\sqrt{4\pi kt}}\int_{-\infty}^{\infty} f(\xi)e^{-(x-\xi)^2/(4kt)} \, d\xi$$

Heat kernel solution!

**Answer:** $u = (G_t * f)(x)$ where $G_t(x) = \frac{1}{\sqrt{4\pi kt}}e^{-x^2/(4kt)}$

### Example 2: Gaussian Initial Data

$u(x,0) = e^{-x^2}$

**Solution:**

Transform: $\hat{f}(\omega) = \sqrt{\pi}e^{-\omega^2/4}$

$$\hat{u}(\omega, t) = \sqrt{\pi}e^{-\omega^2/4}e^{-k\omega^2 t} = \sqrt{\pi}e^{-\omega^2(1/4 + kt)}$$

Inverse transform (Gaussian → Gaussian):
$$u(x, t) = \frac{1}{\sqrt{1 + 4kt}}e^{-x^2/(1+4kt)}$$

**Physical**: Gaussian spreads, amplitude decreases as $1/\sqrt{1+4kt}$.

**Variance**: $\sigma^2(t) = \frac{1+4kt}{2}$ grows linearly with $t$.

**Answer:** $u(x,t) = \frac{1}{\sqrt{1+4kt}}e^{-x^2/(1+4kt)}$

### Example 3: Frequency-Domain Interpretation

Each Fourier mode $e^{i\omega x}$ evolves as:

**Solution:**

$$\hat{u}(\omega, t) = \hat{f}(\omega)e^{-k\omega^2 t}$$

**Decay rate**: $\propto e^{-k\omega^2 t}$

High frequencies decay much faster than low frequencies!

**Smoothing property**: Sharp features (high $\omega$) vanish rapidly.

**Physical**: Diffusion preferentially smooths small-scale variations.

**Answer:** Mode $\omega$ decays as $e^{-k\omega^2 t}$ (faster for larger $|\omega|$)

### Example 4: Delta Function Initial Condition

$u(x, 0) = \delta(x)$ (point source)

**Solution:**

Transform: $\hat{f}(\omega) = 1$ (constant)

$$\hat{u}(\omega, t) = e^{-k\omega^2 t}$$

Inverse transform:
$$u(x, t) = \frac{1}{2\pi}\int_{-\infty}^{\infty} e^{-k\omega^2 t}e^{i\omega x} \, d\omega$$

Complete the square:
$$= \frac{1}{2\pi}\int e^{-k\omega^2 t + i\omega x} d\omega = \frac{1}{\sqrt{4\pi kt}}e^{-x^2/(4kt)}$$

**Fundamental solution** (heat kernel)!

**Answer:** $u(x,t) = \frac{1}{\sqrt{4\pi kt}}e^{-x^2/(4kt)}$

## Wave Equation on Infinite Line

### Example 5: Wave Equation IVP

Solve $u_{tt} = c^2u_{xx}$ with $u(x,0) = f(x)$, $u_t(x,0) = g(x)$.

**Solution:**

Transform in $x$:
$$\hat{u}_{tt} = c^2(i\omega)^2\hat{u} = -c^2\omega^2\hat{u}$$

This is harmonic oscillator ODE:
$$\hat{u}_{tt} + c^2\omega^2\hat{u} = 0$$

$$\hat{u}(\omega, t) = A(\omega)\cos(c\omega t) + B(\omega)\sin(c\omega t)$$

From initial conditions:
$$\hat{u}(\omega, 0) = A(\omega) = \hat{f}(\omega)$$
$$\hat{u}_t(\omega, 0) = c\omega B(\omega) = \hat{g}(\omega)$$

$$\hat{u}(\omega, t) = \hat{f}(\omega)\cos(c\omega t) + \frac{\hat{g}(\omega)}{c\omega}\sin(c\omega t)$$

**Answer:** $\hat{u} = \hat{f}\cos(c\omega t) + \frac{\hat{g}}{c\omega}\sin(c\omega t)$

### Example 6: D'Alembert Formula via Transform

Invert solution from Example 5.

**Solution:**

Using $\cos(c\omega t) = \frac{1}{2}[e^{ic\omega t} + e^{-ic\omega t}]$:

By shift theorem: $\mathcal{F}^{-1}\{\hat{f}e^{ic\omega t}\} = f(x + ct)$

$$\mathcal{F}^{-1}\{\hat{f}\cos(c\omega t)\} = \frac{1}{2}[f(x + ct) + f(x - ct)]$$

For $g$ term (more involved):
$$\mathcal{F}^{-1}\left\{\frac{\hat{g}}{c\omega}\sin(c\omega t)\right\} = \frac{1}{2c}\int_{x-ct}^{x+ct} g(\xi) \, d\xi$$

**D'Alembert formula**:
$$u(x,t) = \frac{1}{2}[f(x+ct) + f(x-ct)] + \frac{1}{2c}\int_{x-ct}^{x+ct} g(\xi) \, d\xi$$

**Answer:** D'Alembert formula recovered via Fourier transform

### Example 7: Dispersion Relation

For wave equation, **dispersion relation** connects $\omega$ and $k$:

**Solution:**

Try solution $u = e^{i(kx - \omega t)}$ (plane wave):
$$-\omega^2 e^{i(kx-\omega t)} = c^2(-k^2)e^{i(kx-\omega t)}$$

$$\omega^2 = c^2k^2$$

$$\omega = \pm ck$$

**Phase velocity**: $v_p = \omega/k = c$ (independent of $k$)

**Non-dispersive**: All frequencies travel at same speed.

**Answer:** $\omega = ck$ (linear dispersion, non-dispersive)

## Inhomogeneous Problems

### Example 8: Heat Equation with Source

$u_t = ku_{xx} + f(x,t)$ with $u(x,0) = 0$.

**Solution:**

Transform:
$$\hat{u}_t = -k\omega^2\hat{u} + \hat{f}(\omega, t)$$

**Integrating factor**: $e^{k\omega^2 t}$

$$\frac{d}{dt}[e^{k\omega^2 t}\hat{u}] = e^{k\omega^2 t}\hat{f}(\omega, t)$$

$$\hat{u}(\omega, t) = \int_0^t e^{-k\omega^2(t-s)}\hat{f}(\omega, s) \, ds$$

**Duhamel's principle** in frequency space!

**Answer:** $\hat{u} = \int_0^t e^{-k\omega^2(t-s)}\hat{f}(\omega,s) ds$

### Example 9: Green's Function

Fundamental solution for $u_t - ku_{xx} = \delta(x)\delta(t)$.

**Solution:**

Transform:
$$\hat{u}_t + k\omega^2\hat{u} = 1 \cdot \delta(t)$$

For $t > 0$:
$$\hat{u} = H(t)e^{-k\omega^2 t}$$

where $H(t)$ is Heaviside step function.

Inverse transform:
$$G(x, t) = \begin{cases} \frac{1}{\sqrt{4\pi kt}}e^{-x^2/(4kt)} & t > 0 \\ 0 & t < 0 \end{cases}$$

**Answer:** Green's function is heat kernel for $t>0$

### Example 10: Superposition for Arbitrary Source

General solution for $u_t = ku_{xx} + f(x,t)$:

**Solution:**

$$u(x, t) = \int_0^t \int_{-\infty}^{\infty} G(x-\xi, t-s)f(\xi, s) \, d\xi \, ds$$

**Interpretation**: Sum (integral) of responses to point sources at all positions and times.

**Answer:** $u = \iint G(x-\xi, t-s)f(\xi,s) d\xi ds$

## Dispersion and Group Velocity

### Example 11: Dispersive Wave Equation

Modified wave equation: $u_{tt} + \beta u_{xxxx} = 0$ (beam equation)

**Solution:**

Try $u = e^{i(kx - \omega t)}$:
$$-\omega^2 + \beta k^4 = 0$$

$$\omega = \pm\sqrt{\beta}k^2$$

**Dispersion relation**: $\omega \propto k^2$ (nonlinear!)

**Phase velocity**: $v_p = \omega/k = \pm\sqrt{\beta}k$ (depends on $k$)

**Dispersive**: Different frequencies travel at different speeds.

**Answer:** $\omega = \sqrt{\beta}k^2$ (dispersive)

### Example 12: Group Velocity

Wave packet: superposition near wavenumber $k_0$.

**Solution:**

**Group velocity**:
$$v_g = \frac{d\omega}{dk}\bigg|_{k=k_0}$$

For $\omega = \sqrt{\beta}k^2$:
$$v_g = 2\sqrt{\beta}k_0$$

**Physical**: Envelope of wave packet travels at $v_g$, not $v_p$.

**Information** propagates at group velocity.

**Dispersion**: Wave packet spreads out over time.

**Answer:** $v_g = d\omega/dk$ (envelope velocity)

### Example 13: Schrödinger Equation

Free particle: $i\hbar\psi_t = -\frac{\hbar^2}{2m}\psi_{xx}$

**Solution:**

Transform:
$$i\hbar\hat{\psi}_t = -\frac{\hbar^2}{2m}(i\omega)^2\hat{\psi} = \frac{\hbar^2\omega^2}{2m}\hat{\psi}$$

$$\hat{\psi}_t = -i\frac{\hbar\omega^2}{2m}\hat{\psi}$$

$$\hat{\psi}(\omega, t) = \hat{\psi}(\omega, 0)e^{-i\hbar\omega^2 t/(2m)}$$

**Dispersion relation**: $E = \frac{\hbar^2k^2}{2m}$ (quantum mechanics!)

**Dispersive**: Wave packet spreads (quantum uncertainty).

**Answer:** $\hat{\psi}(\omega,t) = \hat{\psi}(\omega,0)e^{-i\hbar\omega^2 t/(2m)}$

## Answer Key

**Problem 1: C**
$\hat{u}_t = -k\omega^2\hat{u}$ gives $\hat{u} = \hat{f}(\omega)e^{-k\omega^2 t}$
Quadratic in $\omega$ (from second derivative)
High frequencies decay faster
Smoothing property of diffusion
$\omega^2$ factor crucial

**Problem 2: B**
$\omega^2 = c^2k^2$ so $\omega = ck$
Linear dispersion relation
Non-dispersive (all frequencies same speed)
Phase velocity $v_p = \omega/k = c$
D'Alembert: $f(x \pm ct)$ unchanged

**Problem 3: C**
Response to $\delta(x)\delta(t)$ point source
$G(x,t) = \frac{1}{\sqrt{4\pi kt}}e^{-x^2/(4kt)}$ for $t > 0$
Gaussian spreading with time
Solution via convolution: $u = G * f$
Fundamental solution

**Problem 4: B**
Group velocity: $v_g = \frac{d\omega}{dk}$
Derivative of dispersion relation
Velocity of wave packet envelope
Information propagates at $v_g$
Phase velocity: $v_p = \omega/k$ (different!)

**Problem 5: C**
Spatial derivatives → multiplication by powers of $i\omega$
$u_{xx} \to -\omega^2\hat{u}$
Leaves ODE: $\hat{u}_t = -k\omega^2\hat{u}$
Easy to solve: $\hat{u} = \hat{f}e^{-k\omega^2 t}$
Then inverse transform

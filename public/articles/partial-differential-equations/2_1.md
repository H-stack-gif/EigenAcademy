# Partial Differential Equations Topic 2.1: Linear First-Order PDEs

Imagine a pollutant spreading through a river, carried by the current. At each point, the concentration changes as material flows past. If the river flows at constant velocity $v$, the concentration $u(x, t)$ satisfies the simple PDE: $u_t + vu_x = 0$. This is a **first-order linear PDE**—the simplest nontrivial PDE, yet it captures essential physics: information travels along curves called **characteristics**.

First-order PDEs are fundamentally different from second-order PDEs like the heat or wave equations. They describe transport and advection rather than diffusion or oscillation. Solutions don't smooth out discontinuities; they preserve and propagate them along characteristic curves. Understanding characteristics transforms PDE solving from impossible to straightforward: along each characteristic, the PDE reduces to an ordinary differential equation.

This article develops the **method of characteristics** for linear first-order PDEs. We'll learn to find characteristic curves, solve the PDE by reducing it to ODEs, and interpret solutions geometrically. The method works brilliantly for transport equations, revealing the deep connection between PDEs and geometry. Once you see characteristics, first-order PDEs become visual and intuitive.

## Linear First-Order PDEs

The general **linear first-order PDE** in two variables is:

$$a(x, y)u_x + b(x, y)u_y = c(x, y, u)$$

where $a, b, c$ are given functions.

**Key insight**: Along special curves (characteristics), the PDE becomes an ODE.

### Example 1: Transport Equation

The simplest first-order PDE is the **transport equation**:

$$u_t + cu_x = 0$$

where $c$ is constant (wave speed).

What does this mean physically?

**Solution:**

Rewrite using chain rule: if $u = u(x - ct, t)$, then along curves $x - ct = \text{const}$:

$$\frac{du}{dt} = u_t + u_x \frac{dx}{dt}$$

If $\frac{dx}{dt} = c$ (moving with speed $c$), then $\frac{du}{dt} = u_t + cu_x = 0$.

**Physical interpretation**: $u$ is constant along lines $x = ct + x_0$. Solution propagates rightward at speed $c$.

**Answer:** $u(x, t) = f(x - ct)$ for any function $f$ (traveling wave)

### Example 2: Verifying Solution

Verify that $u(x, t) = \sin(x - 3t)$ satisfies $u_t + 3u_x = 0$.

**Solution:**

$$u_t = \frac{\partial}{\partial t}[\sin(x - 3t)] = \cos(x - 3t) \cdot (-3) = -3\cos(x - 3t)$$

$$u_x = \frac{\partial}{\partial x}[\sin(x - 3t)] = \cos(x - 3t)$$

$$u_t + 3u_x = -3\cos(x - 3t) + 3\cos(x - 3t) = 0$$ ✓

**Answer:** Verified; sine wave traveling right at speed 3

### Example 3: Initial Condition

Solve $u_t + 2u_x = 0$ with $u(x, 0) = e^{-x^2}$.

**Solution:**

General solution: $u(x, t) = f(x - 2t)$ for arbitrary $f$.

Initial condition: $u(x, 0) = f(x) = e^{-x^2}$

Therefore: $f(\xi) = e^{-\xi^2}$

Solution: $u(x, t) = e^{-(x-2t)^2}$

**Answer:** $u(x, t) = e^{-(x-2t)^2}$ (Gaussian pulse moving right at speed 2)

## Method of Characteristics

For $au_x + bu_y = c$, the **characteristic equations** are:

$$\frac{dx}{a} = \frac{dy}{b} = \frac{du}{c}$$

These are parametric ODEs. Solving gives characteristic curves and solution.

### Example 4: Finding Characteristics

For $u_x + 2u_y = 0$, find the characteristic curves.

**Solution:**

Characteristic equations:
$$\frac{dx}{1} = \frac{dy}{2} = \frac{du}{0}$$

From $\frac{dx}{1} = \frac{dy}{2}$:
$$\frac{dy}{dx} = 2 \implies y = 2x + c_1$$

From $\frac{du}{0}$: $du = 0 \implies u = c_2$ (constant along characteristics)

**Characteristics**: Straight lines $y = 2x + c$

**Answer:** $u$ is constant along lines $y - 2x = \text{const}$

### Example 5: General Solution from Characteristics

For Example 4, if $u$ is constant along $y - 2x = \text{const}$, what is the general solution?

**Solution:**

$u$ depends only on the combination $y - 2x$:

$$u(x, y) = f(y - 2x)$$

for arbitrary function $f$.

Verify: $u_x = f'(y - 2x) \cdot (-2) = -2f'$, $u_y = f'(y - 2x)$

$u_x + 2u_y = -2f' + 2f' = 0$ ✓

**Answer:** $u(x, y) = f(y - 2x)$ for arbitrary $f$

### Example 6: Using Initial Data

Solve $u_x + 2u_y = 0$ with $u(x, 0) = \sin x$.

**Solution:**

General solution: $u(x, y) = f(y - 2x)$

Initial condition: $u(x, 0) = f(-2x) = \sin x$

Let $\xi = -2x$, so $x = -\xi/2$:
$$f(\xi) = \sin(-\xi/2)$$

Therefore:
$$u(x, y) = f(y - 2x) = \sin(-(y - 2x)/2) = \sin(x - y/2)$$

**Answer:** $u(x, y) = \sin(x - y/2)$

## Variable Coefficients

When $a, b$ depend on $x, y$, characteristics are curves, not straight lines.

### Example 7: Variable Coefficient Example

Solve $yu_x - xu_y = 0$.

**Solution:**

Characteristic equations:
$$\frac{dx}{y} = \frac{dy}{-x} = \frac{du}{0}$$

From $\frac{dx}{y} = \frac{dy}{-x}$:
$$x \, dx + y \, dy = 0$$

Integrate: $\frac{x^2}{2} + \frac{y^2}{2} = c_1$

So $x^2 + y^2 = \text{const}$ (circles centered at origin)

From $du = 0$: $u = c_2$

**Answer:** $u(x, y) = f(x^2 + y^2)$ for arbitrary $f$ (constant on circles)

### Example 8: Radial Solution

For $yu_x - xu_y = 0$ with $u(x, 0) = x^2$ for $x > 0$, find the solution.

**Solution:**

General solution: $u = f(x^2 + y^2)$

On positive $x$-axis ($y = 0$): $u(x, 0) = f(x^2) = x^2$

Therefore: $f(r^2) = r^2$ for $r > 0$, so $f(\xi) = \xi$

Solution: $u(x, y) = x^2 + y^2$

**Answer:** $u(x, y) = x^2 + y^2$

### Example 9: Parametric Form

For $u_x + yu_y = 0$, find characteristics parametrically.

**Solution:**

Characteristic equations:
$$\frac{dx}{ds} = 1, \quad \frac{dy}{ds} = y, \quad \frac{du}{ds} = 0$$

From first: $x = s + c_1$

From second: $\frac{dy}{ds} = y \implies y = c_2e^s$

From third: $u = c_3$

Eliminating $s$: From $x = s + c_1$, we have $s = x - c_1$

So $y = c_2e^{x-c_1} = (c_2e^{-c_1})e^x$

Characteristics: $y = Ce^x$ for various constants $C$

**Answer:** Characteristics are $ye^{-x} = \text{const}$; solution $u = f(ye^{-x})$

## Inhomogeneous Equations

For $au_x + bu_y = c(x, y, u)$ with $c \neq 0$, the PDE is **inhomogeneous**.

### Example 10: Source Term

Solve $u_x + u_y = 1$.

**Solution:**

Characteristic equations:
$$\frac{dx}{1} = \frac{dy}{1} = \frac{du}{1}$$

From first two: $\frac{dx}{dy} = 1 \implies x - y = c_1$

From $\frac{dx}{du} = 1$: $u = x + c_2$

Combine: $u = x + c_2$ and $x - y = c_1$

Eliminate $c_1, c_2$: $u = x + g(x - y)$ for arbitrary $g$

Or equivalently: $u - x = g(x - y)$

**Answer:** $u(x, y) = x + f(x - y)$ for arbitrary $f$

### Example 11: With Initial Condition

Solve $u_x + u_y = 1$ with $u(x, 0) = 0$.

**Solution:**

General solution: $u = x + f(x - y)$

Initial condition: $u(x, 0) = x + f(x) = 0$

So $f(x) = -x$

Therefore: $u(x, y) = x + f(x - y) = x - (x - y) = y$

**Answer:** $u(x, y) = y$

### Example 12: Linear in $u$

Solve $u_x + u_y = u$ with $u(x, 0) = e^x$.

**Solution:**

Characteristic equations:
$$\frac{dx}{1} = \frac{dy}{1} = \frac{du}{u}$$

From $\frac{dx}{1} = \frac{dy}{1}$: $x - y = c_1$

From $\frac{dx}{1} = \frac{du}{u}$: $\frac{du}{dx} = u \implies u = c_2e^x$

On characteristic through $(x_0, 0)$: $c_1 = x_0$ and $u(x_0, 0) = e^{x_0} = c_2e^{x_0}$

So $c_2 = 1$.

Along this characteristic: $u = e^x$ and $x - y = x_0$

Therefore $x_0 = x - y$, and $u = e^x$ everywhere.

**Answer:** $u(x, y) = e^x$

### Example 13: Geometric Interpretation

For $u_t + cu_x = 0$, sketch characteristics in the $x$-$t$ plane for $c = 2$.

**Solution:**

Characteristic equations: $\frac{dx}{2} = \frac{dt}{1}$

So $\frac{dx}{dt} = 2$, giving $x = 2t + x_0$

**Graph**: Family of parallel lines with slope $dt/dx = 1/2$ (equivalently, slope $dx/dt = 2$)

Each line carries constant value of $u$.

**Initial data** at $t = 0$ propagates along these lines.

**Answer:** Straight lines $x = 2t + x_0$ (slope 2 in $x$-$t$ plane)

## Practice Problems

**Problem 1:** The transport equation $u_t + cu_x = 0$ has solutions of the form:

A) $u = f(x + ct)$
B) $u = f(x - ct)$
C) $u = f(x^2 + t^2)$
D) $u = e^{ct}f(x)$
E) $u = t f(x)$

**Problem 2:** For $2u_x + 3u_y = 0$, the characteristics are:

A) $2x + 3y = \text{const}$
B) $3x - 2y = \text{const}$
C) $3x + 2y = \text{const}$
D) $2y - 3x = \text{const}$
E) Circles

**Problem 3:** The method of characteristics reduces a PDE to:

A) An algebraic equation
B) An ODE
C) A higher-order PDE
D) A nonlinear equation
E) Nothing useful

**Problem 4:** In the characteristic equations $\frac{dx}{a} = \frac{dy}{b} = \frac{du}{c}$, the quantity that is constant is:

A) $x$
B) $y$
C) $u$ (if $c = 0$)
D) $x + y$
E) Always changing

**Problem 5:** For $u_x + yu_y = 0$, characteristics are curves:

A) $y = \text{const}$
B) $x = \text{const}$
C) $ye^{-x} = \text{const}$
D) $x^2 + y^2 = \text{const}$
E) $xy = \text{const}$

## Answer Key

**Problem 1: B**
Transport equation: $u_t + cu_x = 0$
General solution: $u = f(x - ct)$ (rightward if $c > 0$)
Represents wave traveling right at speed $c$
Along $x = ct + x_0$: $u$ constant
Initial profile $f(x)$ translates: $f(x) \to f(x - ct)$

**Problem 2: D**
Characteristic equations: $\frac{dx}{2} = \frac{dy}{3}$
Cross-multiply: $3 \, dx = 2 \, dy$
Integrate: $3x = 2y + C$
Rearrange: $2y - 3x = \text{const}$
General solution: $u = f(2y - 3x)$

**Problem 3: B**
Along characteristics, PDE becomes ODE
Multi-variable PDE → single-variable ODE
Characteristic curves: solution constant or evolves by ODE
Transforms difficult PDE into tractable problem
Foundation of method of characteristics

**Problem 4: C**
If $c = 0$: $\frac{du}{0}$ means $du = 0$
So $u = \text{const}$ along characteristics
If $c \neq 0$: $u$ changes according to $\frac{du}{ds} = c$
Characteristics are curves of constant $u$ when homogeneous
Not $x$ or $y$ (these vary along characteristics)

**Problem 5: C**
$\frac{dx}{1} = \frac{dy}{y}$
$\frac{dy}{y} = dx \implies \ln|y| = x + C$
$y = Ae^x$ or $ye^{-x} = A$
Characteristics: exponential curves
General solution: $u = f(ye^{-x})$

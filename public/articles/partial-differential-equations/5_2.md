# Partial Differential Equations Topic 5.2: D'Alembert's Solution

On an infinitely long string, pluck one point and release it. What happens? The disturbance splits into two pulses—one traveling left at speed $c$, the other traveling right at speed $c$. Each pulse maintains its shape perfectly, propagating forever without attenuation or distortion. This is the essence of **d'Alembert's solution**: any solution to the wave equation on an infinite domain is a superposition of two traveling waves.

Jean le Rond d'Alembert discovered this solution in 1747, providing the first explicit formula for wave motion. The **d'Alembert formula** expresses the solution as a simple combination of initial displacement and velocity: $u(x,t) = \frac{1}{2}[f(x+ct) + f(x-ct)] + \frac{1}{2c}\int_{x-ct}^{x+ct} g(s) \, ds$. This remarkable formula lets you write down the solution immediately—no separation of variables, no Fourier series, just evaluate functions and an integral.

This article develops d'Alembert's solution systematically. We'll derive the general solution for infinite strings, interpret it geometrically, handle various initial conditions, and understand the domain of influence. D'Alembert's formula reveals the transparent connection between wave equation solutions and their initial data: you can literally see where each piece of the solution comes from.

## General Solution: Traveling Waves

The wave equation $u_{tt} = c^2u_{xx}$ has special solutions of form $u = f(x - ct)$ and $u = g(x + ct)$.

### Example 1: Verifying Right-Traveling Wave

Show $u = f(x - ct)$ satisfies wave equation for any twice-differentiable $f$.

**Solution:**

Let $\xi = x - ct$, so $u = f(\xi)$.

$$u_t = f'(\xi) \cdot (-c) = -cf'(\xi)$$
$$u_{tt} = -c \cdot f''(\xi) \cdot (-c) = c^2f''(\xi)$$

$$u_x = f'(\xi) \cdot 1 = f'(\xi)$$
$$u_{xx} = f''(\xi)$$

$$c^2u_{xx} = c^2f''(\xi) = u_{tt}$$ ✓

**Physical meaning**: $f(x - ct)$ is a pulse moving right at speed $c$.

**Answer:** Any function $f(x - ct)$ satisfies wave equation

### Example 2: Left-Traveling Wave

Similarly verify $u = g(x + ct)$ satisfies wave equation.

**Solution:**

Let $\eta = x + ct$, so $u = g(\eta)$.

$$u_t = g'(\eta) \cdot c = cg'(\eta)$$
$$u_{tt} = c \cdot g''(\eta) \cdot c = c^2g''(\eta)$$

$$u_x = g'(\eta)$$
$$u_{xx} = g''(\eta)$$

$$c^2u_{xx} = c^2g''(\eta) = u_{tt}$$ ✓

**Physical meaning**: $g(x + ct)$ is a pulse moving left at speed $c$.

**Answer:** Any function $g(x + ct)$ satisfies wave equation

### Example 3: General Solution

The most general solution is:

$$u(x, t) = f(x - ct) + g(x + ct)$$

Why is this complete?

**Solution:**

Wave equation is **linear and second-order**.

Characteristic curves: $x - ct = \text{const}$ and $x + ct = \text{const}$

General solution has two arbitrary functions (like two constants for second-order ODE).

These are determined by two initial conditions: $u(x, 0)$ and $u_t(x, 0)$.

**Answer:** $u = f(x - ct) + g(x + ct)$ is complete general solution

## D'Alembert's Formula

Given initial conditions $u(x, 0) = \phi(x)$ and $u_t(x, 0) = \psi(x)$, determine $f$ and $g$.

### Example 4: Matching Initial Displacement

From $u(x, t) = f(x - ct) + g(x + ct)$, at $t = 0$:

**Solution:**

$$u(x, 0) = f(x) + g(x) = \phi(x)$$ ... (1)

**Answer:** $f(x) + g(x) = \phi(x)$

### Example 5: Matching Initial Velocity

From $u_t = -cf'(x - ct) + cg'(x + ct)$, at $t = 0$:

**Solution:**

$$u_t(x, 0) = -cf'(x) + cg'(x) = \psi(x)$$

Integrate from $0$ to $x$:
$$-c[f(x) - f(0)] + c[g(x) - g(0)] = \int_0^x \psi(s) \, ds$$

$$g(x) - f(x) = \frac{1}{c}\int_0^x \psi(s) \, ds + [f(0) - g(0)]$$ ... (2)

**Answer:** $g(x) - f(x) = \frac{1}{c}\int_0^x \psi(s) \, ds + \text{const}$

### Example 6: Solving for $f$ and $g$

Add equations (1) and (2):

**Solution:**

From (1): $f + g = \phi$
From (2): $g - f = \frac{1}{c}\int_0^x \psi + C$

Adding: $2g = \phi + \frac{1}{c}\int_0^x \psi + C$

$$g(x) = \frac{1}{2}\phi(x) + \frac{1}{2c}\int_0^x \psi(s) \, ds + \frac{C}{2}$$

Subtracting: $2f = \phi - \frac{1}{c}\int_0^x \psi - C$

$$f(x) = \frac{1}{2}\phi(x) - \frac{1}{2c}\int_0^x \psi(s) \, ds - \frac{C}{2}$$

**Answer:** $f$ and $g$ determined by $\phi$ and $\psi$

### Example 7: D'Alembert's Formula

Substitute $f(x - ct)$ and $g(x + ct)$:

**Solution:**

$$u(x, t) = f(x - ct) + g(x + ct)$$

$$= \frac{1}{2}\phi(x - ct) + \frac{1}{2}\phi(x + ct) + \frac{1}{2c}\left[\int_0^{x+ct} \psi(s) \, ds - \int_0^{x-ct} \psi(s) \, ds\right]$$

$$= \frac{1}{2}[\phi(x - ct) + \phi(x + ct)] + \frac{1}{2c}\int_{x-ct}^{x+ct} \psi(s) \, ds$$

**D'Alembert's Formula**:

$$\boxed{u(x, t) = \frac{1}{2}[\phi(x + ct) + \phi(x - ct)] + \frac{1}{2c}\int_{x-ct}^{x+ct} \psi(s) \, ds}$$

**Answer:** Explicit solution formula for initial value problem

### Example 8: Zero Initial Velocity

If $\psi(x) = 0$ (released from rest):

**Solution:**

$$u(x, t) = \frac{1}{2}[\phi(x + ct) + \phi(x - ct)]$$

**Physical interpretation**: 
- Initial profile $\phi(x)$ splits into two pulses
- Each pulse has half the amplitude
- One travels left, one travels right

**Answer:** $u = \frac{1}{2}[\phi(x + ct) + \phi(x - ct)]$

### Example 9: Gaussian Pulse

Solve with $\phi(x) = e^{-x^2}$, $\psi(x) = 0$.

**Solution:**

$$u(x, t) = \frac{1}{2}[e^{-(x+ct)^2} + e^{-(x-ct)^2}]$$

**At $t = 0$**: $u = \frac{1}{2}[e^{-x^2} + e^{-x^2}] = e^{-x^2}$ ✓

**For $t > 0$**: Two Gaussian pulses moving apart.

**At large $t$**: Pulses separated by distance $2ct$.

**Answer:** $u(x,t) = \frac{1}{2}[e^{-(x+ct)^2} + e^{-(x-ct)^2}]$

## Applications of D'Alembert's Formula

### Example 10: Plucked String

String plucked at center: $\phi(x) = \begin{cases} x & 0 \leq x \leq 1 \\ 2 - x & 1 \leq x \leq 2 \\ 0 & \text{otherwise} \end{cases}$, $\psi = 0$.

Describe motion.

**Solution:**

Two triangular pulses, each half the original height, traveling apart.

**At $t = 1/c$**: Pulses completely separated.

**At $t = 2/c$**: Each pulse has traveled distance 2 from original position.

Pulses propagate indefinitely without change in shape.

**Answer:** Triangular pulses split and travel apart at speed $c$

### Example 11: Struck String

String struck at origin: $\phi(x) = 0$, $\psi(x) = v_0\delta(x)$ (impulse).

**Solution:**

$$u(x, t) = \frac{1}{2c}\int_{x-ct}^{x+ct} v_0\delta(s) \, ds$$

Integral is $v_0$ if $0 \in [x - ct, x + ct]$, i.e., $-ct < x < ct$.

$$u(x, t) = \begin{cases} \frac{v_0}{2c} & |x| < ct \\ 0 & |x| > ct \end{cases}$$

**Physical meaning**: Rectangular pulse expanding outward from origin.

**Answer:** Expanding rectangular pulse with constant height $v_0/(2c)$

### Example 12: Domain of Influence

Given initial data at point $x_0$ (localized disturbance), which points $(x, t)$ are affected?

**Solution:**

Point $(x, t)$ is affected if $x_0 \in [x - ct, x + ct]$, i.e., $x - ct \leq x_0 \leq x + ct$.

Equivalently: $x_0 - ct \leq x \leq x_0 + ct$

**Domain of influence** (or **range of influence**): triangular region bounded by characteristics $x = x_0 \pm ct$.

**Answer:** Region $|x - x_0| \leq ct$ (expanding cone in spacetime)

### Example 13: Smooth vs. Discontinuous Data

If $\phi$ has discontinuity at $x = 0$, what happens to solution?

**Solution:**

$$u(x, t) = \frac{1}{2}[\phi(x + ct) + \phi(x - ct)]$$

Discontinuity at $x = 0$ propagates along characteristics:
- Along $x = ct$ (right-moving)
- Along $x = -ct$ (left-moving)

**Contrast heat equation**: discontinuities immediately smoothed.

Wave equation preserves discontinuities (no smoothing).

**Answer:** Discontinuities propagate along characteristics $x = \pm ct$

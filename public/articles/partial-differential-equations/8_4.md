# 8.4: Green’s Functions for ODEs

Green's functions for ODE boundary value problems: construction, properties, and how point-source responses build solutions to inhomogeneous problems.

Topics covered:
- Definition of Green's function for linear ODEs
- Construction via fundamental solutions and matching conditions
- Using Green's functions to write solutions as integrals against the source

## Practice problem

1) True/False: The Green's function is the impulse response for a linear differential operator with given boundary conditions. (Answer: True)

# Partial Differential Equations Topic 7.3: Laplace Transform for PDEs

The Fourier transform handles spatial variables beautifully, converting spatial derivatives into algebraic operations. But what about time-dependent problems with boundary conditions? Enter the **Laplace transform**, which transforms the time variable and converts initial value problems into boundary value problems. Taking the Laplace transform in time converts $u_t$ to $s\hat{u} - u(x,0)$, automatically incorporating initial conditions.

The Laplace transform $\mathcal{L}\{f(t)\} = \int_0^{\infty} f(t)e^{-st} dt$ is particularly suited for problems starting at $t=0$ with specified initial conditions—exactly the setup for most time-evolution PDEs. The transform only integrates over $t > 0$, naturally handling causal systems (no effect before cause). Combined with Fourier transforms in space, Laplace transforms provide powerful tools for solving parabolic and hyperbolic PDEs.

This article develops Laplace transform methods for PDEs. We'll define the transform, compute standard transforms, derive key properties (especially the derivative property), solve heat and wave equations with various boundary conditions, and understand the $s$-domain interpretation. These techniques are essential for engineering applications and control theory.

## Laplace Transform Fundamentals

### Example 1: Definition

For function $f(t)$ defined for $t \geq 0$:

**Solution:**

**Laplace transform**:
$$\mathcal{L}\{f(t)\}(s) = F(s) = \int_0^{\infty} f(t)e^{-st} \, dt$$

**Convergence**: Requires $s$ large enough (typically $\text{Re}(s) > a$).

**Inverse Laplace transform**: $f(t) = \mathcal{L}^{-1}\{F(s)\}$ (via complex integration)

**Variables**:
- $t$: time
- $s$: complex frequency (dimensions: 1/time)

**Answer:** $F(s) = \int_0^{\infty} f(t)e^{-st} dt$

### Example 2: Transform of Elementary Functions

Compute $\mathcal{L}\{1\}$, $\mathcal{L}\{e^{at}\}$, $\mathcal{L}\{t^n\}$.

**Solution:**

**Constant**:
$$\mathcal{L}\{1\} = \int_0^{\infty} e^{-st} dt = \frac{1}{s} \quad (s > 0)$$

**Exponential**:
$$\mathcal{L}\{e^{at}\} = \int_0^{\infty} e^{at}e^{-st} dt = \frac{1}{s-a} \quad (s > a)$$

**Power**:
$$\mathcal{L}\{t^n\} = \int_0^{\infty} t^n e^{-st} dt = \frac{n!}{s^{n+1}} \quad (s > 0)$$

(By integration by parts $n$ times)

**Answer:** $\mathcal{L}\{1\} = 1/s$, $\mathcal{L}\{e^{at}\} = 1/(s-a)$, $\mathcal{L}\{t^n\} = n!/s^{n+1}$

### Example 3: Transform of Trigonometric Functions

Find $\mathcal{L}\{\sin(\omega t)\}$ and $\mathcal{L}\{\cos(\omega t)\}$.

**Solution:**

$$\mathcal{L}\{\sin(\omega t)\} = \int_0^{\infty} \sin(\omega t)e^{-st} dt$$

Using $\sin(\omega t) = \frac{e^{i\omega t} - e^{-i\omega t}}{2i}$:

$$= \frac{1}{2i}\left[\frac{1}{s - i\omega} - \frac{1}{s + i\omega}\right] = \frac{\omega}{s^2 + \omega^2}$$

Similarly:
$$\mathcal{L}\{\cos(\omega t)\} = \frac{s}{s^2 + \omega^2}$$

**Answer:** $\mathcal{L}\{\sin\omega t\} = \frac{\omega}{s^2+\omega^2}$, $\mathcal{L}\{\cos\omega t\} = \frac{s}{s^2+\omega^2}$

### Example 4: Transform of Derivative

**Key property**: $\mathcal{L}\{f'(t)\}$

**Solution:**

$$\mathcal{L}\{f'\} = \int_0^{\infty} f'(t)e^{-st} dt$$

Integration by parts:
$$= \left[f(t)e^{-st}\right]_0^{\infty} + s\int_0^{\infty} f(t)e^{-st} dt$$

Assuming $f(t)e^{-st} \to 0$ as $t \to \infty$:
$$= -f(0) + sF(s)$$

$$\mathcal{L}\{f'\} = sF(s) - f(0)$$

**Higher derivatives**:
$$\mathcal{L}\{f''\} = s^2F(s) - sf(0) - f'(0)$$

**Automatic incorporation of initial conditions!**

**Answer:** $\mathcal{L}\{f'\} = sF(s) - f(0)$

### Example 5: Shifting Theorem

Find $\mathcal{L}\{e^{at}f(t)\}$.

**Solution:**

$$\mathcal{L}\{e^{at}f(t)\} = \int_0^{\infty} e^{at}f(t)e^{-st} dt = \int_0^{\infty} f(t)e^{-(s-a)t} dt$$

$$= F(s - a)$$

**$s$-shifting**: Multiplication by $e^{at}$ shifts transform by $a$.

**Example**: $\mathcal{L}\{e^{at}\cos(\omega t)\} = \frac{s-a}{(s-a)^2 + \omega^2}$

**Answer:** $\mathcal{L}\{e^{at}f(t)\} = F(s-a)$

## Heat Equation with Laplace Transform

### Example 6: Semi-Infinite Rod

Solve $u_t = ku_{xx}$ for $x > 0$, $t > 0$ with:
- $u(x, 0) = 0$
- $u(0, t) = T_0$ (constant boundary)

**Solution:**

**Step 1**: Laplace transform in $t$:
$$\mathcal{L}\{u_t\} = k\mathcal{L}\{u_{xx}\}$$

$$sU(x, s) - u(x, 0) = kU_{xx}(x, s)$$

$$sU = kU_{xx}$$ (since $u(x,0) = 0$)

**Step 2**: This is ODE in $x$:
$$U_{xx} - \frac{s}{k}U = 0$$

$$U(x, s) = Ae^{\sqrt{s/k}x} + Be^{-\sqrt{s/k}x}$$

**Step 3**: Boundary conditions:
- $U(0, s) = \mathcal{L}\{T_0\} = T_0/s$
- $U \to 0$ as $x \to \infty$ (bounded)

From boundedness: $A = 0$

From boundary: $B = T_0/s$

$$U(x, s) = \frac{T_0}{s}e^{-x\sqrt{s/k}}$$

**Answer:** $U(x,s) = \frac{T_0}{s}e^{-x\sqrt{s/k}}$

### Example 7: Inverse Transform

Invert $U(x,s)$ from Example 6.

**Solution:**

$$U(x, s) = T_0 \cdot \frac{1}{s}e^{-x\sqrt{s/k}}$$

Using tables (or contour integration):
$$\mathcal{L}^{-1}\left\{\frac{1}{s}e^{-a\sqrt{s}}\right\} = \text{erfc}\left(\frac{a}{2\sqrt{kt}}\right)$$

where $\text{erfc}$ is complementary error function.

$$u(x, t) = T_0 \, \text{erfc}\left(\frac{x}{2\sqrt{kt}}\right)$$

**Physical**: Temperature front diffuses into rod, described by error function.

**Answer:** $u(x,t) = T_0 \, \text{erfc}(x/(2\sqrt{kt}))$

### Example 8: Alternative Boundary Condition

Now $u(0, t) = T_0\sin(\omega t)$ (oscillating boundary).

**Solution:**

Transform: $U(0, s) = \frac{T_0\omega}{s^2 + \omega^2}$

From Example 6 structure:
$$U(x, s) = \frac{T_0\omega}{s^2 + \omega^2}e^{-x\sqrt{s/k}}$$

**Inverse** (complex):
$$u(x, t) = T_0 e^{-x\sqrt{\omega/(2k)}}\sin\left(\omega t - x\sqrt{\omega/(2k)}\right)$$

**Physical**: Damped wave penetrating into rod.

**Penetration depth**: $\delta = \sqrt{2k/\omega}$ (decreases with frequency).

**Answer:** Temperature oscillations decay exponentially with distance

## Wave Equation with Laplace Transform

### Example 9: Wave on Semi-Infinite String

$u_{tt} = c^2u_{xx}$ for $x > 0$ with:
- $u(x, 0) = 0$, $u_t(x, 0) = 0$
- $u(0, t) = f(t)$

**Solution:**

Transform in $t$:
$$s^2U - su(x,0) - u_t(x,0) = c^2U_{xx}$$

$$s^2U = c^2U_{xx}$$

$$U_{xx} - \frac{s^2}{c^2}U = 0$$

$$U(x, s) = Ae^{sx/c} + Be^{-sx/c}$$

Boundedness: $A = 0$

Boundary: $U(0, s) = F(s)$

$$U(x, s) = F(s)e^{-sx/c}$$

**Answer:** $U(x,s) = F(s)e^{-sx/c}$

### Example 10: Time Delay Interpretation

Invert $U(x, s) = F(s)e^{-sx/c}$ from Example 9.

**Solution:**

**Time-shift theorem**: $\mathcal{L}^{-1}\{F(s)e^{-as}\} = f(t-a)H(t-a)$

where $H$ is Heaviside function.

$$u(x, t) = f(t - x/c)H(t - x/c)$$

**Physical**: Boundary disturbance $f(t)$ arrives at $x$ after time delay $x/c$.

**Wave speed** $c$ directly visible!

**Answer:** $u(x,t) = f(t-x/c)$ for $t > x/c$, zero otherwise

### Example 11: Impulse Response

$u(0, t) = \delta(t)$ (delta function boundary input).

**Solution:**

Transform: $F(s) = 1$

$$U(x, s) = e^{-sx/c}$$

Inverse:
$$u(x, t) = \delta(t - x/c)$$

**Interpretation**: Delta pulse propagates unchanged at speed $c$.

**Green's function** for wave equation on half-line.

**Answer:** $u(x,t) = \delta(t - x/c)$

## Convolution and Transfer Functions

### Example 12: Convolution Theorem

For Laplace transform:
$$\mathcal{L}\{(f * g)(t)\} = F(s)G(s)$$

where $(f * g)(t) = \int_0^t f(t-\tau)g(\tau) d\tau$

**Solution:**

**Proof sketch**: Similar to Fourier convolution theorem.

**Application**: System response = convolution of input with impulse response.

$$y(t) = (h * f)(t) \quad \text{where } h \text{ is impulse response}$$

In Laplace domain: $Y(s) = H(s)F(s)$

**Transfer function**: $H(s) = Y(s)/F(s)$

**Answer:** Convolution in time ↔ multiplication in $s$-domain

### Example 13: RC Circuit Analogy

First-order system: $\tau y' + y = f(t)$, $y(0) = 0$

**Solution:**

Transform:
$$\tau[sY(s) - 0] + Y(s) = F(s)$$

$$Y(s)(\tau s + 1) = F(s)$$

$$Y(s) = \frac{F(s)}{\tau s + 1}$$

**Transfer function**: $H(s) = \frac{1}{\tau s + 1}$

**Impulse response**: $h(t) = \frac{1}{\tau}e^{-t/\tau}$

**Time constant**: $\tau$ (decay rate)

**Physical**: Exponential approach to equilibrium.

**Answer:** $H(s) = 1/(\tau s + 1)$ (first-order lag)

## Answer Key

**Problem 1: C**
$\mathcal{L}\{f'(t)\} = sF(s) - f(0)$
Incorporates initial condition automatically
Higher derivatives: $\mathcal{L}\{f''\} = s^2F(s) - sf(0) - f'(0)$
Key advantage: ICs built into transform
Converts ODEs to algebra

**Problem 2: B**
$\mathcal{L}\{\sin\omega t\} = \frac{\omega}{s^2+\omega^2}$
Cosine: $\mathcal{L}\{\cos\omega t\} = \frac{s}{s^2+\omega^2}$
Poles at $s = \pm i\omega$
Oscillatory behavior → imaginary poles
Damped oscillation: poles in left half-plane

**Problem 3: B**
Time-shift theorem: $\mathcal{L}\{f(t-a)H(t-a)\} = e^{-as}F(s)$
$e^{-as}$ factor = delay by $a$
Wave propagation: $e^{-sx/c}$ = delay $x/c$
Causal: $H(t-a)$ ensures $f=0$ for $t<a$
Different from $s$-shift: $\mathcal{L}\{e^{at}f(t)\} = F(s-a)$

**Problem 4: B**
Laplace: time-dependent initial value problems
Transforms IVP to BVP in $x$
Initial conditions built in
Fourier: spatial transforms
Combined: powerful for PDEs

**Problem 5: B**
Transfer function: $H(s) = Y(s)/F(s)$
Output = $H(s) \times$ Input (in $s$-domain)
Time domain: $y = h * f$ (convolution)
Characterizes linear system
Poles/zeros determine stability, response

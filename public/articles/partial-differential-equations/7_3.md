# 7.3: Laplace Transform for PDEs

Using Laplace transforms for time-dependent PDEs: transform in time to reduce PDEs to ODEs, then invert using tables and convolution.

Topics covered:
- Laplace transform basics and inversion
- Combining Laplace (time) with spatial methods for PDEs
- Example applications: diffusion with time-dependent forcing

## Practice problem

1) True/False: Laplace transforms reduce time derivatives to algebraic multiplication by the Laplace variable.

**Answer:** True

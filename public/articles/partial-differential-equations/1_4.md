
# Partial Differential Equations Topic 1.4: Superposition Principle

One of the most powerful properties of linear PDEs is the **superposition principle**: if $u_1$ and $u_2$ are solutions, then any linear combination $c_1u_1 + c_2u_2$ is also a solution. This simple fact transforms PDE solving from impossible to tractable. It means we can build complex solutions from simple building blocks, solving simpler problems and combining their answers.

Superposition underlies virtually every analytical technique for linear PDEs. Fourier series work because we can superpose sine and cosine solutions. Green's functions work because we can superpose point-source responses. The method of separation of variables produces infinitely many solutions, which we superpose to match arbitrary initial conditions. Without superposition, PDEs would be nearly impossible to solve—we'd need to guess the exact answer for each specific problem.

This article explores the superposition principle in depth. We'll prove why it works for linear PDEs but fails for nonlinear ones, see how it enables Fourier series solutions, understand its role in homogeneous versus inhomogeneous problems, and apply it to construct solutions to the heat and wave equations. Superposition is the key that unlocks linear PDEs.

## The Superposition Principle for Linear PDEs

**Theorem (Superposition)**: If $\mathcal{L}$ is a linear differential operator and $u_1, u_2$ satisfy $\mathcal{L}u_1 = 0$ and $\mathcal{L}u_2 = 0$, then for any constants $c_1, c_2$:

$$\mathcal{L}(c_1u_1 + c_2u_2) = 0$$

**Proof**: By linearity,
$$\mathcal{L}(c_1u_1 + c_2u_2) = c_1\mathcal{L}u_1 + c_2\mathcal{L}u_2 = c_1(0) + c_2(0) = 0$$

### Example 1: Verifying Linearity

Show that $\mathcal{L}u = u_{xx} + u_{yy}$ is linear.

**Solution:**

Need to show: $\mathcal{L}(c_1u_1 + c_2u_2) = c_1\mathcal{L}u_1 + c_2\mathcal{L}u_2$

$$\mathcal{L}(c_1u_1 + c_2u_2) = (c_1u_1 + c_2u_2)_{xx} + (c_1u_1 + c_2u_2)_{yy}$$
$$= c_1u_{1xx} + c_2u_{2xx} + c_1u_{1yy} + c_2u_{2yy}$$
$$= c_1(u_{1xx} + u_{1yy}) + c_2(u_{2xx} + u_{2yy})$$
$$= c_1\mathcal{L}u_1 + c_2\mathcal{L}u_2$$ ✓

**Answer:** Linear operator verified

### Example 2: Nonlinear Counterexample

Why does superposition fail for $u_t = uu_x$ (Burgers' equation)?

**Solution:**

If $u_1$ and $u_2$ satisfy $u_{1t} = u_1u_{1x}$ and $u_{2t} = u_2u_{2x}$:

Test $u = c_1u_1 + c_2u_2$:
$$u_t = c_1u_{1t} + c_2u_{2t} = c_1u_1u_{1x} + c_2u_2u_{2x}$$

But:
$$uu_x = (c_1u_1 + c_2u_2)(c_1u_{1x} + c_2u_{2x})$$
$$= c_1^2u_1u_{1x} + c_2^2u_2u_{2x} + c_1c_2(u_1u_{2x} + u_2u_{1x})$$

These don't match! (cross terms $u_1u_{2x}$ appear)

**Answer:** Nonlinear term $uu_x$ violates superposition

### Example 3: Laplace's Equation Solutions

If $u_1 = x^2 - y^2$ and $u_2 = xy$ both satisfy $u_{xx} + u_{yy} = 0$, find three more solutions.

**Solution:**

By superposition, any linear combination works:

$$u_3 = 2u_1 + 3u_2 = 2(x^2 - y^2) + 3xy$$
$$u_4 = u_1 - u_2 = x^2 - y^2 - xy$$
$$u_5 = -u_1 = -(x^2 - y^2) = y^2 - x^2$$

All satisfy Laplace's equation by superposition.

**Answer:** $u_3 = 2x^2 - 2y^2 + 3xy$, $u_4 = x^2 - y^2 - xy$, $u_5 = y^2 - x^2$ (and infinitely many more)

## Infinite Superposition and Fourier Series

For infinite series of solutions, superposition extends if series converges:

$$u = \sum_{n=1}^{\infty} c_nu_n$$

This is the foundation of **Fourier series** solutions.

### Example 4: Heat Equation Building Blocks

For $u_t = ku_{xx}$ on $[0, L]$ with $u(0,t) = u(L,t) = 0$:

The functions $u_n(x,t) = e^{-kn^2\pi^2t/L^2}\sin(n\pi x/L)$ are solutions for each $n$.

Verify this.

**Solution:**

$$u_n = e^{-kn^2\pi^2t/L^2}\sin(n\pi x/L)$$

$$(u_n)_t = -\frac{kn^2\pi^2}{L^2}e^{-kn^2\pi^2t/L^2}\sin(n\pi x/L)$$

$$(u_n)_x = e^{-kn^2\pi^2t/L^2} \cdot \frac{n\pi}{L}\cos(n\pi x/L)$$

$$(u_n)_{xx} = e^{-kn^2\pi^2t/L^2} \cdot \left(-\frac{n^2\pi^2}{L^2}\right)\sin(n\pi x/L)$$

$$k(u_n)_{xx} = -\frac{kn^2\pi^2}{L^2}e^{-kn^2\pi^2t/L^2}\sin(n\pi x/L) = (u_n)_t$$ ✓

**Answer:** Each $u_n$ is a solution; called **normal modes**

### Example 5: General Solution by Superposition

By superposition, the general solution is:

$$u(x,t) = \sum_{n=1}^{\infty} c_n e^{-kn^2\pi^2t/L^2}\sin(n\pi x/L)$$

How do we find coefficients $c_n$ to match initial condition $u(x,0) = f(x)$?

**Solution:**

At $t = 0$:
$$f(x) = \sum_{n=1}^{\infty} c_n\sin(n\pi x/L)$$

This is a **Fourier sine series**! Coefficients:
$$c_n = \frac{2}{L}\int_0^L f(x)\sin(n\pi x/L) \, dx$$

**Answer:** Fourier coefficients determined by initial data

### Example 6: Specific Initial Condition

Solve $u_t = ku_{xx}$ with $u(x,0) = \sin(3\pi x/L)$ on $[0, L]$.

**Solution:**

Initial condition is already in form of single Fourier mode ($n = 3$):

All $c_n = 0$ except $c_3 = 1$.

Solution:
$$u(x,t) = e^{-9k\pi^2t/L^2}\sin(3\pi x/L)$$

**Physical interpretation**: Single mode decays exponentially with rate depending on $n^2$ (higher modes decay faster).

**Answer:** $u(x,t) = e^{-9k\pi^2t/L^2}\sin(3\pi x/L)$

## Homogeneous vs. Inhomogeneous Problems

**Homogeneous**: $\mathcal{L}u = 0$ (superposition applies to solutions)

**Inhomogeneous**: $\mathcal{L}u = f$ (superposition applies differently)

### Example 7: Inhomogeneous Superposition

If $u_1$ satisfies $\mathcal{L}u_1 = f_1$ and $u_2$ satisfies $\mathcal{L}u_2 = f_2$, what does $u = u_1 + u_2$ satisfy?

**Solution:**

$$\mathcal{L}(u_1 + u_2) = \mathcal{L}u_1 + \mathcal{L}u_2 = f_1 + f_2$$

**Answer:** $u = u_1 + u_2$ satisfies $\mathcal{L}u = f_1 + f_2$

### Example 8: Particular Plus Homogeneous

General solution to inhomogeneous PDE: $u = u_p + u_h$

where $\mathcal{L}u_p = f$ (particular solution) and $\mathcal{L}u_h = 0$ (homogeneous solution).

Verify this satisfies $\mathcal{L}u = f$.

**Solution:**

$$\mathcal{L}u = \mathcal{L}(u_p + u_h) = \mathcal{L}u_p + \mathcal{L}u_h = f + 0 = f$$ ✓

**Answer:** General solution = particular + homogeneous (like ODEs)

### Example 9: Poisson's Equation

For $\nabla^2 u = x^2 + y^2$ in square with $u = 0$ on boundary:

If $u_p$ is any particular solution satisfying $\nabla^2 u_p = x^2 + y^2$, and $u_h$ satisfies $\nabla^2 u_h = 0$ with appropriate boundary conditions, then $u = u_p + u_h$ is the solution.

Why?

**Solution:**

$$\nabla^2(u_p + u_h) = \nabla^2 u_p + \nabla^2 u_h = (x^2 + y^2) + 0 = x^2 + y^2$$ ✓

Boundary: Choose $u_h$ so that $u_p + u_h = 0$ on boundary.

**Answer:** Decompose into particular (satisfies PDE) + homogeneous (adjusts boundary)

## Wave Equation and Superposition

### Example 10: D'Alembert's Solution

The general solution to $u_{tt} = c^2u_{xx}$ is:

$$u(x,t) = f(x - ct) + g(x + ct)$$

for arbitrary functions $f, g$. This is superposition of two traveling waves.

Verify this is a solution.

**Solution:**

Let $u = f(x - ct) + g(x + ct)$.

$$u_t = -cf'(x-ct) + cg'(x+ct)$$
$$u_{tt} = c^2f''(x-ct) + c^2g''(x+ct)$$

$$u_x = f'(x-ct) + g'(x+ct)$$
$$u_{xx} = f''(x-ct) + g''(x+ct)$$

$$c^2u_{xx} = c^2f''(x-ct) + c^2g''(x+ct) = u_{tt}$$ ✓

**Answer:** Superposition of left-traveling ($f$) and right-traveling ($g$) waves

### Example 11: Standing Waves

For wave equation with fixed ends, solutions include:

$$u_n(x,t) = \sin(n\pi x/L)\cos(n\pi ct/L)$$

These are **standing waves** (normal modes). General solution is superposition:

$$u(x,t) = \sum_{n=1}^{\infty} \left[A_n\cos(n\pi ct/L) + B_n\sin(n\pi ct/L)\right]\sin(n\pi x/L)$$

What determines $A_n$ and $B_n$?

**Solution:**

Initial conditions:
$$u(x,0) = \sum_{n=1}^{\infty} A_n\sin(n\pi x/L)$$

$$u_t(x,0) = \sum_{n=1}^{\infty} B_n \cdot \frac{n\pi c}{L}\sin(n\pi x/L)$$

These are Fourier sine series determined by initial displacement and velocity.

**Answer:** $A_n$ from initial position, $B_n$ from initial velocity

### Example 12: Principle of Linear Combination

If a vibrating string starts with initial displacement $f(x) = \sin(\pi x/L) + 2\sin(3\pi x/L)$ and zero velocity, find the solution.

**Solution:**

Initial displacement already in Fourier form:
- Mode $n=1$: amplitude $A_1 = 1$
- Mode $n=3$: amplitude $A_3 = 2$
- All other $A_n = 0$
- All $B_n = 0$ (zero initial velocity)

Solution:
$$u(x,t) = \sin(\pi x/L)\cos(\pi ct/L) + 2\sin(3\pi x/L)\cos(3\pi ct/L)$$

**Answer:** Superposition of two standing waves with different frequencies

### Example 13: Energy in Modes

For the solution in Example 12, the total energy is sum of energies in each mode. Why?

**Solution:**

Total energy: $E = \int_0^L [u_t^2 + c^2u_x^2] \, dx$

Due to orthogonality of $\sin(n\pi x/L)$:
$$\int_0^L \sin(m\pi x/L)\sin(n\pi x/L) \, dx = 0 \text{ for } m \neq n$$

Cross terms vanish:
$$E = E_1 + E_3$$

(Energy in mode 1) + (energy in mode 3)

**Answer:** Orthogonality → energies add independently (no interference)

## Answer Key

**Problem 1: B**
Superposition requires linearity: $\mathcal{L}(c_1u_1 + c_2u_2) = c_1\mathcal{L}u_1 + c_2\mathcal{L}u_2$
Fails for nonlinear PDEs (e.g., $u_t = uu_x$)
Essential property enabling:
- Fourier series
- Green's functions
- Separation of variables

**Problem 2: A**
Laplacian is linear operator
If $\nabla^2 u_1 = 0$ and $\nabla^2 u_2 = 0$:
$\nabla^2(3u_1 - 2u_2) = 3\nabla^2 u_1 - 2\nabla^2 u_2 = 0$
Any linear combination is harmonic
Infinitely many solutions

**Problem 3: B**
Fourier series: $u = \sum c_n u_n$ (infinite superposition)
Each $u_n$ is a solution
Combine to match initial/boundary conditions
Without superposition, Fourier method fails
Linear PDEs only

**Problem 4: C**
$u = u_p + u_h$ where:
- $u_p$: particular solution ($\mathcal{L}u_p = f$)
- $u_h$: homogeneous solution ($\mathcal{L}u_h = 0$)
Then $\mathcal{L}u = \mathcal{L}u_p + \mathcal{L}u_h = f + 0 = f$ ✓
Same structure as ODEs

**Problem 5: B**
Normal modes: $u_n(x,t) = \phi_n(x)T_n(t)$
Each satisfies PDE and boundary conditions
Superpose with coefficients $c_n$: $u = \sum c_n u_n$
Coefficients determined by initial conditions
Fourier series matches arbitrary initial data

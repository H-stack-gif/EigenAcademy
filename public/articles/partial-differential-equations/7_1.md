# 7.1: Fourier Transform

Introduction to the Fourier transform: definition, basic properties (linearity, scaling, shift), and the convolution theorem — tools used to solve PDEs on infinite domains.

Topics covered:
- Definition and examples of Fourier transforms
- Properties: scaling, translation, and inversion
- Convolution theorem and applications to PDEs

## Practice problem

1) True/False: The Fourier transform turns convolution in x into multiplication in k.

**Answer:** True

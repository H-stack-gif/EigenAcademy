# Partial Differential Equations Topic 8.3: Green's Functions for ODEs

When solving inhomogeneous differential equations like $Ly = f$, we seek the solution as an integral of $f$ against a special function called the **Green's function**. The Green's function $G(x, \xi)$ is the response at $x$ due to a delta function source at $\xi$: it solves $LG = \delta(x - \xi)$. Once we know $G$, the solution to any inhomogeneous problem is $y(x) = \int G(x, \xi)f(\xi) d\xi$. This transforms the differential equation into an integral equation.

Green's functions embody the **principle of superposition**: the response to a general source is the sum (integral) of responses to point sources. They're fundamental to both classical physics (electrostatics, acoustics) and quantum mechanics (propagators). Computing Green's functions requires understanding the delta function, matching conditions at the source point, and satisfying boundary conditions.

This article develops Green's functions for ordinary differential equations systematically. We'll construct Green's functions by direct methods, understand the matching/jump conditions, use eigenfunction expansions, handle different boundary conditions, and see the connection to inverse operators. These techniques extend naturally to PDEs, where Green's functions become even more powerful.

## Delta Function and Green's Function Definition

### Example 1: Delta Function Properties

Dirac delta function $\delta(x - \xi)$:

**Solution:**

**Defining property**:
$$\int_{-\infty}^{\infty} f(x)\delta(x - \xi) dx = f(\xi)$$

**"Function" that samples $f$ at $\xi$**.

**Properties**:
- $\delta(x - \xi) = 0$ for $x \neq \xi$
- $\int \delta(x - \xi) dx = 1$
- $\delta(-x) = \delta(x)$ (even)
- $\delta(ax) = \frac{1}{|a|}\delta(x)$

**Not a function** in classical sense—a distribution/generalized function.

**Physical**: Idealized point source/impulse.

**Answer:** $\int f(x)\delta(x-\xi) dx = f(\xi)$

### Example 2: Green's Function Definition

For operator $L$, Green's function $G(x, \xi)$ satisfies:
$$LG(x, \xi) = \delta(x - \xi)$$

**Solution:**

**Interpretation**: Response at $x$ to unit impulse at $\xi$.

**Solution to $Ly = f$**:
$$y(x) = \int_a^b G(x, \xi)f(\xi) d\xi$$

**Verification**: Apply $L$:
$$Ly = L\int G(x, \xi)f(\xi) d\xi = \int LG(x, \xi)f(\xi) d\xi = \int \delta(x - \xi)f(\xi) d\xi = f(x)$$

**Answer:** $LG = \delta(x-\xi)$; solution $y = \int Gf d\xi$

### Example 3: Simplest Example

Find Green's function for $\frac{d^2G}{dx^2} = \delta(x - \xi)$ on $(-\infty, \infty)$.

**Solution:**


For infinite domain, choose $G \to 0$ as $|x| \to \infty$:
$$G(x, \xi) = -\frac{|x - \xi|}{2} + \text{const}$$

Or conventionally:
$$G(x, \xi) = -\frac{1}{2}|x - \xi|$$

**Answer:** $G(x,\xi) = -\frac{1}{2}|x-\xi|$

## Direct Construction Method

### Example 4: Second-Order ODE with Dirichlet BCs

Find Green's function for $-y'' = f$ on $[0, L]$ with $y(0) = y(L) = 0$.

**Solution:**

**Green's function equation**: $-G_{xx} = \delta(x - \xi)$

**Away from $\xi$**: $G_{xx} = 0$ → $G$ is linear.

$$G(x, \xi) = \begin{cases} A(\xi)x + B(\xi) & 0 \leq x < \xi \\ C(\xi)x + D(\xi) & \xi < x \leq L \end{cases}$$

**Boundary conditions**:
- $G(0, \xi) = 0$: $B = 0$
- $G(L, \xi) = 0$: $CL + D = 0$, so $D = -CL$

**Continuity at $\xi$**: $A\xi = C\xi - CL$

**Jump condition**: $G_x(\xi^+, \xi) - G_x(\xi^-, \xi) = -1$
$$C - A = -1$$

**Solve**: From continuity: $A\xi = C(\xi - L)$

From jump: $C = A - 1$

Substitute: $A\xi = (A-1)(\xi - L) = A\xi - A L - \xi + L$

$$AL + \xi = L$$
$$A = \frac{L - \xi}{L}$$

$$C = A - 1 = \frac{L - \xi}{L} - 1 = -\frac{\xi}{L}$$

$$G(x, \xi) = \begin{cases} \frac{L-\xi}{L}x & x < \xi \\ \frac{\xi}{L}(L - x) & x > \xi \end{cases}$$

**Symmetric**: $G(x, \xi) = G(\xi, x)$ (reciprocity!)

**Answer:** $G(x,\xi) = \begin{cases} (L-\xi)x/L & x < \xi \\ \xi(L-x)/L & x > \xi \end{cases}$

### Example 5: Symmetry of Green's Function

Why is $G(x, \xi) = G(\xi, x)$?

**Solution:**

**General property** for self-adjoint operators.

**Proof**: Let $G_1 = G(x, \xi_1)$ and $G_2 = G(x, \xi_2)$.

$$LG_1 = \delta(x - \xi_1), \quad LG_2 = \delta(x - \xi_2)$$

Multiply first by $G_2$, second by $G_1$, subtract, integrate:
$$\int_a^b [G_2LG_1 - G_1LG_2] dx = G_2(\xi_1) - G_1(\xi_2)$$

For self-adjoint $L$, left side vanishes (Green's identity):
$$G(\xi_2, \xi_1) = G(\xi_1, \xi_2)$$

**Reciprocity**: Response at $x$ from source at $\xi$ equals response at $\xi$ from source at $x$.

**Answer:** Symmetry $G(x,\xi) = G(\xi,x)$ from self-adjointness

### Example 6: Neumann Boundary Conditions

Green's function for $-y'' = f$, $y'(0) = y'(L) = 0$.

**Solution:**

Similar construction:

$$G(x, \xi) = \begin{cases} Ax + B & x < \xi \\ Cx + D & x > \xi \end{cases}$$

**BCs**: $G_x(0) = 0$: $A = 0$

$G_x(L) = 0$: $C = 0$

**Continuity**: $B = D$

**Jump**: $C - A = -1$, so $0 - 0 = -1$ ??? **Contradiction!**

**Issue**: Neumann problem for Poisson equation requires **compatibility condition**:
$$\int_0^L f dx = 0$$

(Integral of source must be zero!)

If compatible, Green's function exists but is **not unique**—defined up to constant.

$$G(x, \xi) = -|x - \xi|/2 + \text{const}$$

**Answer:** Neumann Green's function exists only if $\int f = 0$, non-unique

## Eigenfunction Expansion Method

### Example 7: Green's Function via Eigenfunctions

For Sturm-Liouville $Ly = -y''$, expand Green's function.

**Solution:**

**Eigenfunctions**: $\phi_n$ satisfy $L\phi_n = \lambda_n\phi_n$

**Expand**:
$$G(x, \xi) = \sum_{n=1}^{\infty} c_n(\xi)\phi_n(x)$$

**Apply $L$**:
$$LG = \sum_{n=1}^{\infty} c_n(\xi)\lambda_n\phi_n(x) = \delta(x - \xi)$$

**Expand delta function**:
$$\delta(x - \xi) = \sum_{n=1}^{\infty} \frac{\phi_n(\xi)\phi_n(x)}{\|\phi_n\|^2}$$

(Completeness relation!)

**Match coefficients**:
$$c_n(\xi)\lambda_n = \frac{\phi_n(\xi)}{\|\phi_n\|^2}$$

$$c_n(\xi) = \frac{\phi_n(\xi)}{\lambda_n\|\phi_n\|^2}$$

$$G(x, \xi) = \sum_{n=1}^{\infty} \frac{\phi_n(x)\phi_n(\xi)}{\lambda_n\|\phi_n\|^2}$$

**Answer:** $G(x,\xi) = \sum \frac{\phi_n(x)\phi_n(\xi)}{\lambda_n\|\phi_n\|^2}$

### Example 8: Explicit Example

For $-y'' = f$, $y(0) = y(L) = 0$:

**Solution:**

**Eigenfunctions**: $\phi_n = \sin(n\pi x/L)$

**Eigenvalues**: $\lambda_n = (n\pi/L)^2$

**Norm**: $\|\phi_n\|^2 = L/2$

$$G(x, \xi) = \sum_{n=1}^{\infty} \frac{\sin(n\pi x/L)\sin(n\pi\xi/L)}{(n\pi/L)^2 \cdot L/2}$$

$$= \frac{2L}{\pi^2}\sum_{n=1}^{\infty} \frac{\sin(n\pi x/L)\sin(n\pi\xi/L)}{n^2}$$

**Fourier series representation** of piecewise linear $G$!

**Answer:** $G = \frac{2L}{\pi^2}\sum \frac{\sin(n\pi x/L)\sin(n\pi\xi/L)}{n^2}$

### Example 9: Modified Helmholtz Operator

Green's function for $-y'' + \alpha^2 y = f$ (exponential decay).

**Solution:**

**Fundamental solution** on $(-\infty, \infty)$:

For $-G_{xx} + \alpha^2 G = \delta(x - \xi)$:

Away from $\xi$: $G_{xx} = \alpha^2 G$

$$G = Ae^{\alpha|x-\xi|} + Be^{-\alpha|x-\xi|}$$

Bounded: Choose $B$ form that decays:
$$G(x, \xi) = Ce^{-\alpha|x-\xi|}$$

**Jump condition** at $\xi$: Integrate equation:
$$[-G_x]_{\xi^-}^{\xi^+} + 0 = 1$$

$$-[-C\alpha - C\alpha] = 1$$

$$2C\alpha = 1$$

$$G(x, \xi) = \frac{1}{2\alpha}e^{-\alpha|x-\xi|}$$

**Answer:** $G(x,\xi) = \frac{1}{2\alpha}e^{-\alpha|x-\xi|}$

## Application to Inhomogeneous Problems

### Example 10: Solving with Green's Function

Solve $-y'' = x$ on $[0, 1]$ with $y(0) = y(1) = 0$.

**Solution:**

From Example 4, Green's function:
$$G(x, \xi) = \begin{cases} (1-\xi)x & x < \xi \\ \xi(1-x) & x > \xi \end{cases}$$

**Solution**:
$$y(x) = \int_0^1 G(x, \xi) \cdot \xi \, d\xi$$

$$= \int_0^x \xi(1-\xi)x \, d\xi + \int_x^1 \xi x(1-x) \, d\xi$$

$$= x(1-x)\int_x^1 \xi \, d\xi + x\int_0^x \xi(1-\xi) d\xi$$

After integration (tedious):
$$y(x) = \frac{x(1-x)(1+x)}{6} = \frac{x - x^3}{6}$$

**Check**: $-y'' = -[-6x/6] = x$ ✓

**Answer:** $y(x) = x(1-x^2)/6$

### Example 11: Discontinuous Source

$-y'' = H(x - 1/2)$ (Heaviside) on $[0, 1]$, $y(0) = y(1) = 0$.

**Solution:**

$$y(x) = \int_0^1 G(x, \xi)H(\xi - 1/2) d\xi = \int_{1/2}^1 G(x, \xi) d\xi$$

**For $x < 1/2$**:
$$y(x) = \int_{1/2}^1 (1-\xi)x \, d\xi = x\left[\xi - \frac{\xi^2}{2}\right]_{1/2}^1 = x\left[\frac{1}{2} - \frac{3}{8}\right] = \frac{x}{8}$$

**For $x > 1/2$**:
$$y(x) = \int_{1/2}^x \xi(1-x) d\xi + \int_x^1 (1-\xi)x d\xi$$

(After calculation):
$$y(x) = \frac{1 - x - x^2/2 + x^3/2}{2}$$

**Solution is continuous** but $y''$ has jump at $x = 1/2$.

**Answer:** $y$ is piecewise polynomial with $y''$ discontinuity

### Example 12: Initial Value Problem

Green's function can handle IVPs too: $y'' + y = f(t)$, $y(0) = y_0$, $y'(0) = v_0$.

**Solution:**

**Homogeneous solution**: $y_h = y_0\cos t + v_0\sin t$

**Particular solution**: Use Green's function (causal for $t > 0$):
$$G(t, \tau) = \sin(t - \tau) \quad (t > \tau)$$

$$y_p(t) = \int_0^t \sin(t - \tau)f(\tau) d\tau$$

**Total**:
$$y(t) = y_0\cos t + v_0\sin t + \int_0^t \sin(t - \tau)f(\tau) d\tau$$

**Duhamel's principle** for forced oscillator!

**Answer:** $y = y_h + \int_0^t G(t,\tau)f(\tau) d\tau$

### Example 13: Connection to Inverse Operator

Green's function is integral kernel of $L^{-1}$.

**Solution:**

If $Ly = f$, then $y = L^{-1}f$.

**Explicitly**:
$$y(x) = (L^{-1}f)(x) = \int G(x, \xi)f(\xi) d\xi$$

Green's function $G$ **is** the inverse operator in integral form.

**Matrix analogy**: Solving $Ax = b$ gives $x = A^{-1}b$. Here $G$ is like $A^{-1}$.

**Answer:** $G$ is integral kernel representing $L^{-1}$

## Answer Key

**Problem 1: C**
Definition: $LG(x,\xi) = \delta(x-\xi)$
Response to unit point source at $\xi$
Once found, solve $Ly = f$ via $y = \int Gf d\xi$
Fundamental solution
Transforms differential equation to integral equation

**Problem 2: B**
$G$ continuous at $\xi$: $G(\xi^-) = G(\xi^+)$
Derivative has jump: $G'(\xi^+) - G'(\xi^-) = -1$ (for $-y''$)
Jump magnitude depends on operator
Away from $\xi$: $G$ satisfies homogeneous equation
Matching conditions crucial for construction

**Problem 3: B**
Self-adjoint operators have symmetric Green's functions
$G(x,\xi) = G(\xi,x)$ (reciprocity)
Proved using Green's identities
Physical: response at $x$ from $\xi$ = response at $\xi$ from $x$
Fails for non-self-adjoint operators

**Problem 4: B**
Solution as integral: $y(x) = \int_a^b G(x,\xi)f(\xi) d\xi$
Superposition of point source responses
Check: $Ly = \int LG(x,\xi)f(\xi) d\xi = \int \delta(x-\xi)f(\xi) d\xi = f(x)$ ✓
Integral equation formulation
Alternative to differential equation

**Problem 5: B**
Eigenfunction expansion: $G(x,\xi) = \sum_{n=1}^{\infty} \frac{\phi_n(x)\phi_n(\xi)}{\lambda_n\|\phi_n\|^2}$
From completeness: $\delta(x-\xi) = \sum \phi_n(x)\phi_n(\xi)/\|\phi_n\|^2$
Apply $L$: eigenvalues $\lambda_n$ in denominator
Convergent if $\lambda_n \to \infty$
Alternative to direct construction

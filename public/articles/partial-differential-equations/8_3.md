# 8.3: Eigenfunction Expansions

Using eigenfunction expansions to solve inhomogeneous PDEs: representing source terms and building particular solutions using orthogonal bases.

Topics covered:
- Expansions using Sturm-Liouville eigenfunctions
- Solving inhomogeneous boundary-value problems with eigenseries
- Convergence and truncation considerations

## Practice problem

1) Fill in: When solving an inhomogeneous PDE with homogeneous boundary conditions by eigenfunction expansion, you equate coefficients in the _______ basis. (Answer: eigenfunction)

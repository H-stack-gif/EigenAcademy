# Partial Differential Equations Topic 6.2: Separation of Variables in Rectangles

A rectangular metal plate has edges held at specified temperatures. What is the steady-state temperature inside? This classic problem—**Dirichlet problem on a rectangle**—is solved elegantly by separation of variables. The method produces Fourier series solutions, with eigenfunctions determined by the rectangular geometry. Each boundary condition contributes specific terms, and the superposition gives the complete solution.

Separation of variables works beautifully for Laplace's equation on rectangles because Cartesian coordinates align with the geometry. The product ansatz $u(x,y) = X(x)Y(y)$ converts the PDE into two ODEs, each with boundary conditions from one pair of edges. The resulting eigenfunctions are sines and cosines—the same Fourier basis we've already mastered.

This article develops separation of variables systematically for rectangular domains. We'll solve all four cases (different edges held at nonzero temperature), understand how exponential and hyperbolic functions arise naturally, superpose solutions for multiple nonzero boundaries, and see why the method fails for non-rectangular geometries. These techniques extend directly to Poisson's equation and three-dimensional boxes.

## Standard Dirichlet Problem

### Example 1: Problem Setup

Rectangle $0 \leq x \leq a$, $0 \leq y \leq b$ with boundary conditions:
$$u(0, y) = 0, \quad u(a, y) = 0, \quad u(x, 0) = 0, \quad u(x, b) = f(x)$$

**Solution:**

**PDE**: $u_{xx} + u_{yy} = 0$ inside rectangle

**Physical**: Three edges at temperature 0, top edge at $f(x)$.

**Goal**: Find $u(x,y)$ inside satisfying PDE and all four BCs.

**Answer:** Laplace's equation with three homogeneous, one inhomogeneous BC

### Example 2: Separation Ansatz

Assume $u(x, y) = X(x)Y(y)$.

**Solution:**

Substitute into $u_{xx} + u_{yy} = 0$:
$$X''(x)Y(y) + X(x)Y''(y) = 0$$

Divide by $X(x)Y(y)$:
$$\frac{X''(x)}{X(x)} + \frac{Y''(y)}{Y(y)} = 0$$

$$\frac{X''}{X} = -\frac{Y''}{Y}$$

Left side depends only on $x$, right only on $y$ → both equal constant.

$$\frac{X''}{X} = -\lambda, \quad \frac{Y''}{Y} = \lambda$$

**Answer:** Two ODEs: $X'' + \lambda X = 0$ and $Y'' - \lambda Y = 0$

### Example 3: Boundary Conditions on $X$

From $u(0, y) = X(0)Y(y) = 0$ and $u(a, y) = X(a)Y(y) = 0$:

**Solution:**

Since $Y \not\equiv 0$: $X(0) = 0$ and $X(a) = 0$

**Eigenvalue problem** (same as vibrating string!):
$$X'' + \lambda X = 0, \quad X(0) = 0, \quad X(a) = 0$$

**Eigenvalues**: $\lambda_n = (n\pi/a)^2$, $n = 1, 2, 3, \ldots$

**Eigenfunctions**: $X_n(x) = \sin(n\pi x/a)$

**Answer:** $\lambda_n = (n\pi/a)^2$, $X_n = \sin(n\pi x/a)$

### Example 4: Solutions for $Y$

For each $\lambda_n = (n\pi/a)^2$, solve $Y'' - \lambda_n Y = 0$.

**Solution:**

$$Y'' - \left(\frac{n\pi}{a}\right)^2 Y = 0$$

**General solution**:
$$Y_n(y) = A_n e^{n\pi y/a} + B_n e^{-n\pi y/a}$$

Or equivalently:
$$Y_n(y) = C_n\sinh(n\pi y/a) + D_n\cosh(n\pi y/a)$$

**From $u(x, 0) = 0$**: $Y(0) = 0$

Using sinh/cosh form: $D_n = 0$

$$Y_n(y) = C_n\sinh(n\pi y/a)$$

**Answer:** $Y_n(y) = C_n\sinh(n\pi y/a)$

### Example 5: Product Solutions

Combining $X_n$ and $Y_n$:

**Solution:**

$$u_n(x, y) = \sin(n\pi x/a) \sinh(n\pi y/a)$$

Each $u_n$ satisfies:
- Laplace's equation ✓
- $u(0, y) = 0$ ✓
- $u(a, y) = 0$ ✓
- $u(x, 0) = 0$ ✓

**General solution** (by superposition):
$$u(x, y) = \sum_{n=1}^{\infty} B_n \sin(n\pi x/a) \sinh(n\pi y/a)$$

**Answer:** $u = \sum B_n \sin(n\pi x/a) \sinh(n\pi y/a)$

### Example 6: Matching Top Boundary

Apply $u(x, b) = f(x)$:

**Solution:**

$$\sum_{n=1}^{\infty} B_n \sin(n\pi x/a) \sinh(n\pi b/a) = f(x)$$

This is Fourier sine series for $f(x)$!

$$B_n \sinh(n\pi b/a) = \frac{2}{a}\int_0^a f(x)\sin(n\pi x/a) \, dx$$

$$B_n = \frac{2}{a\sinh(n\pi b/a)}\int_0^a f(x)\sin(n\pi x/a) \, dx$$

**Answer:** $B_n = \frac{2}{a\sinh(n\pi b/a)}\int_0^a f(x)\sin(n\pi x/a) \, dx$

### Example 7: Specific Example

For $f(x) = 1$ on $[0, a]$:

**Solution:**

$$\int_0^a \sin(n\pi x/a) \, dx = \frac{a}{n\pi}[1 - \cos(n\pi)] = \begin{cases} \frac{2a}{n\pi} & n \text{ odd} \\ 0 & n \text{ even} \end{cases}$$

$$B_n = \begin{cases} \frac{4}{n\pi\sinh(n\pi b/a)} & n \text{ odd} \\ 0 & n \text{ even} \end{cases}$$

Solution:
$$u(x,y) = \frac{4}{\pi}\sum_{k=0}^{\infty} \frac{\sin((2k+1)\pi x/a) \sinh((2k+1)\pi y/a)}{(2k+1)\sinh((2k+1)\pi b/a)}$$

**Answer:** Only odd harmonics, coefficients involve $\sinh(n\pi b/a)$

## Other Boundary Configurations

### Example 8: Nonzero Right Edge

Now: $u(0, y) = 0$, $u(a, y) = g(y)$, $u(x, 0) = 0$, $u(x, b) = 0$

**Solution:**

Reverse roles of $x$ and $y$!

Separate: $u = X(x)Y(y)$, but now BCs on $Y$ are homogeneous.

$$Y'' + \lambda Y = 0, \quad Y(0) = 0, \quad Y(b) = 0$$

**Eigenvalues**: $\lambda_m = (m\pi/b)^2$

**Eigenfunctions**: $Y_m = \sin(m\pi y/b)$

For $X$: $X'' - (m\pi/b)^2 X = 0$ with $X(0) = 0$

$$X_m(x) = A_m\sinh(m\pi x/b)$$

**General solution**:
$$u(x, y) = \sum_{m=1}^{\infty} A_m \sinh(m\pi x/b) \sin(m\pi y/b)$$

Match $u(a, y) = g(y)$:
$$A_m = \frac{2}{b\sinh(m\pi a/b)}\int_0^b g(y)\sin(m\pi y/b) \, dy$$

**Answer:** $u = \sum A_m \sinh(m\pi x/b) \sin(m\pi y/b)$

### Example 9: Superposition for Multiple Boundaries

If top edge at $f(x)$ AND right edge at $g(y)$:

**Solution:**

**Linearity**: Solve two separate problems and add!

$$u = u_1 + u_2$$

where:
- $u_1$ solves problem with top = $f(x)$, other edges = 0
- $u_2$ solves problem with right = $g(y)$, other edges = 0

Each satisfies Laplace's equation, and BCs add correctly.

**Answer:** Superpose solutions for each nonzero boundary

### Example 10: All Four Edges Nonzero

Edges: $u(0,y) = h_1(y)$, $u(a,y) = h_2(y)$, $u(x,0) = g_1(x)$, $u(x,b) = g_2(x)$

**Solution:**

Solve four separate problems:
- $u_1$: left edge $h_1$, others zero
- $u_2$: right edge $h_2$, others zero
- $u_3$: bottom edge $g_1$, others zero
- $u_4$: top edge $g_2$, others zero

**Total solution**: $u = u_1 + u_2 + u_3 + u_4$

**Answer:** Superpose four solutions (one per edge)

## Behavior of Solutions

### Example 11: Exponential Decay from Boundary

For solution with top at $f(x) = 1$, how does $u$ behave as $y \to 0$?

**Solution:**

$$u(x, y) \approx \frac{4}{\pi\sinh(\pi b/a)}\sin(\pi x/a)\sinh(\pi y/a)$$
(dominant term, $n = 1$)

For small $y$: $\sinh(\pi y/a) \approx \pi y/a$

$$u(x, y) \approx \frac{4}{\sinh(\pi b/a)}\sin(\pi x/a) \cdot \frac{y}{a}$$

**Linear** growth from bottom edge.

For $y$ near $b$: $\sinh(\pi y/a) \approx \frac{1}{2}e^{\pi y/a}$

Solution approaches boundary value with **exponential** convergence.

**Answer:** Linear growth from zero boundary, exponential approach to nonzero boundary

### Example 12: Influence of Aspect Ratio

Compare tall rectangle ($b \gg a$) vs. wide rectangle ($a \gg b$).

**Solution:**

For tall rectangle: $\sinh(n\pi b/a)$ is very large.

Coefficients $B_n \propto 1/\sinh(n\pi b/a)$ are very small.

**Physical**: Top boundary condition has weak influence at bottom.

**Decay length**: $\sim a/\pi$ (shorter dimension sets scale)

For wide rectangle: boundary influence penetrates entire height.

**Answer:** Influence decays over distance $\sim$ smaller dimension

### Example 13: Symmetry

If $f(x)$ is even about $x = a/2$, what about $u(x, y)$?

**Solution:**

$$f(x) = f(a - x)$$ (even about center)

Only **even** modes contribute (odd $n$ for sine series).

Solution $u(x, y)$ inherits symmetry: $u(x, y) = u(a - x, y)$

**Physical**: Symmetric boundary → symmetric solution.

**Answer:** Symmetric boundaries produce symmetric solutions

## Answer Key

**Problem 1: B**
Separation of variables: $u(x,y) = X(x)Y(y)$
Product form, not sum
Converts PDE to two ODEs
Standard technique for Laplace's equation
Works when geometry aligns with coordinates

**Problem 2: B**
Eigenvalue problem: $X'' + \lambda X = 0$ with $X(0) = X(a) = 0$
Solutions: $X_n = \sin(n\pi x/a)$
Eigenvalues: $\lambda_n = (n\pi/a)^2$
Same as vibrating string modes
Cosines don't satisfy $X(0) = 0$

**Problem 3: E**
For $Y'' - \lambda Y = 0$ with $\lambda > 0$:
General solution: $Y = Ae^{\sqrt{\lambda} y} + Be^{-\sqrt{\lambda} y}$
Equivalently: $Y = C\sinh(\sqrt{\lambda} y) + D\cosh(\sqrt{\lambda} y)$
Both exponential and hyperbolic forms valid
Choice depends on boundary conditions

**Problem 4: B**
Linearity allows superposition
Solve four separate problems (one nonzero edge each)
Add solutions: $u = u_1 + u_2 + u_3 + u_4$
Each piece satisfies Laplace's equation
Boundary conditions add correctly

**Problem 5: C**
Decay length scale: $\sim a$ (shorter dimension)
Tall rectangle: top BC weak at bottom
Wide rectangle: BC penetrates throughout
Physical: heat diffuses distance $\sim$ width
$\sinh(n\pi b/a)$ large when $b \gg a$
